### questions.json 结构

```text
{ "course": 科目名,
  "courseId": "…",
  "chapters": [
    { "name": "第N章 章名",
      "sections": [
        { "name": "第N节 节名",
          "questions": [
            { "subType": 1,          // 1=单选 2=多选 …
              "issue":  "题干",
              "sOption": "A.…|B.…|C.…|D.…",
              "answer":  "D",
              "analysis": "解析",
              "childre": []           // 共享题干子题
            } ] } ] } ] }
```

文件名格式：`NN_第N章 <章名>.md`。

## 每章的结构

```text
# 科目 · 第N章 章名
（本章概述 + 题量分布）

## 第N节 节名
1. 考点一：……
2. 考点二：……

## 易混易错
（按主题分组，把易混概念、数字、正反表述集中对照）
```

## 标注约定

- `⭐` / `⭐⭐`：高频程度，越多越该优先看
- `**加粗**`：核心术语、关键数字、判断方向（如「先税后分」vs「先分后税」）
- 「易混易错」一节按主题分组，列出正确表述与常见干扰项

## 使用建议

1. 先看 `考点/AGENTS.md` 的 ⭐ 列，按高频程度排复习顺序
2. 每章先过「第N节」的考点条目，再重点看「易混易错」
3. 涉及数字的章节（基金基础第2章、私募第7/9章、证券第13章）建议单独整理成卡片
