# 证券投资基金基础知识 · 第10章 投资交易管理

## 第1节 证券市场的交易机制（13题）

**1.（单选题）** （　）在交易中执行投资者的指令。
A.监管人
B.托管人
C.做市商
D.经纪人
**答案：** D
**解析：** 经纪人接受投资者委托，在交易中执行投资者指令。做市商主要是提供买卖双边报价等；监管人负责监督管理；托管人主要负责资产保管等。所以执行投资者指令的是经纪人。答案：D

**2.（单选题）** （　）在交易中执行投资者的指令。
A.监管人
B.托管人
C.做市商
D.经纪人
**答案：** D
**解析：** 经纪人接受客户委托，在交易中执行投资者指令，为买卖双方撮合交易。做市商主要是提供买卖双边报价并按报价与投资者交易；监管人负责监管市场；托管人主要负责资产保管等。所以选经纪人。答案：D

Ⅰ投资者要卖出证券，证券账户上必须有属于投资者支配范围内的足量的可交易证券，这样的交易称为期货交易
Ⅱ保证金交易使投资者能够以较小的资本基础参与超出其自身资金能力的交易
Ⅲ保证金交易也叫杠杆交易
Ⅳ保证金交易中投资者用于投资的自有资金或证券就称为保证金
A.Ⅰ、Ⅱ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅲ、Ⅳ
**答案：** C
**解析：** Ⅰ项：投资者要卖出证券，证券账户上必须有属于投资者支配范围内的足量的可交易证券，这样的交易称为现货交易，并非期货交易，所以Ⅰ错误。 Ⅱ项：保证金交易可以让投资者通过缴纳一定保证金，进行超出自身资金能力的交易，以小博大，该项正确。 Ⅲ项：保证金交易利用保证金撬动更大规模交易，本质就是杠杆交易，该项正确。 Ⅳ项：保证金交易中投资者用于投资的自有资金或证券就是保证金，该项正确。答案：C（Ⅱ、Ⅲ、Ⅳ正确，对应选项C）

## 第2节 交易执行（12题）

**1.（单选题）** （　）根据市场成交量加权均价下单，以降低交易对市场的冲击。
A.成交量加权平均价格算法
B.时间加权平均价格算法
C.跟量算法
D.执行缺口算法
**答案：** A
**解析：** 成交量加权平均价格算法就是根据市场成交量加权均价下单，能降低交易对市场冲击。而时间加权平均价格算法是按时间间隔均匀下单；跟量算法是根据实时市场成交情况调整下单；执行缺口算法旨在最小化执行缺口。所以符合描述的是成交量加权平均价格算法。答案：A

**2.（单选题）** TVOL是指（　）。
A.成交量加权平均价格算法
B.时间加权平均价格算法
C.跟量算法
D.执行缺口算法
**答案：** C
**解析：** TVOL即跟量算法，其核心逻辑是根据市场实时成交量分布来调整订单的执行节奏，使订单执行量与市场成交量占比相匹配，从而减少大额订单对市场价格的冲击、降低交易成本。VWAP为成交量加权平均价格算法（A），TWAP为时间加权平均价格算法（B），执行缺口算法为IS（D），均与TVOL含义不符。本题选C。

**3.（单选题）** 显性成本按照收费主体来划分，不包括（　）。

**4.（单选题）** （　）是投资者在委托买卖证券成交后按成交金额一定比例支付的费用，是证券经纪商为客户提供证券代理买卖服务收取的费用。
A.过户费

**5.（单选题）** 投资者A计划购买100股某上市公司股票，该公司股票价格为20元/股，第一个交易日投资者向经纪人下达限价指令，将目标购买价格定为19.5元，但是本日股票上涨收盘价为20.2元。第二个交易日投资者将目标价格修改为20.5元/股，成交80股，假设每股交易佣金为0.05元，不考虑其他成本，股票收盘价为21元/股。该交易的机会成本为（　）。
A.1.6%
B.1.4%
C.1.2%
D.1.0%
**答案：** D
**解析：** 1. 首先明确机会成本计算原理： 机会成本是指如果投资者没有将资金用于实际投资，而是投资于其他可替代投资所可能获得的收益，这里可理解为未成交部分股票价格变动带来的成本。 投资者计划买100股，第一个交易日没成交，第二个交易日成交80股，那么未成交股数为100 - 80 = 20股。 第一个交易日收盘价20.2元，第二个交易日收盘价21元，每股价格上涨了21 - 20.2 = 0.8元。2. 然后计算机会成本： 未成交20股，每股上涨0.8元，所以机会成本为20×0.8 = 16元。 投资者实际购买80股，成本为(20.5 + 0.05)×80 = 1644元。 机会成本率 = 机会成本÷实际投资金额，即16 ÷ 1644 ≈ 1.0%。答案：D

## 第3节 基金管理人投资交易管理（3题）

**1.（单选题）** 基金公司在交易执行环节可能存在的风险包括（　）。
Ⅰ未践行最佳执行原则，交易效率低或差错率高
Ⅱ交易系统未经严格测试论证，系统缺陷造成交易失误
Ⅲ交易执行独立于基金经理
Ⅳ交易员不能有效履行对基金经理交易指令的监督、复核职责
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** Ⅲ交易执行独立于基金经理本身是合理的风险防控机制，不属于交易执行环节的风险。而Ⅰ未践行最佳执行原则会影响交易效果；Ⅱ交易系统缺陷易致交易失误；Ⅳ交易员不能有效监督复核指令也会引发风险。所以风险包括Ⅰ、Ⅱ、Ⅳ。答案：C

**2.（单选题）** 基金交易过程中的风险主要体现在投资交易过程中的（　）。
Ⅰ合规风险
Ⅱ操作风险
Ⅲ经营风险
Ⅳ利率风险
A.Ⅰ、Ⅲ
B.Ⅱ、Ⅳ
C.Ⅲ、Ⅳ
D.Ⅰ、Ⅱ
**答案：** D
**解析：** 合规风险是基金交易过程中若违反法律法规等规定会面临的风险；操作风险是在投资交易操作环节因人为失误等导致的风险，这两者都属于基金投资交易过程中的风险。 经营风险主要侧重于基金管理公司整体经营层面，并非直接在投资交易过程中；利率风险是市场宏观因素导致，不是投资交易过程特有的风险。答案：D （Ⅰ合规风险、Ⅱ操作风险符合题意）

Ⅲ.违规指令被系统拦截或人工驳回并反馈给基金经理，合规指令分发给交易员
Ⅳ.基金托管人对交易指令的执行结果进行确认
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 交易指令在基金公司内部执行流程主要涉及基金公司内部相关环节。 Ⅰ项，基金经理下达指令是内部执行流程的开始；Ⅱ项，对指令进行合法合规性审核也是内部流程的重要步骤；Ⅲ项，对指令合规与否的处理同样属于基金公司内部针对指令执行的操作。 Ⅳ项，基金托管人对交易指令执行结果确认不属于基金公司内部执行流程，基金托管人是独立于基金公司的机构。答案：A
