# 证券投资基金基础知识 · 第13章 基金的募集、交易与登记

## 第1节 公募基金的募集与认购（16题）

**1.（单选题）** 下列关于基金份额发售的说法，不正确的是（　）。
A.基金份额的发售，由基金管理人负责办理
B.基金管理人应当自收到准予注册文件之日起6个月内进行基金份额的发售
C.基金募集期间募集的资金应存入专门账户
D.募集期限一般不得超过6个月
**答案：** D
**解析：** 基金份额发售由基金管理人负责，A 正确；管理人自收到准予注册文件起 6 个月内发售基金份额，B 正确；募集期间资金要存专门账户，C 正确。而基金募集期限一般不得超过 3 个月，不是 6 个月，D 错误。答案：D

**2.（单选题）** 封闭式基金的网上发售是指通过与（　）的交易系统联网的全国各地的证券营业部，向公众发售基金份额的发行方式。

B.证券交易所
C.基金管理人
D.商业银行
**答案：** B
**解析：** 封闭式基金网上发售是借助证券交易所交易系统，通过各地证券营业部发售基金份额。答案选B 。

**11.（单选题）** 若某投资者投资10万元认购某保本基金，假设该笔认购按照100%比例全部确认，并持有到保本期到期，认购费率为1.0%。假定募集期间产生的利息为50元，基金份额面值为1元，持有期基金累计分红0.08元/基金份额。则认购份额为（　）份。
A.99009.90
B.990.10
C.99059.90
D.100000
**答案：** C
**解析：** 1. 首先计算净认购金额： 净认购金额 = 认购金额÷（1 + 认购费率）。这里认购金额是10万元即100000元，认购费率为1.0%，则净认购金额 = 100000 ÷ (1 + 1.0%) 100000÷(1 + 0.01)=100000÷1.01≈99009.90（元）。2. 然后计算认购份额： 认购份额 =（净认购金额 + 募集期利息）÷基金份额面值。 净认购金额约为99009.90元，募集期间产生利息50元，基金份额面值为1元。 所以认购份额 = (99009.90 + 50)÷1 = 99059.90份。答案选C。

**12.（单选题）** 开放式基金认购份额的计算公式为（　）。
A.认购份额=（净认购金额-认购利息）／净认购金额
B.认购份额=（净认购金额+认购利息）／净认购金额
C.认购份额=（净认购金额-认购利息）／基金份额面值
D.认购份额=（净认购金额+认购利息）／基金份额面值
**答案：** D
**解析：** 开放式基金认购份额的计算，是用净认购金额与认购利息之和除以基金份额面值。因为净认购金额加上因认购资金产生的利息才是投资者实际能用来认购基金的总金额，再除以基金份额面值得到认购份额。答案：D

**13.（单选题）** 某投资者投资3万元认购某开放式基金，认购资金在募集期间产生的利息为5元，其对应的认购费率为1.8％，基金份额面值为1元，则基金净认购金额为（　）元。
A.29469.55
B.28389.45
C.13985.33
D.26934.54
**答案：** A
**解析：** 1. 首先明确净认购金额计算公式：净认购金额 = 认购金额÷（1 + 认购费率）。2. 这里认购金额是30000元，认购费率为1.8% 。3. 代入公式计算：净认购金额 = 30000 ÷ (1 + 1.8%) 先算1 + 1.8% = 1 + 0.018 = 1.018。 再算30000 ÷ 1.018 ≈ 29469.55（元）。答案：A

## 第2节 公募基金的交易、申购和赎回（22题）

**1.（单选题）** LOF在交易所的交易规则与（　）基本相同。
A.股票
B.债券
C.封闭式基金
D.开放式基金
**答案：** C
**解析：** LOF是上市开放式基金，它在交易所交易，其交易规则和封闭式基金基本相同，都是在证券交易所挂牌交易，价格受供求关系影响等。而股票交易机制虽有相似但细节有差异，债券交易规则与LOF差异较大，开放式基金一般不在交易所按此种规则交易。答案：C

**2.（单选题）** 下列关于开放式基金申购和赎回登记及款项支付的说法，正确的是（　）。
A.申购采用部分缴款方式，若资金在规定时间内未全额到账，则申购不成功
B.基金管理人应当在每两个工作日办理基金份额的申购和赎回业务；基金合同另有约定的，按照其约定
C.投资者赎回基金份额成功后，登记机构一般在T+1日为投资者办理扣除权益的登记手续
D.基金管理人最迟于开始对登记办理时间进行调整前2工作日至少一种中国证监会指定的信息披露媒体公告
**答案：** C
**解析：** A项申购一般采用全额缴款，非部分缴款，A错误；B项基金管理人应在每个工作日办理基金份额申购赎回，不是每两个工作日，B错误；C项投资者赎回基金份额成功后，登记机构一般在T + 1日为投资者办理扣除权益的登记手续，C正确；D项基金管理人最迟于开始对登记办理时间进行调整前3个工作日至少一种中国证监会指定的信息披露媒体公告，不是2个工作日，D错误。答案：C

**3.（单选题）** （　）属于股票基金、债券基金、货币市场基金三者共同遵守的申购和赎回原则。
A.未知价交易原则
B.确定价原则
C.金额申购、份额赎回原则
D.份额申购、金额赎回原则
**答案：** C
**解析：** 股票基金、债券基金遵循未知价交易原则和金额申购、份额赎回原则；货币市场基金遵循确定价原则和金额申购、份额赎回原则。所以三者共同遵守的是金额申购、份额赎回原则。答案：C

**4.（单选题）** 开放式基金申购采用（　）方式。若资金在规定时间内未（　）到账，则申购不成功。
A.全额缴款；全额
B.部分缴款；全额
C.全额缴款；半数
D.部分缴款；半数
**答案：** A
**解析：** 开放式基金申购采用全额缴款方式，只有当资金全额到账，申购才会成功，若未全额到账则申购不成功。答案：A

**5.（单选题）** 证券交易所在开市后根据ETF基金份额申购、赎回清单和组合证券内各只证券的实时成交数据，计算并每（　）发布一次基金份额参考净值（IOPV），供投资者交易、申购、赎回基金份额时参考。
A.1分钟
B.隔几秒
C.5分钟
D.15分钟
**答案：** B
**解析：** 证券交易所通常是每15秒计算并发布一次ETF基金份额参考净值（IOPV），最接近的选项表述是隔几秒。答案：B

**6.（单选题）** 基金管理人可以从开放式基金财产中计提一定比例的（　），用于基金的持续销售和给基金份额持有人提供服务。
A.申购费
B.赎回费
C.信息披露费
D.销售服务费
**答案：** D
**解析：** 销售服务费是基金管理人用于基金的持续销售和给基金份额持有人提供服务而从基金财产中计提的费用。申购费是投资者购买基金时支付的费用；赎回费是投资者卖出基金时支付的费用；信息披露费是用于信息披露相关支出。答案：D

**7.（单选题）** ETF建仓期通常不超过（　）。
A.1个月
B.3个月
C.6个月
D.12个月
**答案：** B
**解析：** ETF在基金合同生效后需要按基金合同约定的投资比例买入标的指数成份股构建投资组合，这一建仓期通常不超过3个月；建仓完成后即可申请在上海或深圳证券交易所上市交易，建仓期内基金份额净值随组合构建进度波动。本题选B。

**8.（单选题）** 基金认购与基金申购略有不同，其区别一般不包括（　）。
A.认购费率一般低于申购费率
B.认购是按确定价进行认购，而申购通常是按未知价确认
C.认购份额要在基金合同生效时确认，并且有封闭期
D.申购份额通常在T+1日之内确认
**答案：** D
**解析：** 基金认购和申购存在多方面区别。认购费率常低于申购费率，A 选项是区别之一；认购时基金价格相对固定，按确定价认购，申购是按申购当日基金份额净值这一未知价确认，B 选项是区别之一；认购份额在基金合同生效时确认，之后可能有封闭期，C 选项是区别之一。而申购份额一般在 T + 2 日之内确认，不是 T + 1 日之内，D 选项描述错误且这不是两者的正常区别。答案：D

**10.（单选题）** 下列关于ETF份额申购和赎回原则，说法错误的是（　）。

**13.（单选题）** 下列关于开放式基金申购和赎回原则的说法，错误的是（　）。

**16.（单选题）** 某投资人投资10000申购某基金，申购费率为1.5％，假定申购当日基金份额净值为1.05元，则其可得到的申购份额为（　）份。

B.9383.06
C.9350.95
D.9280.95
**答案：** B
**解析：** 1. 首先计算净申购金额： 净申购金额 = 申购金额÷（1 + 申购费率）。 这里申购金额是10000元，申购费率为1.5%，即0.015。 净申购金额 = 10000 ÷ (1 + 0.015) = 10000 ÷ 1.015 ≈ 9852.22（元）。2. 然后计算申购份额： 申购份额 = 净申购金额÷申购当日基金份额净值。 申购当日基金份额净值为1.05元。 申购份额 = 9852.22 ÷ 1.05 ≈ 9383.06（份）。答案：B

**2.（单选题）** 下列关于基金登记的说法错误的是（　）。
A.基金份额登记具有确定和变更基金份额持有人及其权利的法律效力
B.我国开放式基金的登记业务只能由基金管理人办理
C.建立并管理投资者基金份额账户是基金注册登记机构的主要职责之一

**答案：** B
**解析：** 我国开放式基金登记业务可以由基金管理人办理，也可以委托中国证监会认定的其他机构办理，B 选项说只能由基金管理人办理错误。A 选项，份额登记确实有确定和变更持有人及权利的效力；C 选项，注册登记机构职责包含管理投资者基金份额账户；D 选项，不同基金品种份额登记时间不同符合实际情况。答案：B

A.具有确定基金份额持有人及其权利的法律效力
B.具有变更基金份额持有人及其权利的法律效力
C.是保障基金管理人合法权益的重要环节
D.是确认基金份额持有人持有基金份额的事实的行为
**答案：** C
**解析：** 基金份额登记是确认基金份额持有人持有基金份额的事实的行为，具有确定和变更基金份额持有人及其权利的法律效力，是保障基金份额持有人合法权益的重要环节，而不是保障基金管理人合法权益。所以C说法错误。答案：C

**4.（单选题）** 关于基金申购和赎回的资金结算，下列说法错误的是（　）。
A.资金结算分清算和交收两个环节
