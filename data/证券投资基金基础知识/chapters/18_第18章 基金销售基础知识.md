# 证券投资基金基础知识 · 第18章 基金销售基础知识

## 第1节 基金投资者（13题）

**1.（单选题）** 若没有预期的变现需求，投资者可以适当____流动性要求，以____投资的预期收益率。（　）
A.降低；提高
B.提高；提高
C.提高；降低
D.降低；降低
**答案：** A
**解析：** 如果没有预期变现需求，对资金快速变现的要求就不高，即可以降低流动性要求。而降低流动性要求后，可选择的投资产品范围更广，一些流动性差但预期收益率高的产品也能投资，所以能提高投资的预期收益率。答案：A

**2.（单选题）** 保险公司可分为财险公司与（　）。
A.寿险公司
B.意外保险公司
C.直接保险公司
D.健康保险公司
**答案：** A
**解析：** 在保险行业分类中，常见的是将保险公司分为财险公司和寿险公司，这是基于保险标的等因素的主要分类方式。意外保险、健康保险常是寿险公司经营的险种类别，直接保险公司并非与财险公司相对应的分类。答案：A。

**3.（单选题）** 在较长的时间内，市场行情总体向好的概率要（　）走低的概率。
A.大于
B.小于
C.等于
D.无关
**答案：** A
**解析：** 通常从经济发展规律来看，随着社会进步、生产力提升等因素，从较长时间跨度而言，市场整体有向上发展的趋势，向好概率大于走低概率。所以答案选A。

**4.（单选题）** 下列关于社会保障基金说法错误的是（　）。
A.全国社会保障基金于2005年8月设立
B.是国家社会保障储备基金
C.由全国社会保障基金理事会（简称社保基金会）负责管理运营
D.社会保障资金的投资运作受到严格的制度约束
**答案：** A
**解析：** 全国社会保障基金于2000 年8 月设立，A 选项中说2005 年设立错误。B、C、D 关于社保基金性质、管理运营及投资约束描述正确。答案：A

**5.（单选题）** 下列关于保险公司的说法错误的是（　）。
A.保险公司通过销售保单募集大量保费
B.财险公司通常将保费投资于低风险资产
C.寿险公司通常将保费投资于低风险资产
D.保险公司分为财险公司与寿险公司两种类型
**答案：** C
**解析：** 寿险公司的保险金支付具有较长的时间跨度，通常将保费投资于能够提供长期稳定收益的资产，比如一些风险相对较高但收益也可能较高的资产，并非仅投资于低风险资产。而财险公司因理赔的不确定性和及时性要求，通常将保费投资于低风险资产。选项A，保险公司确实通过销售保单募集大量保费；选项D，保险公司常见分为财险公司与寿险公司两种类型。答案：C

**6.（单选题）** 投资目标取决于（　）
A.风险容忍度
B.收益目标
C.风险容忍度和收益目标
D.投资风险
**答案：** C
**解析：** 投资目标的确立需要综合考虑投资者对风险的承受能力即风险容忍度，以及期望获得的收益水平即收益目标。二者共同作用来明确投资目标。答案：C

**7.（单选题）** 投资者的（　）取决于投资者的风险承受能力和风险承受意愿。
A.风险容忍度
B.投资期限
C.收益要求
D.流动性需求
**答案：** A
**解析：** 风险容忍度是指投资者能够接受的最大损失，它由投资者的风险承受能力（如财务状况等客观因素决定的承受损失能力）和风险承受意愿（主观上愿意承担风险的倾向）共同决定。投资期限主要与投资者目标等有关；收益要求基于投资者预期等；流动性需求关乎资产变现难易等，均与题干所强调因素关系不大。答案：A

**8.（单选题）** 风险承受能力最低的投资者是指（　）中含风险承受能力最低类别。
A.C1
B.C2
C.C3
D.C4
**答案：** A
**解析：** 在投资者风险承受能力分类中，C1是风险承受能力最低类别。答案：A

**9.（单选题）** 普通投资者为专业投资者之外的投资者，具有特别保护。下列选项中，不属于普通投资者特别保护内容的是（　）。
A.信息告知
B.适当性匹配
C.政策红利
D.风险警示
**答案：** C
**解析：** 对普通投资者的特别保护主要体现在信息告知、适当性匹配、风险警示等方面，这些都是为了保障普通投资者在投资过程中的权益，因为普通投资者相比专业投资者在信息、专业知识等方面处于劣势。而政策红利通常不是针对普通投资者特别保护的特定内容，它更多是宏观层面政策给予的优惠等，不具有与普通投资者保护直接的紧密联系。答案：C

**10.（单选题）** 下列属于专业投资者的是（　）。
Ⅰ.经有关金融监管部门批准设立的金融机构

Ⅲ.QFII
Ⅳ.RQFII

**11.（单选题）** （　）即基金份额的持有人，是基金资产所有者和基金投资盈亏的承担者。
A.基金托管人
B.基金管理人
C.基金投资者

**12.（单选题）** 根据相关规定，下列属于合格投资者的是（　）。

Ⅳ.乙公司最近1年末净资产1200万元
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅳ
C.Ⅱ、Ⅲ

## 第2节 基金销售机构、策略和业务规范（4题）

**1.（单选题）** 基金销售机构的销售策略不包括（　）。
A.产品策略
B.价格策略
C.数量策略
D.营销策略
**答案：** C
**解析：** 基金销售机构常见销售策略有产品、价格、渠道、促销策略等，数量策略并非基金销售机构常规销售策略。答案：C

**2.（单选题）** 关于基金管理人直销的特点，下列表述正确的是（　）。
Ⅰ.成本较低
Ⅱ.投资者关系紧密
Ⅲ.信息透明度高
Ⅳ.销售渠道广泛
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 基金管理人直销是指基金管理人直接向投资者销售基金产品。 直销没有中间代销环节，所以成本较低，Ⅰ正确；直接面对投资者，能与投资者建立紧密关系，Ⅱ正确；由于直接沟通，信息传递更直接，透明度高，Ⅲ正确。而直销相比代销等方式，销售渠道相对单一，并非广泛，Ⅳ错误。答案：A

**3.（单选题）** 根据支付时点的不同，参与费用一般分为（　）等类。
A.前端参与费用、中期参与费用、后端参与费用
B.前端参与费用、后端参与费用、销售服务费用
C.申购参与费用、赎回参与费用、销售服务费用
D.前端参与费用、赎回参与费用、后端参与费用
**答案：** B
**解析：** 参与费用是投资者在参与基金等金融产品过程中支付的费用，根据支付时点不同分类如下：前端参与费用是投资者在购买产品时直接支付的费用；后端参与费用则是在投资者赎回产品时才支付，通常持有时间越长费率越低；销售服务费用（如 “尾随佣金”）是按持有期限分期支付，用于支付销售渠道的服务成本，属于按支付时点划分的费用类型。选项 A 中 “中期参与费用” 并非行业标准分类；选项 C 的 “申购、赎回参与费用” 主要按交易行为划分，而非支付时点；选项 D 的 “赎回参与费用” 是与赎回行为相关的费用，不属于按支付时点对 “参与费用” 的分类。综上，根据支付时点不同，参与费用分为前端参与费用、后端参与费用、销售服务费用，答案选 B。

**4.（单选题）** 某基金销售人员在向投资者推介基金产品时，下列做法符合行为规范要求的是（　）。
A.为促成交易，承诺该基金产品未来年化收益不低于10%
B.私下向好友透露某未公开的基金投资标的信息，建议其提前申购
C.因与某大客户关系密切，在基金份额发售时优先为其预留额度
D.主动向投资者出示工作证件以明示身份，并详细揭示产品风险
**答案：** D
**解析：** A选项承诺收益不符合规定；B选项泄露未公开信息违规；C选项优先预留额度不公平对待投资者违规。D选项主动出示证件并揭示风险是符合行为规范要求的。答案：D

## 第3节 投资者服务（8题）

**1.（单选题）** （　）是对投资产品和服务做出选择的行为或过程，是整个投资者教育体系的基础。
A.市场参与教育
B.资产管理教育
C.知识普及教育
D.投资决策教育
**答案：** D
**解析：** 投资决策教育就是要指导投资者对投资产品和服务做出选择，它是投资者教育体系基础。市场参与教育、资产管理教育、知识普及教育与对投资产品和服务做选择的关联性不如投资决策教育直接。答案：D

**2.（单选题）** （　）要求在销售基金产品或者服务的过程中，应根据投资者的风险承受能力销售不同风险等级的基金产品或者服务，把合适的基金产品或者服务销售给合适的投资者。
A.适当性管理原则
B.专业规范原则
C.投资者利益优先原则
D.有效沟通原则
**答案：** A
**解析：** 题干描述的是要将合适产品卖给合适投资者，这正是适当性管理原则的核心内容。专业规范强调业务的专业性和规范性；投资者利益优先突出以投资者利益为重；有效沟通侧重与投资者的沟通交流。均与题干表述不符。答案：A

**3.（单选题）** 综合当前投资者教育的理论和实践，投资者教育主要包含（　）。
Ⅰ.心理素质教育
Ⅱ.投资决策教育
Ⅲ.资产配置教育
Ⅳ.权益保护教育
A.Ⅰ、Ⅱ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅲ、Ⅳ
**答案：** C
**解析：** 投资者教育主要包含投资决策教育、资产配置教育、权益保护教育，心理素质教育并非投资者教育主要内容。答案：C

**4.（单选题）** 基金投资者服务的原则包括（　）。
Ⅰ、投资者利益优先原则
Ⅱ、安全第一原则
Ⅲ、专业规范原则
Ⅳ、依法监管原则
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 基金投资者服务原则主要围绕投资者权益保障、运营安全及专业规范展开。投资者利益优先原则是核心，要把投资者利益放在首位；安全第一原则确保投资者资产等安全；专业规范原则保证服务的专业性和规范性。 而依法监管原则主要是监管机构遵循的，并非基金投资者服务的原则。答案：A（Ⅰ、Ⅱ、Ⅲ）

**5.（单选题）** （　）不属于具体的基金投资者服务流程。
A.投资咨询与基金咨询
B.投资跟踪与评价
C.受理投诉
D.公开投资者档案
**答案：** D
**解析：** 公开投资者档案涉及投资者隐私，不能随意公开，这并非正常的基金投资者服务流程内容。而投资咨询与基金咨询、投资跟踪与评价、受理投诉都是常见的为投资者服务的环节。答案：D

**6.（单选题）** 投资者服务人员都应站在投资者的角度，理解投资者，不能臆测投资者需求。这体现了基金投资者服务的（　）原则。
A.适当性管理
B.有效沟通
C.安全第一
D.专业规范
**答案：** B
**解析：** 站在投资者角度理解投资者、不臆测需求，强调的是要与投资者有良好、有效的沟通交流，才能真正明白投资者想法。A选项适当性管理主要针对匹配投资者与产品；C选项安全第一侧重于保障资产等安全；D选项专业规范强调服务要符合专业标准规范。均与题意不符。答案选B有效沟通。

**7.（单选题）** 以下针对“一对一”专人服务的表述中错误的一项是（　）。
A.主要针对投资额较大的个人投资者与机构投资者
B.基金销售者每次安排最优秀的投资顾问，但不固定
C.从基金销售开始就“一对一”服务
D.这种服务方式贯穿整个销售过程
**答案：** B
**解析：** “一对一”专人服务会安排固定的投资顾问为客户服务，而不是每次安排最优秀但不固定的投资顾问。答案：B

**8.（单选题）** 关于国际证监会组织为投资者保护工作设定的六个基本原则，以下说法正确的有（　）。
Ⅰ.投资者教育应有助于监管者保护投资者
Ⅱ.证券经营机构应当将投资者教育纳入各业务环节
Ⅲ.投资者教育有一个固定的模式
Ⅳ.投资者教育不能也不应等同于投资咨询
Ⅴ.投资者教育不应被视为是对市场参与者监管工作的替代
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ
B.Ⅱ、Ⅲ、Ⅳ、Ⅴ
C.Ⅰ、Ⅱ、Ⅳ、Ⅴ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 投资者教育有助于监管者保护投资者，Ⅰ正确；证券经营机构应将投资者教育融入各业务环节，Ⅱ正确；投资者教育没有固定模式，Ⅲ错误；投资者教育和投资咨询不同，Ⅳ正确；投资者教育不能替代对市场参与者的监管工作，Ⅴ正确。答案：C
