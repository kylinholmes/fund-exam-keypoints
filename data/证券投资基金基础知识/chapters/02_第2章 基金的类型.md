# 证券投资基金基础知识 · 第2章 基金的类型

## 第1节 证券投资基金分类概述（11题）

**1.（单选题）** 管理人中管理人产品需委托两个或者两个以上符合条件的第三方资产管理机构就资产管理产品的部分或者全部资产提供（　）。
A.资金支持
B.投资建议
C.托管服务
D.销售服务
**答案：** B
**解析：** 管理人中管理人产品是委托符合条件第三方资产管理机构提供投资建议。资金支持、托管服务、销售服务不符合其业务实质。答案：B

**2.（单选题）** 非公开募集基金的合格投资者累计人数上限为（　）。
A.100人
B.200人
C.300人
D.500人
**答案：** B
**解析：** 根据相关规定，非公开募集基金合格投资者累计不得超过200人。答案：B

**3.（单选题）** 混合基金的特征是（　）。
A.80%以上资产投资于股票
B.资产配置比例不符合股票基金、债券基金等标准
C.仅投资于货币市场工具
D.80%以上资产投资于基金份额
**答案：** B
**解析：** A选项是股票基金特征；C选项是货币基金特征；D选项一般是基金中基金特征。而混合基金是资产配置比例不符合股票基金、债券基金等标准的基金。答案：B

**4.（单选题）** 按照中国证监会分类标准，某基金资产60%投资于债券，30%投资于股票，该基金应归类为（　）。
A.债券基金
B.股票基金
C.混合基金
D.货币市场基金
**答案：** C
**解析：** 根据规定，60%以上的基金资产投资于股票的，为股票基金；80%以上的基金资产投资于债券的，为债券基金；仅投资于货币市场工具的，为货币市场基金。而该基金既投资债券又投资股票，且不符合上述股票基金、债券基金、货币市场基金的资产配置比例界定，所以属于混合基金。答案：C

**5.（单选题）** 下列选项中属于商品基金的是（　）。
A.黄金ETF和黄金期货
B.黄金ETF和商品期货基金
C.黄金期货和商品期货基金
D.黄金ETF、黄金期货和商品期货基金
**答案：** B
**解析：** 商品基金是以商品现货或者期货等为投资对象的基金。黄金ETF是一种以黄金为基础资产，追踪现货黄金价格波动的金融衍生产品，属于商品基金范畴；商品期货基金是以期货合约为主要投资对象的基金，也属于商品基金；而黄金期货只是一种期货合约，并非基金。答案：B

**6.（单选题）** ETF属于（　）。
A.避险策略基金
B.主动型基金
C.基金中的基金
D.指数基金
**答案：** D
**解析：** ETF即交易型开放式指数基金，本质是追踪特定指数，紧密复制指数表现，属于指数基金。答案选D。

**7.（单选题）** 对基金研究评价机构而言，（　）是进行基金评级的基础。
A.基金的管理人
B.基金的份额
C.基金的分类
D.基金的收益
**答案：** C
**解析：** 基金分类是进行基金评级的基础，只有先对基金合理分类，才能在同类基金中进行科学比较与评价。答案：C

**8.（单选题）** 对证券投资基金分类有助于（　）。
Ⅰ.投资者对各种基金风险收益特征的把握
Ⅱ.完善不同风险收益特征的产品布局
Ⅲ.基金研究评价机构进行基金评级
Ⅳ.监管部门实施分类监管
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 对证券投资基金分类，能让投资者清晰知晓不同基金风险收益特征，便于把握选择，Ⅰ正确；有助于基金公司完善不同风险收益特征产品布局，Ⅱ正确；方便基金研究评价机构依据分类进行评级，Ⅲ正确；也利于监管部门针对不同类别基金实施分类监管，Ⅳ正确。答案：D。

**9.（单选题）** 力图取得超越基准组合表现的基金是（　）。
A.主动型基金
B.被动型基金
C.公开募集基金
D.非公开募集基金
**答案：** A
**解析：** 主动型基金是通过积极的投资策略，力图超越基准组合表现；被动型基金是复制指数，一般试图与指数表现一致。公开募集基金和非公开募集基金是按募集方式分类，与是否力图超越基准组合表现无关。答案：A。

**10.（单选题）** 证券投资基金按募集方式的不同，分为（　）。
A.公开募集基金和非公开募集基金
B.主动型基金与被动型基金
C.封闭式和开放式
D.股票基金和债券基金
**答案：** A
**解析：** 题目问按募集方式不同的分类，A选项公开募集基金和非公开募集基金是按照募集方式划分的；B选项是按投资理念划分；C选项是按运作方式划分；D选项是按投资对象划分。答案：A

**11.（单选题）** 从基金的资金来源和用途划分，证券投资基金可分为（　）。
A.公募基金和私募基金
B.开放式基金和封闭式基金
C.在岸基金、离岸基金和国际基金
D.上市基金与非上市基金
**答案：** C
**解析：** 从资金来源和用途划分，证券投资基金分为在岸基金、离岸基金和国际基金：在岸基金是本国募集资金并投资于本国市场；离岸基金是一国基金组织在他国发售基金份额并将募集资金投资于本国或第三国市场；国际基金是资本来源于国内、并投资于国外市场的证券投资基金。原解析中"国际基金是资金来源和运用都在国外"的表述有误（资金来源和运用均在国外的表述与离岸基金更接近），按教材口径国际基金资金来源在国内、投资于国外。本题分类正确，答案仍选C。

## 第2节 股票基金（7题）

**1.（单选题）** 股票基金提供的长期投资增值性可用于满足（　）等远期支出需要。
A.短期旅游支出
B.教育支出、退休支出
C.日常购物支出
D.应急医疗支出
**答案：** B
**解析：** 股票基金是长期投资工具，适合用于远期支出规划。A选项短期旅游支出是近期需求；C选项日常购物支出是日常消费需求；D选项应急医疗支出强调应急，通常需要流动性强的储备，而非长期投资的股票基金。B选项教育支出、退休支出是远期的大额支出，符合股票基金用于长期规划的特点。答案：B

**2.（单选题）** 投资者投资股票基金时，无需主要关注的因素是（　）。
A.基金的投资策略
B.基金的投资风格
C.基金的长期业绩
D.基金的短期净值波动
**答案：** D
**解析：** 股票基金投资是较长期行为，投资策略、投资风格影响其长期表现，长期业绩可反映基金运作成效。而短期净值波动在股票基金投资中相对不重要，不应过度关注短期波动而频繁买卖。答案：D。

**3.（单选题）** 基金份额净值合理性无法判断的原因是（　）。
A.数据不透明
B.由持有证券价格复合形成
C.计算标准不一致
D.受政策调控
**答案：** B
**解析：** 基金份额净值是由其持有证券价格经过一系列计算复合形成，证券价格处于动态变化中且组合复杂，这使得其合理性难以简单判断。答案选B 。

**4.（单选题）** 同时投资于价值型股票与成长型股票的基金被称为（　）。
A.混合型基金
B.平衡型基金
C.稳定型基金
D.封闭式基金
**答案：** B
**解析：** 平衡型基金通常会同时投资于价值型股票和成长型股票，追求资产在两者间合理配置以平衡风险和收益。混合型基金概念更宽泛；稳定型基金不是这种分类称呼；封闭式基金是按运作方式分类，与投资股票类型无关。答案：B

**5.（单选题）** 关于股票基金的特点，以下表述错误的是（　）。
A.风险较高，但预期收益也较高
B.以追求长期的资本增值为目标
C.应对通货膨胀有效的手段
D.适合短期波段操作，通过买卖价差盈利
**答案：** D
**解析：** 股票基金以追求长期资本增值为目标，风险较高预期收益也高，且在通货膨胀时，股票价格可能上升，是应对通胀有效手段。而它不适合短期波段操作盈利，因为其净值波动非短期内能精准把握，频繁买卖还会增加成本。答案：D

**6.（单选题）** 下列关于价值型股票与成长型股票的表述中，错误的是（　）。
A.价值型股票通常是指模式成熟、增长稳定的上市公司股票
B.成长型股票通常是指未来收入增长较快、发展潜力大的上市公司股票
C.价值型股票的市盈率、市净率通常较高
D.价值型股票与成长型股票的分类依据为股票性质的不同
**答案：** C
**解析：** 价值型股票一般是业绩稳定、股息丰厚的成熟企业股票，其市盈率、市净率通常较低，因为这类企业增长相对稳定，市场预期的估值不会过高；而成长型股票未来发展潜力大，市场对其预期高，市盈率、市净率通常较高。 A选项对价值型股票特点表述正确；B选项对成长型股票特点表述正确；D选项股票按性质分为价值型和成长型表述正确。答案：C

**7.（单选题）** 按股票市值的大小分类的股票类型不包括（　）。
A.大盘股
B.小盘股
C.中盘股
D.蓝筹股
**答案：** D
**解析：** 大盘股、小盘股、中盘股是按照股票市值大小分类的；而蓝筹股是指长期稳定增长的、大型的、传统工业股及金融股等，并非按市值大小分类。答案：D

## 第3节 债券基金（7题）

**1.（单选题）** 对于债券基金，投资者需主要关注基金的（　）。
A.基金经理的投资经验
B.基金的平均持仓久期、杠杆率、基金所持债券信用等级
C.基金的销售渠道
D.基金的宣传推广力度
**答案：** B
**解析：** 债券基金收益与债券相关，平均持仓久期影响利率风险，杠杆率影响风险与收益，债券信用等级关乎违约风险等，这些都是投资者关注债券基金的关键因素。而基金经理投资经验并非债券基金特有关注点；销售渠道和宣传推广力度对投资收益影响不大。答案：B

**2.（单选题）** 投资者通常认为债券基金是（　）的投资工具。
A.高收益、高风险
B.收益稳定、中低风险
C.收益波动大、高风险
D.收益极低、低风险
**答案：** B
**解析：** 债券具有收益相对稳定、风险较低的特点，债券基金主要投资于债券，所以投资者通常认为债券基金收益稳定、风险处于中低水平。答案：B

**3.（单选题）** 以下关于债券基金和债券区别的说法中，错误的是（　）。
A.单一债券随着到期日的临近，所承担的利率风险会上升
B.债券基金没有固定的到期日，所承担的利率风险将取决于所持有的债券的平均到期日
C.单一债券的信用风险比较集中
D.债券基金的平均到期日常常会相对固定
**答案：** A
**解析：** 对于A选项，单一债券随着到期日临近，利率风险会下降，而不是上升，因为剩余期限越短，受利率波动影响越小。 B选项，债券基金没有固定到期日，利率风险取决于债券平均到期日，表述正确。 C选项，单一债券信用风险集中在单个发行人，表述正确。 D选项，债券基金投资多种债券，平均到期日常常相对固定，表述正确。答案：A

**4.（单选题）** 仅能投资于固定收益类金融工具，不能投资于股票市场的是（　）。
A.一级债基
B.二级债基
C.标准债券型基金
D.普通债券型基金
**答案：** C
**解析：** 标准债券型基金仅投资于固定收益类金融工具，不能投资股票市场。 一级债基可参与一级市场新股申购等权益类投资。 二级债基不仅可参与一级市场新股申购，还能在二级市场买卖股票。 普通债券型基金包括一级债基和二级债基，都有权益类投资。答案：C

**5.（单选题）** 普通债券基金常被称为（　），以投资固定收益类金融工具为主，也可以投资股票等权益类资产和可转换债券、可交换债券等金融工具。
A.一级债基
B.二级债基
C.纯债基金
D.可转债基金
**答案：** B
**解析：** 普通债券基金主要投资于固定收益类金融工具，但也可以投资股票等权益类资产以及可转换债券、可交换债券等。根据这个描述，我们可以排除纯债基金（C选项），因为它不投资股票等权益类资产。一级债基（A选项）通常是指只投资于债券的基金，不涉及股票等权益类资产的投资，因此也可以排除。可转债基金（D选项）主要投资于可转换债券，虽然也投资于债券，但其重点在于可转债，与题目描述的普通债券基金不完全吻合。二级债基（B选项）是指除了投资债券外，还可以投资股票等权益类资产的债券基金，这与题目描述的普通债券基金的投资范围相符。因此，正确答案是B.二级债基。

**6.（单选题）** 单一债券随着到期日的临近，所承担的利率风险会（　）。
A.上升
B.下降
C.保持不变
D.不确定
**答案：** B
**解析：** 利率风险是指由于市场利率变动引起债券价格波动的风险。随着债券到期日临近，债券价格受市场利率波动的影响会逐渐减小，因为距离到期日越近，债券的未来现金流越确定，所以利率风险下降。答案：B

**7.（单选题）** 关于债券和债券基金信用风险，说法正确的是（　）
A.单一债券信用风险集中
B.债券基金信用风险更高
C.两者信用风险程度相同
D.债券基金无法分散风险
**答案：** A
**解析：** 单一债券若发行主体信用出现问题，风险集中；债券基金投资多种债券，能分散部分信用风险，通常比单一债券信用风险低。答案：A

## 第4节 货币市场基金（6题）

**1.（单选题）** 《货币市场基金管理暂行规定》规定货币市场基金不能投资的金融工具包括（　）。
　Ⅰ.股票
　Ⅱ.可转换债券
　Ⅲ.剩余期限在397天以内（含397天）的债券
　Ⅳ.信用等级在AA+级以下的债券
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 货币市场基金主要投资短期货币工具，股票风险较高不适合，可转换债券兼具股性，也不合适，信用等级低的债券风险大，货币市场基金一般不投。而剩余期限在397天以内（含397天）的债券是货币市场基金可投资的。所以不能投资的是Ⅰ股票、Ⅱ可转换债券、Ⅳ信用等级在AA+级以下的债券。答案：B

**2.（单选题）** 场内货币基金可以分为申赎型、（　）。
A.单一型
B.普通型
C.创新型
D.交易型
**答案：** D
**解析：** 场内货币基金常见分类是申赎型和交易型。其他选项单一型、普通型、创新型并非场内货币基金这种对应分类表述。答案：D

**3.（单选题）** 货币市场基金以（　）为投资对象。
A.股票
B.债券
C.货币市场工具
D.金融衍生工具
**答案：** C
**解析：** 货币市场基金主要投资于货币市场工具，这是其定义决定的。股票是股票型基金投资对象，债券是债券型基金重要投资对象，金融衍生工具一般不是货币市场基金投资方向。答案：C

**4.（单选题）** 关于货币市场基金的特征，下列表述正确的有（　）。
　Ⅰ.每个交易日可办理基金份额申购、赎回
　Ⅱ.收益分配方式约定为红利再投资，且每日分配
　Ⅲ.每日按照面值（一般为1元）进行报价
　Ⅳ.所有货币市场基金均提供T+0快速赎回服务
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ

**解析：** 这是对商品期货基金持有商品期货合约价值占基金资产净值比例规定的考查，属于记忆性知识点，商品期货基金除特殊规定外，持有所有商品期货合约价值合计（买入、卖出轧差计算）不低于基金资产净值的 90%，不高于基金资产净值的 110% 。答案：B

**2.（单选题）** 商品基金具有的特点有（　）。
Ⅰ.较直接投资商品现货或者期货合约门槛低且便捷
Ⅱ.主要投资于股票和债券
Ⅲ.交易效率高
Ⅳ.是大类资产配置的良好工具
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 商品基金主要投资于商品相关资产，并非股票和债券，所以Ⅱ错误。商品基金相比直接投资商品现货或期货合约，门槛低且便捷，交易效率高，还是大类资产配置良好工具，Ⅰ、Ⅲ、Ⅳ正确。答案：C

**3.（单选题）** MOM产品的特点包括（　）。
Ⅰ.大类资产配置
Ⅱ.精选子管理人
Ⅲ.分散风险，提升收益
Ⅳ.专业管理
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** MOM产品通过大类资产配置，实现资产合理布局；精选子管理人，发挥各管理人专长；能分散风险，在一定程度上提升收益；并且是专业机构进行管理。这四点均是其特点。答案：D
