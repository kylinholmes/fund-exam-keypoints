# 证券投资基金基础知识 · 第9章 投资组合管理

## 第1节 现代投资组合理论（15题）

**1.（单选题）** 对于多个资产组成的投资组合，设E(rp)为投资组合的期望收益率，E(ri)为第i个资产的收益率，Wi为第i个资产的权重，n为资产数目，那么投资组合期望收益率为（　）。
A. E(r_p) = w_i × E(r_i)　（单资产，无求和）
B. E(r_p) = Σ(i=1→n) [w_i × E(r_i)]　（按权重加权求和）
C. E(r_p) = Σ(i=1→n) E(r_i)　（直接相加）
D. E(r_p) = w_i × E(r_i) ÷ n　（加权后除以n）
**答案：** B
**解析：** 投资组合的期望收益率是各资产期望收益率按其**权重加权**后的加总：

E(r_p) = Σ(i=1→n) [w_i × E(r_i)]，其中 w_i 为第 i 个资产的权重，且 Σw_i = 1。

A 项只写了单个资产、没有求和；C 项直接相加未加权；D 项多除以 n。答案：B

**2.（单选题）** 可行集代表市场上可投资产所形成的所有组合，所有可能的组合都位于可行集的（　）。
A.内部
B.边界
C.内部或边界
D.外部
**答案：** C
**解析：** 可行集包含了所有可投资产形成的组合，那么所有可能的组合必然都在可行集涵盖的范围内，也就是在可行集的内部或者边界上，不可能在外部。答案选C。

**3.（单选题）** 现代投资组合理论的开端是（　）。

C.1966年简·莫辛“资本资产定价模型”
D.1976年斯蒂芬·罗斯“套价定价理论”
**答案：** A
**解析：** 现代投资组合理论由马科维茨开创，1952 年他提出“均值一方差模型”标志着现代投资组合理论开端。答案选A。

**4.（单选题）** 相关系数ρ＞0，表示两变量间（　）；ρ＜0，表示两变量间（　）。
A.负线性相关；正线性相关
B.正线性相关；无线性相关关系
C.正线性相关；负线性相关
D.无线性相关关系；负线性相关
**答案：** C
**解析：** 相关系数ρ是用于衡量两个变量之间线性相关程度的指标。当ρ > 0时，意味着两个变量的变化趋势是同向的，即呈现正线性相关；当ρ < 0时，表明两个变量的变化趋势是反向的，也就是负线性相关。答案：C

**5.（单选题）** 马科维茨用来衡量投资者所面临的可能收益与预期收益偏离程度的指标是（　）。
A.收益率的高低
B.收益率低于期望收益率的频率
C.收益率为负的频率
D.收益率的方差
**答案：** D
**解析：** 马科维茨用收益率的方差来衡量资产收益率与预期收益率的偏离程度，方差越大，偏离程度越大，风险越高。A选项收益率高低并非衡量偏离程度指标；B选项收益率低于期望收益率的频率以及C选项收益率为负的频率，都不是马科维茨用于衡量偏离程度的指标。答案：D

**6.（单选题）** （　）是由全部有效投资组合构成的集合。

B.均值方差法

**答案：** C

**7.（单选题）** 根据投资者对风险不同的态度，可以将投资者分为三类，以下不属于其分类的是（　）。

**8.（单选题）** 马科维茨的现代投资组合理论假设投资者对风险的态度是（　）。

**答案：** A

**9.（单选题）** 下列无差异曲线的特点不包括（　）。
A.同一条无差异曲线上的所有点向投资者提供了相同的效用
B.当向较高的无差异曲线移动时，投资者的效用减少
C.风险厌恶的投资者的无差异曲线是从左下方向右上方倾斜的
D.对于给定风险厌恶系数的某投资者来说，可以画出无数条无差异曲线，且这些曲线不会交叉
**答案：** B
**解析：** 无差异曲线的基本性质是，同一条无差异曲线上所有点效用相同，A选项正确；风险厌恶投资者的无差异曲线从左下方向右上方倾斜，C选项正确；对于给定风险厌恶系数的投资者能画出无数条无差异曲线且不交叉，D选项正确。而当向较高的无差异曲线移动时，投资者效用是增加的，不是减少，B选项说法错误。答案：B

**10.（单选题）** 使投资者效用最大化的是（　）。
A.无差异曲线上的投资组合
B.有效前沿上的投资组合
C.无差异曲线与有效前沿相交的点所代表的投资组合
D.无差异曲线和有效前沿相切的点所代表的投资组合
**答案：** D
**解析：** 无差异曲线反映投资者的偏好，同一无差异曲线上的组合给投资者带来的效用相同；有效前沿是能够达到的最优投资组合的集合。投资者要在有效前沿中寻找使自己效用最大化的组合。 无差异曲线和有效前沿相切的点，意味着在该点，投资者在自己的偏好（无差异曲线代表）和市场能提供的最优组合（有效前沿代表）之间达到了平衡，这个切点所代表的投资组合能使投资者效用最大化。答案：D

**11.（单选题）** 单一资产方差不变，相关系数（　），资产组合的方差（　）。
A.越小，越小
B.越小，越大
C.越小，不变
D.两者不会相互影响
**答案：** A
**解析：** 资产组合方差不仅取决于单一资产方差，还与资产间相关系数有关。相关系数越小，分散风险效果越好，资产组合方差也就越小。答案：A

**12.（单选题）** 资产收益率的相关性系数用ρ表示，相关系数的取值范围是（　）。
A.[-1,0]
B.[0,+1]
C.[-1,+1]
D.(-1,+1)
**答案：** C
**解析：** 资产收益率相关性系数ρ衡量两个资产收益率之间的相关程度，其取值范围是从 - 1到 + 1，包括 - 1和 + 1。 - 1表示完全负相关， + 1表示完全正相关，0表示不相关。答案：C

**13.（单选题）** 股票A、B、C具有相同的预期收益和风险，股票之间的相关系数如下：A和B的相关系数为0.8，B和C的相关系数为0.2，A和C的相关系数为-0.4，哪种等权重投资组合的风险最低？（　）
A.股票B和C组合
B.股票A和C组合
C.股票A和B组合
D.无法判断
**答案：** B
**解析：** 投资组合的风险与组合中各资产的相关系数密切相关。当资产间相关系数越小，分散风险的效果越好，组合风险越低。 已知A和B相关系数为0.8，B和C相关系数为0.2，A和C相关系数为-0.4。-0.4<0.2<0.8，即A和C的相关系数最小。答案：B。股票A和C组合风险最低。

**14.（单选题）** 对于由两种股票构成的资产组合，当他们之间的相关系数为（　）时，能够最大限度地降低组合风险。
A.0.5
B.0
C.-1
D.1
**答案：** C
**解析：** 相关系数反映两种资产收益率之间的变动关系。当相关系数为1时，两种股票完全正相关，组合不能降低风险；相关系数为0时，两种股票不相关，有一定分散风险作用；相关系数为-1时，两种股票完全负相关，此时可通过合理配置比例，使得一种股票收益上升时，另一种股票收益下降，从而最大限度地降低组合风险。答案：C

**15.（单选题）** 如果资产i和资产j的收益率和相关系数在-1和1之间，那么两个资产的投资组合将呈一条（　）
A.左上方弯曲的曲线
B.左下方弯曲的曲线
C.右上方弯曲的曲线
D.右下方弯曲的曲线
**答案：** A
**解析：** 当资产i和资产j收益率相关系数在 -1和1之间时，投资组合风险分散化效应使得组合曲线向左上方弯曲，即可以在相同风险下获得更高收益或相同收益下承担更低风险。答案：A

## 第2节 资本市场理论（14题）

**1.（单选题）** 有关资本市场线的表述，最准确的是指（　）。
A.无风险资产和有效前沿上的点连接形成的直线
B.与马科维茨有效前沿相交的一条直线
C.无风险资产和风险资产的线性组合
D.与马科维茨有效前沿相切的一条直线
**答案：** D
**解析：** 资本市场线是与马科维茨有效前沿相切的一条直线，切点是市场组合，该直线反映了有效投资组合的预期收益率和标准差之间的均衡关系。A选项描述不准确；B选项不是相交；C选项表述不确切。答案选D。

**2.（单选题）** 假设有两个公司，一个是橙汁生产公司，一个是雨伞制造公司。两个公司的业绩都易受到天气的影响。假设在未来一年天气平均较为晴朗的概率为50％，平均较为阴雨的概率为50％。两个公司在两种状态下的预期收益率如下：橙汁公司在晴朗时收益率为10％、阴雨时为−2％；雨伞公司在晴朗时收益率为−2％、阴雨时为10％。如果投资者将所有的资金都投资于其中某一家公司，那么他的预期收益率和标准差分别是（　）。
A.4％：4％
B.5％；5％
C.4％；6％
D.3％；7％
**答案：** C
**解析：** 预期收益率 = 50%×10% + 50%×(−2%) = 5% − 1% = 4%。两公司对称，结果相同。

标准差：各状态偏离均值的幅度均为 6%（10%−4%=6%，−2%−4%=−6%），
σ = √(0.5×6%² + 0.5×(−6%)²) = 6%。

故两家公司的预期收益率均为 4%、标准差均为 6%。答案：C

**3.（单选题）** 下列有关系统性风险和非系统性风险判断中，错误的一项是（　）。
A.总风险=系统性风险+非系统性风险
B.投资者要求在承担风险的时候得到风险补偿，即风险溢价
C.承担非系统性风险可以得到风险补偿
D.无论资产的数目有多少，系统性风险都是同定不变的
**答案：** C
**解析：** 系统性风险是由整体政治、经济、社会等环境因素对证券价格所造成的影响，这种风险不能通过分散投资加以消除，也被称为不可分散风险。投资者承担系统性风险会得到风险补偿。 非系统性风险是指对某个行业或个别证券产生影响的风险，它通常由某一特殊的因素引起，与整个证券市场的价格不存在系统的全面联系，其对个别或少数证券的收益产生影响，可以通过分散投资来降低或消除，承担非系统性风险不会得到风险补偿。 A选项，总风险由系统性风险和非系统性风险构成，该说法正确。 B选项，投资者承担风险期望获得风险溢价，即风险补偿，说法正确。 D选项，系统性风险不受资产数目的影响，固定不变，说法正确。答案：C（因为承担非系统性风险不会得到风险补偿，C选项说法错误）

**4.（单选题）** 在资本市场理论假设成立的前提下，下列对市场均衡状态的判断中，错误的有（　）。
Ⅰ市场投资组合包含市场上所有风险资产，其包含的各资产的投资比例与整个市场上的风险资产的相对市值比例一致

Ⅳ单个资产的风险溢价与市场投资组合m的风险溢价和该资产的β系数成比例

**5.（单选题）** （　）系数衡量的是资产收益率和市场组合收益率之间的线性关系。
A.α
B.σ
C.β
D.ρ
**答案：** C
**解析：** β系数衡量的是资产收益率与市场组合收益率之间的线性关系，它反映资产系统性风险大小。α是资产的实际收益率与根据资本资产定价模型计算出的预期收益率的差值；σ一般表示标准差，衡量的是资产收益率的波动程度；ρ一般表示相关系数，虽也涉及变量间关系但并非资产收益率和市场组合收益率这种特定线性关系衡量指标。答案：C

**6.（单选题）** 某大学基金会的投资目标是资产的长期保值增值。该基金会将20%的资产配置于国内股票，80%的资产配置于国内债券。为了分散风险，提高收益，该基金会可以采取的措施有（　）。
Ⅰ、将部分资产配置于外国股票
Ⅱ、将部分资产配置于房地产投资
Ⅲ、将部分资产配置于私募股权投资
Ⅳ、将所有资产配置于国内股票
Ⅴ、将所有资产配置于国内债券
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅲ、Ⅴ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅳ、Ⅴ
**答案：** C
**解析：** 题干中基金会目前资产集中在国内股票和国内债券，要分散风险提高收益，需要拓展投资领域。 Ⅰ将部分资产配置于外国股票，能通过不同国家股票市场分散风险；Ⅱ将部分资产配置于房地产投资，房地产与股票、债券相关性较低，可分散风险；Ⅲ将部分资产配置于私募股权投资，也是丰富投资类别，分散风险。 Ⅳ将所有资产配置于国内股票，风险集中在国内股票市场，无法分散风险；Ⅴ将所有资产配置于国内债券，风险集中在国内债券市场，也无法分散风险。答案：C

**7.（单选题）** 假设市场组合预期收益率为5.6%，无风险利率为2.6%，如果该股票的β值为2.6，则该股票的预期收益率与市场组合预期收益率之差为（　）。
A.2.4%
B.3.9%
C.4.8%
D.5.5%
**答案：** C
**解析：** E(Ri)=Rf+3[E(Rm)-Rf]
已知：E(Rm)=5.6%,Rf=2.6%,β=2.6
市场风险溢价：E(Rm)-Rf=5.6%-2.6%=3%
股票预期收益率：E(Ri)=2.6%+2.6×3%=2.6%+7.8%=10.4%
题目求：股票预期收益率-市场组合预期收益率10.4%-5.6%=4.8%

**9.（单选题）** 假设资本资产定价模型成立，某股票的预期收益率为16%，贝塔系数（β）为2，如果市场预期收益率为12%，市场的无风险利率为（　）。

D.8%
**答案：** D
**解析：** 1. 首先明确资本资产定价模型公式：R_i = R_f + β × (R_m − R_f)，其中R_i是股票预期收益率，R_f是无风险利率，β是贝塔系数，R_m是市场预期收益率。2. 把已知数据代入公式：已知R_i = 16%，β = 2，R_m = 12%，设R_f为x，则16% = x + 2 × (12% − x)。3. 解方程： 展开式子得16% = x + 24% − 2x。 移项得2x − x = 24% − 16%。 解得x = 8%。答案：D
