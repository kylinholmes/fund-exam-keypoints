# 证券投资基金基础知识 · 第6章 衍生工具

## 第1节 衍生工具概述（9题）

**1.（单选题）** 权益类衍生工具不包括（　）。
A.股票指数期货
B.股票期货
C.货币期货
D.股票期权
**答案：** C
**解析：** 权益类衍生工具是基于股票等权益类基础资产产生的衍生工具。股票指数期货、股票期货、股票期权都与股票相关，属于权益类衍生工具。而货币期货是以货币为基础资产的衍生工具，不属于权益类。答案：C

**2.（单选题）** 下列不属于衍生工具特点的是（　）。
A.跨期性
B.杠杆性
C.联动性
D.确定性
**答案：** D
**解析：** 衍生工具是基于基础金融工具衍生出来的，其价值随基础资产变动而变动，结果具有不确定性。跨期性指交易双方通过对利率、汇率等因素变动趋势的预测，约定在未来某一时间按照一定条件进行交易或选择是否交易；杠杆性能以少量资金进行较大价值交易；联动性指其价值与基础资产价值紧密关联。所以不属于衍生工具特点的是确定性。答案选D。

**3.（单选题）** 衍生工具按（　）分类，可以分为远期合约、期货合约、期权合约、互换合约四种。
A.自身的合约特点
B.产品形态
C.合约标的资产的种类
D.交易场所
**答案：** A
**解析：** 衍生工具按自身合约特点分为远期合约、期货合约、期权合约、互换合约这四种，而按产品形态分为独立衍生工具和嵌入式衍生工具，按合约标的资产种类分为货币衍生工具等多种，按交易场所分为场内交易和场外交易衍生工具。所以本题选A。答案：A

**4.（单选题）** （　）合约是指交易双方约定在未来的某一确定的时间，按约定的价格买入或卖出一定数量的某种合约标的资产的合约。是非标准化的合约。
A.期权
B.远期
C.互换
D.期货
**答案：** B
**解析：** 首先明确题目强调是非标准化合约且描述的是未来按约定买卖资产。期权是赋予权利的合约，不符合此定义；互换是一系列现金流交换，并非单纯买卖资产；期货是标准化合约；而远期合约是非标准化的，交易双方约定未来按约定价格买卖资产，符合题意。答案：B

**5.（单选题）** 下列金融衍生工具中属于货币衍生工具的是（　）。
A.股票期货合约
B.股票期权合约
C.货币远期合约
D.利率互换合约
**答案：** C
**解析：** 货币衍生工具主要是围绕货币进行的衍生，货币远期合约是关于货币买卖的远期约定。而A、B选项是围绕股票，属于股权类衍生工具；D选项利率互换是利率相关，属于利率衍生工具。答案：C。

**6.（单选题）** 以基础产品所蕴含的信用风险或违约风险为合约标的资产的金融衍生工具属于（　）。
A.货币衍生工具
B.利率衍生工具
C.信用衍生工具
D.权益类衍生工具
**答案：** C
**解析：** 题目明确指出以信用风险或违约风险为合约标的资产的金融衍生工具，根据定义，这种工具就是信用衍生工具。答案：C

**7.（单选题）** （　）属于在交易所内交易的衍生工具。
A.利率互换
B.信用违约互换
C.货币互换
D.期货合约
**答案：** D
**解析：** 交易所交易的衍生工具是指在有组织的交易所上市交易的衍生工具，期货合约是在期货交易所交易的，而利率互换、信用违约互换、货币互换通常在场外市场交易。答案：D

**8.（单选题）** （　）是指不通过集中交易所，而是通过金融机构之间或金融机构与客户之间谈判进行交易的衍生工具。
A.内置型衍生工具
B.交易所交易的衍生工具
C.信用创造型的衍生工具
D.OTC交易的衍生工具
**答案：** D
**解析：** 题目强调不通过集中交易所，而是金融机构间或与客户谈判交易，OTC交易即场外交易，符合这种不通过集中交易所的交易形式。答案：D

**9.（单选题）** （　）是指赋予期权买方在规定期限内按双方约定的价格买入或卖出一定数量的某种资产的权利的合同。
A.期货合约
B.远期合约
C.期权合约
D.互换合约
**答案：** C
**解析：** 题目描述的是一种赋予买方按约定价格买卖资产权利的合同，这符合期权合约的定义。期货合约是在未来特定时间交割特定资产；远期合约是交易双方约定未来某一时期交割资产；互换合约是双方约定在未来互相交换现金流。答案：C

## 第2节 远期合约（3题）

**1.（单选题）** 如果交割价格高于远期价格，套利者可以通过买入现货资产并卖出远期合约，待合约到期时交割，从而获取无风险利润。此时，套利行为将推动现货价格（　），交割价格（　），直至套利机会消失。
A.上涨；上涨
B.上涨；下降
C.下降；上涨
D.下降；下降
**答案：** B
**解析：** 套利者买入现货，会使现货市场需求增加，根据供求关系，需求增加会推动现货价格上涨。 套利者卖出远期合约，增加了远期合约的供给，使得交割价格有下降压力，会推动交割价格下降。答案：B

**2.（单选题）** 若交割价格高于远期价格，套利者就可以通过（　）并等待交割来获取无风险利润。
A.买入标的资产现货、卖出远期
B.卖出标的资产现货、买入远期
C.同时买进标的资产现货和远期
D.同时卖出标的资产现货和远期
**答案：** A
**解析：** 当交割价格高于理论远期价格时，远期合约的卖出价值被高估。
套利者在现货市场低价买入标的资产，同时在远期市场以更高的交割价格卖出远期合约。
持有至交割日时，用手中的现货履行远期合约的卖出义务，直接锁定两者的价差，获得无风险利润。
其他选项说明
B选项：这是‌交割价格低于远期价格‌时的套利操作，通过卖空现货、买入低价远期来获利。
C、D选项：同时同向买卖现货和远期，无法形成对冲套利，不能锁定无风险价差收益。
套利行为最终会推动现货价格上升、被高估的交割价格下降，直到价差消失，市场回归无套利均衡状态。

**3.（单选题）** 下列关于远期合约表述错误的是（　）。
A.远期合约的流动性比较差
B.远期合约没有固定的、集中的交易场所
C.远期合约履约有保证
D.远期合约市场效率偏低
**答案：** C
**解析：** 远期合约是交易双方约定在未来某一确定时间，以确定价格买卖一定数量资产。由于它没有固定集中交易场所，是交易双方私下协商，所以履约依赖双方信用，无特别保证，流动性差，市场效率也低。答案：C

## 第3节 期货合约（9题）

**1.（单选题）** 在市场经济条件下，价格是根据市场（　）状况形成的。
A.需求
B.供给
C.供求
D.均衡
**答案：** C
**解析：** 在市场经济中，价格不是仅由需求或供给单方面决定，而是由供给和需求共同作用，即供求状况决定的。当供求达到均衡时会形成均衡价格，但价格形成基础是供求状况。答案：C

**2.（单选题）** 按照实物商品种类的不同，商品期货不包括（　）。
A.股指期货
B.农产品期货
C.金属期货
D.能源期货
**答案：** A
**解析：** 商品期货是标的物为实物商品的期货合约，农产品、金属、能源都属于实物商品。而股指期货的标的物是股票价格指数，并非实物商品。答案：A

**3.（单选题）** 关于期货合约要素，下列叙述不正确的是（　）。
A.交易期货合约时，只能以交易单位的整数倍进行买卖
B.期货合约的交易时间是由交易者决定的
C.期货的合约月份由期货交易所规定，交易者可选择不同合约月份的期货合约
D.如果过了最后交易日仍未做对冲，就必须进行实物交割或现金结算
**答案：** B
**解析：** 期货合约交易时间是由期货交易所统一规定的，并非由交易者决定。A选项，交易以交易单位整数倍买卖符合规定；C选项，合约月份由交易所规定，交易者可选择，表述正确；D选项，过了最后交易日未对冲就要实物交割或现金结算也是正确的。答案：B

**4.（单选题）** 下列不属于金融期货的交易品种的是（　）。
A.外汇
B.商品
C.债券
D.股票
**答案：** B
**解析：** 金融期货主要包括外汇期货、利率期货（债券属于利率期货基础资产）、股票期货、股指期货等。商品期货与金融期货是期货市场不同类别，商品不属于金融期货交易品种。答案选B。

**5.（单选题）** 沪深300股指期货合约的最低交易保证金是合约价值的（　）。
A.5%
B.8%
C.10%
D.12%
**答案：** B
**解析：** 保证金制度，就是指在期货交易中，任何交易者必须按其所买入或者卖出期货合约价值的一定比例交纳资金的制度。沪深300指数期货合约条款中规定最低交易保证金为合约价值的【8%】。

**6.（单选题）** 关于沪深300股指期货合约，下列叙述有误的是（　）。
A.最小变动价位是0.2指数点
B.每日涨跌停板幅度为上一个交易日结算价的±10%
C.最后交易日为合约到期月份的第二个周五，遇国家法定假日顺延
D.上市交易所为中国金融期货交易所
**答案：** C
**解析：** 沪深300股指期货合约最后交易日为合约到期月份的第三个周五，遇国家法定假日顺延，C选项说第二个周五叙述错误。A、B、D选项关于最小变动价位、涨跌停板幅度、上市交易所的描述均正确。答案：C

**7.（单选题）** 下列各项不属于金融期货交易制度的是（　）。
A.盯市制度
B.连续交易制度
C.对冲平仓制度
D.保证金制度
**答案：** B
**解析：** 金融期货交易制度主要包括保证金制度、盯市制度、对冲平仓制度和交割制度等。连续交易制度一般不是金融期货特有的交易制度，它更广泛涉及市场交易时间等方面安排，并非金融期货核心的交易制度。答案：B

**8.（单选题）** 在金融期货交易中，期货交易者了结交易的方式是（　）。
A.全部通过对冲平仓
B.少数通过对冲平仓，大多数进行实物交割
C.全部进行实物交割
D.少数进行实物交割，大多数通过对冲平仓
**答案：** D
**解析：** 在金融期货交易中，实物交割的成本较高等原因，使得多数交易者选择对冲平仓来了结交易，只有少数进行实物交割。答案：D

**9.（单选题）** 期货市场的基本功能不包括（　）。
A.风险管理
B.价格发现
C.投机和套利
D.增加收益
**答案：** D
**解析：** 期货市场有风险管理（通过套期保值等手段管理风险）、价格发现（众多交易者交易形成价格）、投机和套利（投机者承担风险获利，套利者利用价差获利）功能，而增加收益并非其基本功能，期货交易本身有风险，不能简单说能增加收益。答案：D

## 第4节 期权合约（14题）

**1.（单选题）** （　）是指在期权到期之前，由于标的资产价格可能波动而带来的潜在价值。
A.外在价值
B.时间价值
C.内在价值
D.期权价值
**答案：** B
**解析：** 时间价值是指期权权利金扣除内涵价值的剩余部分，它是在期权到期之前，由于标的资产价格可能波动而带来的潜在价值。 内在价值是期权立即行权时所能获得的收益，不涉及到期前价格波动的潜在价值。 期权价值是内在价值和时间价值之和，概念较宽泛。 外在价值并非期权常用术语。答案：B

**2.（单选题）** 期权合约的价值可以分为（　）。
A.外在价值和内在价值
B.时间价值和内在价值
C.时间价值和外在价值
D.外在价值和远期价值
**答案：** B
**解析：** 期权合约价值由内在价值和时间价值构成。内在价值是期权立即行权时所能获得的收益，时间价值是期权权利金扣除内在价值的剩余部分。答案：B

**3.（单选题）** 期权的（　）是指期权合约即刻行权时可能获得的收益。
A.外在价值
B.相对价值
C.内在价值
D.时间价值
**答案：** C
**解析：** 期权内在价值是指期权合约立刻行权时所能获得的收益。外在价值、相对价值并非这种定义；时间价值是期权权利金扣除内在价值的剩余部分。答案：C

**4.（单选题）** 标的资产的价格越低、执行价格越高，看跌期权的价格（　）。
A.越高
B.越低
C.不变
D.没关系
**答案：** A
**解析：** 对于看跌期权，当标的资产价格越低、执行价格越高时，期权的行权可能性越大，获利空间越大，所以其价值也就越高。答案：A

**5.（单选题）** （　）是指市场上交易的期权价格蕴含的波动率。
A.历史波动率
B.隐含波动率
C.期权价格波动率
D.每日波动率
**答案：** B
**解析：** 题干强调的是期权价格蕴含的波动率，隐含波动率就是市场上交易的期权价格所蕴含的波动率。历史波动率是基于过去数据计算的；期权价格波动率表述不准确；每日波动率概念不契合。答案：B

**6.（单选题）** （　）指期权的买方只有在期权到期日才能执行期权，既不能提前也不能推迟。
A.欧式期权
B.美式期权
C.看涨期权
D.看跌期权
**答案：** A
**解析：** 欧式期权规定买方只能在期权到期日执行期权；美式期权买方在到期日前任何时间都能执行；看涨期权是预期标的资产价格上涨时的期权；看跌期权是预期标的资产价格下跌时的期权。题目描述符合欧式期权特点。答案：A

**7.（单选题）** 按（　）分类，期权可分为看涨期权和看跌期权两种。
A.期权买方执行期权的时限
B.期权买方的权利
C.执行价格与标的资产的市场价格的关系
D.按偿还期限
**答案：** B
**解析：** 根据期权买方的权利不同，期权可分为看涨期权（买方有权在约定时间以约定价格买入标的资产）和看跌期权（买方有权在约定时间以约定价格卖出标的资产） 。A选项按期权买方执行期权的时限，分为欧式期权和美式期权等；C选项按执行价格与标的资产市场价格关系分实值期权、平值期权、虚值期权等；D选项期权一般无偿还期限分类。答案：B

**8.（单选题）** （　）是指期权买方为获取期权合约所赋予的权利而向期权卖方支付的费用。
A.保证金
B.期权费
C.佣金
D.手续费
**答案：** B
**解析：** 题目描述的是期权买方为获得权利向卖方支付的费用，这正是期权费的定义。保证金是期货交易等涉及的概念，佣金、手续费通常与交易行为相关，并非期权买方为获权利支付给卖方的特定费用。答案：B

**9.（单选题）** 关于欧式期权和美式期权，下列说法错误的是（　）。
A.对于欧式期权，如果买方要提前执行权利，期权卖出者可以拒绝履约
B.超过到期日，美式期权失效
C.其他条件相同时，美式期权的期权费通常要比欧式期权的低
D.美式期权对买方更有利
**答案：** C
**解析：** 美式期权买方可以在到期日及之前任一交易日行权，灵活性更强，所以期权费通常比欧式期权高，C 选项说法错误。A 选项，欧式期权只能在到期日行权，提前行权卖方可拒绝，该说法正确；B 选项，超过到期日期权失效，对美式期权也适用，说法正确；D 选项，美式期权行权更灵活，对买方更有利，说法正确。答案：C

**10.（单选题）** 交易者买入看跌期权，是因为他预期某种标的资产的价格在近期内将会（　）。
A.上下波动
B.下跌
C.上涨
D.不变
**答案：** B
**解析：** 看跌期权是指期权的购买者拥有在期权合约有效期内按执行价格卖出一定数量标的物的权利。交易者买入看跌期权，只有当标的资产价格下跌时，期权才更有可能行权获利。所以买入看跌期权是预期价格下跌。答案：B

**11.（单选题）** 当投资者买入看涨期权后，如果判断失误，则最大损失为（　）。
A.标的资产价格
B.协定价格
C.无限
D.期权价格
**答案：** D
**解析：** 对于买入看涨期权的投资者，当判断失误，即市场走势并未如预期上涨时，投资者可以选择不行权。此时，最大损失就是购买期权时所支付的期权价格。因为即使标的资产价格大幅下跌，投资者的损失也仅限于支付的期权费，不会更多。答案：D

**12.（单选题）** 看跌期权的买方具有在约定期限内按（　）卖出一定数量标的资产的权利。
A.期权价格
B.市场价格
C.执行价格
D.买入价格
**答案：** C
**解析：** 看跌期权买方有权在约定期限内按执行价格卖出标的资产，执行价格是期权合约中规定的价格。期权价格是买方为获得权利支付的费用，市场价格随时波动，买入价格概念不准确。答案是C。

**13.（单选题）** 期权合约约定的价格被称作（　）。
A.合约价格
B.执行价格
C.市场价格
D.内在价值
**答案：** B
**解析：** 期权合约中约定的价格就是执行价格，当期权买方行使权利时，按照执行价格买入或卖出标的资产。合约价格这种表述不准确；市场价格是市场上实际交易的价格；内在价值是期权立即行权时所能获得的收益。答案：B

**14.（单选题）** 某基金经理在分析欧式期权与美式期权的定价差异时，提到了期权平价公式的适用条件。根据相关理论，期权平价公式（　）。
A.适用于美式期权，且需考虑标的资产的分红情况
B.仅适用于欧式期权，且不考虑交易成本及卖空限制
C.适用于所有期权类型，且假设无风险利率可波动
D.仅适用于欧式期权，且需考虑标的资产的分红情况
**答案：** B
**解析：** 期权平价公式是基于一系列严格假设推导出来的，其中重要一点就是仅适用于欧式期权，因为美式期权可提前行权会使情况变复杂。同时，推导过程假设无交易成本、无卖空限制等理想市场条件。答案：B

## 第5节 互换合约（7题）

**1.（单选题）** 利率互换包括基础互换和（　）两种形式。
A.金融互换
B.息票互换
C.人民币利率互换
D.净额互换
**答案：** B
**解析：** 利率互换常见形式是基础互换和息票互换。A选项金融互换概念宽泛；C选项人民币利率互换只是利率互换的一种类别，非并列形式；D选项净额互换不是利率互换下与基础互换并列的形式。答案选B。

**2.（单选题）** 被称作单边合约的是（　）。
A.信用违约互换合约
B.期货合约
C.远期合约
D.互换合约
**答案：** A
**解析：** 信用违约互换合约只有一方在一定情形下需向另一方付费，另一方不一定有对等支付义务，具有单边性，被称作单边合约。而期货合约、远期合约和互换合约双方都有对应的权利和义务。答案：A

**3.（单选题）** 利率互换是指互换合约双方同意在约定期限内按不同的利息计算方式（　）向对方支付由（　）的名义本金额所确定的利息。
A.定期；不同币种
B.定期：币种相同
C.分期；不同币种
D.分期：币种相同
**答案：** D
**解析：** 利率互换的核心特征是合约双方在约定期限内，基于币种相同的名义本金额，按照不同利息计算方式（通常为固定利率与浮动利率）进行利息交换。首先，名义本金额仅作为利息计算的基准，不发生实际交割，且双方交换的利息基于同一币种，不存在币种转换，因此排除 “不同币种” 的 A、C 选项。其次，利息支付并非一次性完成，而是在合约期限内按约定周期（如季度、半年）分期进行，“定期” 更侧重时间规律性，未能准确体现支付的阶段性特征，故排除 B 选项。综上，符合利率互换定义的是 D 选项，答案选 D。

**4.（单选题）** 根据利息支付方式不同，货币互换的分类形式不包括（　）。
A.固定对固定
B.固定对浮动
C.人民币利率互换
D.浮动对浮动
**答案：** C
**解析：** 货币互换根据利息支付方式不同，有固定对固定、固定对浮动、浮动对浮动三种类型。而人民币利率互换属于利率互换，并非货币互换按利息支付方式的分类。答案：C

**5.（单选题）** 在现实生活中较为常见的两种互换合约是（　）。
A.利率互换合约和股权互换合约
B.货币互换合约和信用违约互换合约
C.利率互换合约和货币互换合约
D.股权互换合约和信用违约互换合约
**答案：** C
**解析：** 利率互换和货币互换是现实生活中较为常见的互换合约类型，在金融市场应用广泛。股权互换、信用违约互换相对没那么常见。答案：C

**6.（单选题）** 下列关于常见衍生工具的区别中，说法有误的是（　）。
A.常见的衍生工具包括远期合约、期货合约、期权合约和互换合约
B.期权合约与远期合约以及期货合约的不同之处是其损益的不对称性
C.期货合约的实物交割比例非常高，远期合约的实物交割比例非常低
D.期货合约具有杠杆效应
**答案：** C
**解析：** 期货合约实物交割比例非常低，远期合约实物交割比例较高，C选项说法错误。A选项阐述常见衍生工具类别正确；B选项期权损益不对称说法正确；D选项期货合约有杠杆效应说法正确。答案：C

**7.（单选题）** 目前，中国外汇交易中心人民币利率互换参考利率不包括（　）。
A.上海银行间同业拆放利率
B.国债回购利率（7天）
C.1年期定期存款利率
D.3年期定期存款利率
**答案：** D
**解析：** 人民币利率互换参考利率主要有上海银行间同业拆放利率、国债回购利率（7天）、1年期定期存款利率等，并不包含3年期定期存款利率。答案选D。
