# 证券投资基金基础知识 · 第16章 基金的利润分配与税收

## 第1节 基金利润及利润分配（8题）

**1.（单选题）** 基金利润的来源不包括（　）。
A.利息收入
B.投资收益
C.佣金
D.其他收入
**答案：** C
**解析：** 基金利润来源主要有利息收入、投资收益及其他收入等。而佣金是基金交易时支付给券商等的费用，并非基金利润来源。答案选C。

**2.（单选题）** 下列关于货币市场基金的利润分配的说法错误的有（　）。
A.货币市场基金每周五进行收益分配时，将同时分配周六和周日的收益
B.每周一至周四进行收益分配时，仅对当日收益进行分配
C.投资者于周五申购或转换转入的基金份额享有周五、周六、周日的收益
D.投资者于周五赎回或转换转出的基金份额享有周五、周六、周日的收益
**答案：** C
**解析：** 货币市场基金中，周五申购或转换转入的基金份额不享有周五、周六、周日的收益；周五赎回或转换转出的基金份额享有周五、周六、周日的收益。A、B 选项关于收益分配时间的描述正确。答案：C

**3.（单选题）** 根据《证券投资基金运作管理办法》的规定，下列关于封闭式基金收益分配说法错误的是（　）。
A.每年不得少于一次
B.不得低于基金年度可供分配利润的90%
C.不得高于基金年度可供分配利润的100%
D.采用现金方式分红
**答案：** C
**解析：** 封闭式基金收益分配每年不得少于一次，分配比例不得低于基金年度可供分配利润的90%，且只能采用现金方式分红。并没有不得高于基金年度可供分配利润100%这一说法。答案：C

**4.（单选题）** 某基金2015年获得利润有：投资债券利息收入12万元，银行存款利息8万元，买卖股票获利20万元，权证行权获利20万元，赎回费扣除基本手续费余额10万元。则该基金的投资收益为（　）。
A.20万元
B.52万元
C.32万元
D.40万元
**答案：** D
**解析：** 投资收益是指基金经营活动中因买卖股票、债券、资产支持证券、基金等实现的差价收益，因股票、基金投资等获得的股利收益，以及衍生工具投资产生的相关损益。这里投资债券利息收入、银行存款利息属于利息收入，赎回费扣除基本手续费余额属于其他收入。投资收益为买卖股票获利20万元与权证行权获利20万元之和。答案：D（20 + 20 = 40万元）

**5.（单选题）** 与基金利润有关的财务指标不包括（　）。
A.本期利润
B.本期已实现收益
C.已分配利润
D.未分配利润
**答案：** C
**解析：** 基金利润相关财务指标主要有本期利润、本期已实现收益、期末可供分配利润（包括已分配利润和未分配利润等情况，但不是单独说已分配利润或未分配利润）。答案：C

**6.（单选题）** 下列不属于投资收益的是（　）。
A.买卖股票、债券、资产支持证券、基金等实现的差价收益
B.债券投资而实现的利息收入
C.因股票、基金投资等获得的股利收益
D.衍生工具投资产生的相关损益
**答案：** B
**解析：** 投资收益包括买卖金融资产的差价收益、因投资获得的股利收益以及衍生工具投资产生的相关损益等。而债券投资实现的利息收入通常单独归类为利息收入，不属于投资收益范畴。答案：B

**7.（单选题）** 某基金在利润分配前的份额净值是1.62元，假设每份基金分配0.04元，进行利润分配后的基金份额净值会下降到（　）元。
A.1.54
B.1.56
C.1.58
D.1.60
**答案：** C
**解析：** 基金进行利润分配后，份额净值会相应下降，下降的数值就是每份分配的金额。已知分配前份额净值是1.62元，每份分配0.04元，那么分配后的份额净值=1.62 - 0.04 = 1.58元。答案选C。

**8.（单选题）** 对于每日按照面值进行报价的货币市场基金，应当（　）进行收益分配。
A.每日
B.每周
C.每月
D.每季度
**答案：** A
**解析：** 货币市场基金通常流动性强，且每日按面值报价，为保持收益的及时性和稳定性，是每日进行收益分配。所以答案是A。

## 第2节 基金税收（8题）

**1.（单选题）** 下列关于增值税的说法中，错误的是（　）。
A.存款利息不征收增值税
B.资管产品运营过程中发生的增值税应税行为，以资管产品管理人为增值税纳税人
C.证券投资基金开展质押式买入返售业务和持有政策性金融债券取得的金融同业往来利息收入计征增值税
D.个人买卖基金份额的行为免征增值税
**答案：** C
**解析：** 选项A：存款利息属于不征收增值税项目，该说法正确。 选项B：资管产品运营过程中发生的增值税应税行为，以资管产品管理人为增值税纳税人，这是规定内容，说法正确。 选项C：证券投资基金开展质押式买入返售业务和持有政策性金融债券取得的金融同业往来利息收入免征增值税，而不是计征增值税，该选项说法错误。 选项D：个人买卖基金份额的行为免征增值税，说法正确。答案：C

**2.（单选题）** 机构投资者在境内买卖基金份额获得的差价收入，应并入企业的应纳税所得额，征收企业（　）
A.印花税
B.消费税
C.营业税
D.所得税
**答案：** D
**解析：** 题干说机构投资者买卖基金份额差价收入并入企业应纳税所得额，应纳税所得额对应的是所得税。印花税主要针对合同、账簿等凭证征收；消费税是对特定消费品征收；营业税（现已全面营改增）主要针对一些服务、销售不动产等业务征收，均与应纳税所得额的概念不直接相关。答案：D

**3.（单选题）** 个人投资者买卖基金份额（　）征收印花税。
A.减半
B.双倍
C.全额
D.暂免
**答案：** D
**解析：** 目前我国对个人投资者买卖基金份额暂免征收印花税，这是常见的税收优惠规定。答案：D

**4.（单选题）** 从（　）起，对证券交易印花税实行单向征收。
A.2007年6月5日
B.2008年6月5日
C.2008年9月19日
D.2009年9月19日
**答案：** C
**解析：** 我国于2008年9月19日起，调整证券（股票）交易印花税征收方式，将现行的对买卖、继承、赠与所书立的A股、B股股权转让书据按千分之一的税率对双方当事人征收证券（股票）交易印花税，调整为单边征税，即对出让方按千分之一的税率征收证券（股票）交易印花税，对受让方不再征税。答案：C

**5.（单选题）** 2016年5月1日起，全国范围内全面推开营业税改征增值税（简称营改增）试点，金融业纳入试点范围，由缴纳营业税改为缴纳增值税，增值税税率为（　）。
A.2%
B.4%
C.6%
D.8%
**答案：** C
**解析：** 营改增后金融业增值税税率为6% 。答案：C

**6.（单选题）** 从2008年9月19日起，基金卖出股票时__________印花税，买入股票时__________印花税。（　）
A.征收；征收
B.征收；不征收
C.不征收；征收
D.不征收；不征收
**答案：** B
**解析：** 从2008年9月19日起，证券交易印花税调整为单边征收，即只对卖出方（或继承、赠与A股、B股股权的出让方）征收证券（股票）交易印花税，对买入方（受让方）不再征税。所以基金卖出股票时征收印花税，买入股票时不征收印花税。答案是B。

**7.（单选题）** 目前，我国对证券投资基金从证券市场中取得的收入（　）企业所得税。
A.暂不征收
B.征收4%
C.征收5%
D.征收10%
**答案：** A
**解析：** 我国有相关政策规定，对证券投资基金从证券市场中取得的收入暂不征收企业所得税，这是一种税收优惠政策，以鼓励证券投资基金发展。答案：A

**8.（单选题）** 下列关于投资者买卖基金产生的税收说法错误的是（　）。
A.机构投资者买卖基金份额暂免征收印花税
B.个人投资者买卖基金份额暂免征收印花税
C.对香港市场投资者通过基金互认买卖、继承、赠予内地基金份额，暂不征收印花税
D.对内地投资者通过基金互认买卖、继承、赠予香港基金份额，暂不征收印花税
**答案：** D
**解析：** 对于投资者买卖基金产生的印花税相关规定，机构和个人投资者买卖基金份额都是暂免征收印花税的，A、B 选项表述正确。 关于基金互认，对香港市场投资者通过基金互认买卖、继承、赠予内地基金份额，暂不征收印花税；而内地投资者通过基金互认买卖、继承、赠予香港基金份额，按照香港特别行政区现行印花税税法规定执行，并非暂不征收印花税，D 选项说法错误，C 选项说法正确。答案：D
