# 证券投资基金基础知识 · 第1章 证券投资基金概述

## 第1节 证券投资基金简介（14题）

**1.（单选题）** 下列关于证券投资基金的叙述中，错误的是（　）。
A.证券投资基金是一种集合投资方式
B.证券投资基金反映的是一种信托关系
C.证券投资基金在美国被称为“单位信托基金”
D.证券投资基金通过公开募集或非公开募集的方式，汇集投资者的资金形成独立财产
**答案：** C
**解析：** 证券投资基金在美国被称为“共同基金”，在英国和我国香港特别行政区被称为“单位信托基金”，C选项说法错误。A选项，基金是集合投资方式；B选项，基金反映信托关系；D选项，基金可公开或非公开募集资金形成独立财产，这三个选项说法正确。答案：C

**2.（单选题）** 关于证券投资基金“利益共享、风险共担”的特点，下列表述正确的是（　）。
A.基金投资收益在扣除由基金承担的费用后，优先分配给管理人和托管人，部分盈余归基金投资者所有
B.基金投资者一般按照所持有的基金份额分配基金收益
C.基金托管人与基金管理人共同分担投资风险
D.为基金提供服务的基金管理人会参与基金收益的分配
**答案：** B
**解析：** “利益共享、风险共担”是指基金投资者是基金的所有者，基金投资收益在扣除由基金承担的费用后的盈余全部归基金投资者所有，并依据各投资者所持有的基金份额比例进行分配。基金管理人、托管人只是按规定收取一定比例的管理费、托管费，并不参与基金收益分配，也不承担投资损失。答案：B

**3.（单选题）** 证券投资基金具有集合理财的特点，下列属于集合理财的优点是（　）。
A.具有规模优势
B.强化监管
C.收益稳定
D.风险固定
**答案：** A
**解析：** 集合理财是将众多投资者资金集中起来，形成规模。凭借规模优势，在投资中可降低成本等，这是集合理财优点。强化监管不是集合理财自身优点；证券投资基金收益不稳定，风险也不固定。答案：A

**4.（单选题）** 开放式基金与银行储蓄存款的主要差异不包括（　）。
A.性质不同
B.收益与风险特性不同
C.信息披露程度不同
D.变现能力不同
**答案：** D
**解析：** 开放式基金是一种利益共享、风险共担的集合证券投资方式，与银行储蓄存款在性质（基金有投资性质，存款是债权债务关系）、收益与风险特性（基金收益风险波动大，存款相对稳定安全）、信息披露程度（基金需定期披露净值等信息，存款披露要求低）上均有不同。而两者变现能力并非其主要差异，开放式基金赎回有一定流程和时间，银行储蓄也可提前支取，只是可能影响利息收益，这并非本质的主要区别。答案：D

**5.（单选题）** 下列关于证券投资基金的说法中，正确的是（　）。
Ⅰ、反映的是债权债务关系，是一种债权凭证
Ⅱ、基金是独立的资产管理产品，风险自担
Ⅲ、资金主要投向有价证券等金融工具或产品
Ⅳ、可以投资于众多金融工具或产品，能有效分散风险
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 选项Ⅰ，证券投资基金反映的是一种信托关系，不是债权债务关系，不是债权凭证，所以Ⅰ错误。 选项Ⅱ，基金是独立的资产管理产品，投资者自担风险，该说法正确。 选项Ⅲ，基金资金主要投向有价证券等金融工具或产品，说法正确。 选项Ⅳ，由于投资众多金融工具或产品，能有效分散风险，说法正确。答案：B

**6.（单选题）** （　）在基金运作中具有核心作用。
A.基金管理人
B.基金份额持有人
C.基金销售机构
D.证券交易所
**答案：** A
**解析：** 基金管理人负责基金的投资运作、资产估值等关键事务，在基金运作体系里处于核心地位。基金份额持有人是基金的所有者，但不直接参与运作；基金销售机构只是负责销售基金；证券交易所为基金交易提供场所，但并非核心。答案：A 。

**7.（单选题）** 我国的证券交易所是依法设立的，（　），为证券的集中和有组织的交易提供场所和设施，履行国家有关法律法规、规章、政策规定的职责，实行自律性管理的法人。
A.以利润最大化为目的
B.不以营利为目的
C.以收入最大化为目的
D.以指数最大化为目的
**答案：** B
**解析：** 我国证券交易所的性质决定其设立并非为追求营利，而是提供证券交易场所等服务并自律管理。答案：B 。

**8.（单选题）** 我国股票反映的是一种（　）关系。
A.股东权利
B.债务
C.信托
D.担保
**答案：** A
**解析：** 股票是股份公司发行的所有权凭证，代表股东对公司的所有权，反映的是股东权利关系。债券反映债务关系，信托有专门的信托机制，担保是对债务等的保障方式，均与股票性质不同。答案：A

**9.（单选题）** 基金的运作包括（　）。
Ⅰ、基金的募集
Ⅱ、基金的投资管理
Ⅲ、基金财产的托管
Ⅳ、基金的估值与会计核算
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** B
**解析：** 基金运作涵盖多个环节。基金募集是开始，有了资金才能后续操作；投资管理是对募集资金进行运用以获利；财产托管保障资金安全；估值与会计核算用于衡量基金资产价值等。这些环节都是基金运作不可或缺部分。所以答案是B.Ⅰ、Ⅱ、Ⅲ、Ⅳ 。

**10.（单选题）** 基金的运作活动从基金管理人的角度看，可以分为（　）。
Ⅰ、基金的市场营销
Ⅱ、基金的盈亏核算
Ⅲ、基金的投资管理
Ⅳ、基金的中后台管理
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 从基金管理人角度，基金运作活动主要包括基金市场营销，要把基金产品推广出去吸引投资者；投资管理是对基金资产进行投资运作以实现目标；中后台管理涉及基金运营的各类支持保障工作，如估值、清算等。而盈亏核算只是投资管理等过程中的一个环节，并非与其他并列的基金运作活动主要分类。答案：B

**11.（单选题）** 在我国，基金托管人只能由依法设立并取得基金托管资格的（　）或其他金融机构担任。
A.商业银行
B.保险公司
C.基金管理公司
D.信托公司
**答案：** A
**解析：** 在我国，基金托管人主要由具备一定条件的商业银行担任，这是基于商业银行在资金保管、风险控制等方面的优势。虽然其他金融机构理论上也可能取得资格，但目前主要是商业银行承担基金托管工作。答案：A

**12.（单选题）** 证券投资基金通过公开或非公开募集的方式，汇集投资者的资金形成（　），由专业的基金管理机构进行投资管理。
A.公司财产
B.独立财产
C.集体财产
D.混合资产
**答案：** B
**解析：** 证券投资基金通过募集资金形成独立财产，它独立于基金管理人、托管人的固有财产，有自己独立的运作规则等。 答案：B

**13.（单选题）** 基金管理人最核心的职责是（　）。
A.办理基金份额登记
B.负责基金资产的投资运作
C.办理清算交割
D.安全保管基金财产
**答案：** B
**解析：** 基金管理人是基金产品的募集者和管理者，其最主要职责就是按照基金合同的约定，负责基金资产的投资运作，以实现基金资产的保值增值。A选项办理基金份额登记一般由基金注册登记机构等负责；C选项办理清算交割是基金托管人等相关机构的部分职责；D选项安全保管基金财产是基金托管人的主要职责。答案：B

**14.（单选题）** 基金管理人将部分业务外包后，依法应承担的责任（　）。
A.转由服务机构承担
B.自动免除
C.不因委托而免除
D.需重新约定
**答案：** C
**解析：** 基金管理人即使将部分业务外包，其依法应承担的责任并不因委托给服务机构而免除。答案：C

## 第2节 证券投资基金的起源与发展（1题）

**1.（单选题）** 世界上第一只公认的证券投资基金是（　）。
A.海外及殖民地政府信托
B.苏格兰美国投资信托
C.马萨诸塞投资信托基金
D.英国投资信托
**答案：** A
**解析：** 1868年，英国成立“海外及殖民地政府信托基金”，这是世界上第一只公认的证券投资基金 。答案：A

## 第3节 中国证券投资基金业的发展历程（6题）

**1.（单选题）** 我国《证券投资基金法》于（　）开始实施。
A.2003年7月14日
B.2005年1月1日
C.2002年8月1日
D.2004年6月1日
**答案：** D
**解析：** 《证券投资基金法》于2004年6月1日起施行 ，答案选D。

**2.（单选题）** 中国证券投资基金探索阶段的特点不包括（　）。
A.探索性
B.自发性
C.不规范性
D.监管严格性
**答案：** D
**解析：** 中国证券投资基金探索阶段，由于处于早期探索，更多呈现出探索性、自发性和不规范性的特点 ，当时监管体系尚不完善，并非监管严格。答案：D

**3.（单选题）** 2001年9月，我国第一只开放式基金——（　）诞生。
A.华安创新
B.基金开元
C.基金金泰
D.淄博基金
**答案：** A
**解析：** 华安创新是我国第一只开放式基金。基金开元和基金金泰是我国首批封闭式基金，淄博基金是我国第一只投资基金。答案：A

**4.（单选题）** 2008年至2014年属于我国基金业发展的（　）阶段。
A.萌芽和早期发展时期
B.试点发展阶段
C.平稳发展及创新探索阶段
D.快速发展阶段
**答案：** C
**解析：** 2008 年至 2014 年，基金行业面临市场波动等挑战，同时也在产品创新、业务拓展等方面不断探索，处于平稳发展及创新探索阶段。答案：C

**5.（单选题）** 2018年10月中国证监会出台了《证券期货经营机构私募资产管理业务管理办法》《证券期货经营机构私募资产管理计划运作管理规定》，明确将各类私募资产管理业务统一为信托法律关系，并确立了（　）等基本原则。
Ⅰ.卖者尽责、买者自负
Ⅱ.审慎经营
Ⅲ.禁止刚兑
Ⅳ.集中运作
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 《证券期货经营机构私募资产管理业务管理办法》及相关规定确立的基本原则包括卖者尽责、买者自负，这体现市场参与者责任界定；审慎经营要求机构稳健运作；禁止刚兑打破不合理兜底预期。而集中运作并非确立的基本原则。答案：A
