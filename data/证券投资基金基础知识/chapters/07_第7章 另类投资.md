# 证券投资基金基础知识 · 第7章 另类投资

## 第1节 另类投资概述（2题）

**1.（单选题）** 私募股权的组织形式包括（　）。
Ⅰ管理型
Ⅱ公司型
Ⅲ合伙型
Ⅳ信托型
A.Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ
C.Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 私募股权常见组织形式有公司型、合伙型、信托型。管理型并非私募股权典型组织形式。所以答案选A。

**2.（单选题）** 另类投资的局限性不包括（　）。
A.产品结构复杂
B.流动性较差，杠杆率偏高
C.估值难度大
D.通货膨胀对冲
**答案：** D
**解析：** 另类投资通常存在产品结构复杂、流动性差、杠杆率高、估值难度大等局限性。而通货膨胀对冲是另类投资的优点，并非局限性。答案：D

## 第2节 大宗商品投资（5题）

**1.（单选题）** （　）是指同质化、可交易、非零售环节销售、用于工农业生产或消费的大批量买卖的原材料或初级产品，一般具有实体形态。
A.私募股权
B.不动产
C.大宗商品
D.对冲基金
**答案：** C
**解析：** 题干描述的是具有同质化、可交易、非零售、用于工农业生产或消费、大批量买卖且一般有实体形态等特点的物品，符合大宗商品的定义。私募股权是对非上市公司进行的权益性投资；不动产主要指土地、建筑物等；对冲基金是采用对冲交易手段的基金。答案：C

**2.（单选题）** 能源类大宗商品不包括（　）。
A.原油
B.汽油
C.天然气
D.棉花
**答案：** D
**解析：** 能源类大宗商品主要涉及与能源相关的产品，原油、汽油、天然气都属于能源产品，而棉花属于农产品类大宗商品，并非能源类。答案：D

**3.（单选题）** 大宗商品的投资方式不包括（　）。
A.购买大宗商品实物
B.购买资源或者购买大宗商品相关股票
C.购买大宗商品相关债券
D.投资大宗商品衍生工具
**答案：** C
**解析：** 大宗商品投资方式常见有购买实物、投资相关股票、利用衍生工具，而购买大宗商品相关债券不属于大宗商品常见投资方式。答案：C

**4.（单选题）** 下列不属于基础原材料类大宗商品的是（　）。
A.钢铁
B.铜
C.铅
D.动力煤
**答案：** D
**解析：** 基础原材料类大宗商品主要包含钢铁、铜、铝、铅等金属材料，动力煤属于能源类大宗商品，不属于基础原材料类。答案：D

**5.（单选题）** 下列关于贵金属类大宗商品的特点，说法不正确的是（　）。
A.具备相对较好的物理属性
B.高度的发展性
C.稀少
D.繁多
**答案：** D
**解析：** 贵金属类大宗商品通常具备相对较好的物理属性（如质地稳定等），所以A选项正确； 因其在自然界中含量稀少，所以C选项正确； 贵金属类大宗商品一般不是繁多的特点，且“高度的发展性”表述模糊且不属于其典型特点，题目问不正确的，BD表述都不太符合贵金属大宗商品特点，相比之下，“繁多”与贵金属稀有相悖，更明显错误。答案：D

## 第3节 不动产投资（4题）

**1.（单选题）** 基于未被开发这一特征，土地本身的不确定性非常高，因此土地投资可能具有（　）。
A.较低的投机性
B.较高的投机性
C.较高的收益性
D.较低的收益性
**答案：** B
**解析：** 因为土地未被开发不确定性高，这种不确定性常伴随着较大风险，而高风险往往与高投机性相关，较高收益性和较低收益性并非由不确定性高直接得出，较低投机性不符合其不确定性高的特点。答案：B

**2.（单选题）** （　）是指土地以及建筑物等土地定着物，相对动产而言，强调财产和权利载体在地理位置上的相对固定性。
A.房地产
B.不动产
C.固定资产
D.流动资产
**答案：** B
**解析：** 题目描述强调了财产和权利载体在地理位置上相对固定，且提及土地及建筑物等土地定着物，这符合不动产的定义。房地产主要侧重房产与地产结合用于经济活动方面；固定资产范围更广，并非仅强调地理位置固定；流动资产明显与地理位置固定相悖。答案：B.不动产

**3.（单选题）** 房地产投资信托的主要收益来自（　）。
A.固定比例的管理费
B.佣金
C.租金收入
D.稳定的股息和证券价格增值
**答案：** D
**解析：** 房地产投资信托（REITs）是通过发行受益凭证或股票募集资金、投资于房地产或房地产抵押贷款的专门投资机构，是一种资产证券化产品，可采取上市方式在证券交易所挂牌交易。基金从业教材明确：房地产投资信托基金的主要收益来自稳定的股息和证券价格增值；管理费、佣金不是其主要收益来源。本题选D。

**4.（单选题）** 下列关于地产投资的表述，错误的是（　）。
A.不确定性非常高
B.投资价值受法律法规影响较小
C.具有较高的投机性
D.投资价值受宏观环境影响较大
**答案：** B
**解析：** 地产投资不确定性高，受宏观环境影响大，且具有较高投机性，同时，法律法规对地产投资约束多，投资价值受其影响大。所以错误表述是B。答案：B。

## 第4节 对冲基金投资（2题）

**1.（单选题）** 与传统资产管理机构不同，对冲基金通常采用的组织结构是（　）。
Ⅰ.信托合作制
Ⅱ.有限合伙制
Ⅲ.有限责任公司制
Ⅳ.股份有限公司制
A.Ⅰ、Ⅱ
B.Ⅱ、Ⅲ
C.Ⅰ、Ⅳ
D.Ⅲ、Ⅳ
**答案：** B
**解析：** 对冲基金通常采用有限合伙制的组织结构，这种结构能有效结合资金与管理优势。答案选 B，因为Ⅱ有限合伙制是对冲基金常见组织结构，Ⅲ有限责任公司制在一些对冲基金中也有采用，而Ⅰ信托合作制、Ⅳ股份有限公司制并非对冲基金通常采用的组织结构。 答案：B

**2.（单选题）** 以下关于当代对冲基金特点的表述，错误的有（　）。
Ⅰ.采用被动管理方式
Ⅱ.投资策略受到严格限制
Ⅲ.信息透明度相对较低
Ⅳ.面向社会大众公开募集
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 对冲基金采用的是主动管理方式，而非被动管理，所以Ⅰ表述错误。 对冲基金投资策略非常灵活，不受严格限制，Ⅱ表述错误。 对冲基金信息透明度相对较低，这是其特点之一，Ⅲ表述正确。 对冲基金一般是面向特定投资者私募发行，并非面向社会大众公开募集，Ⅳ表述错误。答案：题目问错误的表述，Ⅰ、Ⅱ、Ⅳ错误，所以答案是B。
