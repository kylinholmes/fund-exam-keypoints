# 证券投资基金基础知识 · 第3章 投资管理基础

## 第1节 财务报表（10题）

**1.（单选题）** （　）又称股东权益或净资产，表示企业的资产净值。
A.负债
B.所有者权益
C.资产
D.收入
**答案：** B
**解析：** 所有者权益又称股东权益或净资产，是企业资产扣除负债后，由所有者享有的剩余权益，代表企业的资产净值。而负债是企业所承担的能以货币计量、需以资产或劳务偿还的债务；资产是企业过去的交易或者事项形成的、由企业拥有或者控制的、预期会给企业带来经济利益的资源；收入是企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入。答案：B

**2.（单选题）** 对资产=负债+所有者权益的说法中，错误的是（　）。
A.资产是公司因过去的交易或事项形成的，由公司拥有或控制的资源，预期会带来未来经济利益
B.负债是企业因过去的交易或事项形成的，预期会导致经济利益流出的义务，并且该义务能够可靠计量
C.所有者权益包括实收资本(或股本)、资本公积、盈余公积、未分配利润以及其他综合收益
D.所有者权益是指企业总资产
**答案：** D
**解析：** 选项A、B分别对资产和负债的定义描述正确。 选项C对所有者权益包含的内容描述正确。 选项D错误，所有者权益是指企业资产扣除负债后，由所有者享有的剩余权益，并非企业总资产。答案：D

**3.（单选题）** 对利润表的说法中，错误的是（　）。
A.利润表反映公司在一定期间(如一个季度或年度)的经营成果
B.利润表由收入、费用和利润三部分构成，分别反映公司在特定期间的收入来源、成本支出及最终的盈利结果
C.利润表是一个静态报告
D.利润表通过展示公司收入、费用和利润的变化，揭示其经营趋势
**答案：** C
**解析：** 利润表是反映公司在一定期间经营成果的动态报表，并非静态报告。A选项说明利润表反映一定期间经营成果正确；B选项对利润表构成阐述正确；D选项利润表能揭示经营趋势也正确。答案：C

**4.（单选题）** 某上市公司2025年度销售商品取得的现金为1000万元，支付各项税费150万元，分配股利支付的现金为100万元。则该公司2025年度经营活动产生的现金流量为（）万元。
A.850
B.750
C.-100
D.250
**答案：** A
**解析：** 经营活动产生的现金流量主要涉及销售商品、提供劳务收到的现金以及支付各项税费等与日常经营相关的现金收支。分配股利支付的现金属于筹资活动现金流量，不应计入经营活动现金流量。销售商品取得现金1000万元，支付税费150万元，经营活动现金流量 = 1000 - 150 = 850万元。答案选A。

**5.（单选题）** 下列不属于现金流量表的基本结构的是（）。

D.所有者权益变动表

**9.（单选题）** 财务报表是依据会计准则定期编制的标准化报告，其作用是（　）。

## 第2节 财务报表分析（18题）

B.英国
C.荷兰

**答案：** A
**解析：** 杜邦分析法是由美国杜邦公司首先采用的一种财务分析方法 ，所以答案是A。

**2.（单选题）** 对杜邦分析法的说法中，正确的是（　）。
Ⅰ杜邦分析法的核心是净资产收益率
Ⅱ杜邦分析法侧重分析单一报告期内企业的经营状况，是对过去业绩的评价，无法反映公司的发展前景
Ⅲ净资产收益率=销售利润率×净资产周转率×权益乘数
Ⅳ公司的盈利能力由销售利润率、资产使用效率和财务杠杆共同决定
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** Ⅰ：杜邦分析法的核心确实是净资产收益率，通过层层分解指标来分析影响净资产收益率的因素，该说法正确。 Ⅱ：杜邦分析法主要基于历史财务数据，侧重分析单一报告期内企业经营状况，对公司未来发展前景反映不足，该说法正确。 Ⅲ：净资产收益率 = 销售利润率×总资产周转率×权益乘数，不是净资产周转率，该说法错误。 Ⅳ：销售利润率体现盈利水平，资产使用效率（总资产周转率）和财务杠杆（权益乘数）共同影响公司盈利能力，该说法正确。答案：B

**3.（单选题）** 某公司年初存货为20万元，部分年末数据为：流动负债为60万元，速动比率为2.5，流动比率3.0，销售成本为50万元。若企业无待摊费用和待处理财产损失，则存货周转率为（　）。
A.1.2
B.2
C.1.67
D.1.8
**答案：** B
**解析：** 1. 首先根据流动比率和速动比率公式求存货： 已知流动比率 = 流动资产 ÷ 流动负债，流动比率为3.0，流动负债为60万元，则流动资产 = 3.0×60 = 180万元。 速动比率 = 速动资产 ÷ 流动负债，速动比率为2.5，流动负债60万元，则速动资产 = 2.5×60 = 150万元。 因为流动资产=速动资产+存货，所以存货 = 180 - 150 = 30万元。2. 然后求平均存货： 年初存货20万元，年末存货30万元，平均存货 = (20 + 30) ÷ 2 = 25万元。3. 最后求存货周转率： 存货周转率 = 销售成本 ÷ 平均存货，销售成本为50万元，平均存货25万元，则存货周转率 = 50 ÷ 25 = 2。答案：B

**4.（单选题）** 某公司2025年度部分财务报表资料如下：现金年初780万元，年末320万元，应收账款年初1170万元，年末1350万元；存货年初720万元，年末980万元；总资产年初3800万元，年末3800万元。长期负债1100万元，流动负债1300万元，本年度公司销售收入8500万元，销售成本6600万元，利息费用500万元，所得税150万元，净利润230万元。则该公司2025年度的应收账款周转率为（　）。
A.6.75
B.2.5
C.1.3
D.3.0
**答案：** A
**解析：** 1. 首先明确应收账款周转率公式： 应收账款周转率 = 营业收入÷平均应收账款余额。2. 然后计算平均应收账款余额： 平均应收账款余额 =（年初应收账款余额 + 年末应收账款余额）÷ 2 =（1170 + 1350）÷ 2 = 1260（万元）。3. 最后计算应收账款周转率： 已知营业收入为8500万元，应收账款周转率 = 8500÷1260≈6.75。答案：A

**5.（单选题）** 甲公司的销售收入为2000万元，资产总额为1500万元，债务总额为800万元，如果销售利润率为10%。则该公司的净资产收益率为（）。
A.28.6%
B.34.2%
C.16.9%
D.24.7%
**答案：** A
**解析：** 1. 首先求净利润： 已知销售收入为2000万元，销售利润率为10%，根据公式“净利润 = 销售收入×销售利润率”，可得净利润 = 2000 × 10% = 200（万元）。2. 然后求净资产： 资产总额为1500万元，债务总额为800万元，根据会计恒等式“资产 = 负债 + 所有者权益”，这里净资产就是所有者权益，所有者权益 = 资产总额 - 债务总额，即净资产 = 1500 - 800 = 700（万元）。3. 最后求净资产收益率： 净资产收益率 = 净利润÷净资产×100%，将净利润200万元，净资产700万元代入公式，可得净资产收益率 = 200 ÷ 700 × 100% ≈ 28.6%。答案：A

A.流动性
B.财务杠杆
C.营运效率
D.盈利能力

**解析：** 题干描述的是资产从投入到产出的周转速度，以及对公司资产的管理质量和利用效率的反映，这符合营运效率的概念。流动性侧重于资产的变现能力；财务杠杆主要涉及债务与权益的关系；盈利能力强调获取利润的能力。所以选C。答案：C

**7.（单选题）** 净利润除以总资产等于（　）。
A.销售利润率
B.净资产收益率
C.资产收益率
D.总资产周转率
**答案：** C

**8.（单选题）** 一家企业的应收账款周转率是5，那么这家企业平均需花（　）天收回一次账面上的全部应收账款。
A.55
B.62
C.73
D.84
**答案：** C
**解析：** 1. 首先明确应收账款周转天数的计算公式： 应收账款周转天数 = 365 ÷应收账款周转率。2. 已知应收账款周转率是5，则应收账款周转天数 = 365 ÷ 5 = 73（天）。答案：C

**9.（单选题）** 某公司的销售利润率为4%，总资产周转率为2，资产负债率为60%，则该公司的净资产收益率为（　）。
A.8%
B.20%
C.4.8%
D.12%
**答案：** B
**解析：** 1. 首先明确净资产收益率（ROE）的杜邦分析公式： 净资产收益率（ROE）=销售利润率×总资产周转率×权益乘数。2. 接着求权益乘数： 已知资产负债率 = 60%，资产负债率=负债总额÷资产总额，权益乘数 = 资产总额÷所有者权益总额。 因为资产总额=负债总额 + 所有者权益总额，设资产总额为1，负债总额为0.6，那么所有者权益总额 = 1 - 0.6 = 0.4。 权益乘数 = 1÷0.4 = 2.5。3. 然后计算净资产收益率： 销售利润率为4%，总资产周转率为2，权益乘数为2.5。 净资产收益率（ROE）=4%×2×2.5 = 20%。答案：B

**11.（单选题）** 假设企业年销售收入为50万，年销售成本为20万，企业年初存货是12万元，年末存货是4万元。为了评价该企业的营运效率，计算出来的存货周转率为（　）。
A.2.5
B.5
C.6.25
D.12.5
**答案：** A

**12.（单选题）** 在企业流动比率大于1时，赊购原材料一批，将会（　）。
A.降低营运资金
B.降低流动比率
C.增大流动比率
D.增大营运资金
**答案：** B
**解析：** 流动比率 = 流动资产÷流动负债。当企业流动比率大于1时，赊购原材料，会使流动资产（存货增加）和流动负债（应付账款增加）等额增加。由于流动比率大于1，相当于分子分母同时增加相同数值，根据数学原理，分数值会变小，所以流动比率降低。而营运资金 = 流动资产 - 流动负债，流动资产和流动负债等额增加，营运资金不变。答案：B

**13.（单选题）** 一个公司的总资本是1000万元，其中有300万元的债务资本和700万元的权益资本，那么该公司的资本结构即包含30%的债务和70%的权益，该公司的资产负债率是（　）。
A.25%
B.27%
C.30%
D.32%
**答案：** C
**解析：** 1. 首先明确资产负债率的计算公式： 资产负债率 = 负债总额÷资产总额×100%。 题目中债务资本即负债总额为300万元，总资本就是资产总额为1000万元。2. 然后计算： 资产负债率 = 300 ÷ 1000 × 100% = 30%。答案选C。

**14.（单选题）** 甲公司的营业收入为2900万元，资产总额为1750万元，债务总额为630万元，如果销售利润率为8%。则该公司的净利润为（　）万元。
A.232
B.140
C.250
D.50.4

## 第3节 货币的时间价值与利率（13题）

**1.（单选题）** （　）把未来现金流直接转化为相对应的现值。

## 第4节 常用描述性统计概念（6题）
