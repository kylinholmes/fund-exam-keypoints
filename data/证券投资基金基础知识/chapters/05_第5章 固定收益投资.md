# 证券投资基金基础知识 · 第5章 固定收益投资

## 第1节 债券与债券市场（8题）

**1.（单选题）** （　）是指以其他债券或贷款组成的资产池为支持，构建新的债券产品形式。
A.可回售债券
B.可转换债券
C.可赎回债券
D.资产证券化
**答案：** D
**解析：** 资产证券化就是将其他债券或贷款等资产组成资产池，以此为支持构建新债券产品。A可回售债券是持有者可按约定将债券回售给发行人；B可转换债券是能按条件转换成股票；C可赎回债券是发行人可按约定赎回债券，这三个选项都与以资产池构建新债券产品无关。答案：D

**2.（单选题）** 债券是作为证明（　）关系的凭证。
A.债权债务
B.产权
C.所有权
D.委托代理
**答案：** A
**解析：** 债券是发行人向投资者发行的，承诺按约定支付利息、偿还本金的一种债务凭证，体现的是债权债务关系。答案选A 。

**3.（单选题）** 债券的（　）是指未到期债券的持有者无法以市值变现债券形成的投资风险。
A.利率风险
B.流动性风险
C.汇率风险
D.赎回风险
**答案：** B
**解析：** 题目强调未到期债券持有者无法按市值变现债券产生的风险，这符合流动性风险定义，即资产不能以合理价格及时变现的风险。答案：B

**4.（单选题）** 面值在每个支付日会根据某一消费价格指数调整来反映通货膨胀变化的债券是（　）。
A.通货膨胀联结债券
B.结构化债券
C.可赎回债券
D.浮动利率债券
**答案：** A
**解析：** 题干描述的是债券面值会依据消费价格指数调整以反映通胀变化，这正是通货膨胀联结债券的特点。答案：A

**5.（单选题）** （　）为债券持有者提供在债券到期前的特定时段以事先约定好的价格将债券回售给发行人的权利。
A.可回售债券
B.可转换债券
C.可赎回债券
D.通货膨胀联结债券
**答案：** A
**解析：** 题干描述的是债券持有者有权按约定价格回售债券给发行人，这正是可回售债券的特征。可转换债券是可转换成股票；可赎回债券是发行人有权提前赎回；通货膨胀联结债券与通胀相关。答案：A。

**6.（单选题）** （　）是以居民住房抵押贷款或商用住房抵押贷款组成的资金池为支持的，资金流来自住房抵押贷款人定期还款，由金融中介机构打包建立资金池。
A.住房抵押贷款支持证券
B.商用住房抵押贷款
C.人民币债券
D.外币债券
**答案：** A
**解析：** 题目描述的是以住房抵押贷款组成资金池并以此为支持，资金流源于贷款人定期还款，这种基于住房抵押贷款资金池支持的证券就是住房抵押贷款支持证券。答案：A

**7.（单选题）** （　）是指在市场利率下行的环境中，附息债券收回的利息或者提前于到期日收回的本金，只能以低于原债券到期收益率的利率水平再投资于相同属性的债券而产生的风险。
A.利率风险
B.信用风险
C.通胀风险
D.再投资风险
**答案：** D
**解析：** 题目描述的是因利率下行，债券收回资金再投资时收益降低的风险，这种风险就是再投资风险。利率风险强调的是市场利率变动对债券价格等的影响；信用风险侧重于债券发行人违约的风险；通胀风险主要与物价上涨影响债券实际收益有关。只有再投资风险符合题意。答案：D

**8.（单选题）** （　）是指债券发行者在债券到期日前赎回有提前赎回条款的债券所带来的风险。
A.再投资风险
B.违约风险
C.提前赎回风险
D.信用风险
**答案：** C
**解析：** 题目描述的是债券发行者提前赎回债券带来的风险，根据定义，这就是提前赎回风险。答案：C

## 第2节 中国债券市场体系（8题）

**1.（单选题）** 财政部代表中央政府发行的债券，被称为（　）。
A.国债
B.地方政府债券
C.公司债券
D.金融债券
**答案：** A
**解析：** 国债是由国家财政部代表中央政府发行的债券。地方政府债券由地方政府发行，公司债券由公司发行，金融债券由金融机构发行。所以答案是代表中央政府发行债券的国债。答案：A

**2.（单选题）** 中国债券市场中，以柜台市场为主的阶段是在（　）。
A.1988—1991年
B.1992—2000年
C.2001年至今
D.1978—1987年
**答案：** A
**解析：** 1988 年，财政部在全国 61 个城市进行国债流通转让试点，形成了最初的债券柜台交易市场，到 1991 年，以柜台市场为主。答案：A。

**3.（单选题）** 目前，中国债券市场处于以（　）为主的发展阶段。
A.柜台市场
B.交易所市场
C.银行间市场
D.同业市场
**答案：** C
**解析：** 中国债券市场中，银行间市场规模最大、参与者众多、交易活跃，处于主导地位。答案：C

**4.（单选题）** 某地方政府为筹集基础设施建设资金而发行债券，该债券的（　）是地方政府。
A.投资者

C.发行方
D.监管机构

**解析：** 地方政府为筹集资金发行债券，那地方政府就是债券的发行主体，即发行方。投资者是购买债券的；中介机构是协助发行等相关事务的；监管机构负责监督管理，均不符合题意。答案：C

**5.（单选题）** 在我国债券市场中，为债券发行提供法律服务的律师事务所属于（　）。

D.自律组织
**答案：** C
**解析：** 律师事务所为债券发行提供法律服务，帮助处理法律相关事务，其作用是在债券发行过程中为各方提供专业服务，属于连接发行方和投资者等主体的中介角色。答案：C

**6.（单选题）** 以下属于我国利率债的有（　）。

Ⅱ.中央银行票据
Ⅲ.政策性金融债券

## 第3节 债券价值分析（6题）

**1.（单选题）** 某种贴现式国债面额为1000元，贴现率为5%，到期时间为120天，则该国债内在价值与面值之差为（　）元。

**2.（单选题）** 如果某债券基金的久期为3年，市场利率由5%下降到4%，则该债券基金的资产净值约（　）。
A.增加12%
B.增加3%
C.减少3%
D.减少12%
**答案：** B
**解析：** 久期与债券价格（这里债券基金资产净值类似债券价格概念）和市场利率变动关系为：债券价格变动百分比约等于久期乘以市场利率变动幅度。 市场利率由「公式」下降到「公式」，变动幅度为「公式」（下降「公式」）。 久期为3年，那么债券基金资产净值变动百分比约为「公式」，因为利率下降，债券价格上升，所以资产净值是增加「公式」。答案：B

**3.（单选题）** 显示的期限结构特征是短期债券收益率较低，长期债券收益率较高，属于收益率曲线中的（　）。
A.反转收益率曲线
B.水平收益率曲线
C.拱形收益率曲线
D.正向收益率曲线
**答案：** D
**解析：** 正向收益率曲线的特点就是短期债券收益率较低，长期债券收益率较高。反转收益率曲线是短期收益率高，长期收益率低；水平收益率曲线各期限收益率相近；拱形收益率曲线是期限相对较短的债券，利率与期限成正向关系，期限较长的债券，利率与期限呈反向关系。所以该题符合正向收益率曲线特征。答案：D

**6.（单选题）** 信用利差的特点不包括（　）。
A.对于给定的非政府部门的债券、给定的信用评级，信用利差随着期限增加而减小
B.信用利差随着经济周期的扩张而缩小，随着经济周期的收缩而扩张

## 第4节 货币市场工具（6题）

**1.（单选题）** 商业票据的特点不包括（　）。
A.面额较大
B.期限较短
C.融资方式灵活
D.融资利率相对较高
**答案：** D
**解析：** 商业票据通常面额较大，这样可以满足企业大规模短期融资需求，A 选项是其特点。 期限较短，一般是 270 天以内，以解决企业短期资金周转，B 选项是特点。 发行方式多样，可直接发行或通过交易商发行等，融资方式灵活，C 选项是特点。 商业票据由于风险相对较低，且是短期融资工具，所以融资利率相对较低，而不是较高。答案：D

**2.（单选题）** 下列各类金融资产中，货币市场工具不包括（　）。
A.银行承兑汇票
B.中央银行票据
C.3年期国债
D.银行回购协议
**答案：** C
**解析：** 货币市场工具期限通常在1年及以下。3年期国债期限超过1年，属于资本市场工具。而银行承兑汇票、中央银行票据、银行回购协议期限一般较短，属于货币市场工具。答案：C

**3.（单选题）** 在我国，货币市场工具不包括（　）。
A.现金
B.期限在1年以内(含1年)的银行存款
C.剩余期限在397天以内（含397天）的债券
D.期限在1年以上（含1年）的债券回购
**答案：** D
**解析：** 货币市场工具一般是指期限在1年以内（含1年）的金融工具。债券回购若期限在1年以上（含1年）就不属于货币市场工具范畴，而现金、1年以内（含1年）银行存款、剩余期限在397天以内（含397天）债券都符合货币市场工具期限短的特点。答案：D

**4.（单选题）** 下列选项中，属于短期政府债券特点的是（　）。
A.违约风险小
B.流动性弱
C.利息交税
D.不容易变现
**答案：** A
**解析：** 短期政府债券是政府部门以债务人身份承担到期偿付本息责任的期限在1年以内的债务凭证。政府信用等级高，所以违约风险小；期限短且交易活跃，流动性强、容易变现；同时很多国家对短期政府债券利息免征税收。答案：A

**5.（单选题）** 下列关于短期融资券的说法，错误的是（　）。
A.由承销商承销并采用无担保的方式发行

D.主要目的是为了获得短期流动性
**答案：** B
**解析：** 短期融资券由符合条件的企业发行，由承销商承销，采用无担保方式发行，发行者必须是具有法人资格的企业，其发行主要目的是为了获得短期流动性，A、C、D选项说法正确。 短期融资券对资金用途没有明确限制，B选项说法错误。答案：B

**6.（单选题）** 下列关于银行承兑汇票的表述，不正确的是（　）。
A.贴现业务就是向企业提供短期贷款
B.一般票据的贴现期超过6个月
C.银行对商业汇票进行承兑是基于对出票人资信的认可
D.承兑业务由银行提供，本质是由银行将信用出借给企业
**答案：** B
