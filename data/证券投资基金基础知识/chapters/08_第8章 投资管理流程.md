# 证券投资基金基础知识 · 第8章 投资管理流程

## 第1节 业绩比较基准（4题）

**1.（单选题）** 与道琼斯工业股票平均价格指数相比，标准普尔500指数的特点有（　），被普遍认为是一种理想的股票价格指数期货合约的标的。
Ⅰ采样面广
Ⅱ代表性强
Ⅲ精确度高
Ⅳ连续性好
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 标准普尔500指数采样面广，包含了500只不同类型的股票，能广泛反映市场情况；代表性强，涵盖各行业具有代表性的公司；精确度高，由于样本多，计算更精确；连续性好，能持续稳定地反映股市整体趋势。正因这些特点，它成为理想的股指期货合约标的。答案：A

**2.（单选题）** 沪深300指数采用（　）进行计算。
A.算数平均法
B.派氏加权法
C.几何平均法
D.市值加权法
**答案：** B
**解析：** 沪深300指数以调整股本为权重，采用派氏加权综合价格指数公式进行计算。 答案：B

**3.（单选题）** 以下关于业绩比较基准作用的表述，正确的有（　）。
Ⅰ.帮助投资者评估基金经理的投资能力
Ⅱ.帮助投资者跟踪基金产品的业绩表现
Ⅲ.判断基金实际投资行为是否符合合同约定的投资策略
Ⅳ.决定基金的实际投资收益
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 业绩比较基准可帮助投资者评估基金经理投资能力，比如通过对比基金收益与业绩比较基准，能看出经理是否跑赢基准从而判断能力，Ⅰ正确；也能帮助投资者跟踪基金产品业绩表现，将基金收益和业绩比较基准对比可了解表现情况，Ⅱ正确；还能判断基金实际投资行为是否符合合同约定投资策略，若偏离业绩比较基准风格，可能投资行为与策略不符，Ⅲ正确。而基金实际投资收益受多种市场因素、投资操作等影响，不是由业绩比较基准决定，Ⅳ错误。答案：A

**4.（单选题）** 相对收益型基金的业绩比较基准，通常是参照（　）来设定的。
A.某一固定的收益率水平
B.某一特定指数或指数组合的收益率
C.同类基金的平均收益率
D.基金经理的预期收益率
**答案：** B
**解析：** 相对收益型基金业绩比较基准常基于特定指数或指数组合收益率，以此衡量基金相对表现。A固定收益率水平一般是绝对收益目标；C同类基金平均收益率不常用作比较基准；D基金经理预期收益率主观性强，不适合作基准。答案：B

## 第2节 投资管理流程分类（6题）

**1.（单选题）** 下列关于投资政策说明书包含的内容，说法错误的是（　）。
A.投资目标
B.业绩比较基准
C.投资范围
D.最低收益保障
**答案：** D
**解析：** 投资政策说明书通常涵盖投资目标、业绩比较基准、投资范围等内容，但一般不会提供最低收益保障，因为投资具有不确定性，难以保证最低收益。答案选D。

**2.（单选题）** （　）是指在资产价格发生变化后，投资经理将组合重新调整为最初设定的资产配置比例。
A.规划
B.再平衡
C.执行
D.业绩评估
**答案：** B
**解析：** 题目描述的是资产价格变化后，把组合重新调整回最初资产配置比例，这正是再平衡的概念。规划通常是对投资进行前期谋划；执行是实施投资决策；业绩评估是对投资成果进行评价。所以选B。答案：B

**3.（单选题）** 投资管理人应在明确了投资者的投资目标、投资限制、战略资产配置后为投资者制定（　）。
A.风险揭示书
B.投资政策说明书
C.基金运作说明
D.基金管理协议
**答案：** B
**解析：** 投资管理人在明确投资者投资目标、限制及战略资产配置后，通常制定投资政策说明书，它是投资决策的指导性文件。答案：B

**4.（单选题）** 投资规划需要规划的方面不包括（　）。
A.确定并量化投资者的投资目标和投资限制
B.制定投资政策说明书
C.业绩评估
D.建立战略资产配置
**答案：** C
**解析：** 投资规划主要流程包括明确投资目标与限制、制定投资政策说明书、进行资产配置等，业绩评估是投资实施后对投资效果的评价，不属于投资规划本身需规划的方面。答案：C

**5.（单选题）** 投资规划的首要任务是（　）。
A.确定并量化投资者的投资目标和投资限制
B.制定投资政策说明书
C.形成资本市场预期
D.建立战略资产配置
**答案：** A
**解析：** 投资规划首先要明确投资者的目标和限制，这是后续一系列规划的基础，只有明确了目标和限制，才能制定投资政策说明书、形成资本市场预期以及建立战略资产配置等。所以首要任务是确定并量化投资者的投资目标和投资限制。答案：A

**6.（单选题）** 定制化投资管理流程中，业绩比较基准决定人是（　）。
A.管理人
B.投资者
C.投资者与托管人商定
D.投资者与管理人商定
**答案：** D
**解析：** 在定制化投资管理流程中，业绩比较基准通常需要投资者和管理人共同商定。投资者有自身的收益期望与风险偏好等，管理人具备专业知识和市场经验，双方共同协商能确定出符合投资目标和实际情况的业绩比较基准。所以答案是D。

## 第3节 基金管理人投资管理框架（8题）

**1.（单选题）** （　）在物理上与基金管理人其他部门隔离，保持严格的独立性，并执行严格的保密要求。
A.基金交易部门
B.投资决策委员会
C.基金投资部门
D.基金研究部门
**答案：** A
**解析：** 基金交易部门负责具体交易执行，为防止利益输送等问题，在物理上需与其他部门隔离，有严格独立性和保密要求 。投资决策委员会是为基金投资提供决策指导，并非执行交易操作，无需严格物理隔离。基金投资部门主要负责投资策略等规划，研究部门负责提供研究支持，相比之下，交易部门对隔离和保密的要求最为突出。答案：A

**2.（单选题）** （　）是基金管理公司管理基金投资的最高决策机构。
A.董事会
B.投资决策委员会
C.投资部
D.研究部
**答案：** B
**解析：** 投资决策委员会是基金管理公司管理基金投资的最高决策机构，它为基金投资拟订投资原则、投资方向、投资策略和投资组合的整体目标和计划。董事会是公司的决策机构但并非专门针对基金投资；投资部负责具体投资操作；研究部提供研究支持。答案选B。

**3.（单选题）** 下列不属于投资策略的制定的步骤的是（　）。
A.研究部门提供研究成果
B.交易员接收指令
C.投资决策委员对投资策略形成指导性决议
D.投资部制定投资组合的具体方案
**答案：** B
**解析：** 投资策略制定步骤通常围绕策略的研究、决策和具体方案制定。而交易员接收指令是投资策略制定后的执行环节，并非制定步骤。答案：B

**4.（单选题）** 基金公司投资交易流程不包括下列哪一项（　）。
A.形成投资策略
B.构建投资组合
C.执行交易指令
D.制定投资政策说明书
**答案：** D
**解析：** 基金公司投资交易流程一般先是制定投资政策说明书，基于此形成投资策略，之后构建投资组合并执行交易指令。但题目问的是不包括哪一项，投资政策说明书是投资交易流程的前期准备，并非投资交易流程本身的环节。答案：D

**5.（单选题）** 下列关于投资决策委员会叙述错误的是（　）
A.基金投资运作的基础支持部门
B.由各个基金公司自行设立
C.基金管理人投资管理的最高决策机构
D.对基金公司各项重大投资活动进行管理
**答案：** A
**解析：** 投资决策委员会是基金管理人投资管理的最高决策机构，对基金公司各项重大投资活动进行管理，各基金公司可自行设立。而基金投资运作的基础支持部门一般指研究部等，不是投资决策委员会。答案：A

**6.（单选题）** （　）负责根据投资决策委员会制订的投资原则和计划，设计并执行具体的投资组合方案。
A.投资决策委员会
B.投资部门
C.研究部门
D.交易部门
**答案：** B
**解析：** 投资决策委员会制定原则和计划，而将这些原则和计划具体落实，设计并执行投资组合方案的是投资部门。研究部门主要负责提供研究分析等，交易部门负责执行交易指令。答案：B

**7.（单选题）** 下列关于交易部门表述错误的是（　）
A.负责投资组合交易指令的审核、执行与反馈
B.执行严格的保密要求
C.基金管理人采取分散交易制度
D.交易部的交易员充当着重要角色
**答案：** C
**解析：** 通常基金管理人采取集中交易制度，而非分散交易制度，C选项表述错误。A选项是交易部门的常规职责；B选项交易涉及重要信息需保密；D选项交易员在交易执行中确实重要。答案：C

**8.（单选题）** 交易指令在基金公司内部执行情况以下不包括（　）
A.建立可投池
B.基金经理通过交易系统向交易室下达交易指令
C.交易总监审核投资指令的合法合规性
D.交易员接收到指令后有权根据自身对市场的判断选择合适时机完成交易
**答案：** A
**解析：** 选项B，基金经理下达交易指令是交易指令在基金公司内部执行流程中的常见环节。 选项C，交易总监审核指令的合法合规性也是内部执行的必要步骤。 选项D，交易员根据判断选择时机完成交易，属于指令执行中的一部分。 而选项A建立可投池，主要是确定投资范围，是投资决策前的准备工作，并非交易指令在基金公司内部执行情况。答案：A
