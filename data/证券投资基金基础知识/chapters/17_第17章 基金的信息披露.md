# 证券投资基金基础知识 · 第17章 基金的信息披露

## 第1节 基金信息披露概述（8题）

**1.（单选题）** 下列属于基金定期报告的是（　）。
A.基金年度报告
B.基金合同
C.基金招募说明书
D.基金托管协议
**答案：** A
**解析：** 基金定期报告包括基金年度报告、基金半年度报告和基金季度报告。而基金合同、基金招募说明书、基金托管协议都不属于定期报告范畴。答案：A

**2.（单选题）** 基金信息披露的禁止行为包括（　）。
Ⅰ、虚假记载、误导性陈述或者重大遗漏
Ⅱ、对证券投资业绩进行预测
Ⅲ、承诺收益或者承担损失
Ⅳ、诋毁其他基金管理人、基金托管人或者基金销售机构
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 虚假记载、误导性陈述或者重大遗漏会误导投资者，是基金信息披露禁止行为；对证券投资业绩进行预测，投资有不确定性，预测业绩易误导投资者，属于禁止行为；承诺收益或者承担损失，违背投资风险自担原则，误导投资者，是禁止行为；诋毁其他基金管理人、基金托管人或者基金销售机构，不利于公平竞争，破坏市场秩序，也是禁止行为。答案：D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**3.（单选题）** 基金信息披露的及时性原则体现在基金管理人应在重大事件发生之日起（　）日内披露临时报告。
A.1
B.2
C.3
D.5
**答案：** B
**解析：** 基金信息披露及时性原则要求，当发生对基金份额持有人权益或者基金价格产生重大影响的事件时，基金管理人应在2日内编制并披露临时报告书，并分别报中国证监会及地方证监局备案。所以答案是2日。答案：B

**4.（单选题）** 以下不属于基金公司信息披露基本原则的是（　）。
A.便利性
B.完整性
C.及时性
D.真实性
**答案：** A
**解析：** 基金公司信息披露基本原则包括真实性、准确性、完整性、及时性、公平性等，便利性不属于信息披露基本原则。答案：A

**5.（单选题）** 下列关于基金信息披露作用的表述中，正确的有（　）。
Ⅰ、有利于投资者的价值判断
Ⅱ、能有效防止信息滥用
Ⅲ、可以彻底解决证券市场的信息不对称问题
Ⅳ、有利于提高证券市场的效率
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 基金信息披露有利于投资者进行价值判断，Ⅰ正确；能防止信息滥用，Ⅱ正确；虽能缓解但无法彻底解决证券市场信息不对称问题，Ⅲ错误；有助于提高证券市场效率，Ⅳ正确。答案：C

**6.（单选题）** （　）要求披露所有可能影响投资者决策的信息，在披露某一具体信息时，必须对该信息的所有重要方面进行充分的披露。
A.真实性原则
B.规范性原则
C.及时性原则
D.完整性原则
**答案：** D
**解析：** 题目强调要披露所有可能影响投资者决策的信息以及对信息所有重要方面充分披露，这体现的是完整性原则，即披露的信息要全面完整。答案：D

**7.（单选题）** 基金信息披露的原则体现在（　）上。
A.对披露内容和披露形式的要求
B.对披露制度和披露形式的要求
C.对披露法规和披露形式的要求
D.对披露法规和披露制度的要求
**答案：** A
**解析：** 基金信息披露原则包括对披露内容（如真实性、准确性等要求）和披露形式（如规范性、易解性等要求）两方面。选项中只有A提及对披露内容和披露形式的要求。答案：A

**8.（单选题）** 基金信息披露的最根本、最重要的原则是（　）。
A.时效性原则
B.重要性原则
C.真实性原则
D.全面性原则
**答案：** C
**解析：** 真实性原则是基金信息披露最根本、最重要的原则，它要求披露的信息必须是客观真实的，不能有虚假误导成分。其他选项时效性强调信息披露的及时，重要性侧重于重要信息的披露，全面性要求披露信息完整，但都不如真实性关键。答案：C

## 第2节 基金主要当事人的信息披露义务（5题）

**1.（单选题）** 基金管理人召集基金份额持有人大会，应至少提前30日公告大会的事项不包括（　）。
A.基金份额持有人名录
B.会议形式
C.表决方式
D.审议事项
**答案：** A
**解析：** 基金管理人召集基金份额持有人大会，提前30日公告的内容主要是关于会议本身相关安排及审议事宜，像会议形式、表决方式、审议事项都对持有人参与大会及决策很关键，而基金份额持有人名录无需在公告大会事项时公布。答案：A

**2.（单选题）** 基金托管人披露的信息不涉及（　）。
A.代理清算交割
B.会计核算
C.净值复核
D.投资运作
**答案：** D
**解析：** 基金托管人主要负责资产保管、资金清算、资产核算、监督基金管理人投资运作等，不负责投资运作本身的披露，投资运作是基金管理人披露内容。答案：D。

**3.（单选题）** 根据《证券投资基金法》，当代表基金份额（　）以上的基金份额持有人就同一事项要求召开持有人大会，而基金份额持有人大会的日常机构、基金管理人和托管人都不召集的时候，该部分持有人有权自行召集。
A.3％
B.5％
C.10％
D.20％
**答案：** C
**解析：** 《证券投资基金法》规定，当代表基金份额10％以上的基金份额持有人就同一事项要求召开持有人大会，而相关主体不召集时，该部分持有人有权自行召集。所以答案是与规定份额对应的选项。答案：C

**4.（单选题）** 基金信息披露义务人不包括（　）。
A.基金管理人
B.基金代销机构
C.基金托管人
D.召集基金份额持有人大会的基金份额持有人
**答案：** B
**解析：** 基金信息披露义务人主要包括基金管理人、基金托管人、召集基金份额持有人大会的基金份额持有人等。基金代销机构主要职责是销售基金，并非信息披露主体。答案：B

**5.（单选题）** 下列关于基金管理人的信息披露义务所涉及的时间，说法正确的是（　）。
Ⅰ、管理人召集基金份额持有人大会的，应至少提前30日公告大会的召开时间等事项
Ⅱ、基金募集申请经中国证监会注册后，基金管理人应当在基金份额发售的3日前，及时登载和公告相关公告
Ⅲ、在基金合同生效当日，在规定报刊和规定网站上登载基金合同生效公告
Ⅳ、在每季结束后20个工作日内，在指定报刊和管理人网站上披露基金季度报告
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** Ⅰ项：管理人召集基金份额持有人大会，提前30日公告大会召开时间等事项，符合规定。 Ⅱ项：基金募集申请注册后，基金管理人在基金份额发售3日前进行相关公告，是正确流程。 Ⅲ项：基金合同生效次日，而非生效当日登载基金合同生效公告，该项错误。 Ⅳ项：基金管理人应在每季结束后15个工作日内披露基金季度报告，不是20个工作日，该项错误。答案：B

## 第3节 基金募集信息披露（4题）

**1.（单选题）** 下列说法错误的是（　）。
A.不同类别基金的管理费和托管费水平存在差异
B.不同开放式基金的申购、赎回费率可能不同
C.封闭式基金主要通过交易所进行交易
D.封闭式基金主要在基金的直销和代销网点申购和赎回
**答案：** D
**解析：** 封闭式基金在证券交易所上市交易，而开放式基金主要在基金的直销和代销网点申购和赎回，D 选项说法错误。A 选项，不同类别基金因投资标的、风险等不同，管理费和托管费水平有差异；B 选项，不同开放式基金为吸引投资者，申购、赎回费率会不同；C 选项符合封闭式基金交易特点。答案：D

**2.（单选题）** 下列不属于基金合同主要披露事项的是（　）。
A.风险警示内容
B.基金收益分配原则
C.基金管理人管理费提取方式
D.基金份额发售日期
**答案：** A
**解析：** 基金合同主要披露基金募集、运作等关键信息，风险警示内容通常在招募说明书等文件中重点呈现，不属于基金合同主要披露事项。而基金收益分配原则、管理人管理费提取方式、基金份额发售日期都与基金合同密切相关，是基金合同主要披露内容。答案：A

**3.（单选题）** （　）包含两类重要信息，分别是基金管理人和基金托管人之间的相互监督和核查和协议当事人权责约定中事关持有人权益的重要事项。
A.基金公告
B.基金招募说明书
C.基金合同
D.基金托管协议
**答案：** D
**解析：** 基金托管协议是基金管理人和基金托管人签订的协议，其内容涵盖了基金管理人与基金托管人之间相互监督核查以及涉及持有人权益的重要事项。基金公告是各类公开披露信息；基金招募说明书主要是对基金募集相关情况介绍；基金合同虽重要，但题干描述准确指向基金托管协议。答案：D

**4.（单选题）** 下列不属于基金合同包含的重要信息的是（　）。
A.基金投资运作安排方面的信息
B.基金份额发售安排方面的信息
C.基金份额持有人的个人信息
D.基金合同特别约定的事项
**答案：** C
**解析：** 基金合同包含基金投资运作安排、份额发售安排及特别约定等重要信息，而基金份额持有人个人信息属于隐私，不在基金合同包含的重要信息范畴。答案：C

## 第4节 基金运作信息披露（11题）

**1.（单选题）** 为明确信息披露义务人的责任，提醒投资者注意投资风险，目前法规规定应在基金年度报告的扉页做出的提示不包括（　）。
A.投资风险提示
B.托管人管理和运用基金资产的原则
C.会计师事务所出具审计意见的提示
D.管理人和托管人的披露责任
**答案：** B
**解析：** 基金年度报告扉页的提示主要围绕投资风险、审计意见、管理人和托管人披露责任等，而托管人管理和运用基金资产的原则并非在基金年度报告扉页必须做出的提示内容。答案：B

**2.（单选题）** 投资者通过将基金（　）与同期基金业绩比较基准收益率进行比较，可以了解基金实际运作与基金合同规定基准的差异程度，判断基金的实际投资风格。
A.净值增长指标
B.本期利润
C.加权平均份额本期利润
D.加权平均净值利润率
**答案：** A
**解析：** 净值增长指标能直观体现基金在一定时期内资产净值的增长情况，将其与同期基金业绩比较基准收益率对比，可清晰了解基金实际运作与合同规定基准的差异，进而判断投资风格。而本期利润、加权平均份额本期利润、加权平均净值利润率主要侧重于反映基金盈利方面，并非直接用于判断与业绩比较基准的差异及投资风格。答案：A

**3.（单选题）** 以下不在基金财务报表附注中披露的内容是（　）。
A.重要会计政策
B.资产负债表日后非调整事项的说明
C.投资组合重大变动
D.关联方关系及其交易
**答案：** C
**解析：** 基金财务报表附注主要披露重要会计政策、资产负债表日后非调整事项说明、关联方关系及其交易等内容。而投资组合重大变动通常在基金投资组合报告中披露，不在财务报表附注披露。答案：C

**4.（单选题）** 基金年度报告是基金存续期信息披露中信息量最大的文件，应当在每年结束之日起（　）日内予以公告。
A.10
B.30
C.60
D.90
**答案：** D
**解析：** 基金年度报告应在每年结束之日起90日内公告，这是基金信息披露的相关法规规定的时间要求。答案选D。

**5.（单选题）** 下列报告中，必须每季度定期公布的是（　）。
A.基金投资组合报告
B.基金公开说明书
C.内部监察报告
D.基金净值公告
**答案：** A
**解析：** 基金投资组合报告是反映基金在一定时期内投资组合情况的报告，按规定需每季度公布。基金公开说明书不是每季度定期公布；内部监察报告一般不对外公开披露；基金净值公告一般是每个交易日（开放式基金）或至少每周（封闭式基金）公布，并非每季度。答案：A

**6.（单选题）** 以下选项中不属于基金运作信息披露文件的是（　）。
A.基金上市交易公告书
B.基金资产净值和份额净值公告
C.基金定期公告
D.基金份额发售公告
**答案：** D
**解析：** 基金运作信息披露文件包括基金上市交易公告书、基金资产净值和份额净值公告、基金定期公告等。而基金份额发售公告属于基金募集信息披露文件。答案：D

**7.（单选题）** 无需披露上市交易公告书的基金品种是（　）。
A.上市开放式基金
B.封闭式基金
C.开放式基金
D.交易型开放式指数基金
**答案：** C
**解析：** 上市交易公告书是指基金在证券交易所上市交易时需披露的文件，开放式基金一般不在证券交易所上市交易，而上市开放式基金、封闭式基金、交易型开放式指数基金通常会在交易所上市交易。答案：C

**8.（单选题）** 当上市交易基金受到谣言、猜测、投机等因素的影响时，基金信息披露义务人有义务发布（　）。

C.基金临时公告
D.基金变动公告

**9.（单选题）** 关于中期报告的披露，以下说法不正确的是（　）。
A.中期报告无须披露近3年每年的基金收益分配情况

**10.（单选题）** 基金管理人应当在上半年结束之日起（　）日内，编制完成基金中期报告。
A.15
B.30

**11.（单选题）** 当影子定价与摊余成本法确定的基金资产净值负偏离度绝对值超过（　）时，基金管理人应当在2个交易日内向中国证监会派出机构报告。

## 第5节 特殊类型基金的信息披露（5题）

**1.（单选题）** 下列不属于ETF申购赎回清单的内容的是（　）。
A.证券代码及数量
B.现金替代标志
C.最大申购单位
D.最小赎回单位组合证券名称
**答案：** C
**解析：** ETF申购赎回清单主要包括最小申购、赎回单位对应的各组合证券名称、证券代码及数量、现金替代标志等，没有最大申购单位相关内容。答案：C

**2.（单选题）** 基金上市后，ETF基金份额参考净值的实时计算与公布是由（　）负责。
A.基金托管人
B.基金管理人
C.登记结算机构
D.证券交易所
**答案：** D
**解析：** ETF基金份额参考净值是由证券交易所在交易时间内实时计算并公布的，方便投资者交易参考。答案：D。

**4.（单选题）** 基金管理人关于ETF份额参考净值的计算方式，一般需经（　）认可后公告。

**5.（单选题）** 关于基础设施基金季度报告必须披露的内容，以下表述正确的是（　）。
Ⅰ.报告期内基础设施基金份额持有人结构变化情况
Ⅱ.基础设施基金与参与机构费用收取情况
Ⅲ.基础设施项目明细及相关运营情况
Ⅳ.基础设施项目现金流归集及使用情况
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 根据基础设施基金信息披露相关规则，季度报告需聚焦基金核心运作及底层资产情况，具体解析如下：Ⅰ. 基金份额持有人结构变化情况属于年度报告的强制披露内容，季度报告无需必须披露；Ⅱ. 基金与参与机构的费用收取情况，直接反映基金运作成本，是季度报告必须披露的重要信息；Ⅲ. 基础设施项目明细及运营情况（如出租率、收入等）是底层资产价值的核心体现，为季度报告强制披露内容；Ⅳ. 项目现金流归集及使用情况关乎基金收益实现与分配能力，属于季度报告必须披露的关键内容。综上，Ⅱ、Ⅲ、Ⅳ 为季度报告必须披露的内容，答案选 C。

## 第6节 私募基金的信息披露（2题）

**1.（单选题）** 私募基金管理人应当按照规定在（　）指定的私募基金信息披露备份平台备份各类信息披露报告。
A.中国证监会
B.中国人民银行
C.证券交易所
D.中国证券投资基金业协会
**答案：** D
**解析：** 私募基金相关事务多由中国证券投资基金业协会负责管理，信息披露备份平台也是协会指定。答案：D

**2.（单选题）** 某私募基金托管人在履行信息披露义务时，下列行为符合规定的是（　）。
A.为简化流程，未向投资者披露基金承担的业绩报酬情况
B.按照合同约定，如实向投资者说明基金可能存在的利益冲突
C.因担心影响投资者信心，隐瞒了基金真实的资产负债状况
D.向投资者提供了虚假的基金投资收益分配信息
**答案：** B
**解析：** 信息披露应真实、准确、完整，不得隐瞒重要信息或提供虚假信息，同时要按约定披露相关内容。 A选项不披露业绩报酬情况，不符合完整披露要求；C选项隐瞒资产负债状况，不真实；D选项提供虚假收益分配信息，属于欺诈行为。而B选项按合同约定如实说明基金可能存在的利益冲突，符合信息披露规定。答案：B
