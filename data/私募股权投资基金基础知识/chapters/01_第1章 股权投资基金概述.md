# 私募股权投资基金基础知识 · 第1章 股权投资基金概述

## 第1节 股权投资基金概念与特点（17题）

**1.（单选题）** 市场上的股权投资基金通常委托（　）进行管理。
A.商业银行
B.专业机构
C.金融机构
D.私人公司
**答案：** B
**解析：** 股权投资基金专业性较强，通常委托专业机构进行管理，专业机构在投资策略、风险管理等方面具备专业优势。商业银行主要从事存贷款等传统银行业务；金融机构范围宽泛，不如专业机构精准；私人公司不一定具备管理股权投资基金的专业能力。答案：B

**2.（单选题）** 由于股权投资基金管理（　），所以需要建立有效和充分地针对投资管理团队成员的激励约束机制。
A.投资期限长
B.专业性较强
C.投后管理投入资源较多
D.投资收益波动性较大
**答案：** B
**解析：** 股权投资基金管理专业性较强，这要求投资管理团队具备较高专业素养和能力。为确保团队能充分发挥专业优势，实现基金良好运作，就需要建立有效和充分针对团队成员的激励约束机制。其他选项虽也是股权投资基金特点，但与建立针对团队成员激励约束机制的关联性不如专业性强这一特点紧密。答案：B

**3.（单选题）** 私人股权包括未上市企业和上市企业非公开发行和交易的（　）。
A.普通股
B.可转换为普通股的优先股
C.可转换债券
D.以上都是
**答案：** D
**解析：** 私人股权包含未上市企业股权，以及上市企业非公开发行和交易的普通股、可转换为普通股的优先股和可转换债券等。所以以上选项都符合。答案：D

**4.（单选题）** 股权投资基金的专业性体现在（　）。
A.股权投资基金规模大
B.股权投资基金能够获得超额认购
C.股权投资基金都是进行分散投资
D.股权投资基金需要更多的投资经验积累、团队培育和建设
**答案：** D
**解析：** 股权投资基金的专业性主要源于其投资标的的特殊性等，需要更多投资经验积累、团队培育和建设来应对复杂的投资情况，这体现了专业性。A选项规模大不直接等同于专业；B选项超额认购与专业性无关；C选项股权投资基金并非都分散投资，且分散投资也不是专业性的主要体现。答案：D

**5.（单选题）** 股权投资基金包括的种类有（　）。
Ⅰ未上市企业非公开发行的普通股
Ⅱ已上市企业非公开交易的普通股
Ⅲ未公开发行的可转换为普通股的优先股
Ⅳ未公开发行的可转换为普通股的可转换债券
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅲ、Ⅳ
C.Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 股权投资基金主要投资于未上市企业股权或上市企业非公开交易股权等，未上市企业非公开发行的普通股、已上市企业非公开交易的普通股属于此类。同时，未公开发行的可转换为普通股的优先股和可转换债券，在转换后也相当于对企业进行股权类投资。所以这四类都属于股权投资基金涵盖的种类。答案选D。

**6.（单选题）** 下列关于我国股权投资基金的说法中，正确的是（　）。
A.通常具有低风险、低预期收益的特点
B.主要投资于上市公司股票
C.只能非公开募集
D.投资期限较短
**答案：** C
**解析：** 股权投资基金通常具有高风险、高预期收益特点，A 错误；主要投资于非上市公司股权，B 错误；投资期限较长，D 错误。我国股权投资基金只能非公开募集。答案：C。

**7.（单选题）** 股权投资基金通常被描述为“有耐心的资本”，是因为（　）。
A.股权投资基金主要投资于未上市企业股权或上市企业的非公开交易股权，通常需要5年以上才能完成投资的全部流程实现退出
B.股权投资基金的监管通常较为严格，因此关于基金设立与权益登记的合规流程通常需要较长的时间周期
C.募集资金的对象通常为机构投资人、高净值人群，其关于基金管理人的选择通常需经过“耐心的”筛选过程
D.股权投资基金的分配一定需要等到基金清算时才可进行，因此从投入资金到收回收益需要较长的时间周期
**答案：** A
**解析：** 股权投资基金投资的未上市企业股权或上市企业非公开交易股权，投资周期长，一般5年以上才完成投资到退出流程，所以被称为“有耐心的资本”。A选项准确阐述这一原因。B选项说的是监管和合规流程时间长，与“有耐心的资本”本质原因无关；C选项说投资人筛选管理人时间长，并非基金本身被称为“有耐心的资本”的原因；D选项说基金分配要到清算时，这不是其被称为“有耐心资本”的关键，且表述不准确，股权投资基金并非一定等到清算才分配。答案：A

**8.（单选题）** 下列属于股权投资基金特点的有（　）。
Ⅰ投资期限较长
Ⅱ专业性较强
Ⅲ流动性较差
Ⅳ投资收益波动性较为平稳
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅲ、Ⅳ
C.Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 股权投资基金通常投资于未上市企业股权等，企业成长需要时间，所以投资期限较长，Ⅰ正确。 股权投资涉及对企业价值评估、行业分析等专业知识，专业性较强，Ⅱ正确。 其投资的股权在未上市前或特定阶段较难快速变现，流动性较差，Ⅲ正确。 股权投资受企业经营、市场环境等影响大，投资收益波动性较大，并非平稳，Ⅳ错误。答案：A

**9.（单选题）** “私人股权投资基金”指主要投资于（　）的股权。
A.非公开发行
B.非公开交易
C.公开发行和交易
D.非公开发行和交易
**答案：** D
**解析：** 私人股权投资基金主要投资于非公开发行和交易的股权，这是其显著特点，与投资公开发行和交易股权的投资形式相区别。答案：D

**10.（单选题）** 私人股权包括（　）。
A.企业债
B.公司债
C.可转债
D.私募债
**答案：** C
**解析：** 答案：C私人股权通常指的是非上市公司的股权或对上市公司的非公开交易股权。在这四个选项中，只有可转债（可转换债券）在特定条件下可以转换为公司的股权，因此属于私人股权的一种。企业债、公司债和私募债都是债务工具，不属于股权范畴。

**11.（单选题）** 与其他资产类别相比，股权投资基金通常具有（　）特点。
A.高期望收益、低风险
B.高期望收益、高风险
C.低期望收益、高风险
D.低期望收益、低风险
**答案：** B
**解析：** 股权投资基金投资的项目，若成功回报可能极高，比如投资早期创业公司成功上市可获巨额收益；但投资失败概率也大，比如众多创业项目会失败，血本无归。所以与其他资产类别相比，股权投资基金是高期望收益、高风险的特点。答案：B

**12.（单选题）** 股权投资通常被称为（　）。
A.有耐心的资本
B.价值投资
C.私人投资
D.以上都不是
**答案：** A
**解析：** 股权投资周期相对较长，从投资到退出可能历经数年，投资者需有耐心等待企业成长和价值提升，所以常被称作“有耐心的资本” 。答案：A

**13.（单选题）** 股权投资基金的基金份额流动性（　）。
A.较好
B.一般
C.较差
D.以上都不是
**答案：** C
**解析：** 股权投资基金主要投资于未上市企业股权或上市企业非公开交易股权，其投资期限长、退出渠道有限，不像股票等资产能在公开市场快速交易，所以基金份额流动性较差。答案：C

**14.（单选题）** 股权投资基金投资后管理阶段投入资源（　）。
A.较少
B.一般
C.较多
D.以上都不是
**答案：** C
**解析：** 投资后管理对股权投资基金十分重要，需要投入大量资源来监控被投资企业、提供增值服务等，以保障投资收益和降低风险。所以投资后管理阶段投入资源较多。答案：C

**15.（单选题）** 股权投资基金对专业性的要求较高，需要更多的投资经验积累、团队培育和建设，体现出较明显的（　）密集型特征。
A.体力
B.智力
C.资本
D.以上都不是
**答案：** B
**解析：** 股权投资基金因对专业性要求高，需投资经验积累、团队培育建设等，这都依赖于人的智慧和知识，所以体现智力密集型特征。答案：B

**16.（单选题）** 由于股权投资基金管理对专业性的高要求，市场上的股权投资基金通常（　）。

**17.（单选题）** 关于股权投资基金的投资对象私人股权，不包括（　）。

## 第2节 股权投资基金基本的基本运作模式（14题）

**1.（单选题）** 基金的收入扣除基金承担的（　）之后，首先用于返还基金投资者的投资本金。
A.各项费用
B.税收
C.成本
D.包括A和B
**答案：** D
**解析：** 基金收入在分配时，需先扣除各项费用以及缴纳税收后，才会开始返还投资者本金。所以答案选D，因为各项费用和税收都要扣除。

**2.（单选题）** 在投资阶段，基金管理机构将资金投向被投资企业：这一阶段主要包括（　）
I开发与初审
II签署投资备忘录
III尽职调查
IV签订投资协议
V信息披露
A.I、II、III、IV
B.I、II、III、V
C.I、III、IV、V
D.II、III、IV、V
**答案：** A
**解析：** 投资阶段包括项目开发与初审、签署投资备忘录、尽职调查、投资决策、签订投资协议等，信息披露不属于投资阶段主要内容，它贯穿基金运作全过程。答案：A

**3.（单选题）** 股权投资基金的基本运作流程包括（　）。
Ⅰ退出
Ⅱ管理
Ⅲ投资
Ⅳ募集
A.Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅲ、Ⅳ
**答案：** C
**解析：** 股权投资基金运作流程为募集资金（Ⅳ），然后进行项目投资（Ⅲ），投资后对项目进行管理（Ⅱ），最后选择合适时机退出（Ⅰ），这四个环节构成其基本运作流程。答案：C

**4.（单选题）** 基金规模包括________和________。（　）
A.计划募资规模；实际募资规模
B.计划募资规模；承诺募资规模
C.实际募资规模；认缴募资规模
D.实际募资规模；承诺募资规模
**答案：** C
**解析：** 依据股权投资基金教材，基金规模是全体投资者对基金出资的总和，分为认缴出资规模与实缴出资规模：认缴出资规模即投资者承诺认缴的出资总额，实缴出资规模即投资者实际缴付到位的出资总额。对应本题，即"实际募资规模；认缴募资规模"。故本题选C。

**5.（单选题）** 基金自建投资管理团队并负责基金的投资决策，这种管理方式称为（　）。
A.受托管理

C.决策管理
D.自我管理
**答案：** D
**解析：** 基金自我管理即基金自建投资管理团队并负责基金的投资决策，符合题目描述。答案：D

**6.（单选题）** 基金的投资策略，即基金在选择具体投资对象时所使用的一系列_______、_______和_______的总和。（　）

**7.（单选题）** 股权投资基金从被投资企业中退出的方式包括（　）。

**8.（单选题）** 股权投资基金的募集对象通常只能是（　）。
A.公司

**答案：** B
**解析：** 股权投资基金风险相对较大，为保护投资者利益，其募集对象通常只能是具备相应风险识别和承担能力的合格投资者。答案：B

**9.（单选题）** 国内股权投资基金与国外股权投资基金的主要区别是（　）。
A.投资标的不同

**答案：** B

**10.（单选题）** 关于股权投资基金收益分配方式的说法，正确的是（　）。
Ⅰ.收益主要在投资者和第三方服务机构之间进行分配
Ⅱ.基金管理人因为其管理可以获得一定比例的业绩报酬
Ⅲ.基金的收入扣除基金承担的各项费用和税收之后，超出投资者出资本金的部分为基金利润
Ⅳ.有时候管理人需要先让基金投资者实现某一门槛收益率，之后才可获得业绩报酬
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 股权投资基金收益主要在投资者与基金管理人之间分配，并非投资者和第三方服务机构之间，所以Ⅰ错误。 基金管理人会因管理获得一定比例业绩报酬，Ⅱ正确。 基金收入扣除各项费用和税收后，超出投资者出资本金部分就是基金利润，Ⅲ正确。 实践中常设定门槛收益率，满足后管理人方可获业绩报酬，Ⅳ正确。答案：D

**11.（单选题）** 股权投资基金投资者可以从基金收入分配中获得（　）。
Ⅰ本金
Ⅱ投资收益
Ⅲ管理费
Ⅳ业绩报酬
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** A
**解析：** 股权投资基金投资者是基金的出资人，会获得本金和投资收益。而管理费是基金管理人为管理基金资产而收取的费用，业绩报酬是基金管理人在基金获得超额收益后提取的，都不属于投资者获得的，所以投资者能获得本金和投资收益。答案：A

**12.（单选题）** 股权投资基金在退出阶段采用的变现方式不包括（　）。
A.上市
B.清算
C.挂牌转让

B.基金产品的设计、基金份额的销售与备案、基金资产的管理等重要职能均由基金管理人承担
