# 私募股权投资基金基础知识 · 第6章 股权投资基金的投资后管理

## 第1节 投资后管理概述（20题）

**1.（单选题）** 股权投资基金管理人一般通过（　）参与投资后管理，获取被投资企业信息。
Ⅰ参与被投资企业股东大会(股东会)、董事会、监事会
Ⅱ关注被投资企业经营状况
Ⅲ日常联络和沟通工作
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅲ
C.Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** D
**解析：** 股权投资基金管理人参与投资后管理获取被投资企业信息的方式包括参与被投资企业股东大会（股东会）、董事会、监事会，可直接获取重要决策等信息；关注被投资企业经营状况能掌握其运营情况；日常联络和沟通工作有助于及时了解各种动态。这三种方式都可行。答案：D

**2.（单选题）** 董事会的职责有（　）。
Ⅰ批准公司发展战略
Ⅱ审议公司年度财务预算与决算
Ⅲ聘任和解聘公司高级管理人员
Ⅳ决定公司高级管理人员的薪酬和考核与激励制度
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 董事会职责广泛，批准公司发展战略可从宏观把控方向；审议年度财务预算与决算关乎公司资金安排；聘任和解聘高级管理人员及决定其薪酬等制度，能有效管理公司高层团队，促进公司运营。这几方面都属于董事会职责。答案：D。

**3.（单选题）** 股东大会是公司的最高权力机构，其职责不包括（　）。
A.修改公司章程
B.审批重大关联交易
C.批准公司发展战略
D.聘任和解聘公司董事
**答案：** C
**解析：** 批准公司发展战略一般是董事会的职责，而非股东大会职责。股东大会主要对公司重大事项如修改章程、审批重大关联交易、聘任和解聘董事等作出决策。答案：C

**4.（单选题）** 对于股权投资基金而言，投资后管理的作用不包括（　）。
A.有利于及时了解被投资企业经营运作情况，并根据不同情况及时釆取必要措施，保证资金安全
B.有利于提升被投资企业自身价值，增加投资收益
C.对股权投资基金参与企业后续融资时的决策也起到重要的决策支撑作用
D.确保不会因公司以更低的发行价进行新一轮融资而导致投资人的股权被稀释从而投资被贬值
**答案：** D
**解析：** 投资后管理作用主要体现在对被投企业经营情况把控以保障资金安全（A选项）、提升被投企业价值增加收益（B选项）以及为后续融资决策提供支撑（C选项）。而D选项中“确保不会因公司以更低的发行价进行新一轮融资而导致投资人股权被稀释从而投资被贬值”表述过于绝对，投资后管理虽可一定程度应对股权稀释问题，但无法绝对确保不出现这种情况。答案：D

**5.（单选题）** 投资后管理的作用包括（　）。
Ⅰ保证资金安全
Ⅱ提升被投资企业自身价值
Ⅲ协助被投资企业利用资本市场
Ⅳ促进投资收益
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 投资后管理对投资项目至关重要。它能通过各种措施保障投入资金的安全，即保证资金安全（Ⅰ）；通过提供资源、经验等助力被投资企业成长，提升其自身价值（Ⅱ）；还能凭借自身经验和资源协助被投资企业进入资本市场，如上市等（Ⅲ）；这些举措最终都会有助于促进投资收益（Ⅳ）。答案：D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**6.（单选题）** 在公司的治理结构中，负责修改公司章程的是（　）。
A.股东大会
B.董事会
C.监事会
D.高管团队
**答案：** A
**解析：** 公司章程是公司的基本大法，修改公司章程属于公司重大事项决策。在公司治理结构中，股东大会是公司的权力机构，决定公司重大事项，修改公司章程属于其职权范围。董事会主要负责执行决策等，监事会负责监督，高管团队负责日常经营管理，都无修改公司章程权力。答案：A

B.定期举行业务考核
C.日常联络与沟通工作
D.关注被投资企业经营状况

Ⅰ、投资机构对被投资企业进行的项目跟踪活动

**11.（单选题）** 投资后管理的作用有（　）。
Ⅰ.投资后的增值服务有利于提升被投资企业的自身价值，增加投资收益
Ⅱ.投资后管理对股权投资基金参与企业后续融资时的决策也起到重要的决策支撑作用
Ⅲ.投资后管理对股权投资基金提供全面的数据服务，增加服务信息
Ⅳ.投资后的项目监控有利于及时了解被投资企业经营运作情况，并根据不同情况及时采取必要措施，保证资金安全
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**12.（单选题）** 下列属于股权投资基金管理人参与投资后管理渠道和方式的是（　）。
Ⅰ.日常联络和沟通工作
Ⅱ.关注被投资企业经营状况
Ⅲ.帮助被投资企业进行经营决策
Ⅳ.参与被投资企业股东大会、董事会、监事会
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 这道题目考察的是股权投资基金管理人在投资后管理的渠道和方式。我们可以从以下几个方面进行简析：### 股权投资基金管理人的投资后管理股权投资基金管理人在完成投资后，通常会通过多种方式和渠道参与被投资企业的管理，以确保投资的安全和增值。### 分析各选项 Ⅰ.日常联络和沟通工作：这是最基本的管理方式，通过日常联络和沟通，管理人可以及时了解企业的运营情况。 Ⅱ.关注被投资企业经营状况：这是投资后管理的核心内容之一，管理人需要密切关注企业的财务状况和市场表现。 Ⅲ.帮助被投资企业进行经营决策：虽然管理人可能会提供建议，但直接参与经营决策并不是其主要职责。管理人的角色更多是监督和建议，而不是直接干预。 Ⅳ.参与被投资企业股东大会、董事会、监事会：这是管理人参与企业管理的重要方式，通过参与这些会议，管理人可以对企业的重大决策进行监督和影响。### 结论根据上述分析，Ⅰ、Ⅱ和Ⅳ是股权投资基金管理人参与投资后管理的常见渠道和方式，而Ⅲ项“帮助被投资企业进行经营决策”并不是主要的管理方式。所以，正确答案是B选项：“Ⅰ、Ⅱ、Ⅳ”。

**13.（单选题）** 关于投资后管理，以下表述错误的是（　）。
A.在投资交割之后直到项目退出之前都属于投资后管理的期间
B.投资后管理的作用包括提升被投资企业自身价值、管理和防范投资风险等
C.投资后管理是指股权投资基金(或其他类型投资机构)与被投资企业投资交割之后，基金管理人积极参与被投资企业的管理，对被投资企业实施项目监控并提供各项增值服务的一系列活动
D.投资后管理阶段自投资决策委员会通过投资决策起至投资项目完全退出止
**答案：** D
**解析：** 投资后管理是从投资交割之后到项目退出之前的期间开展的对被投资企业的管理和服务等活动。 A选项符合投资后管理时间范围的描述；B选项阐述的投资后管理作用正确；C选项对投资后管理定义的表述准确。 D选项错误，投资后管理阶段是从投资交割后开始，而不是自投资决策委员会通过投资决策起，投资决策通过后到投资交割还有一系列流程。答案：D

**15.（单选题）** 关于投资机构投资后管理阶段获取信息的方式，以下表述错误的是（　）。

**16.（单选题）** 不属于股权投资基金的投资后管理的是（　）。

**17.（单选题）** 关于投资后管理，表述错误的是（　）。

**20.（单选题）** （　）决定公司高级管理人员的薪酬、考核与激励制度。

B.监事会

## 第2节 投后管理模式、决策机制、组织架构及制度体系（15题）

**1.（单选题）** 以下不属于股权投资基金对被投资企业的监控通常会采取的方式的是（　）。
A.跟踪协议条款执行情况
B.监控被投资企业的各类经营指标与财务状况
C.参与被投资企业的公司治理
D.提供增值服务
**答案：** D
**解析：** 对被投资企业监控方式主要围绕协议、经营财务、公司治理等方面。而提供增值服务并非监控方式，是为企业创造价值的手段。答案：D

**2.（单选题）** 投资机构对被投资企业风险监控的重要途径之一是对被投资企业的财务状况进行（　），以便及时发现生产经营中的重大变化，及时采取改善措施。
A.监管和分析

Ⅲ、存货周转率
Ⅳ、负债率
