# 私募股权投资基金基础知识 · 第5章 股权投资基金的投资

## 第1节 股权投资的一般流程（12题）

**1.（单选题）** 股权投资基金投资的一般流程通常包括（　）。
Ⅰ项目开发与筛选
Ⅱ项目立项
Ⅲ签署投资框架协议
Ⅳ尽职调查、投资决策
V签署投资协议
Ⅵ投资后管理、项目退出
A.Ⅰ、Ⅲ、Ⅳ、Ⅵ
B.Ⅰ、Ⅱ、Ⅳ、V、Ⅵ
C.Ⅰ、Ⅱ、Ⅲ、Ⅳ、V、Ⅵ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ、V
**答案：** D
**解析：** 股权投资基金投资的一般流程聚焦于 “投资实施” 阶段，核心是从项目发掘到完成投资交割的全链条环节。Ⅰ 项目开发与筛选是起点，负责发掘并初步筛选潜在投资项目；Ⅱ 项目立项是对筛选后的项目进行内部审批，确立正式调查资格；Ⅲ 签署投资框架协议为后续谈判设定基础条款；Ⅳ 尽职调查、投资决策是深入核查项目并决定是否投资的关键环节；Ⅴ 签署投资协议标志着投资正式达成。而 Ⅵ 投资后管理、项目退出属于投资交割完成后的后续阶段，不属于 “投资的一般流程” 范畴。综上，Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ 均为投资一般流程的组成部分，答案为 D。

**2.（单选题）** 股权投资基金管理人设立（　）对投资项目行使投资决策权。
A.董事会
B.理事会
C.投资决策委员会
D.股东大会
**答案：** C
**解析：** 股权投资基金管理人通常设立投资决策委员会来对投资项目行使投资决策权，董事会、理事会、股东大会并非专门针对投资项目决策设立，更多涉及公司整体治理等方面。答案：C。

**3.（单选题）** 股权投资基金通常由（　）行使投资决策权。
A.董事会
B.基金经理
C.基金份额持有人
D.投资决策委员会
**答案：** D
**解析：** 投资决策委员会是股权投资基金管理运作中至关重要的环节，负责行使投资决策权。董事会主要是公司制企业治理结构相关；基金经理主要负责执行投资决策等具体事务；基金份额持有人主要是投资者，一般不直接行使投资决策权。答案：D

**4.（单选题）** 股权投资基金投资流程包括（　）。
Ⅰ项目开发与筛选
Ⅱ初步尽职调查
Ⅲ项目立项
Ⅳ签署投资框架协议
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** A
**解析：** 股权投资基金投资流程一般包括项目开发与筛选、初步尽职调查、项目立项、签署投资框架协议、尽职调查、投资决策、签署投资协议、投资交割等主要环节，题中Ⅰ、Ⅱ、Ⅲ、Ⅳ均属于投资流程内容。答案：A

**5.（单选题）** （　）阶段，对目标公司业务、财务与法律进行非常详尽而深入的调查与了解。
A.尽职调查
B.初步尽职调查
C.项目开发与筛选
D.决策调查
**答案：** A
**解析：** 尽职调查就是对目标公司业务、财务与法律进行详尽深入的调查了解。初步尽职调查相对没那么详尽深入，项目开发与筛选主要聚焦项目发掘和挑选，不存在“决策调查”这种常见投资术语。答案：A

**6.（单选题）** 下列关于投资决策的说法，错误的是（　）。
A.股权投资基金管理人通常设立投资决策委员会行使投资决策权
B.投资决策委员会委员聘任和议事规则制定通常由投资管理人董事会或执行事务合伙人负责
C.投资决策委员会委员只能由股权投资基金管理人的高级管理团队成员担任
D.投资决策委员会进行最终投资决策
**答案：** C
**解析：** 投资决策委员会委员不只能由股权投资基金管理人的高级管理团队成员担任，还可能包括外部专家等，C选项说法过于绝对。A选项，管理人常设投资决策委员会行使决策权；B选项，其委员聘任和议事规则通常由投资管理人董事会或执行事务合伙人负责；D选项，投资决策委员会确实进行最终投资决策。答案：C

**7.（单选题）** 股权投资基金投资流程围绕（　）展开。
A.项目立项
B.尽职调查
C.投资决策
D.签署投资意向书
**答案：** C
**解析：** 股权投资基金投资流程主要是为了做出是否投资的决策，项目立项、尽职调查、签署投资意向书等都是为投资决策服务的，投资决策处于核心位置，投资流程围绕它展开。答案：C

**8.（单选题）** （　）不属于中介机构推荐的项目来源。
A.律师事务所
B.会计师事务所
C.财务顾问
D.基金公司
**答案：** D
**解析：** 律师事务所、会计师事务所、财务顾问在业务过程中可能接触各类项目并向相关方推荐。而基金公司主要业务是募集资金、投资管理等，并非像前三者那样以给其他主体推荐项目为常见业务。答案：D

**9.（单选题）** 初步尽职调查的核心是对拟投资项目进行（　）。
A.价值判断
B.信用评估
C.风险预测
D.投资分析
**答案：** A
**解析：** 初步尽职调查主要是对项目的初步价值进行判断，看项目是否值得深入研究，而信用评估、风险预测、投资分析相对更深入，不是初步尽职调查核心。答案：A

**10.（单选题）** 投资意向书也称投资条款清单，通常由（　）提出。
A.基金托管人
B.领投方
C.投资决策委员会
D.目标公司
**答案：** B
**解析：** 投资意向书通常是由投资方提出，领投方属于投资方。基金托管人主要负责资产保管等，不负责提出投资意向书；投资决策委员会是内部决策机构，一般不是提出投资意向书主体；目标公司是被投资方，不是提出意向书的一方。答案：B

**11.（单选题）** 股权投资业务流程中不可或缺的一个环节是（　），通常被视为投资管理人核心竞争力的体现。
A.项目立项
B.投资决策
C.尽职调查
D.投资交割
**答案：** C
**解析：** 尽职调查能充分了解目标企业，为投资决策提供关键依据，对投资成功与否影响重大，是投资管理人核心竞争力体现且是股权投资业务流程关键环节。答案：C

**12.（单选题）** 尽职调查的主要内容不包括（　）。
A.业务
B.财务
C.法律
D.管理
**答案：** D
**解析：** 尽职调查主要围绕业务、财务、法律三方面展开，管理不属于尽职调查主要内容。答案：D

## 第2节 投资调查与分析（34题）

**1.（单选题）** 尽职调查的作用：
I价值发现
II风险发现
III投资决策辅助
A.I、II、III
B.I、II
C.I、III
D.II、III
**答案：** A
**解析：** 尽职调查能够发现目标企业的潜在价值，即价值发现；也能识别出可能存在的风险，也就是风险发现；同时为投资方做出投资决策提供辅助参考。所以尽职调查具有价值发现、风险发现、投资决策辅助这三方面作用。答案选A。

**2.（单选题）** 下列哪项不是尽职调查的内容：
A.业务尽职调查
B.财务尽职调查
C.法律尽职调查
D.信用尽职调查
**答案：** D
**解析：** 尽职调查通常包括业务、财务、法律这三方面的尽职调查。信用方面一般不是独立的尽职调查类别，多融入在其他调查中。答案选D。

**3.（单选题）** 在股权投资基金投资运作流程中，财务尽职调查对（　）起到重大作用。
I了解目标公司资产负债
II内部控制
III充分揭示其财务风险
IV企业基本情况
A.I、II、III
B.I、II
C.I、II、III、IV
D.II、III、IV
**答案：** A
**解析：** 财务尽职调查主要聚焦于目标公司财务相关方面。了解目标公司资产负债是财务尽职调查的重要内容，能清晰掌握公司财务状况；内部控制关乎财务信息可靠性等，财务尽职调查会关注；充分揭示财务风险更是其核心任务之一。而企业基本情况包含较宽泛，比如企业历史沿革等非财务重点方面，财务尽职调查虽会涉及但并非重大作用于这一宽泛概念。所以答案选A，财务尽职调查对I了解目标公司资产负债、II内部控制、III充分揭示其财务风险起到重大作用。

**4.（单选题）** 在企业财务尽职调查中，对于利润表，重点核查的对象不包括（　）
A.收入确认
B.销售成本
C.期间费用核算的规范性
D.存货周转
**答案：** D
**解析：** 利润表主要反映企业在一定会计期间的经营成果，收入确认、销售成本、期间费用核算规范性都直接影响利润表数据。而存货周转主要涉及存货管理效率，与资产负债表中存货项目联系紧密，不属于利润表重点核查对象。答案：D

**5.（单选题）** 在企业财务尽职调查中，对于公司披露的参股子公司，应获取（　）的财务报告及审计报告。
A.最近半年
B.最近一年
C.最近三年
D.最近3个月
**答案：** B
**解析：** 尽职调查中对参股子公司一般获取最近一年财务报告及审计报告，以较全面了解其经营财务状况，时间过短无法展现全貌，时间过长信息相关性减弱。答案：B

**6.（单选题）** （　）是指计算公司各年度毛利率、资产收益率、净资产收益率等，分析公司各年度盈利能力及其变动情况，分析和判断公司盈利能力的持续性。
A.盈利能力分析
B.财务比率分析
C.偿债能力分析
D.运营能力分析
**答案：** A
**解析：** 题目强调计算毛利率、资产收益率等指标，分析公司盈利能力及其变动和持续性，这显然围绕盈利能力展开。答案：A。因为A选项“盈利能力分析”最符合题目对通过计算特定指标来分析公司盈利能力相关内容的描述。

**7.（单选题）** 偿债能力分析是通过计算公司各年度（　）等，结合公司的现金流量状况、在银行的资信状况、可利用的融资渠道及授信额度、表内负债、表外融资及或有负债等情况，分析公司各年度偿债能力及其变动情况，判断公司的偿债能力和偿债风险。
I资产负债率
II流动比率
III速动比率
IV利息保障倍数
V存货周转率
A.I、II、III、V
B.I、II、III、IV
C.I、III、IV、V
D.II、III、IV、V
**答案：** B
**解析：** 存货周转率是反映公司营运能力的指标，用于衡量存货运营效率，与偿债能力无关。 资产负债率衡量长期偿债能力；流动比率和速动比率衡量短期偿债能力；利息保障倍数衡量支付利息的能力，与偿债相关。所以I资产负债率、II流动比率、III速动比率、IV利息保障倍数都用于偿债能力分析。答案：B

**8.（单选题）** 综合评价是指通过对公司的（　）分析，与同行业可比公司的财务指标比较，综合分析公司的财务风险和经营风险，判断公司财务状况是否良好，是否存在持续经营问题。

II偿债能力分析
III运营能力分析
IV负债能力分析
A.II、III、IV
B.I、II、IV
C.I、II、III

**9.（单选题）** 在法律尽职调查关注的重点问题中，应重点关注的问题是主要股东与目标公司之间的关联交易、资金往来及相互担保是否合法，这是属于（　）的内容。

**10.（单选题）** 一份详尽的尽职调查工作计划不包括：

**11.（单选题）** 所谓二手资料，是指股权投资基金按照尽职调查的目的收集、整理的各种现成的资料，又称（　）

**13.（单选题）** （　）在尽职调查工作中，起着防范风险、提高尽职调查质量的作用，属于股权投资机构内部的自我监督机制。

**14.（单选题）** 股权投资基金法律尽职调查的作用不包括（　）。
A.评估企业资产的合法性
B.评估企业业务的合法性
C.评估企业债务的合法性
D.评估企业潜在的法律风险
**答案：** C
**解析：** 法律尽职调查主要围绕目标企业的法律合规方面展开，评估潜在法律风险以及业务、资产、债务等合法性。选项A、B、C都属于法律尽职调查对企业不同方面合法性的评估内容。而题目问的是“不包括”，答案选没有涵盖在法律尽职调查作用范畴内的选项。股权投资基金法律尽职调查重点不在单独强调债务合法性（债务合法性只是调查中可能涉及的一部分，并非其作用的单独分类）。答案：C。

**15.（单选题）** 实施尽职调查前由股权投资基金组建一个尽职调查小组，小组成员不包括（　）。

**16.（单选题）** 下列内容文件不属于尽职调查报告的附件部分的是（　）。

A.如果A基金选择行使随售权，则可以用每股10元的价格向第三方出售10000股，创始股东可同时出售
B.如果A基金选择行使随售权，则可以按每股10元的价格向第三方出售20000股，创始股东将无法出售任何股票
C.如果A基金同时拥有第一拒绝权和随售权，通常先选择行使随售权再行使第一拒绝权
D.如果A基金选择行使随售权，则可以用每股10元的价格向第三方出售8000股，创始股东可同时出售12000股
**答案：** D
**解析：** 随售权是指目标公司的其他股东欲对外出售股权时，股权投资基金有权以其持股比例为基础，以同等条件参与该出售交易。A基金持股比例40%，创始人出售20000股，A基金按比例可出售20000×40% = 8000股，创始人出售20000 - 8000 = 12000股。第一拒绝权是指目标公司的其他股东对外出售股权时，作为老股东的股权投资基金在同等条件下有优先购买权，与随售权行使顺序通常是先第一拒绝权，若放弃才可能行使随售权。答案：D
