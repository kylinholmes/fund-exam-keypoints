# 私募股权投资基金基础知识 · 第2章 股权投资基金管理人

## 第1节 股权投资基金管理人概述（5题）

**1.（单选题）** 股权投资基金的主要特征不包括（　）。
A.向合格投资者非公开募集资金
B.委托管理人进行管理
C.投向公开交易的企业股权类资产
D.依托专业机构运作
**答案：** C
**解析：** 股权投资基金主要投向未公开交易的股权，C选项说投向公开交易的企业股权类资产不符合其特征。而A向合格投资者非公开募集、B委托管理人管理、D依托专业机构运作都是股权投资基金常见特征。答案：C

**2.（单选题）** 股权投资基金管理人的经营活动要（　）。
A.为自身利益
B.为基金投资者利益
C.兼顾自身和投资者利益
D.优先考虑行业利益
**答案：** B
**解析：** 股权投资基金管理人应秉持基金份额持有人利益优先原则，其经营活动目的是为基金投资者利益服务。答案：B

**3.（单选题）** 股权投资基金管理人在完成（　）之后方可开展基金募集、基金管理等业务活动。
A.工商注册
B.税务登记
C.管理人登记
D.产品备案
**答案：** C
**解析：** 股权投资基金管理人只有先完成管理人登记，才具备合法开展基金募集、管理等业务活动的资格，工商注册、税务登记并不直接关联基金业务开展资格，产品备案是在基金募集完成后进行的。答案：C

**4.（单选题）** 基金管理人的资本金出资要求中，关于出资形式说法正确的是（　）
A.可以实物出资
B.可以知识产权出资
C.应当以货币出资
D.可以土地使用权出资
**答案：** C
**解析：** 基金管理人的资本金出资要求一般规定应当以货币出资，因为货币资金具有确定性、流动性等优势，能更直接保障基金管理业务开展所需资金。其他如实物、知识产权、土地使用权等出资形式可能存在价值评估复杂、变现困难等问题。答案：C

**5.（单选题）** 下列属于基金管理人职责的是（　）。
A.代替投资者进行投资决策
B.按照基金合同约定向投资者提供与基金管理业务活动相关的信息
C.决定基金的投资方向不受合同约束
D.不保存基金财产管理业务活动的记录
**答案：** B
**解析：** 基金管理人要按照基金合同约定履行职责。选项A，投资者自行做投资决策，基金管理人不能代替；选项C，基金投资方向应受基金合同约束；选项D，基金管理人需妥善保存基金财产管理业务活动的记录等资料。而选项B，按照基金合同约定向投资者提供与基金管理业务活动相关信息是基金管理人职责之一。答案：B

## 第2节 股权投资基金管理人的信义义务（3题）

**1.（单选题）** 信义义务包括（　）。
A.忠实义务与谨慎义务
B.忠实义务与风险义务
C.勤勉义务与谨慎义务
D.忠实义务与勤勉义务
**答案：** D
**解析：** 信义义务通常指的是公司董事等对公司负有的义务，主要包含忠实义务与勤勉义务。忠实义务要求董事等人员将公司利益置于首位，不得谋取私利；勤勉义务要求以合理谨慎和专业能力履行职责。所以答案是D。

**2.（单选题）** 基金管理人向被投企业收取咨询费等费用时，若未事先与投资者达成一致，这些费用原则上应（　）。
A.归基金管理人所有
B.归被投企业所有
C.归入基金收益
D.捐赠给公益机构
**答案：** C
**解析：** 基金管理人向被投企业收取费用，若未与投资者事先达成一致，从保护投资者利益和基金运作规范角度，这些费用应归入基金收益，因为基金收益本就涉及投资者权益。答案：C

**3.（单选题）** 基金管理人在处理不同基金、管理人自有资金等之间的投资机会分配时，需避免（　）。
A.优先满足机构投资者需求
B.对不同投资者形成不公平对待
C.过多投资早期项目
D.投资机会分配过于集中
**答案：** B
**解析：** 基金管理人处理投资机会分配，核心原则是公平，不能对不同投资者形成不公平对待。A选项优先满足机构投资者需求不一定就不公平；C选项过多投资早期项目与投资机会分配公平性无关；D选项投资机会分配过于集中不直接等同于对投资者不公平。答案：B

## 第3节 股权投资基金管理人的专业要求（3题）

**1.（单选题）** 创业投资基金对被投企业进行投后增值服务，重点之一是（　）。
A.帮企业扩大生产规模
B.协助企业开展市场营销
C.提升企业管理能力
D.为企业寻找更多融资渠道
**答案：** C
**解析：** 创业投资基金投后增值服务重点在于提升被投企业内在价值，提升企业管理能力有助于从根本上增强企业竞争力与运营效率，相比其他选项对企业长远发展更为关键。答案：C

**2.（单选题）** 基金管理人投资管理体系需覆盖的流程不包括（　）。
A.行业研究与项目开发
B.项目筛选、尽职调查
C.投资决策、投后管理
D.员工绩效考核
**答案：** D
**解析：** 基金管理人投资管理体系流程主要围绕投资项目展开，包括从项目开发、筛选、调查到投资决策、投后管理等环节。而员工绩效考核是人力资源管理方面内容，并非投资管理体系所覆盖流程。答案：D

**3.（单选题）** 从内部控制角度看，保障基金管理人专业审慎的重要做法是（　）。
A.让投资团队独立完成项目风险评估
B.保持风险控制团队与投资团队的相对独立性
C.仅依靠投资团队的专业水平
D.减少风险控制团队的参与
**答案：** B
**解析：** 保障基金管理人专业审慎，需要有相互制衡机制。投资团队和风险控制团队若相对独立，风险控制团队能对投资团队形成有效监督和制衡，保证决策的审慎性。A选项投资团队独立完成风险评估缺乏制衡；C选项仅依靠投资团队专业水平，无外部监督易导致不审慎；D选项减少风险控制团队参与不利于风险把控和专业审慎。答案：B

## 第4节 股权投资基金管理人的内部治理（4题）

**1.（单选题）** 依据我国现行立法，基金管理人可采用的法律组织形式是（　）。
A.公司型、合伙型
B.公司型、信托型
C.合伙型、契约型
D.信托型、契约型
**答案：** A
**解析：** 在我国现行立法下，基金管理人主要的法律组织形式有公司型和合伙型。信托型并非基金管理人的法律组织形式，契约型通常是基金的一种形式而非管理人形式。答案：A

**2.（单选题）** 在“鼓励利益相关者参与”原则中，行业协会的监管和自律引导方式，不包括以下哪项？（　）
A.鼓励自身践行ESG投资
B.在管理人申请登记环节引入法律意见书
C.关注管理层未持股情况下的稳定性
D.要求管理人公平对待所有LP
**答案：** D
**解析：** “鼓励利益相关者参与” 原则下，行业协会的监管和自律引导聚焦于推动行业规范发展与 ESG 理念践行。A 项鼓励自身践行 ESG 投资，是协会引导行业落实 ESG 责任的方式；B 项在管理人申请登记环节引入法律意见书，是协会强化登记监管、规范市场准入的自律手段；C 项关注管理层未持股情况下的稳定性，是协会从公司治理角度对管理人合规运营的引导。而 D 项要求管理人公平对待所有 LP，属于对基金管理人信义义务的基本要求，是行业监管的通用准则，并非 “鼓励利益相关者参与” 原则下行业协会特有的监管和自律引导方式。故答案为 D。

**3.（单选题）** 基金管理人财务审计部的职责不包括（　）。
A.公司财务预决算规划
B.基金产品对外投资的资金管理
C.制定投资决策策略
D.财务报告、记账、出纳等
**答案：** C
**解析：** 财务审计部主要负责公司财务相关事务，如预决算规划、财务报告等基础财务工作。而基金产品对外投资的资金管理多由投资部门等负责，制定投资决策策略更是投资决策委员会、投资研究等部门的职责。答案：C

**4.（单选题）** 基金管理人的风险控制与合规部，不需要履行的职责是（　）。
A.拟定投资策略
B.审核经营过程中的法律文件
C.参与基金募集监督
D.审核基金信息披露文件
**答案：** A
**解析：** 风险控制与合规部主要侧重于合规、风控相关工作，拟定投资策略是投资管理相关部门职责，并非风险控制与合规部职责。而审核法律文件、参与基金募集监督、审核基金信息披露文件都与合规等相关。答案：A
