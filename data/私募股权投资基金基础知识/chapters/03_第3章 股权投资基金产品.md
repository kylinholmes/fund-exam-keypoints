# 私募股权投资基金基础知识 · 第3章 股权投资基金产品

## 第1节 股权投资基金产品概述（2题）

**1.（单选题）** 按照组织形式的不同，股权投资基金不包括以下哪类（　）。
A.公司型基金
B.合伙型基金
C.契约型基金
D.股票型基金
**答案：** D
**解析：** 股权投资基金按组织形式分为公司型基金、合伙型基金、契约型基金。股票型基金是按照投资对象分类的基金类型，并非按股权投资基金组织形式分类。答案：D

**2.（单选题）** 基金产品基本信息不包括以下哪项（　）。
A.基金名称
B.成立日期
C.投资方向
D.管理人名称
**答案：** C
**解析：** 基金产品基本信息通常涵盖基金名称、成立日期、管理人名称等，投资方向属于基金投资相关具体策略信息，相对而言不算是最基础的产品基本信息。答案选C。

## 第2节 公司型基金、合伙型基金与契约型基金（26题）

**1.（单选题）** 以下关于公司型股权投资基金说法正确的是（　）
A.公司型股权投资基金采用公司的组织形式，投资者并不是公司股东
B.公司型股权投资的投资者，不享有股东权力
C.公司型基金可采取有限责任公司或股份有限公司的形式
D.公司型股权投资的投资者,以其自有资产和投资额为限对公司债务承担无限责任
**答案：** C
**解析：** 公司型股权投资基金采用公司组织形式，投资者是公司股东，享有股东权力，以其投资额为限对公司债务承担有限责任，且公司型基金可采取有限责任公司或股份有限公司形式。答案：C

**2.（单选题）** 公司型基金的参与主体主要为投资者和（　）。
A.基金服务机构
B.基金管理人
C.经理层
D.基金公司
**答案：** B
**解析：** 公司型基金中，投资者作为股东，而基金管理人负责基金的投资运作等核心事务，是公司型基金重要的参与主体。基金服务机构是辅助角色；经理层是基金管理人内部组成部分；基金公司表述宽泛不准确。答案：B

**3.（单选题）** （　）采用有限合伙企业的组织形式，投资者作为合伙人参与投资，依法享有合伙企业财产权，由普通合伙人对合伙债务承担无限连带责任，由基金管理人具体负责投资运作。
A.合伙型股权投资基金
B.公司型股权投资基金
C.创业投资基金
D.契约型投资基金
**答案：** A
**解析：** 题目强调采用有限合伙企业组织形式，普通合伙人承担无限连带责任等，这些都是合伙型股权投资基金的典型特征。答案：A

**4.（单选题）** 普通合伙人对基金(合伙企业)债务承担（　）。
A.有限责任
B.无限连带责任
C.无限责任
D.有限连带责任
**答案：** B
**解析：** 普通合伙人在合伙企业中，需对合伙企业债务承担较重责任，这是为保障债权人利益及合伙企业经营稳定性。无限连带责任意味着不仅要以个人全部财产承担责任，且对其他合伙人的债务份额也有连带清偿义务。而有限责任、有限连带责任不符合普通合伙人责任特征，无限责任表述不如无限连带责任全面准确。答案：B

**5.（单选题）** 以下关于合伙型基金的特点说法错误的是（　）
A.合伙型基金本质上是一种合伙关系
B.普通合伙人对合伙企业债务承担有限责任
C.合伙型基金有利于避免双重纳税
D.有限合伙企业并不是独立的法人，不能独立于合伙人而存在
**答案：** B
**解析：** 普通合伙人对合伙企业债务承担无限连带责任，并非有限责任，B 选项说法错误。A 选项，合伙型基金就是基于合伙关系设立；C 选项，相比公司型基金，合伙型基金在纳税方面避免了公司和个人双重纳税；D 选项，有限合伙企业确实不是独立法人，依赖合伙人存在。答案：B

**6.（单选题）** 下列具有独立法人地位的股权投资基金的是（　）
A.公司型股权投资基金
B.契约型股权投资基金
C.信托型股权投资基金
D.合伙型股权投资基金
**答案：** A
**解析：** 公司型基金具有独立法人地位，契约型（信托型）基金不具有独立法人地位，合伙型基金是非法人企业。答案：A。

**7.（单选题）** 信托(契约)型基金的参与主体主要有（　）.
I基金投资者
II基金管理人
III基金托管人
IV证券业协会
V银保监会
A.I、II、IV
B.I、II、V
C.I、II、III
D.II、III、V
**答案：** C
**解析：** 信托（契约）型基金的参与主体主要包括基金投资者、基金管理人、基金托管人。证券业协会主要是对证券行业自律管理，并非信托（契约）型基金直接参与主体；银保监会主要负责对银行和保险等金融领域监管，也不是信托（契约）型基金直接参与主体。答案：C

**8.（单选题）** 下列关于公司型基金的描述，错误的是（　）。
A.公司型基金是指投资者依据公司法，通过出资形成一个独立的公司法人实体
B.在我国，公司法人实体可采取无限责任公司的形式
C.公司型基金的参与主体主要为投资者和基金管理人，投资者既是基金份额持有者又是公司股东
D.公司型基金可以由公司管理团队自行管理，或者委托专业的基金机构担任基金管理人
**答案：** B
**解析：** 在我国，公司法人实体只能采取有限责任公司或股份有限公司的形式，不能是无限责任公司形式。答案选B 。

**9.（单选题）** 合伙型基金是指投资者依据合伙企业法成立有限合伙企业，由普通合伙人合伙债务承担无限连带责任，由（　）具体负责投资运作的股权投资基金。
A.全体合伙人
B.有限合伙人
C.基金管理人
D.基金托管人
**答案：** C
**解析：** 在合伙型基金中，普通合伙人承担无限连带责任，而具体负责投资运作的通常是具备专业投资管理能力的基金管理人。有限合伙人一般不参与投资运作。全体合伙人不会都具体负责投资运作。基金托管人主要负责资产保管等，非投资运作。答案：C

**10.（单选题）** 关于契约型基金，下列说法不正确的是（　）。
A.契约型基金不具有独立的法人地位
B.契约型基金是指通过订立信托契约的形式设立的股权投资基金
C.契约型基金的参与主体主要为基金投资者、基金管理人及基金托管人
D.基金托管人负责保管基金资产，执行投资者的有关指令，办理基金名下的资金往来
**答案：** D
**解析：** 契约型基金中，基金托管人负责保管基金资产，执行基金管理人的有关指令，办理基金名下的资金往来，而不是执行投资者指令。答案选D 。

**11.（单选题）** 关于合伙型基金，下列说法错误的是（　）。
A.普通合伙人对基金（合伙企业）债务承担无限连带责任
B.有限合伙人以其认缴的出资额为限对基金（合伙企业）债务承担责任
C.普通合伙人可自行担任基金管理人，或者委托专业的基金管理机构担任基金管理人
D.有限合伙人可以参与投资决策
**答案：** D
**解析：** 在合伙型基金中，有限合伙人不参与投资决策，这是其重要特点之一。而A选项普通合伙人承担无限连带责任、B选项有限合伙人以认缴出资额为限承担责任、C选项普通合伙人可自行或委托他人担任基金管理人，均为正确表述。答案：D

**12.（单选题）** 公司型基金中，投资者可通过（　）委任并监督基金管理人。
A.基金业协会
B.高级管理层
C.监事会
D.股东大会和董事会
**答案：** D
**解析：** 公司型基金中，股东大会是公司的权力机构，董事会对股东大会负责，投资者通过股东大会和董事会来委任并监督基金管理人。基金业协会是行业自律组织，与委任监督基金管理人无关；高级管理层由董事会聘任，本身并非投资者委任监督基金管理人的途径；监事会主要是监督公司运作，但委任基金管理人主要靠股东大会和董事会。答案：D

**13.（单选题）** 我国公司型基金按照（　）来运营。
A.公司章程
B.合伙协议
C.信托契约
D.投资者意愿
**答案：** A
**解析：** 公司型基金以公司形式设立，依据公司章程运营。合伙协议是合伙型基金遵循的，信托契约是契约型基金遵循的，投资者意愿过于宽泛且不是运营依据。答案：A

**14.（单选题）** 以下有关信托(契约)型基金的说法中，错误的是（　）。
A.信托(契约)型基金不具有独立的法人地位
B.信托(契约)型基金不是企业所得税的纳税主体，不需要缴纳所得税，只有基金投资者需要对取得的投资收益缴纳所得税，避免了双重纳税
C.信托(契约)型基金的法律依据为《中华人民共和国信托法》和《中华人民共和国证券投资基金法》
D.信托(契约)型基金是指通过订立信托契约的形式设立的股权投资基金，其本质是公司型基金
**答案：** D
**解析：** 信托（契约）型基金本质不是公司型基金，它与公司型基金在法律主体资格、组织形式等方面存在差异。A选项，信托（契约）型基金确实不具独立法人地位；B选项，其税收安排合理，避免双重纳税描述正确；C选项，法律依据也正确。答案：D

**15.（单选题）** 信托(契约)型基金主要特点有（　）。
Ⅰ信托(契约)型基金本质上是一种信托关系，因此，契约各方可通过信托契约进行相关约定，运作比较灵活
Ⅱ信托(契约)型基金不是企业所得税的纳税主体，不需要缴纳所得税，只有基金投资者需要对取得的投资收益缴纳所得税，避免了双重纳税
Ⅲ信托(契约)型基金中，除非基金合同另有约定，基金投资者以其出资为限对基金的债务承担有限责任
Ⅳ公司的有限责任，意味着全体股东承担有限责任
A.Ⅰ、Ⅱ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** Ⅰ项，信托（契约）型基金基于信托关系，通过契约约定运作，确实灵活，该说法正确。 Ⅱ项，信托（契约）型基金本身非企业所得税纳税主体，投资者就投资收益纳税，避免双重纳税，说法正确。 Ⅲ项，通常情况下，除非基金合同另有约定，基金投资者以出资为限对基金债务承担有限责任，该说法正确。 Ⅳ项，题干说的是信托（契约）型基金，而该项阐述的是公司的有限责任，与信托（契约）型基金特点无关，所以该项错误。答案：B

**16.（单选题）** 合伙型股权投资基金的参与主体主要包括（　）。

B.普通合伙人、有限合伙人及基金管理人

**17.（单选题）** 下列关于公司型基金的说法中，错误的是（　）。

**19.（单选题）** 下列关于合伙型基金的表述中，正确的有（　）。

**20.（单选题）** 通过订立信托契约的形式设立的基金本质是（　）。

**解析：** 政府引导基金对创业投资基金支持方式有参股、融资担保、跟进投资三种。所以正确答案是B 。

## 第5节 政府投资基金（3题）

**1.（单选题）** 产业投资类政府投资基金可采取的架构是（　）。
A.仅母子基金架构
B.仅直投基金架构
C.混合基金架构
D.母子基金架构或直投基金架构
**答案：** D
**解析：** 产业投资类政府投资基金常见架构有母子基金架构和直投基金架构两种。母子基金架构是通过设立母基金，再由母基金投资子基金；直投基金架构则是直接对项目进行投资。所以产业投资类政府投资基金可采取母子基金架构或直投基金架构。答案选D。

**2.（单选题）** 相较于母基金模式，直投模式的优势在于（　）。
A.分散投资风险能力更强
B.对项目投资参与度和把控力更强
C.借助专业管理人提升运作水平更突出
D.撬动社会资本效果更好
**答案：** B
**解析：** 直投模式是直接对项目进行投资，母基金是通过投资子基金间接投资项目。直投模式没有中间环节，能更直接地参与和把控项目。而A选项分散风险能力母基金因投资多个子基金通常更强；C选项借助专业管理人方面母基金更有优势；D选项撬动社会资本方面母基金也更突出。答案：B

**3.（单选题）** 政府投资基金在投资领域，主要聚焦（　）。
A.所有行业均衡投资
B.成熟产业，避免风险
C.重大战略、重点领域和市场不能充分发挥作用的薄弱环节
D.仅新兴产业
**答案：** C
**解析：** 政府投资基金目的并非均衡投资所有行业，A 排除；不是只聚焦成熟产业来避风险，B 排除；也不是仅关注新兴产业，D 排除。政府投资基金主要是为了弥补市场失灵，聚焦重大战略等市场薄弱环节。答案：C
