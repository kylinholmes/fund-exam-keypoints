# 私募股权投资基金基础知识 · 第8章 股权投资基金治理

## 第1节 股权投资基金治理概述（4题）

**1.（单选题）** 广义基金治理权力配置的最终目的是（　）。
A.内部机构相互制衡
B.确保科学决策，维护利益相关者利益
C.限制基金管理人权力
D.增加基金公司盈利
**答案：** B
**解析：** 广义基金治理权力配置是为了让基金运作科学合理，保障各利益相关者的利益，这是根本目的。而A选项内部机构制衡是手段；C选项限制基金管理人权力不是最终目的；D选项增加基金公司盈利片面，治理权力配置不仅关乎公司盈利，更要考虑多方利益。答案选B。

**2.（单选题）** 基金治理的机制不包括以下哪项（　）。
A.决策机制
B.激励机制
C.约束机制
D.销售机制
**答案：** D
**解析：** 基金治理机制主要涉及基金运作过程中的决策、激励与约束等方面，以保障基金有效运作和投资者利益。销售机制主要是关于基金产品的市场推广与销售，不属于基金治理机制范畴。答案：D

**3.（单选题）** 合伙型股权投资基金中，投资者作为有限合伙人（LP）和普通合伙人（GP）是（　）关系。
A.监督与被监督
B.委托代理
C.共同经营
D.债权债务
**答案：** B
**解析：** 在合伙型股权投资基金中，有限合伙人将资金交给普通合伙人进行管理运作，二者是典型的委托代理关系，有限合伙人不参与日常经营管理，普通合伙人负责基金的运营。答案：B

**4.（单选题）** 公司治理选择的价值取向，应（　）为准则。
A.以股东利益
B.以管理层利益
C.以公司股东利益和公司各方利益相关者利益
D.以公司股东利益为主导、兼顾利益相关者
**答案：** D
**解析：** 公司治理不能只关注股东或管理层利益，而应平衡各方利益。既要重视股东利益，也要兼顾利益相关者利益，这样才能保证公司可持续发展。答案：D

## 第2节 股权投资基金治理主要原则（15题）

**1.（单选题）** 从息披露的性质看，可以区分为（　）。
Ⅰ.强制性信息披露
Ⅱ.约定信息披露
Ⅲ.自愿信息披露
A.Ⅰ、Ⅱ
B.Ⅱ、Ⅲ
C.Ⅰ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** D
**解析：** 从信息披露的性质划分，其核心分类涵盖以下三类：Ⅰ 项强制性信息披露是指依据法律法规、监管规定等必须履行的披露义务，具有法定性和义务性；Ⅱ 项约定信息披露是基于当事人之间的合同、协议等约定而产生的披露责任，受契约关系约束；Ⅲ 项自愿信息披露则是信息披露义务人主动、自愿超出法定或约定要求进行的额外披露，具有自主性。这三类从不同依据和性质出发，共同构成了信息披露的完整体系，故答案为 D。

**2.（单选题）** 信义义务的核心目标不包括以下哪项（　）。
A.防范利益冲突
B.确保基金有效运作
C.维护基金管理人利益
D.维护投资者最佳利益
**答案：** C
**解析：** 信义义务强调基金管理人要为投资者利益服务，防范利益冲突、确保基金有效运作都是为了维护投资者最佳利益，而不是维护基金管理人自身利益。答案选C。

**3.（单选题）** 以下哪项不属于基金治理主要原则（　）。
A.利益一致
B.优先对待部分投资者
C.专业审慎
D.信息透明
**答案：** B
**解析：** 基金治理应公平对待所有投资者，不能优先对待部分投资者，这违背公平公正原则。而利益一致、专业审慎、信息透明都是基金治理的重要原则。答案是B。

**4.（单选题）** 基金管理人“公平对待”原则的适用范围，不包括（　）。
A.同一只基金中的不同投资者
B.管理人管理的不同基金的投资者
C.未履行出资义务的投资者
D.已履行出资义务的投资者
**答案：** C
**解析：** 公平对待原则应适用于所有已履行出资义务的正常投资者，对于同一只基金不同投资者、管理人管理的不同基金的投资者都要公平对待。而未履行出资义务的投资者情况特殊，不属于公平对待原则通常适用范围。答案：C

**5.（单选题）** 合规风控人员定期合规和风险自查后，需向（　）披露报告？
A.管理人内部
B.投资者
C.监管部门
D.行业自律组织
**答案：** B
**解析：** 合规风控人员定期自查旨在保障投资者知情权，让其充分了解基金运作的合规性与潜在风险，根据股权投资基金监管要求与行业实践，自查报告属需向投资者披露的重要信息。A 项管理人内部是报告流转环节而非核心披露对象，C 项监管部门与 D 项行业自律组织仅在特定情况（如检查、备案）下需提交报告，非定期自查后的常规披露对象，故答案为 B。

**6.（单选题）** 基金管理人应当按照要求进行信息披露，定期信息披露包括（　）。
Ⅰ.月度信息
Ⅱ.季度信息
Ⅲ.半年度信息
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ
C.Ⅰ、Ⅱ
D.Ⅰ、Ⅲ
**答案：** B
**解析：** 基金管理人定期信息披露主要有季度、半年度和年度等，月度信息并非普遍要求的定期披露内容。所以定期信息披露包括季度信息和半年度信息。答案选B。

**7.（单选题）** 在股权投资基金行业中，基金管理人与投资者之间构成（　）关系。
A.债权债务
B.信义
C.雇佣
D.合伙
**答案：** B
**解析：** 股权投资基金管理人是基金产品的募集者和管理者，基金管理人受托管理基金财产，需按照基金合同约定，恪尽职守、履行诚实信用、谨慎勤勉义务，这种关系本质上是信义关系。答案：B

**8.（单选题）** 基金管理人出资比例高，通常意味着（　）。
A.代理风险越高
B.代理风险越低
C.与投资者利益冲突越大
D.无需承担风险
**答案：** B
**解析：** 基金管理人出资比例高，意味着其自身利益与基金利益关联更紧密，会更用心管理基金，从而降低代理风险，因为代理风险往往源于管理人不完全从投资者利益出发。与投资者利益冲突也会因自身利益绑定而减小，且管理人出资不可能无需承担风险。所以答案是B。

**9.（单选题）** 根据利益一致原则，基金合同中需明确约定的收益分配内容不包括（　）
A.基金管理人办公地址
B.分配时间
C.可分配资金
D.分配模式
**答案：** A
**解析：** 收益分配内容主要围绕与收益分配相关的要素，像可分配资金、分配时间、分配模式都直接关乎收益分配。而基金管理人办公地址与收益分配毫无关系。答案：A

**10.（单选题）** 除关联交易情形外，基金合同应明确列示其他利益冲突行为，以下属于可能产生利益冲突的基金行为是（　）。
A.基金正常投资优质项目

**11.（单选题）** 基金投资者未按基金合同约定缴付出资额，需承担（　）。

**12.（单选题）** 基金管理人是基金治理的（　）。
A.第一责任人

**13.（单选题）** 专业审慎原则中专业性要求基金合同中通常要明确（　）。
A.普通员工的具体人选

**14.（单选题）** 基金设置的信息披露机制，内容不包括（　）。

## 第3节 股权投资基金内部治理（11题）

**1.（单选题）** 治理机制的核心内容包括（　）。
Ⅰ、决策机制
Ⅱ、激励机制
Ⅲ、约束机制
Ⅳ、监督机制
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** A
**解析：** 治理机制的核心是通过一系列规则与制度规范主体行为、协调利益关系，其核心内容包括决策机制（明确决策主体、程序与权限，是治理的基础）、激励机制（通过利益引导激发主体积极性）、约束机制（以规则限制不当行为，保障合规运作），三者相互配合构成治理机制的核心框架。Ⅳ 项监督机制是保障治理机制有效运行的重要支撑手段，用于监督决策、激励与约束机制的执行情况，并非核心内容本身。因此，治理机制的核心内容为 Ⅰ、Ⅱ、Ⅲ，答案为 A。

**2.（单选题）** 基金达成科学决策目标，重要一点是建立科学治理结构，明确划分（　）等各自权利和责任。
A.投资者、托管人
B.投资者、管理人
C.管理人、托管人
D.投资者、监管部门
**答案：** B
**解析：** 基金科学决策要明确权利责任划分，基金涉及投资者提供资金，管理人负责运作管理，明确二者权利责任对科学决策重要。托管人主要负责资产保管监督等，监管部门是外部监管，相比之下投资者与管理人权利责任划分对基金决策目标达成更关键。答案选B 。

**3.（单选题）** 基金内部治理旨在规范（　）之间的权利义务关系。
A.基金托管人与管理人
B.基金投资者与托管人
C.管理人内部各部门
D.基金投资者、管理人等利益主体
**答案：** D
**解析：** 基金内部治理涉及的是基金运行中各个主要利益主体，包括投资者、管理人等，并非局限于某两个特定主体或管理人内部部门。答案：D

**4.（单选题）** 基金内部治理包括哪两个层面（　）。
A.决策机制和激励机制
B.约束机制和协调机制
C.治理结构和治理机制
D.投资者结构和管理人结构
**答案：** C
**解析：** 基金内部治理主要围绕治理结构和治理机制展开，治理结构涉及组织架构设置等，治理机制关乎运营管理的各项规则等。其他选项A决策机制和激励机制只是治理机制的部分内容；B约束机制和协调机制属于治理机制范畴；D投资者结构和管理人结构并非基金内部治理核心的两个层面。答案：C

**5.（单选题）** 除自我管理型基金外，公司型基金通常会委托（　）负责运营和管理基金。
A.托管人
B.基金管理人
C.投资者
D.监管机构
**答案：** B
**解析：** 公司型基金除自我管理型外，一般委托专业的基金管理人负责运营管理基金。基金管理人具备专业的投资管理能力等。答案：B

**6.（单选题）** 在公司型基金治理结构中，为保证投资运作效率，应注意（　）。
A.合理分配决策权限
B.扩大投资者决策权限
C.完全由管理人决策
D.取消内部治理机构
**答案：** A
**解析：** 公司型基金治理中，合理分配决策权限能在保障各方利益的同时保证投资运作效率。扩大投资者决策权限可能降低运作效率；完全由管理人决策易缺乏监督制衡；取消内部治理机构会使治理混乱，都不利于保证投资运作效率。答案：A

**7.（单选题）** 有限合伙企业的治理问题与公司治理均属（　）范畴。
A.政府治理
B.行业治理
C.社会治理
D.企业治理
**答案：** D
**解析：** 有限合伙企业和公司都属于企业形式，它们的治理问题自然属于企业治理范畴。答案：D

**8.（单选题）** 有限合伙企业中，普通合伙人对合伙企业债务承担（　）。
A.补充责任
B.有限责任
C.按份责任
D.无限连带责任
**答案：** D
**解析：** 这是关于有限合伙企业中普通合伙人责任形式的考查。在有限合伙企业里，普通合伙人对企业债务承担无限连带责任，这是其区别于有限合伙人承担有限责任的关键。答案：D

**9.（单选题）** 基金治理的核心机制是（　）。
A.约束机制
B.激励机制
C.决策机制
D.监督机制
**答案：** C
**解析：** 基金治理核心机制是决策机制。决策机制关乎基金运营方向、资产配置等关键事务，对基金运作起决定性作用。其他机制围绕决策机制展开辅助。所以答案是C。

**10.（单选题）** 公司型基金委托外部基金管理人进行管理，聘请基金管理人的决定应当由（　）作出。
Ⅰ.股东会
Ⅱ.董事会
Ⅲ.公司章程
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ
C.Ⅰ、Ⅱ
D.Ⅰ、Ⅲ
**答案：** D
**解析：** 公司型基金中，股东会是公司的权力机构，董事会对股东会负责，聘请基金管理人属于公司重要事务决策，一般由股东会作出决定，同时公司章程也可能对相关决策程序等作出规定。而董事会通常执行股东会决议，直接决定聘请基金管理人不是其常规职权。所以答案选D.Ⅰ、Ⅲ 。

**11.（单选题）** 投委会是负责基金投资决策的机构，投委会通常由若干名自然人委员组成，常见人数为（　）。
A.1-2人
B.2-3人
C.3-5人
D.3-7人
**答案：** D
**解析：** 投委会常见人数规模通常不会太少，1 - 2人难以充分讨论决策，3 - 7人能在保证充分交流意见基础上维持决策效率，相比3 - 5人，3 - 7人涵盖范围更广且更符合实际情况。答案：D。
