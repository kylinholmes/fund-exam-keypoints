# 私募股权投资基金基础知识 · 第9章 股权投资基金运营管理

## 第1节 股权投资基金权益登记（11题）

**1.（单选题）** 有限责任公司型股权投资基金作出增资或者减资决议必须经代表（　）以上表决权的股东通过；股份有限公司型股权投资基金作出增资或者减资决议，必须经出席股东会的股东所持表决权的（　）以上通过。
A.1/2；1/2
B.1/2；2/3
C.2/3；2/3
D.3/4；3/4
**答案：** C
**解析：** 有限责任公司和股份有限公司型股权投资基金作出增资或减资决议，都需要经代表2/3以上表决权的相关人员通过，有限责任公司是代表2/3以上表决权股东，股份有限公司是出席股东会股东所持表决权2/3以上。答案：C

**2.（单选题）** 合伙型股权投资基金的变更登记不包括以下哪项（　）。
A.入伙/增加出资
B.退伙/减少出资
C.财产份额转让
D.股份转让
**答案：** D
**解析：** 合伙型股权投资基金涉及入伙、退伙、财产份额转让等变更登记情形，而“股份转让”一般是股份有限公司的概念，合伙型基金不存在“股份”这一说法。答案：D

**3.（单选题）** 公司董事应当在解散事由出现之日起（　）日内组成清算组进行清算。
A.10
B.15
C.20
D.30
**答案：** B
**解析：** 根据相关法律规定，公司董事应当在解散事由出现之日起15日内组成清算组进行清算。这是一个记忆性知识点。答案：B

**4.（单选题）** 合伙型股权投资基金具有较强人合性特征，新合伙人入伙（除合伙协议另有约定外），需经（　）。
A.半数以上合伙人同意
B.2/3以上合伙人同意
C.全体合伙人一致同意
D.无需其他合伙人同意
**答案：** C
**解析：** 由于合伙型股权投资基金人合性较强，新合伙人入伙会对原合伙人关系等产生重要影响，所以通常除合伙协议另有约定外，需经全体合伙人一致同意。答案：C

**5.（单选题）** 契约型股权投资基金的变更登记不包括以下哪项（　）。
A.申购
B.赎回
C.基金份额转让
D.基金管理人变更
**答案：** D
**解析：** 申购、赎回和基金份额转让主要涉及的是基金份额数量或持有者的变动；而基金管理人变更属于重大实质性变更，契约型股权投资基金的变更登记通常不涵盖基金管理人变更这类主体层面的变动。答案：D

**6.（单选题）** 股份有限公司型股权投资基金的发起人人数要求是（　）。
A.1人以上200人以下
B.2人以上50人以下
C.2人以上200人以下
D.50人以下
**答案：** A
**解析：** 股份有限公司型股权投资基金的发起人人数需遵循《中华人民共和国公司法》规定，设立股份有限公司应当有 1 人以上 200 人以下为发起人（且半数以上发起人在中国境内有住所），该规定允许单一发起人设立，同时设定 200 人上限，兼顾灵活性与规范性。B 项 “2 人以上 50 人以下”、D 项 “50 人以下” 均为有限责任公司股东人数要求，C 项错误在于限定最低 2 人发起，不符合一人发起的法律规定，故答案为 A。

**11.（单选题）** 除合伙协议另有约定外，新合伙人与原有合伙人（　）。

## 第2节 股权投资基金托管（6题）

**1.（单选题）** 关于股权投资基金托管，以下说法正确的是（　）
A.都强制要求托管
B.均不强制要求托管
C.未强制要求托管，全体投资者和管理人可约定不托管
D.未强制要求托管，管理人可单方面决定不托管
**答案：** C
**解析：** 股权投资基金并非都强制要求托管，若全体投资者和管理人协商一致，可约定不进行托管，管理人单方面不能决定不托管。答案选C。

**2.（单选题）** 股权投资基金的托管人不得超过（　）。
A.1家
B.2家
C.3家
D.5家
**答案：** A
**解析：** 一般情况下，股权投资基金的托管人只能有1家，这是行业常见规范。答案：A

**3.（单选题）** 基金托管的作用包括（　）。
Ⅰ.有利于形成更加平衡的基金治理结构
Ⅱ.有利于保障基金财产的安全
Ⅲ.有利于监督基金管理人的投资运作
Ⅳ.有利于增加基金运作的透明度
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅳ
**答案：** A
**解析：** 基金托管人对基金管理人的投资运作进行监督，能保障基金财产安全，使基金治理结构更平衡，监督过程也在一定程度上增加了基金运作透明度。所以基金托管有利于形成更平衡基金治理结构、保障基金财产安全、监督基金管理人投资运作、增加基金运作透明度。答案选A。

**4.（单选题）** 基金托管的基本原则包括（　）。
Ⅰ.合规性原则
Ⅱ.安全性原则
Ⅲ.独立性原则
Ⅳ.公开性原则
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** D
**解析：** 基金托管基本原则中，合规性原则要求托管业务必须在法律法规框架内进行；安全性原则保障基金资产的安全；独立性原则确保托管人独立于管理人等其他机构开展业务。而公开性原则并非基金托管的基本原则，它更多与信息披露等方面相关。答案：D

**5.（单选题）** 股权投资基金的现金类资产主要包括（　）。
Ⅰ.货币市场工具
Ⅱ.银行存款
Ⅲ.上市公司股票
Ⅳ.理财产品
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** B
**解析：** 上市公司股票不属于现金类资产，而货币市场工具、银行存款、理财产品都属于现金类资产范畴。答案：B

**6.（单选题）** 基金财产独立于基金托管人托管的其他基金产品的资产，目的是（　）
A.确保单只基金财产的完整与独立
B.方便托管人统一管理
C.简化账户管理流程
D.降低托管人运营成本
**答案：** A
**解析：** 基金财产独立于基金托管人托管的其他基金产品资产，主要是为了防止不同基金财产之间相互混淆、干扰，保障每一只基金财产自身的完整与独立，这对维护投资者权益至关重要。而B选项方便统一管理、C选项简化账户管理流程、D选项降低运营成本都不是其主要目的。答案：A

## 第3节 股权投资基金的估值核算与业绩评价（11题）

**1.（单选题）** 股权投资基金的收入主要包括投资项目期间产生的（　）。
A.已实现投资收益和未实现公允价值变动损益
B.未实现投资收益和已实现公允价值变动损益
C.已实现投资收益和已实现公允价值变动损益
D.已实现投资收益和未实现账面价值变动损益
**答案：** A
**解析：** 股权投资基金收入包括已实现投资收益（如项目退出获利等）以及未实现公允价值变动损益（因所投项目估值变化带来的潜在收益变动） 。答案选A 。

**2.（单选题）** 股权投资基金估值针对的期间是（　）。
A.基金存续期间
B.基金销售期间
C.基金成立时
D.基金清算时
**答案：** A
**解析：** 股权投资基金在整个存续期间都可能涉及对投资项目的估值，以对基金资产进行合理定价、业绩评估等。而基金销售期间、成立时、清算时只是存续期间中的特定阶段，估值并非仅针对这些特殊阶段。答案：A。

**3.（单选题）** 对于存在活跃市场且能获取相同资产报价的投资项目，在估值日有报价且无减持限制时，公允价值计量应（　）。
A.对估值日报价调整后应用
B.将估值日的报价不加调整地应用
C.采用最近交易日报价
D.忽略报价自行估计
**答案：** B
**解析：** 当存在活跃市场且能获取相同资产报价，在估值日有报价且无减持限制时，应直接采用估值日的报价，这样能最准确反映公允价值。答案：B

**4.（单选题）** 股权基金业绩评价主要采用的指标有（　）。
Ⅰ内部收益率
Ⅱ已分配倍数
Ⅲ总收益倍数
Ⅳ市净率倍数
A.ⅠⅡⅢⅣ
B.ⅠⅡⅣ
C.ⅠⅡⅢ
D.ⅠⅡⅣ
**答案：** C
**解析：** 内部收益率（IRR）反映基金投资项目实际收益水平，已分配倍数（DPI）体现投资者已获得的分配情况，总收益倍数（TVPI）衡量基金从投资项目中获得的总收益，这三个都是股权基金业绩评价常用指标。而市净率倍数主要用于股票估值等，并非股权基金业绩评价主要指标。答案：C

**5.（单选题）** 每只基金能开立（　）基本存款账户。
A.1个
B.2个
C.3个
D.5个
**答案：** A
**解析：** 一般规定，每只基金只能开立1个基本存款账户，用于基金资金的存放与收付等。答案：A

**6.（单选题）** 关于托管账户，下列说法正确的是（　）。
A.由基金管理人开立并保管
B.募集期间投资者资金先划入此账户
C.投资款项划转无需管理人指令
D.所有基金资产货币收支活动均需通过该账户进行
**答案：** D
**解析：** 托管账户由托管人开立并保管，A 错误。 募集期间投资者资金先划入募集账户，不是托管账户，B 错误。 投资款项划转需管理人指令，托管人复核，C 错误。 基金托管账户是基金资产的保管账户，所有基金资产货币收支活动均需通过该账户进行，D 正确。答案：D

**7.（单选题）** 基金管理费是基金管理人因（　）而向基金收取的费用。
A.提供咨询服务
B.投资管理基金资产

D.保管基金资产
**答案：** B
**解析：** 基金管理费是基金管理人管理基金资产而收取的费用。A选项提供咨询服务并非收取管理费主要原因；C选项销售基金产品对应销售费用；D选项保管基金资产是基金托管人的职责，对应托管费。答案：B

**8.（单选题）** 下列关于《创业投资企业管理暂行办法》的说法中正确的是（　）。
A.以公司形式设立的创业投资企业必须自行负责投资管理业务

C.对各类处于创建或重建过程中的未上市成长性企业的投资，均可归入创业投资

**答案：** C

**9.（单选题）** 基金管理人选择估值方法时，应依据基金投资项目的核心价值决定因素、行业惯例等，体现了估值的（　）。

**10.（单选题）** 基金管理人编制财务报告时，所有收入和费用应在其实际发生时确认，遵循的是（　）。

**11.（单选题）** 管理人报送经审计的股权投资基金年度财务报告的时间要求是每个会计年度结束之日起（　）内。
A.4个月

## 第4节 股权投资基金的税收（7题）

**1.（单选题）** 公司型创业投资企业转让持有（　）以上股权的所得占年度股权转让所得总额比例超50%，按年末个人股东持股比例减半征收当年企业所得税。
A.3年
B.5年
C.7年
D.10年
**答案：** A
**解析：** 根据相关税收优惠政策，公司型创业投资企业享受特定企业所得税减免的条件之一为：转让持有3 年以上股权的所得占年度股权转让所得总额的比例超过 50%。满足该条件时，可按年末个人股东持股比例减半征收当年企业所得税，这一政策旨在鼓励创业投资企业长期持有被投企业股权，支持创业创新发展。B 项 5 年、C 项 7 年、D 项 10 年均非该政策中规定的股权持有期限门槛，故答案为 A。

**2.（单选题）** 股权投资基金可能涉及的增值税应税行为主要包括（　）。
A.固定收益投资和金融商品转让
B.权益投资和金融商品持有
C.固定收益投资和权益投资
D.金融商品持有和转让
**答案：** A

## 第5节 股权投资基金的收益分配与账面分摊（6题）

**1.（单选题）** 瀑布式收益分配体系中，项目投资退出资金先（　）。
A.分配业绩报酬
B.返还至基金投资者
C.分配门槛收益
D.由管理人自由支配
**答案：** B
**解析：** 瀑布式收益分配体系下，项目投资退出资金通常先返还至基金投资者，保障投资者本金，之后才涉及业绩报酬、门槛收益等分配。答案：B

**2.（单选题）** 股权投资基金的分配，通常采用（　）方式。
A.按基金成立时间分配
B.按管理人规模分配
C.按基金整体收益分配
D.按投资者人数分配
**答案：** C
**解析：** 股权投资基金分配通常是围绕基金整体收益展开，按基金成立时间、管理人规模、投资者人数分配都不符合行业常规分配逻辑。答案：C

**3.（单选题）** 按照单一项目收益分配方式，管理人获取业绩报酬的时间特点是（　）。
A.比基金整体分配方式提前
B.比基金整体分配方式滞后
C.与基金整体分配方式一致
D.以上说法都错误
**答案：** A
**解析：** 单一项目收益分配方式下，在单个项目实现收益后就可对该项目收益进行分配，管理人能较早拿到业绩报酬；而基金整体分配方式，需等基金清算时才统一分配收益，管理人获取业绩报酬相对滞后。所以单一项目收益分配方式下管理人获取业绩报酬比基金整体分配方式提前。答案：A

**4.（单选题）** 为保护投资者权益，单一项目收益分配方式通常需设置（　）。
A.提前分配机制
B.额外奖励机制
C.收益回拨机制
D.降低门槛收益机制
**答案：** C
**解析：** 收益回拨机制可以在前期业绩报酬分配不合理时，将已分配给基金管理人的部分业绩报酬返还至基金资产，以保护投资者权益，而提前分配机制、额外奖励机制主要侧重于不同分配时间和对管理人激励方面，降低门槛收益机制更多关乎收益计算标准，并非直接从保护投资者权益角度出发。答案：C

**5.（单选题）** 关于单一项目收益分配方式，下列说法正确的是（　）。
A.要求所有投资者收回全部实缴金额后才进行业绩报酬分配
B.项目退出收益只能在基金清算时进行分配
C.若基金无追赶机制，剩余资金直接全部分配给投资者
D.管理人可在特定项目退出收益中，符合约定条件时收取业绩报酬
**答案：** D
**解析：** A项，并非所有单一项目收益分配都要求所有投资者收回全部实缴金额后才进行业绩报酬分配，有多种分配方式，该项说法太绝对； B项，项目退出收益并非只能在基金清算时分配，也可在项目退出时及时分配； C项，若基金无追赶机制，剩余资金一般也是按约定在投资者和管理人之间分配，不是直接全部分配给投资者； D项，管理人在符合约定条件时，可在特定项目退出收益中收取业绩报酬，该项说法合理。答案：D

**6.（单选题）** 下列属于资本账户调整增项的是（　）。
A.分配给投资者的现金
B.投资者的亏损分摊
C.投资者新增实缴出资额
D.投资者应分摊的基金费用
**答案：** C
**解析：** 资本账户调整增项意味着会使资本账户金额增加。A选项分配给投资者现金会使资本减少；B选项投资者亏损分摊会减少资本；D选项投资者应分摊基金费用也会减少资本；而C选项投资者新增实缴出资额会使资本增加，属于增项。答案：C

## 第6节 投资者退出与股权投资基金的清算（6题）

**1.（单选题）** 股权投资基金投资者退出的行为是（　）。

**答案：** A
**解析：** 退出行为意味着投资者收回对基金的投资并从基金中退出，B选项增加投资不是退出；C选项更换基金管理人主要涉及管理人的变动，并非投资者退出；D选项调整基金投资策略是关于基金投资方向等的改变，和投资者退出无关。答案：A

**2.（单选题）** 份额转让交易的受让方成为股权投资基金投资者，除符合合格投资者条件外，还需（　）。

D.获得基金管理人批准即可
**答案：** C

**3.（单选题）** 股权投资基金份额转让中，投资者主导（LP-led）的交易，交易完成后需要管理人配合办理（　）。
A.基金清算手续
B.工商变更登记手续
C.基金备案手续
D.税务注销手续
**答案：** B
**解析：** 股权投资基金份额转让中，投资者主导（LP-led）的交易核心是基金份额在不同投资者之间的转移，交易本身不涉及基金的清算、注销或新设备案。交易完成后，基金的出资人（有限合伙人）发生变更，而基金通常以合伙企业或公司等组织形式存在，出资人变更需依法在市场监督管理部门办理登记公示，即工商变更登记手续。管理人作为基金的日常运营方，需配合提供相关文件、协助对接登记机关等，以完成该手续。A 项基金清算手续针对基金终止场景，C 项基金备案手续针对基金设立或重大变更（非单纯份额转让），D 项税务注销手续针对基金税务主体终止，均与题意不符，故答案为 B。

**6.（单选题）** 股权投资基金清算的原因不包括（　）。

Ⅳ完整性原则

**5.（单选题）** 一般来说，基金的定期报告包括（　）

## 第8节 股权投资基金争议解决（1题）

**1.（单选题）** 诉讼作为争议解决的（　），发挥着不可替代作用。
A.常规手段
B.最后手段
C.唯一手段

**答案：** B
**解析：** 诉讼是在其他争议解决方式无法有效解决问题时的最终途径，具有权威性和终局性，并非常规、唯一或前置手段。答案：B
