# 私募股权投资基金基础知识 · 第4章 股权投资基金的募集与设立

## 第1节 募集与设立概述（6题）

**1.（单选题）** 从募集主体机构的角度看，股权投资基金的募集可以分为（　）。
A.直接募集和间接募集
B.直接募集和受托募集
C.自行募集和受托募集
D.自行募集和委托募集
**答案：** D
**解析：** 这是一道关于股权投资基金募集方式的选择题。从募集主体机构的角度出发，我们需要明确两种基本的募集方式。首先，理解关键概念：1. 自行募集：指基金管理人直接负责基金的募集工作，不通过第三方机构。2. 委托募集：指基金管理人委托第三方机构来代为完成基金的募集工作。接下来，对比选项：A. 直接募集和间接募集 - 这种分类更侧重于募集的途径，而不是从募集主体机构的角度出发。B. 直接募集和受托募集 - “受托募集”在此语境下并不常用，且与“自行募集”不构成明确的对立关系。C. 自行募集和受托募集 - 同B选项，“受托募集”不是标准术语，容易造成混淆。D. 自行募集和委托募集 - 正确反映了从募集主体机构角度的分类，即基金管理人自己募集或委托第三方募集。综上所述，从募集主体机构的角度看，股权投资基金的募集明确分为自行募集和委托募集两种方式。所以，正确答案是D选项：“自行募集和委托募集”。

**2.（单选题）** （　）是基金管理人依法设立开展股权投资业务主体的过程，主要考虑基金组织形式、基金架构、登记备案等问题。
A.基金的募集
B.基金的设立
C.基金的招募
D.基金的流通
**答案：** B
**解析：** 题干描述的是设立开展股权投资业务主体的过程，涉及组织形式、架构、登记备案等，这明显是基金设立的范畴。募集侧重于资金筹集，招募类似募集表述，基金流通主要说的是基金份额的交易等，均与题干设立主体过程的描述不符。答案：B

**3.（单选题）** 按照现行规则，股权投资基金设立完成后，应在（　）办理基金备案。
A.基金公司
B.基金份额登记机构
C.中国证监会
D.中国证券投资基金业协会
**答案：** D
**解析：** 股权投资基金设立完成后，需在中国证券投资基金业协会办理基金备案，这是行业规定的备案场所。答案：D

**4.（单选题）** 从募集主体机构的角度来看，股权投资基金的募集分为（　）。
Ⅰ.公开募集
Ⅱ.自行募集
Ⅲ.委托募集
Ⅳ.非公开募集
A.Ⅰ、Ⅳ
B.Ⅱ、Ⅲ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 从募集主体机构角度，股权投资基金募集方式是自行募集与委托募集。公开募集和非公开募集是按募集方式不同分类，并非从募集主体机构角度。所以答案是B（Ⅱ、Ⅲ） 。

**5.（单选题）** 我国现行的股权投资基金组织形式主要分为（　）。
Ⅰ.公司型
Ⅱ.合伙型
Ⅲ.基金型
Ⅳ.信托型
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 我国现行的股权投资基金组织形式主要有公司型、合伙型和信托（契约）型，不存在基金型这种类别。答案：C

**6.（单选题）** 影响组织形式选择的因素众多，主要有（　）。
Ⅰ.法律依据
Ⅱ.监管要求
Ⅲ.股权投资业务的适应程度
Ⅳ.基金运营实务的要求

B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 法律依据决定了组织形式的合法性基础；监管要求会限制或引导组织形式的选择；股权投资业务的特点不同需要匹配不同组织形式；基金运营实务的要求也影响组织形式，如决策流程、利益分配等方面。这几个因素都对组织形式选择有重要影响。答案：D

## 第2节 募集对象（13题）

**1.（单选题）** 合格投资者制度起源于（　）。
A.美国
B.英国
C.加拿大
D.日本
**答案：** A
**解析：** 合格投资者制度起源于美国，当时主要是为了保护投资者利益、维护金融市场稳定等目的而设立。答案：A

**2.（单选题）** 中国证监会从下列哪些方面对合格投资者作出了限定（　）。
Ⅰ、信用记录
Ⅱ、风险识别能力和风险承担能力
Ⅲ、资产规模或者收入水平
Ⅳ、基金份额认购金额
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 合格投资者是指具备相应风险识别能力和风险承担能力，投资于单只私募基金的金额不低于100万元且符合下列相关标准的单位和个人：（1）净资产不低于1000万元的单位；（2）金融资产不低于300万元或者最近三年个人年均收入不低于50万元的个人。所以对合格投资者从风险识别与承担能力、资产规模或收入水平、基金份额认购金额方面作出限定，未提及信用记录。答案：D

**3.（单选题）** 国内外股权投资基金共同的投资者类型有（　）。
Ⅰ母基金
Ⅱ金融机构
Ⅲ企业
Ⅳ个人
A.Ⅲ、Ⅳ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 母基金、金融机构、企业和个人在国内外都可以作为股权投资基金的投资者。所以这四类都是国内外股权投资基金共同的投资者类型。答案：D

**4.（单选题）** 合格投资者比一般投资者__________、__________的能力更强、_________更为丰富，对基金管理人及其发起设立的基金具有较强的筛选、判断及监督能力。（　）
A.人数更多；运作资本；经验
B.资本更雄厚；识别与承受风险；专业知识
C.掌握的信息更多；自我管理；人脉资源
D.自我保护意识更强；监督管理人；知识
**答案：** B
**解析：** 合格投资者与一般投资者相比，从后两个空来看，通常强调在风险和知识等方面的优势。A选项“运作资本”并非与能力直接相关表述，且“人数更多”不是合格投资者相对一般投资者的突出特征；C选项“人脉资源”与对基金的筛选、判断及监督能力关联不紧密；D选项“监督管理人”表述较片面，且不如“识别与承受风险”全面。而B选项“资本更雄厚”体现合格投资者资金实力，“识别与承受风险能力更强”以及“专业知识更为丰富”都符合合格投资者相对一般投资者在能力和知识储备上的优势，能更好地对应对基金管理人及其基金的筛选、判断及监督能力。答案：B

**5.（单选题）** 中国最大的养老基金是（　）。
A.母基金
B.政府引导基金
C.全国社会保障基金
D.公司型基金
**答案：** C
**解析：** 全国社会保障基金是国家重要的战略储备，用于人口老龄化高峰时期的养老保险等社会保障支出的补充、调剂 ，是中国最大的养老基金。答案：C

**6.（单选题）** 国外股权投资基金的募集对象不包括（　）。
A.养老基金

**解析：** 国外股权投资基金募集对象有养老基金、母基金、大学基金会等，政府引导基金主要是国内扶持产业发展设立，国外股权投资基金募集对象一般不涉及。答案：D

**7.（单选题）** 国外股权投资基金的募集对象主要是（　）。
Ⅰ.养老基金

**8.（单选题）** 国内股权投资基金的募集对象主要包括（　）等。
Ⅰ.政府引导基金

Ⅰ.以子公司的形式进行创业投资或并购投资业务

## 第3节 募集与设立流程（15题）

**1.（单选题）** 我国要求（　）应获得中国证监会基金销售业务资格且成为中国证券投资基金业协会会员。
A.基金代销机构
B.基金代理机构
C.基金管理机构
D.基金服务机构
**答案：** A
**解析：** 在我国，从事基金销售业务，需要获得中国证监会基金销售业务资格且成为中国证券投资基金业协会会员的主要是基金代销机构 。基金管理机构主要职责是管理基金资产等，不是销售；基金服务机构包含范围广，并非都涉及销售；没有基金代理机构这种确切说法。答案：A

**2.（单选题）** （　）指的是通过公开渠道向非特定对象推介基金产品
A.非公开募集
B.公开募集
C.自行募集
D.委托募集
**答案：** B
**解析：** 公开募集是指向不特定对象募集资金、向特定对象募集资金累计超过200人，以及法律、行政法规规定的其他情形，是通过公开渠道向非特定对象推介基金产品。非公开募集是面向特定对象募集。自行募集和委托募集强调的是募集方式，不是针对对象。所以答案选公开募集。答案：B

**3.（单选题）** 自行募集股权投资基金的，应根据投资者适当性管理要求，采取问卷调查等方式，对投资者的__________和__________进行评估。（　）
A.专业知识；收入情况
B.资产情况；家庭情况
C.操作能力；鉴别能力
D.风险识别能力；风险承担能力
**答案：** D
**解析：** 对投资者进行评估主要是围绕与投资风险相关的能力，风险识别能力和风险承担能力是关乎投资能否合理匹配及承受潜在风险的关键因素。答案：D

**4.（单选题）** 募集机构在募集阶段应与基金投资者关于基金合同及附属文件_________，并就法规可能影响的基金合同生效程序进行_________。（　）
A.充分沟通；客观描述
B.快速制定；侧重评价
C.快速制定；侧重描述
D.充分沟通；侧重评价
**答案：** A
**解析：** 募集阶段要和投资者就合同等充分交流，让投资者清楚了解，而不是快速制定，所以排除B、C；对于法规影响的合同生效程序应客观呈现，侧重评价带有主观色彩不合适，排除D。答案：A

**5.（单选题）** 目前，我国要求股权投资基金代销机构应获得（　）且成为（　）会员。

**答案：** C

**6.（单选题）** 基金募集需要的资料有（　）。
Ⅰ私募备忘录(PPM)
Ⅱ收益分析报告
Ⅲ募集推介资料
Ⅳ(反向)尽职调查资料
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅳ
**答案：** A
**解析：** 基金募集资料主要包括私募备忘录（PPM），它是基金管理人准备的说明自身优势等的文件；募集推介资料，用于向潜在投资者宣传；（反向）尽职调查资料，供投资者对基金管理人调查。而收益分析报告并非基金募集的必备资料，基金不能对收益进行确定性承诺。答案：A

**7.（单选题）** 基金管理人对基金投资者的资金进行基金投资管理，从募集阶段开始就需要对基金投资者投向基金的资金与财产安全承担责任与义务，从原则上主要包括（　）。

B.董事会；董事会
C.股东大会（股东会）；董事会
D.董事会；股东大会（股东会）
**答案：** A
**解析：** 公司型基金的权力机构是股东大会（股东会） ，投资者作为股东在股东大会（股东会）层面对基金重大事项等进行决策。所以答案是A。

**49.（单选题）** 契约型基金合同当事人订立合同遵循的原则不包括（　）。
A.平等自愿
B.诚实信用
C.公平
D.收益最大化
**答案：** D
**解析：** 契约型基金合同当事人订立合同应遵循平等自愿、诚实信用、公平等原则，这些原则是保障合同订立公平公正、维护各方合法权益的基础。而收益最大化并非订立合同时遵循的原则，合同订立要确保公平等，不能单纯追求收益最大化，且收益本身具有不确定性。答案：D

**50.（单选题）** 股权投资基金（　）是投资者和基金管理人需要约定的关键内容。
A.如何保证资金安全
B.如何规避投资风险
C.如何选择投资标的
D.如何进行收益分配
**答案：** D
**解析：** 收益分配关乎投资者和基金管理人的核心利益，是双方在合作中着重约定的关键内容。资金安全、规避风险和选择投资标的虽也重要，但收益分配直接决定双方所得，更为关键。答案：D

**51.（单选题）** 企业每个纳税年度的收入总额减去（　）后的余额为企业的应纳税所得额。
Ⅰ不征税收入
Ⅱ免税收入
Ⅲ各项扣除
Ⅳ允许弥补的以前年度亏损
A.Ⅰ、Ⅱ、Ⅳ
B.Ⅰ、Ⅲ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 应纳税所得额是企业每一纳税年度的收入总额，减除不征税收入、免税收入、各项扣除以及允许弥补的以前年度亏损后的余额。这几个方面都要从收入总额中减去来计算应纳税所得额。答案：D

**53.（单选题）** 下列有关公司税收的说法，错误的是（　）。
A.当投资人是企业时，来自公司型基金分配的股息、红利所得为免税收入
B.当投资人是个人时，按股息、红利所得缴纳个人所得税的适用税率一般为50%
C.创业投资企业从事国家需要重点扶持和鼓励的创业投资，可以按投资额的一定比例抵扣应纳税所得额
D.转让财产收入是公司型基金转让标的企业股权获得的收入
**答案：** B
**解析：** A项，符合税法规定，居民企业直接投资于其他居民企业取得的股息、红利等权益性投资收益（除连续持有居民企业公开发行并上市流通的股票不足12个月取得的投资收益外），属于免税收入，所以该项说法正确。 B项，个人从公开发行和转让市场取得的上市公司股票，持股期限超过1年的，股息红利所得暂免征收个人所得税；持股期限在1个月以内（含1个月）的，其股息红利所得全额计入应纳税所得额；持股期限在1个月以上至1年（含1年）的，暂减按50%计入应纳税所得额，并非适用税率为50%，该项说法错误。 C项，创业投资企业采取股权投资方式投资于未上市的中小高新技术企业2年以上的，可以按照其投资额的70%在股权持有满2年的当年抵扣该创业投资企业的应纳税所得额，该项说法正确。 D项，公司型基金转让标的企业股权获得的收入属于转让财产收入，该项说法正确。答案：B

**54.（单选题）** 根据合伙企业所得税的相关规定，以下说法正确的是（　）。
A.从所得税层面看，合伙企业以每一个合伙人为纳税义务人
B.合伙企业生产经营所得和其他所得采取“先税后分”的原则
C.合伙企业的合伙人为自然人时，缴纳企业所得税
D.如果合伙人本身为合伙企业，该合伙企业为纳税义务人
**答案：** A
**解析：** 合伙企业生产经营所得和其他所得采取“先分后税”原则，B 错误；合伙人为自然人时，缴纳个人所得税，C 错误；合伙人本身为合伙企业，应先分至该合伙企业合伙人，由最终合伙人纳税，该合伙企业不是纳税义务人，D 错误。从所得税层面看，合伙企业以每一个合伙人为纳税义务人，A 正确。答案：A

**55.（单选题）** 下列属于公司型基金的增值税征税范围的是（　）。
A.项目股息
B.项目分红收入
C.项目上市后通过二级市场退出的退出收入
D.项目通过并购或回购等非上市股权转让方式退出的退出收入
**答案：** C
**解析：** 公司型基金的项目股息、分红收入属于股息红利所得，不属于增值税征税范围。 项目通过并购或回购等非上市股权转让方式退出，不涉及增值税应税行为。 而项目上市后通过二级市场退出的退出收入，属于金融商品转让，按照规定要缴纳增值税。答案：C

**56.（单选题）** 对于合伙型基金，下列不属于增值税征税范围的是（　）。
Ⅰ项目股息、分红收入
Ⅱ项目上市后通过二级市场退出的退出收入
Ⅲ项目通过并购或回购等非上市股权转让方式退出的退出收入
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅲ
C.Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** B
**解析：** 项目股息、分红收入，不属于增值税征税范围，因为股息红利是税后利润分配，不涉及流转税。项目通过并购或回购等非上市股权转让方式退出的退出收入，非上市股权不属于金融商品转让，不征增值税。而项目上市后通过二级市场退出的退出收入，属于金融商品转让，需缴纳增值税。所以Ⅰ和Ⅲ不属于增值税征税范围。答案：B

**57.（单选题）** 在公司型基金的章程中应列明投资的具体事项，主要包括（　）。
Ⅰ投资范围
Ⅱ投资运作方式
Ⅲ所投标的担保措施
Ⅳ投资后对被投资企业的持续监控
Ⅴ.关联方认定标准及关联方投资的回避制度
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅲ、Ⅳ、Ⅴ

D.Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ
**答案：** D
