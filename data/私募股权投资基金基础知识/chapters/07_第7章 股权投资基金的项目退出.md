# 私募股权投资基金基础知识 · 第7章 股权投资基金的项目退出

## 第1节 项目退出概述（7题）

**1.（单选题）** 以下属于协议转让退出的是（　）。
A.上市转让退出
B.挂牌转让退出
C.清算退出
D.并购退出
**答案：** D
**解析：** 协议转让退出主要包括并购退出、回购退出等。A选项上市转让退出是通过证券市场，并非协议转让；B选项挂牌转让退出是在特定交易场所挂牌，和协议转让有区别；C选项清算退出是企业解散清算，和协议转让不同。D选项并购退出属于协议转让退出方式。答案：D

**2.（单选题）** 下列说法关于股权投资基金退出，错误的是（　）
A.从退出收益的角度来看，上市转让退出的收益一般要比挂牌转让退出和协议转让退出的收益高
B.从退出效率的角度来看，上市成功后一般还有相当期限的限售期，实现最终退出耗时较长
C.场外股权交易市场挂牌一般实行注册制，所需时间相对较短
D.清算退出所需时间受债权公告、资产处置等环节影响，不同企业清算所花时间大体相同
**答案：** D
**解析：** A选项：上市转让退出因面向更广泛投资者，企业估值可能更高，所以收益通常比挂牌转让和协议转让高，该说法正确。 B选项：上市成功后确实存在限售期，实现最终退出耗时久，说法正确。 C选项：场外股权交易市场挂牌实行注册制，相比复杂的上市流程，所需时间较短，说法正确。 D选项：不同企业的债权债务情况、资产规模和性质等差异大，清算时在债权公告、资产处置等环节花费时间不同，“大体相同”说法错误。答案：D

**3.（单选题）** 股权投资基金的项目退出，是指股权投资基金选择合适的时机，将其在被投资企业的股权变现，由（　）转化为具有流动性的现金收益，以实现资本增值，或及时避免和降低损失。
A.债权形态
B.股权形态
C.资本形态
D.资产形态
**答案：** B
**解析：** 题目强调将在被投资企业的股权变现，也就是从股权形态转化为现金收益，所以答案围绕股权形态。答案：B

**4.（单选题）** 下列关于项目退出的说法，错误的是（　）。
A.股权投资基金的项目退出是整个投资的关键环节
B.上市转让退出的收益一般要比挂牌转让退出和协议转让退出的收益高
C.清算退出所需时间受债权公告、资产处置等环节影响
D.在场外交易市场挂牌转让退出的风险主要表现为由信息不对称所引起的价格不能充分反映被投资企业实际价值的不确定性
**答案：** D
**解析：** A选项，项目退出是实现投资收益、完成投资闭环的关键，该说法正确。 B选项，通常上市后企业价值能得到更充分体现，所以上市转让退出收益一般高于挂牌转让和协议转让，该说法正确。 C选项，清算退出涉及债权公告、资产处置等流程，这些环节确实会影响所需时间，该说法正确。 D选项，在场外交易市场挂牌转让退出风险主要是流动性较差，而非信息不对称引起价格不能充分反映价值，说法错误。答案：D

**5.（单选题）** 对股权投资基金而言，股权投资的关键环节是（　）。
A.实现投资收益
B.控制风险
C.实现项目退出
D.公开上市
**答案：** C
**解析：** 股权投资最终目的是要将投资退出以实现收益，只有成功退出才能真正实现投资价值，所以实现项目退出是关键环节。公开上市只是项目退出的一种方式。实现投资收益是结果，控制风险贯穿投资过程但不是关键环节。答案：C

**6.（单选题）** 项目退出通常需要选择适当的退出时机，下列关于项目退出的一般顺序排列正确的是（　）。
Ⅰ.进行交易结算并进行退出后的评估与评价
Ⅱ.评估公开上市、股权转让等不同退出路径的收益
Ⅲ.设计退出方案
Ⅳ.进行退出启动前的准备
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅱ、Ⅲ、Ⅳ、Ⅰ
C.Ⅰ、Ⅲ、Ⅳ、Ⅱ
D.Ⅰ、Ⅱ、Ⅳ、Ⅲ
**答案：** B
**解析：** 首先要评估不同退出路径收益（Ⅱ），才能据此设计退出方案（Ⅲ），方案确定后进行退出启动前准备（Ⅳ），最后进行交易结算及退出后评估（Ⅰ）。答案：B

**7.（单选题）** 从退出风险的角度来看，下列说法正确的是（　）。
Ⅰ.采用上市转让退出，企业上市申请能否获得核准仍然存在相当大的不确定性
Ⅱ.采用挂牌退出，存在挂牌后一段时间内无人受让或价格被高估的风险
Ⅲ.采用协议转让退出，由信息不对称所引起的价格不能充分反映被投资企业实际价值的不确定性
Ⅳ.采用清算退出，部分流动性较差的资产可能将不得不以极低的价格转让，甚至存在短期内无法变现的可能性
A.Ⅰ、Ⅱ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ
**答案：** C
**解析：** 对于Ⅰ，上市核准存在不确定性，这确实会给上市转让退出带来退出风险，因为若无法核准则不能实现上市退出。 对于Ⅱ，挂牌后无人受让或价格高估，都会影响退出的顺利进行和收益，属于挂牌退出的风险。但挂牌后价格一般是被低估风险大，题干表述“价格被高估”不准确。 对于Ⅲ，协议转让因信息不对称导致价格不能反映企业实际价值，影响退出收益，是协议转让退出的风险。 对于Ⅳ，清算退出时流动性差资产低价转让或无法变现，影响退出资金回收，是清算退出的风险。答案：C （Ⅱ表述错误，排除含Ⅱ选项，所以选C）

**答案：** C
**解析：** 清算退出流程一般包括清查公司财产并制订清算方案，了结债权债务与未了结业务，以及分配剩余财产等。而办理变更登记不属于清算退出流程内容，变更登记多用于公司正常经营中的信息变更等情况。答案选C。

**6.（单选题）** 清算组进行清算退出的流程不包括（　）。
A.清查公司财产，制订清算方案
B.处理公司未了结的业务
C.分配公司剩余财产
D.开展新的经营活动
**答案：** D
**解析：** 清算退出是公司结束经营活动进行清算，而开展新的经营活动与清算目的相悖。清算流程主要是清查财产、处理未了结业务、分配剩余财产等。答案：D

**7.（单选题）** （　）是指股权投资基金通过被投资企业清算实现退出，主要是投资项目失败后的一种退出方式。
A.项目退出
B.清算退出
C.评估公开上市
D.股份转让
**答案：** B
**解析：** 题目描述的是因投资项目失败，通过被投资企业清算来实现退出，这明显符合清算退出的定义。答案：B

**8.（单选题）** 公司解散清算的，有限责任公司的清算组由（　）组成，股份有限公司的清算组由（　）或者股东大会确定的人员组成。
A.股东；股东
B.股东；董事
C.董事会；股东
D.董事会；董事会
**答案：** B
**解析：** 有限责任公司清算组由股东组成，这是因为股东是公司的所有者，对公司清算事宜有直接利益关系和责任。股份有限公司清算组由董事或者股东大会确定的人员组成，是基于股份公司规模较大、股东分散等特点，董事熟悉公司运营等情况可参与清算，股东大会也有权确定合适人员。答案：B

**9.（单选题）** 清查公司财产、制订清算方案是清算退出的流程之一，编制公司财务会计报告之后，清算组应当制订清算方案，提出收取债权和清偿债务的具体安排，提交（　）通过或者报主管机关确认，若公司财产不足清偿债务的，清算组有责任向（　）申请宣告破产。
A.股东大会；有管辖权的人民法院
B.股东大会；政府主管部门
C.董事会；有管辖权的人民法院
D.董事会；政府主管部门
**答案：** A
**解析：** 清算方案通常需提交给股东大会通过，因为股东大会是公司的最高权力机构，涉及公司清算这样重大的事项需其决策。当公司财产不足清偿债务时，应向有管辖权的人民法院申请宣告破产，这是走法律程序，不是向政府主管部门申请。答案：A

**10.（单选题）** 关于清算的说法，错误的是（　）。
A.清算组在催告债权人申报债权的同时，应当调查和清理公司的财产
B.解散清算是公司自愿或被迫宣告解散而进行的清算
C.人民法院裁定宣告公司破产后，清算组应当继续推进清算事务的执行
D.调查和清理公司财产的工作主要由清算组进行
**答案：** C
**解析：** 人民法院裁定宣告公司破产后，破产管理人会接管清算事务，而不是清算组继续推进，C 说法错误。A 选项清算组有调查清理财产及催告债权申报职责；B 选项对解散清算定义表述正确；D 选项调查清理公司财产主要由清算组进行表述无误。答案：C

**11.（单选题）** 关于股权投资基金的清算退出，下列说法错误的是（　）。
A.清算退出主要是针对股权投资基金投资项目获得成功的一种退出方式
B.清算退出主要有两种方式：破产清算和解散清算
C.清算期间公司不得开展新的经营活动
D.解散清算是公司自愿或被迫宣告解散而进行的清算
**答案：** A
**解析：** 清算退出是投资项目失败时的退出方式，并非项目成功的退出方式，A 错误；B 对，清算退出确实主要有破产清算和解散清算两种；C 对，清算期间公司不能开展新经营活动；D 对，解散清算是公司因各种原因宣告解散而进行的清算。答案：A

**12.（单选题）** 关于股权投资基金清算退出的流程和方法，下列说法正确的是（　）。
A.公司财产不足清偿债务，经人民法院裁定宣告破产后，清算组应当在人民法院监督下完成清算事务
B.清算期间公司不得开展新的经营活动，公司清算组无权处理公司尚未了结的业务
C.对于未到期的公司债权，清算组应强制要求债务人提前清偿
D.公司清偿了全部公司债务之后，如果公司财产还有剩余的，清算组才能够将公司剩余财产分配给包括股权投资基金在内的股东
**答案：** D
**解析：** A项，宣告破产后由法院指定的破产管理人完成清算，并非清算组在法院监督下完成；B项，清算组有权处理未了结业务；C项，未到期债权，清算组可要求到期清偿，非强制提前清偿。D项，先清偿债务，有剩余再分配给股东，说法正确。答案：D
