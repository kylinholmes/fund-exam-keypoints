# 基金基础知识与法律法规 · 第4章 基金市场参与主体及其从业人员的法规要求

## 第1节 公募基金管理人应当遵守的法律规定（16题）

**1.（单选题）** 公募基金管理人应按照基金合同的规定及时地向（　）支付基金收益。
A.基金份额持有人
B.基金托管人
C.基金发起人
D.基金管理人
**答案：** A
**解析：** 基金收益是要给到基金的投资者，也就是基金份额持有人。基金托管人负责资金保管等，基金发起人在基金成立后职责基本完成，基金管理人是管理运作基金的主体，不是收益支付对象。所以答案是A。

**2.（单选题）** 根据《公开募集证券投资基金管理人监督管理办法》的规定，同一主体或者受同一主体控制的不同主体参股基金管理公司的数量不得超过（　）。
A.1家
B.2家
C.3家
D.5家
**答案：** B
**解析：** 《公开募集证券投资基金管理人监督管理办法》规定同一主体或者受同一主体控制的不同主体参股基金管理公司的数量不得超过2家 。答案：B

**3.（单选题）** 根据《公开募集证券投资基金管理人监督管理办法》，公募基金管理人退出的情形不包括（　）。
A.解散
B.破产
C.股东变更备案
D.风险处置
**答案：** C
**解析：** 公募基金管理人退出意味着主体不再存续，解散、破产、风险处置都可能导致管理人退出运营，而股东变更备案只是管理人内部股东结构的变动，不代表管理人整体退出。答案：C

**4.（单选题）** 公募基金管理人因违法违规、违反基金合同等原因给基金财产或者基金份额持有人合法权益造成损失，应当承担赔偿责任的，可以优先使用（　）予以赔偿。
A.备用金
B.账户存款
C.风险准备金
D.法定准备金
**答案：** C
**解析：** 公募基金管理人因违法违规等给基金财产或份额持有人造成损失，优先用风险准备金赔偿，这是为了保障投资者权益，风险准备金就是为此设立。答案：C。

**5.（单选题）** 公募基金管理人应当从管理基金的报酬中计提（　）。
A.净资本
B.基金手续费
C.交易佣金
D.风险准备金
**答案：** D
**解析：** 公募基金管理人需从管理基金的报酬中计提风险准备金，以应对可能的风险。这是相关法规对基金管理人的要求，用于保障基金份额持有人利益。其他选项净资本是衡量证券公司资本充足和资产流动性状况的指标；基金手续费是基金销售等过程中收取的费用，并非从管理报酬计提；交易佣金是证券交易时支付给券商的费用，和从管理报酬计提无关。答案：D

**6.（单选题）** 当公募基金管理人违法经营或者出现重大风险，严重损害基金份额持有人利益或者危害金融市场秩序时，中国证监会或者其派出机构可以采取的风险处置措施有（　）。
Ⅰ.风险监控
Ⅱ.责令停业整顿
Ⅲ.指定其他机构托管
Ⅳ.取消或者撤销公募基金管理业务资格
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 当公募基金管理人出现题干所述严重问题时，中国证监会或其派出机构为处置风险，可采取风险监控来实时掌握情况，责令停业整顿让其改正问题，指定其他机构托管以保障基金资产运作，取消或撤销业务资格从根本上解决风险源。这些措施都在其权限范围内用于风险处置。答案：D

**7.（单选题）** 关于公募基金管理人的主要业务规范，下列说法正确的有（　）。
Ⅰ.公募基金管理人应当建立健全由授权、研究、决策、执行、评估、考核、监察、惩戒等环节构成的投资管理制度和流程
Ⅱ.公募基金管理人应当按照中国基金业协会的规定加强基金销售管理，建立和完善投资者适当性管理制度
Ⅲ.公募基金管理人应当建立健全人力资源管理和薪酬管理制度以及规范的考核机制
Ⅳ.公募基金管理人应当建立公募基金财务核算与基金资产估值制度和流程
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅰ、Ⅱ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅲ、Ⅳ
**答案：** D
**解析：** Ⅰ项，建立健全包含多环节的投资管理制度和流程是公募基金管理人规范投资运作的必要举措，正确。 Ⅱ项，是应按照中国证监会而非中国基金业协会规定加强基金销售管理和完善投资者适当性管理制度，所以Ⅱ错误。 Ⅲ项，建立健全人力资源和薪酬管理及考核机制有利于管理人内部管理，正确。 Ⅳ项，建立财务核算与基金资产估值制度和流程是保障基金资产准确核算和估值的关键，正确。答案：D

**8.（单选题）** 关于公募基金管理人的治理，以下说法错误的是（　）。
A.公募基金管理人的公司章程应当明确股东会的职权范围和议事规则
B.公募基金管理人设置监事(会)或审计委员会行使内部监督职能
C.公募基金管理人的总经理负责公司的经营管理
D.公募基金管理人的监事应当为董事会成员
**答案：** D
**解析：** 监事主要对公司经营运作进行监督，不能同时为董事会成员，二者职责相互独立、制衡。而A选项明确股东会职权和议事规则是合理的；B选项设置监事（会）或审计委员会可行使监督职能；C选项总经理负责公司经营管理也是常见设置。答案：D

**9.（单选题）** 目前我国公募基金管理人的基金国际化业务主要包括（　）。
Ⅰ.申请QDII资格和额度开展境外投资
Ⅱ.设立境外经营机构拓展境外业务
Ⅲ.通过基金互认在境外市场向公众投资者销售基金
Ⅳ.通过互联互通机制交易香港市场的股票
A.Ⅰ、Ⅳ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 我国公募基金管理人的基金国际化业务涵盖多个方面。申请QDII资格和额度可开展境外投资；设立境外经营机构能拓展境外业务；基金互认可在境外向公众销售基金；通过互联互通机制交易香港股票也是国际化业务表现。这几方面都属于基金国际化业务范畴。答案：D

**10.（单选题）** 基金管理人应当自责令停业整顿决定生效之日起（　）内提交整顿计划，并取得中国证监会或者其派出机构认可。
A.3日
B.7日
C.2周
D.1个月
**答案：** D

**11.（单选题）** 下列关于基金管理人及其从业人员的说法，正确的是（　）。
A.基金从业人员不得买卖证券
B.公开募集基金的基金管理人可以将其固有财产混同于基金财产从事证券投资
C.公开募集基金的基金管理人应当进行基金会计核算并编制基金财务会计报告
D.当基金管理人及其从业人员的利益与基金份额持有人利益发生冲突时，应以基金管理人利益优先
**答案：** C
**解析：** A 选项，基金从业人员可以在遵守相关规定下买卖证券，并非绝对不得买卖，A 错误；B 选项，公开募集基金的基金管理人不能将固有财产混同于基金财产从事证券投资，B 错误；C 选项，公开募集基金的基金管理人有进行基金会计核算并编制基金财务会计报告的职责，C 正确；D 选项，当利益冲突时，应以基金份额持有人利益优先，D 错误。答案：C

**12.（单选题）** 设立公募基金管理公司的注册资本不低于（　）人民币，且股东必须以来源合法的自有货币资金实缴。
A.4亿元
B.3亿元
C.2亿元
D.1亿元
**答案：** D
**解析：** 根据相关规定，设立公募基金管理公司的注册资本不低于1亿元人民币，且为实缴货币资本。答案：D

**13.（单选题）** 下列说法中，错误的是（　）。
A.公募基金管理人应当从管理基金的报酬中计提风险准备金。
B.公募基金管理人被依法宣告破产时，其主要股东应召集其他股东及当事人，以基金份额持有人利益优先为原则，妥善处理相关事宜
C.公募基金管理人应当按照法律、行政法规和中国证券投资基金业协会的规定，建立组织机构健全、职责划分清晰、制衡监督有效、激励约束合理的治理结构
D.公募基金管理人应当按照中国证监会的规定，在保持公司正常运营的前提下，管理和运用固有资金
**答案：** C
**解析：** A项正确：公募基金管理人应当从管理基金的报酬中计提风险准备金。B项正确：基金管理人被依法宣告破产时，其主要股东应当召集其他股东及相关当事人，以基金份额持有人利益优先为原则妥善处理相关事宜。D项正确：基金管理人应当按照中国证监会的规定，在保持公司正常运营的前提下管理和运用固有资金。C项错误：基金管理人应当依照法律、行政法规和国务院证券监督管理机构（中国证监会）的规定，建立组织机构健全、职责划分清晰、制衡监督有效、激励约束合理的治理结构，而非按中国证券投资基金业协会的规定。本题选C。

**14.（单选题）** 设立公募基金管理公司应当具备包括（　）。
Ⅰ、有符合中国证监会规定的内部管理制度
Ⅱ、有符合要求的公司名称、营业场所、安全防范设施和与业务有关的其他设施
Ⅲ、设置了分工合理、职责清晰的组织机构和工作岗位

**15.（单选题）** 公募基金管理公司的主要股东是指持有基金管理公司股权比例不低于（　）的股东，如任一股东持股均未达该比例的，则主要股东为持有5%以上股权的第一大股东。
A.10%
B.20%
C.25%
D.50%
**答案：** C

**16.（单选题）** 公募基金管理人应当履行的职责不包括（　）。
A.依法募集资金，办理基金份额的发售和登记事宜
B.按照基金合同的约定确定基金收益分配方案
C.编制中期和年度基金报告
D.安全保管基金财产
**答案：** D
**解析：** 安全保管基金财产是基金托管人的职责，而A、B、C选项均属于公募基金管理人的职责。答案：D

## 第2节 私募基金管理人应当遵守的法律规定（12题）

**1.（单选题）** 私募基金管理人开展或者参与具有（　）等特征的资金池业务，中国证券投资基金业协会可以撤销私募基金管理人登记。
Ⅰ.滚动发行
Ⅱ.集合运作
Ⅲ.期限错配
Ⅳ.分离定价
A.Ⅰ、Ⅲ、Ⅳ
B.Ⅰ、Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅳ
**答案：** B
**解析：** 私募基金管理人开展或者参与具有滚动发行、集合运作、期限错配、分离定价等特征的资金池业务，中国证券投资基金业协会可以撤销私募基金管理人登记。

**2.（单选题）** 中国证监会和中国证券投资基金业协会加强对私募基金管理人的持续监管，通过（　）等手段，防范私募基金管理人出现重大风险和损害投资人利益，维护市场稳定。
Ⅰ.数据报送
Ⅱ.风险事件监测
Ⅲ.日常合规检查
Ⅳ.提供保本承诺
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** C
**解析：** 私募基金管理人不得向投资者提供保本承诺，Ⅳ错误；而中国证监会和中国证券投资基金业协会可通过数据报送、风险事件监测、日常合规检查等手段对私募基金管理人持续监管，Ⅰ、Ⅱ、Ⅲ正确。答案：C

**3.（单选题）** 关于《私募投资基金管理人内部控制指引》对私募基金管理人经营中的各项规定，说法正确的有（　）。
Ⅰ.私募基金管理人应当遵循专业化运营原则，主营业务清晰
Ⅱ.私募基金管理人不得兼营与私募基金管理无关或存在利益冲突的其他业务
Ⅲ.私募基金管理人应当健全治理结构，防范不正当关联交易、利益输送和内部人控制风险
Ⅳ.私募基金管理人授权控制要全面，应具备贯穿于资金募集、投资研究、投资运作、运营保障和信息披露等主要环节始终的授权控制，建立健全授权标准和程序
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** Ⅰ项，遵循专业化运营原则，主营业务清晰，有助于私募基金管理人专注核心业务，符合行业规范，表述正确。 Ⅱ项，兼营与私募基金管理无关或存在利益冲突业务可能损害投资者利益，所以不得兼营，表述正确。 Ⅲ项，健全治理结构防范不正当关联交易等风险，是保障基金管理规范运作和投资者权益的重要举措，表述正确。 Ⅳ项，全面的授权控制贯穿各主要环节，能有效规范业务流程，表述正确。答案：D  这四项说法均正确，所以选D选项。

**7.（单选题）** 关于私募基金管理人登记的基本要求，下列说法错误的是（　）。

B.内部治理结构健全、风控合规制度和利益冲突防范机制等完善

**19.（单选题）** 基金托管人的行为严重影响所托管基金的稳健运行、损害基金份额持有人利益的，监管机构可以采取的措施不包括（　）。

## 第4节 基金服务机构应当遵守的法律规定（18题）

**1.（单选题）** （　）应当按照规定办理基金销售结算资金的划付，确保基金销售结算资金安全、及时划付。

C.基金投资顾问机构
D.基金估值核算机构
**答案：** A
**解析：** 基金销售支付机构主要负责办理基金销售结算资金的划付，保障资金安全与及时划付。其他选项中，基金份额登记机构负责份额登记等，基金投资顾问机构提供投资建议等，基金估值核算机构进行估值核算，都与销售结算资金划付职责不符。答案：A

**2.（单选题）** 基金份额登记机构的主要职责包括（　）。

C.基金份额的登记
D.基金份额的募集与运作管理
**答案：** C
**解析：** 基金份额登记机构主要职责围绕基金份额登记相关工作。A选项中募集是基金管理人等的职责，客户服务并非份额登记机构主要职责；B选项销售一般是销售机构职责，投资是基金管理人职责；D选项募集和运作管理多为基金管理人职责。只有C选项基金份额的登记是基金份额登记机构主要职责。答案：C

**3.（单选题）** 按照规定办理基金销售结算资金的划付，是（　）的法定义务。

B.基金销售支付机构
C.基金评价机构
D.基金投资顾问机构
**答案：** B
**解析：** 基金销售支付机构主要负责销售支付相关工作，按规定办理基金销售结算资金划付是其法定义务。而基金份额登记机构主要负责份额登记等，基金评价机构负责基金评价，基金投资顾问机构提供投资顾问服务，它们不主要承担销售结算资金划付职责。答案：B

**4.（单选题）** 基金交易确认的机构是（　）。
A.基金销售机构
B.基金销售支付机构
C.基金份额登记机构
D.基金评价机构
**答案：** C
**解析：** 基金份额登记机构的主要职责包括建立并管理投资者的基金账户、负责基金份额的登记及资金结算、基金交易确认等。而基金销售机构主要负责销售基金；基金销售支付机构负责提供支付服务；基金评价机构负责对基金进行评价。所以基金交易确认的机构是基金份额登记机构。答案：C

**5.（单选题）** 从事公募基金的（　）等基金服务业务的机构，应当按照中国证监会的规定进行注册或者备案。

C.投资顾问
D.以上都是
**答案：** D
**解析：** 从事公募基金的销售支付、份额登记、投资顾问等基金服务业务的机构，都需要按照中国证监会规定进行注册或备案。所以这几个选项都符合题意。答案：D

**6.（单选题）** 基金销售机构应当履行的义务有（　）。
Ⅰ.向投资人充分揭示投资风险
Ⅱ.向投资人销售合适的基金产品
Ⅲ.提供基金投资顾问服务
Ⅳ.妥善保存登记数据
A.Ⅰ
B.Ⅰ、Ⅱ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 这是一道关于基金销售机构义务的选择题。我们来简化解析一下：基金销售机构的核心义务是确保投资人的权益得到保护，并提供合规的服务。Ⅰ. 向投资人充分揭示投资风险：这是基金销售机构的基本义务之一，确保投资人在了解风险的基础上做出决策。Ⅱ. 向投资人销售合适的基金产品：基金销售机构应根据投资人的风险承受能力和投资目标推荐合适的基金，这也是其重要义务。Ⅲ. 提供基金投资顾问服务：虽然提供顾问服务是基金销售机构的一项功能，但它并非销售机构的特定义务，而是可选服务之一。Ⅳ. 妥善保存登记数据：这更多是基金注册登记机构的职责，而非销售机构的直接义务。综上所述，基金销售机构必须履行的义务是Ⅰ和Ⅱ，即向投资人充分揭示投资风险和销售合适的基金产品。所以，正确答案是B.Ⅰ、Ⅱ。

**7.（单选题）** 基金投资顾问机构应当履行的义务包括（　）。

## 第5节 基金从业人员的法规要求（19题）

A.具备3年以上与其拟任职务相关的证券、基金、金融、法律、会计、信息技术等工作经历

D.曾担任证券基金经营机构部门负责人以上职务不少于1年
**答案：** D
**解析：** 公募基金管理公司高级管理人员任职基本条件中，一般要求具备3年以上与其拟任职务相关的证券、基金、金融、法律、会计、信息技术等工作经历（A选项正确）；具有与拟任职务相适应的管理经历和经营管理能力（B选项正确）；熟悉证券基金法律法规和中国证监会的规定（C选项正确）。而对于曾担任证券基金经营机构部门负责人以上职务的时间要求通常是2年以上，并非1年，所以D选项错误。答案：D

**2.（单选题）** 公募基金管理人的董事、监事、高级管理人员及从业人员的禁止行为包括（　）。
Ⅰ挪用或者侵占公司、客户资产或者基金财产
Ⅱ私下接受客户委托从事证券基金投资
Ⅲ利用职务之便为本人或者他人牟取不正当利益
Ⅳ对所管理的不同基金财产分别管理、分别记账，进行证券投资
A.Ⅰ、Ⅱ
B.Ⅱ、Ⅳ
C.Ⅰ、Ⅱ、Ⅲ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**6.（单选题）** 下列选项中，（　）不是高级管理人员的廉洁从业管理职责。

B.)听取机构廉洁从业管理情况及廉业相关的重大违规行为或者风险事项的报告
