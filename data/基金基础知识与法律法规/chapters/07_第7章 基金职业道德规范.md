# 基金基础知识与法律法规 · 第7章 基金职业道德规范

## 第1节 基金职业道德建设（66题）

**1.（单选题）** 岗前职业道德教育主要是通过（　）和基金从业人员所在机构在其入职时上岗前对其进行教育等途径来督促完成的。
A.在职培训
B.基金从业资格考试
C.职业道德检查和奖惩机构
D.基金从业人员职业道德档案
**答案：** B
**解析：** 岗前职业道德教育途径，一是基金从业资格考试，二是所在机构上岗前教育。A选项在职培训是岗后；C选项奖惩机构、D选项档案都不属于岗前教育途径。答案：B

**2.（单选题）** （　）是基金职业道德规范教育的基础和保障。
A.投资者信任
B.基金职业道德观念教育
C.基金监管法规
D.职业道德素养
**答案：** B
**解析：** 基金职业道德观念教育是基金职业道德规范教育的基础和保障，只有先树立正确的职业道德观念，才谈得上遵循职业道德规范。答案：B

**3.（单选题）** 下列关于道德的差异性，说法不正确的是（　）。
A.不同的社会有完全不同的道德
B.社会经济基础和社会关系的不同决定了道德的差异性
C.不同的社会条件下有着不同的社会价值观念
D.社会道德规范包括基本道德规范和一系列特定道德规范
**答案：** A
**解析：** 不同社会虽道德有差异，但并非完全不同，存在一些普遍认可的道德原则，A 表述太绝对。B 指出社会经济基础和关系决定道德差异，合理；C 不同社会条件下价值观念不同，会影响道德，合理；D 社会道德规范确实包含基本和特定道德规范，合理。答案：A

**4.（单选题）** 下列关于道德的继承性，说法错误的是（　）。
A.随着社会经济基础的变化，属于意识形态的道德也会发生相应变化
B.没有永恒不变的道德，现代道德与传统道德已经完全不一样了
C.因为影响道德形成和发展的各种因素具有历史延续性，所以道德有历史的传承
D.传统道德的传承力往往是巨大的，现代道德都深深烙有传统道德的印记
**答案：** B
**解析：** 道德具有继承性。社会经济基础变化，道德会相应变化，A选项正确，体现道德随社会发展而发展。 C选项指出影响道德形成和发展因素有历史延续性，所以道德有传承，这符合道德继承性特点。 D选项说明传统道德传承力大，现代道德有传统道德印记，也是道德继承性的体现。 而B选项说现代道德与传统道德完全不一样，过于绝对，道德有继承性，并非完全割裂，现代道德是在传统道德基础上发展而来，存在一定联系。答案：B

**5.（单选题）** 下列选项不是道德的评价标准的是（　）。
A.善与恶
B.是与非
C.正与邪
D.法与规
**答案：** D
**解析：** 道德评价标准多基于伦理、价值层面，善与恶、是与非、正与邪都从不同角度体现道德层面判断。而法与规是法律范畴，法律有其特定制定、实施体系，和道德评价标准有本质区别。答案：D

**6.（单选题）** 关于职业道德的作用，说法正确的是（　）。
A.职业道德可以引导和规范从业人员的职业行为
B.职业道德只能调整从业人员与其服务对象之间的关系
C.职业道德只能调整从业人员的内部关系
D.法律是化解矛盾、解决冲突的重要手段，因此不需要职业道德
**答案：** A
**解析：** 职业道德不仅能调整从业人员与其服务对象间关系、内部关系，还对行业、社会等都有重要作用，它能引导和规范从业人员职业行为，且法律虽重要，职业道德也不可或缺，可辅助法律调整诸多方面。答案：A

**7.（单选题）** 关于职业道德与职业素质，说法正确的是（　）。

**答案：** C

**13.（单选题）** 道德与法律是社会行为规范最重要的两种形式，关于道德与法律的联系，下列说法中正确的是（　）。
A.如果某些行为违反了道德，该行为一定是违反法律的
B.绝大多数的道德规范都是以法律作为价值基础的
C.法律的实施对道德观念的培养起到强化促进作用

**14.（单选题）** 道德的特征不包括（　）。
A.道德具有差异性
B.道德具有继承性
C.道德具有约束性
D.道德具有抽象性
**答案：** D
**解析：** 道德具有差异性，不同社会、文化等道德不同；有继承性，会传承前代道德精华；有约束性，规范人的行为。而道德是具体的，通过行为规范等具体形式表现，并非抽象。答案选D。

**答案：** D
**解析：** 基金职业道德强调守法合规、诚实守信、专业审慎等，以维护市场秩序和投资者利益，而利益至上不符合基金行业秉持的道德原则，会导致损害投资者等相关方利益的不良行为。答案选D。

**16.（单选题）** 道德与法律的区别不包括（　）。

**答案：** C
**解析：** 道德与法律在表现形式上，法律有明确条文，道德较为模糊；内容结构上，法律严谨成体系，道德较松散；调整手段上，法律靠强制，道德靠舆论等。而两者根本目的都是维护社会秩序、保障社会稳定发展。所以答案选C 。

**20.（单选题）** 道德是一种（　）。
A.社会关系
B.权利义务关系
C.社会意识形态
D.以上都不是
**答案：** C
**解析：** 道德是社会意识形态之一，是人们共同生活及其行为的准则和规范。社会关系包含多种，道德只是其中通过观念等约束行为的一种特殊表现形式，不能简单等同于社会关系；道德主要依靠内心信念等维系，并非像法律那样明确的权利义务关系。所以道德是一种社会意识形态。答案：C
