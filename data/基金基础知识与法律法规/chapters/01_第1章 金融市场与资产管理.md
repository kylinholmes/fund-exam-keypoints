# 基金基础知识与法律法规 · 第1章 金融市场与资产管理

## 第1节 金融市场（68题）

**1.（单选题）** 下列属于金融市场按交易标的物划分的是（　）。
①货币市场②资本市场
③现货市场④期货市场
A.①②
B.①③
C.②③
D.③④
**答案：** A
**解析：** 金融市场按交易标的物可划分为货币市场、资本市场、外汇市场、金融衍生品市场、保险市场、黄金市场等。现货市场和期货市场是按交割期限划分的。所以①货币市场和②资本市场符合按交易标的物划分。答案选A。

**2.（单选题）** 金融市场分类不包括（　）。
A.按交易标的物分类
B.按融资方式分类
C.按交易区域分类
D.按交割期限分类
**答案：** C
**解析：** 金融市场常见分类有按交易标的物分，如货币市场、资本市场等；按融资方式分，像直接融资市场、间接融资市场；按交割期限分，有现货市场、期货市场。而按交易区域分类并非金融市场主流分类方式。答案：C

**3.（单选题）** 金融工具是金融市场的（　）。
A.交易方式
B.交易中介
C.主体
D.客体
**答案：** D
**解析：** 金融市场主体是参与者，交易方式是买卖等形式，交易中介是促进交易达成的机构等，而金融工具是金融市场上进行交易的对象，也就是客体。答案：D

**4.（单选题）** 根据交易的组织方式，金融市场交易方式可分为（　）。
A.场内交易和场外交易
B.高频交易和低频交易
C.短线交易和长线交易
D.日内交易和日外交易
**答案：** A
**解析：** 按照交易的组织方式，金融市场交易方式分为场内交易和场外交易，场内交易在固定场所集中进行，场外交易在非固定场所分散进行。而高频低频、短线长线、日内日外都不是按交易组织方式划分。答案：A

**5.（单选题）** 按金融市场主体的参与身份划分，金融市场主体不包括（　）。
A.政府
B.中央银行
C.社会团体
D.个人
**答案：** C
**解析：** 金融市场主体常见的有政府、中央银行、各类金融机构、企业和个人。社会团体一般不是金融市场主体的常规划分类别。答案：C

**6.（单选题）** 完整的金融市场有（　）必备的构成要素。
A.5个
B.4个
C.3个
D.2个
**答案：** A
**解析：** 完整的金融市场有五大必备的构成要素，分别是主体、客体、交易价格、交易方式和交易中介。

**7.（单选题）** 下列哪项不是金融市场交易中介？（　）
A.银行
B.证券公司
C.基金公司
D.科技公司
**答案：** D
**解析：** 金融市场交易中介是指在金融市场上充当交易媒介，从事交易或促使交易完成的组织、机构或个人。银行、证券公司、基金公司都在金融市场交易中发挥重要中介作用，比如银行提供存贷款等金融服务、证券公司协助证券交易等、基金公司负责基金的运作等。而科技公司主要业务通常是围绕科技研发、产品开发等，一般不直接作为金融市场交易中介。答案：D

**8.（单选题）** 下列哪些是金融市场的构成要素？（　）
Ⅰ.主体
Ⅱ.客体
Ⅲ.交易价格
Ⅳ.交易方式
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅱ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 金融市场构成要素包括主体（参与者，如政府、企业、居民等）、客体（交易对象，如股票、债券等金融工具）、交易价格（利率等体现金融资产价格）以及交易方式（现货交易、期货交易等不同交易形式），它们共同支撑金融市场运行。答案：D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**9.（单选题）** （　）是资金供给方和资金需求方通过金融工具等进行交易融通资金的场所。
A.政府机构
B.公益组织
C.金融市场
D.商品交易所
**答案：** C
**解析：** 金融市场的定义就是资金供给方和需求方通过金融工具交易融通资金的场所。A政府机构主要履行行政管理等职能；B公益组织致力于公益事业，并非资金融通场所；D商品交易所主要针对商品交易，并非资金融通。答案：C

**10.（单选题）** 金融市场的（　）是指资金融通所支付的对价。
A.交易目标
B.交易中介
C.交易方式
D.交易价格
**答案：** D
**解析：** 金融市场中，资金融通所支付的对价就是交易价格，比如借款要付利息，利息就是使用资金的价格。而交易目标是金融交易的对象，交易中介是促成交易的机构或个人，交易方式是达成交易的形式，都与资金融通支付的对价无关。答案：D

**12.（单选题）** 市场的核心是（　），买方的需求和卖方的供给相互作用，决定了商品或服务的价格和数量。
A.价格机制
B.供求关系
C.生产要素
D.消费者偏好
**答案：** B
**解析：** 题干提到买方需求（即求）和卖方供给（即供）相互作用决定价格和数量，这明显体现的是供求关系对市场的关键影响。而价格机制是供求关系影响下产生价格变动等一系列规则；生产要素是生产所需的各种资源；消费者偏好只是影响需求的一个因素，都不如供求关系契合题意。答案：B

**15.（单选题）** 金融市场的功能包括（　）。
Ⅰ.资金融通
Ⅱ.资源配置

B.Ⅰ、Ⅳ
C.Ⅱ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 金融市场具有资金融通功能，能将资金盈余者的资金转移到资金短缺者手中，实现资金流动，Ⅰ正确。 资源配置功能体现在引导资金流向不同部门和企业，实现资源合理分配，Ⅱ正确。 风险管理功能是指市场参与者可通过金融工具进行风险转移、分散等操作，Ⅲ正确。 经济反映功能表现为金融市场能反映宏观经济运行情况等信息，Ⅳ正确。答案：D.Ⅰ、Ⅱ、Ⅲ、Ⅳ

**16.（单选题）** （　）的繁荣程度、价格波动等反映出社会经济发展状况，也被称为社会经济活动的“晴雨表”。

**32.（单选题）** （　）是金融市场最基本的功能。
A.资金融通
B.经济反映
C.价格发现
D.效率提升

**42.（单选题）** 美国资产管理机构之一银行，通过独立账户或银行共同信托基金和集合投资基金，为客户提供投资基金、财富管理、信托服务、退休产品等服务。此项业务属于银行的（　）。
A.资产业务
B.负债业务
C.表外业务
D.代理业务
**答案：** C
**解析：** 这道题目考察的是银行业务的分类。首先，我们要明确银行业务的三大基本分类：资产业务、负债业务和表外业务。1. 资产业务：主要是银行利用吸收的资金进行贷款和投资的活动。2. 负债业务：是银行形成资金来源的业务，主要包括存款和借款。3. 表外业务：是指那些不影响资产负债表中资产和负债总额，但能改变当期损益及营运资金，从而提高银行资产报酬率的经营活动。这类业务通常是以或有资产或或有负债的形式存在。接下来，我们针对题目中的描述进行分析：* 投资基金、财富管理、信托服务、退休产品等服务，这些都是银行为客户提供的一种服务，而不是银行自身的资金运用或资金来源。* 这些服务不会直接增加银行的资产或负债，但可以为银行带来手续费或佣金收入。对照上述三类业务，我们可以明确：* 这些服务不属于资产业务，因为银行并没有直接运用自己的资金。* 也不属于负债业务，因为这些服务不会为银行形成资金来源。* 这些服务属于表外业务，因为它们不影响银行的资产负债表，但可以为银行带来收入。至于D选项“代理业务”，虽然这些服务中有代理的成分，但从银行业务分类的角度看，它们更准确地被归类为表外业务。综上所述，此项业务属于银行的表外业务。所以，正确答案是C.表外业务。
