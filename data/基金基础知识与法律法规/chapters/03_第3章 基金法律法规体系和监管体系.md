# 基金基础知识与法律法规 · 第3章 基金法律法规体系和监管体系

## 第1节 法律法规体系（8题）

**1.（单选题）** 下列属于公募基金适用的自律规则是（　）。
A.《基金管理公司风险管理指引（试行）》
B.《基金管理公司子公司管理规定》
C.《公开募集证券投资基金运作管理办法》
D.《证券期货经营机构及其工作人员廉洁从业规定》
**答案：** A
**解析：** 题目问公募基金适用的自律规则，A选项《基金管理公司风险管理指引（试行）》是关于基金管理公司风险管理的自律规则，与公募基金直接相关。B选项是针对基金管理公司子公司。C选项《公开募集证券投资基金运作管理办法》属于部门规章，不是自律规则。D选项《证券期货经营机构及其工作人员廉洁从业规定》主要是关于廉洁从业方面，并非针对公募基金特点的自律规则。答案：A

**2.（单选题）** 《私募投资基金信息披露管理办法》在基金监管法律制度体系中属于（　）。
A.法律
B.部门规章
C.规范性文件
D.自律规则
**答案：** D
**解析：** 《私募投资基金信息披露管理办法》由中国证券投资基金业协会于2016年2月4日发布实施，属于行业自律规则；协会配套发布的《私募投资基金信息披露内容与格式指引1号、2号》同属自律规则。全国人大及其常委会制定的是法律，国务院制定的是行政法规，中国证监会制定的是部门规章。本题选D。

**3.（单选题）** 2014年，中国证监会颁布了《私募投资基金监督管理暂行办法》，其对私募基金的（　）进行了明确。

**4.（单选题）** 《证券投资基金法》的颁布对中国基金行业具有重要意义，以下关于该法核心内容的表述‌错误‌的是（　）。

## 第2节 基金监管（27题）

**1.（单选题）** （　）是指有法定监管权的行政机构依法对基金市场、基金市场主体及其活动的监督和管理。
A.行业自律监管
B.机构内部监管
C.基金监管
D.社会监管‌
**答案：** C
**解析：** 题干强调法定监管权的行政机构对基金市场等的监督管理，这正是基金监管的定义。行业自律监管是行业协会等自律组织的行为；机构内部监管是机构自身内部的监督；社会监管是社会力量的监督，均不符合题干描述。答案：C

**2.（单选题）** (狭义)基金监管是指有（　）依法对基金市场、基金市场主体及其活动的监督和管理。
A.社会力量
B.基金机构内部监督部门
C.基金行业自律组织
D.有法定监管权的行政机构
**答案：** D
**解析：** 狭义的基金监管，主体是具有法定监管权的行政机构 。社会力量、基金机构内部监督部门、基金行业自律组织等进行的监督不属于狭义基金监管范畴。所以答案是D。

**3.（单选题）** 根据我国《证券投资基金法》的立法宗旨，下列哪一项不属于基金监管的核心目标？（　）
A.保护基金投资人的合法权益
B.通过行政干预直接提高基金投资收益
C.对基金募集、交易等行为进行规范化约束
D.促进基金行业和资本市场的健康发展
**答案：** B
**解析：** 基金监管核心目标围绕保护投资者权益、规范行业行为、促进市场健康发展等，而行政干预直接提高基金投资收益并非监管核心目标，监管主要营造良好环境而非直接干涉收益。答案：B

**4.（单选题）** 我国基金监管的职责范围不包括（　）。
A.对基金市场主体的准入监管
B.对市场行为的监管
C.对各种违法违规行为的处置措施
D.‌对基金投资人的监管
**答案：** D
**解析：** 基金监管主要是对基金市场主体、市场行为等进行监管，以及处置违法违规行为，而基金投资人是市场参与者，一般不会对其进行监管。答案：D

**5.（单选题）** 基金监管应当着眼全局，以防范资本市场的（　）为底线，确保基金行业发展过程中风险可控。
A.非系统性风险
B.系统性风险
C.操作风险
D.模型风险
**答案：** B
**解析：** 基金监管要着眼全局防范风险，系统性风险影响整个资本市场，而非系统性风险、操作风险、模型风险多针对局部或特定领域。防范资本市场的系统性风险是底线，以保障行业风险可控。答案：B

**解析：** 基金主要投资的期货合约和衍生品常见有股指期货用于资产配置、规避风险；国债期货可助力债券投资风险管理；商品期货也在一些基金投资范畴内。而期权期货这种表述不准确，期货与期权是不同的金融衍生品，不存在期权期货这样作为基金主要投资对象的常规说法。答案：A

**24.（单选题）** 不符合普通会员条件的其它私募基金管理人加入基金业协会，成为（　）。
A.高级会员
B.联席会员
C.观察会员
D.特别会员
**答案：** C
**解析：** 私募基金管理人不符合普通会员条件时，加入基金业协会成为观察会员 。答案：C

**25.（单选题）** 根据《证券投资基金法》的规定，中国证券投资基金业协会的职责不包括（　）。
A.依法维护会员的合法权益，反映会员的建议和要求
B.依法办理公开募集基金的注册和备案
C.对会员之间、会员与客户之间发生的基金业务纠纷进行调解
D.提供会员服务，组织行业交流，推动行业创新，开展行业宣传和投资人教育活动
**答案：** B
**解析：** 公开募集基金的注册由中国证监会负责，并非中国证券投资基金业协会职责。而A、C、D 选项均属于中国证券投资基金业协会职责。答案：B

**26.（单选题）** （　）加入基金业协会的，可为特别会员。
A.基金管理人
B.基金托管人
C.地方基金业协会
D.基金发起人
**答案：** C
**解析：** 基金业协会会员分为普通会员、联席会员、观察会员和特别会员。其中，公募基金的基金管理人、基金托管人加入为普通会员；基金服务机构加入为联席会员；私募基 金管理人加入为观察会员；而地方基金业协会及其他资产管理相关机构加入为特别会员 。答案：C
