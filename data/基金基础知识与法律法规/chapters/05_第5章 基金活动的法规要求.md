# 基金基础知识与法律法规 · 第5章 基金活动的法规要求

## 第1节 公募基金管理规范（92题）

**1.（单选题）** 基金销售适用性管理制度的必要内容不包含（　）。
A.对投资者进行分类的方法和程序
B.对基金产品和基金投资人进行匹配的方法
C.对基金销售人员进行审慎调查的方式和方法
D.对基金产品进行风险评价的方式和方法
**答案：** C
**解析：** 基金销售适用性管理制度主要围绕投资者、基金产品及两者匹配展开。A对投资者分类、B基金产品与投资人匹配、D对基金产品风险评价都属于其必要内容。而对基金销售人员进行审慎调查并非销售适用性管理制度针对投资者与产品关系的必要内容。答案选C。

B.投资策略
C.风险收益特征

**答案：** D
**解析：** 对于特殊基金品种，投资范围、投资策略、风险收益特征都对投资者了解产品很关键，都应专门揭示。答案：D

**14.（单选题）** 基金销售机构及其从业人员从事基金销售业务，不得有以下哪些情形？（　）
Ⅰ虚假记载、误导性陈述或者重大遗漏
Ⅱ对基金的投资业绩预测
Ⅲ违规承诺收益或者承担损失
Ⅳ误导投资人购买与其风险承担能力不相匹配的基金产品

**15.（单选题）** 公募基金管理人运用基金财产进行证券投资时的禁止情形包括（　）。
Ⅰ一只基金持有一家公司发行的证券，其市值超过基金资产净值的10%
Ⅱ违反基金合同关于投资范围、投资策略和投资比例等约定
Ⅲ基金中基金持有其他单只基金，其市值超过基金资产净值的20%
Ⅳ基金总资产超过基金净资产的100%
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 1. 分析Ⅰ：一只基金持有一家公司发行的证券，市值超过基金资产净值的10%，这是《证券投资基金运作管理办法》规定的禁止情形，防止过度集中投资风险。2. 分析Ⅱ：违反基金合同关于投资范围、策略和比例等约定，违背了合同约定和合规运作要求，属于禁止情形。3. 分析Ⅲ：基金中基金持有其他单只基金，市值超过基金资产净值的20%，不符合相关投资限制规定，是禁止情形。4. 分析Ⅳ：公募基金总资产通常不能超过基金净资产的140%（开放式）或200%（封闭式） ，说超过100%就禁止不准确。综上，Ⅰ、Ⅱ、Ⅲ属于禁止情形，答案是B。

**解析：** 反洗钱行政主管部门等履行职责获得的客户身份资料和交易信息，主要用于反洗钱监督管理和行政调查工作，刑事诉讼是在后续涉及犯罪时可能用到，但题干强调的是履行职责所获信息用途，民事诉讼一般并非这些信息的主要用途。答案：A

**9.（单选题）** 金融机构发现客户单笔交易或者在一定期限内的累计交易超过规定金额的，应当及时向（　）报告。

B.司法机构

**10.（单选题）** 下列选项中，（　）不是反洗钱需预防的上游犯罪。

**11.（单选题）** 根据《反洗钱法》的要求，客户身份资料在业务关系结束后、客户交易信息在交易结束后，应当至少保存（　）。

**12.（单选题）** 2021年1月，中国人民银行反洗钱局发布（　），以指导法人金融机构落实洗钱和恐怖融资风险自评估工作要求，推动反洗钱工作向风险为本转型，提升反洗钱工作有效性。
A.《反洗钱法》
B.《证券期货业反洗钱工作实施办法》
C.《基金管理公司反洗钱工作指引》
D.《法人金融机构洗钱和恐怖融资风险自评估指引》
**答案：** D
**解析：** 题目关键信息是2021年1月央行反洗钱局发布用于指导法人金融机构落实洗钱和恐怖融资风险自评估工作的文件。选项A《反洗钱法》并非2021年1月发布；选项B《证券期货业反洗钱工作实施办法》重点在证券期货业，与法人金融机构风险自评估针对性不符；选项C《基金管理公司反洗钱工作指引》针对基金管理公司，范围较窄。只有选项D符合题意。答案：D

**13.（单选题）** 当金融机构（　）时，应当将客户身份资料和客户交易信息移交国务院有关部门指定的机构。
A.解散
B.被撤销
C.被宣告破产
D.以上都是
**答案：** D
**解析：** 金融机构在解散、被撤销、被宣告破产等情况时，都需要将客户身份资料和客户交易信息移交国务院有关部门指定的机构，以确保相关信息的妥善处理。答案：D

**14.（单选题）** 下列关于金融机构委托第三方开展客户尽职调查的说法错误的是（　）。
A.金融机构无需承担因第三方未采取符合《反洗钱法》要求的客户尽职调查措施所产生的法律责任
B.金融机构应当评估第三方的风险状况及其履行反洗钱义务的能力
C.金融机构应当确保第三方已经采取符合《反洗钱法》要求的客户尽职调查措施
D.金融机构不得委托具有较高风险情形的第三方进行客户尽职调查
**答案：** A
**解析：** 金融机构委托第三方开展客户尽职调查，不能免除自身法律责任，A选项说法错误。而B评估第三方风险和能力、C确保第三方措施合规、D不委托高风险第三方都是合理要求。答案：A

Ⅰ、反洗钱行政主管部门
Ⅱ、市场监督管理部门
Ⅲ、电信管理部门
Ⅳ、公安部门
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
