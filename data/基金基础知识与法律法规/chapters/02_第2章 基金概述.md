# 基金基础知识与法律法规 · 第2章 基金概述

## 第1节 基金的概念（63题）

**1.（单选题）** 基金一旦设立，其财产本身具有（　），这是基金最典型的特征。
A.风险性
B.专业性
C.汇集性
D.独立性
**答案：** D
**解析：** 基金财产独立性是基金最典型特征，它独立于基金管理人、托管人的固有财产等，保障基金财产安全运作。其他选项风险性、专业性、汇集性并非基金最典型特征。答案：D

**2.（单选题）** 在风险程度上，按照理论推测和以往的投资实践，证券投资中风险最大的是（　）。
A.银行存款投资
B.债券投资
C.股票投资
D.国债投资
**答案：** C
**解析：** 银行存款和国债通常风险较低，有相对稳定收益。债券风险一般也小于股票，股票价格波动受众多复杂因素影响，不确定性大，所以风险最大。答案：C

**3.（单选题）** 目前，我国的公募证券投资基金、私募证券投资基金多数属于（　）。
A.契约型基金
B.公司型基金
C.封闭式基金
D.开放式基金
**答案：** A
**解析：** 在我国，公募证券投资基金和多数私募证券投资基金都是依据基金合同设立的，属于契约型基金。公司型基金在我国数量较少。封闭式基金和开放式基金与题目所问基金组织形式并非同一范畴概念。答案：A

**4.（单选题）** 同银行存款相比，基金的投资风险（　）银行存款的投资风险。
A.大于
B.等于
C.小于
D.基本接近
**答案：** A
**解析：** 银行存款收益相对稳定，风险较低；基金投资受多种因素影响，收益波动较大，风险相对较高。所以基金投资风险大于银行存款投资风险。答案：A

**5.（单选题）** 下列有关股票、债券、基金的叙述中，错误的是（　）。
A.基金是一种间接投资工具，所筹集的资金主要投向有价证券、未上市股权等
B.股票和债券是直接投资工具，筹集的资金主要投向实业领域
C.基金收益具有波动性，存在投资损失风险
D.债券反映的是股东权利关系，是一种股东权利凭证
**答案：** D
**解析：** 债券反映的是债权债务关系，不是股东权利关系，股票才是一种股东权利凭证，所以D选项叙述错误。 A选项，基金是间接投资工具，资金投向有价证券等，表述正确。 B选项，股票和债券资金投向实业领域，是直接投资工具，表述正确。 C选项，基金收益有波动有风险，表述正确。答案：D

**6.（单选题）** 关于基金的表述，下列说法正确的是（　）。
A.基金财产归基金管理机构所有，投资者仅享有收益分配权
B.基金管理人可自由调整投资策略，无需遵守基金合同约定
C.基金通过公开募集或非公开募集的方式，汇集投资者的资金
D.基金投资者按照所持有的基金份额享有投资收益，但无需承担投资风险
**答案：** C
**解析：** A选项，基金财产独立于基金管理机构，不归其所有，投资者对基金财产按份额享有权益，并非仅收益分配权；B选项，基金管理人需按基金合同约定进行投资运作，不能自由调整策略；C选项，基金可通过公开或非公开募集方式汇集资金，表述正确；D选项，投资者按份额享有收益，同时要承担投资风险。答案：C

**7.（单选题）** （　）是指通过非公开募集方式，向合格投资者募集资金设立的基金。
A.公募基金
B.私募基金
C.开放式基金
D.封闭式基金
**答案：** B
**解析：** 题目强调非公开募集方式向合格投资者募集资金设立的基金，这是私募基金的特点。公募基金是公开募集，开放式和封闭式基金侧重于基金份额是否可变动，与募集方式无关。答案：B

**8.（单选题）** 债券是一种（　）凭证。
A.所有权
B.债权
C.债务
D.受益
**答案：** B
**解析：** 债券是发行人向投资者发行的一种债务凭证，表明发行人欠投资者的债务，而投资者拥有按约定获取本息的债权。所以债券是一种债权凭证。答案选B 。

**9.（单选题）** 下列关于基金与银行储蓄存款的说法，正确的是（　）。
Ⅰ.银行储蓄存款表现为银行的负债
Ⅱ.基金与银行储蓄存款的性质不同
Ⅲ.基金的风险大于银行储蓄存款的风险
Ⅳ.基金与银行储蓄存款的信息披露程度相同
A.Ⅰ、Ⅱ
B.Ⅰ、Ⅱ、Ⅲ
C.Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** B
**解析：** 银行储蓄存款是银行对存款人的负债，Ⅰ正确；基金是一种受益凭证，储蓄存款是债务凭证，性质不同，Ⅱ正确；基金投资有风险，储蓄存款相对风险低，Ⅲ正确；基金信息披露要求更严格，与储蓄存款信息披露程度不同，Ⅳ错误。综上，Ⅰ、Ⅱ、Ⅲ正确。答案：B

**10.（单选题）** 根据（　）不同，可将基金分为封闭式基金和开放式基金。
A.运作方式
B.法律形式
C.募集方式
D.交易场所
**答案：** A
**解析：** 基金根据运作方式不同，分为封闭式基金和开放式基金。封闭式基金份额固定，存续期内规模固定，在封闭期内不能赎回；开放式基金份额不固定，投资者可随时申购或赎回。答案选A 。

**11.（单选题）** （　）在基金的信托关系中是受益人。
A.基金服务机构
B.基金托管人
C.基金管理人
D.基金份额持有人
**答案：** D
**解析：** 在基金的信托关系中，基金份额持有人是将资产委托给基金管理人管理、基金托管人托管，享有收益等权益的一方，也就是受益人。而基金服务机构是为基金业务提供服务的；基金托管人负责保管资产等；基金管理人负责基金的投资运作，他们都不是受益人。答案：D

**12.（单选题）** 下列哪项是基金与股票、债券的主要差异？（　）
A.发行主体不同
B.所筹资金的投向不同
C.监管主体不同
D.变现能力不同
**答案：** B
**解析：** 基金、股票、债券发行主体、监管主体、变现能力虽有不同，但主要差异在于所筹资金投向。股票是企业为筹集资金用于自身发展，债券是政府或企业等为特定项目等筹资，基金是把投资者资金集中起来投向多种资产。答案：B

**13.（单选题）** 根据投资策略不同，可将基金分为（　）。
A.公募基金和私募基金
B.封闭式基金和开放式基金
C.证券投资基金和股权投资基金
D.主动型基金和被动型基金
**答案：** D
**解析：** 题目问根据投资策略不同对基金的分类。A选项是按募集方式分类；B选项是按运作方式分类；C选项是按投资对象分类；D选项主动型基金是积极寻求超越市场表现，被动型基金一般复制指数等，是根据投资策略分类。答案：D

**14.（单选题）** 基金的特点不包括（　）。
A.财产的汇集性
B.操作的简易性
C.财产的独立性
D.管理的专业性
**答案：** B
**解析：** 基金是通过汇集众多投资者资金，形成独立财产，由专业基金管理人进行管理。财产汇集性、独立性以及管理专业性都是其特点。而操作简易性并非基金本身突出特点，不同基金操作复杂程度有差异。答案选B。

**15.（单选题）** 基金与期货、期权是性质截然不同的金融工具，其区别不包括（　）。
A.风险收益特征不同
B.交易方向不同
C.投资期限不同
D.监管主体不同
**答案：** D
**解析：** 基金与期货、期权是性质截然不同的金融工具，区别体现在以下四个方面。
　1、性质不同
基金本身是一种金融工具，投资者所持有的基金份额能对应具体的基金财产。期货、期权的本质是一份合约(即合同)，该合约会挂钩相关的标的物（如商品、股票指数等)，但该合约本身不是具体的财产，而是一份约定关于买卖相关标的物权利或义务的合同，该等权利或义务是从所挂钩的标的物衍生而来。
　2、交易方向不同（B项）
基金是单向交易工具。对于场外基金，投资者只能通过低价认购或申购、高价赎回或转让以及基金分配收益来获利；对于场内交易的基金，投资者通过低价买入、高价卖出来获利。期货和期权是双向交易工具，即投资者可以通过买涨卖跌或买跌卖涨来获利。
　3、投资期限不同（C项）
投资者可以在基金合同约定的期限内认（申）购并持有；期货和期权是有限期的交易工具，即投资者必须在合约到期前进行交割或行权。
　4、风险收益特征不同（A项）
期货、期权采用保证金交易方式，具有杠杆交易的特点。而基金一般不采用保证金交易方式。

**22.（单选题）** 投资者购买基金份额就成为（　）。

B.基金公司的债权人
C.基金公司的受益人

**答案：** B
**解析：** 基金是一种间接投资工具，主要通过汇集众多投资者资金，交由专业基金管理人管理，资金主要投向有价证券等金融资产，而不是直接投向实业领域、生产工具等。所以答案选B。

**24.（单选题）** 基金与保险产品的差异，主要体现在（　）。
Ⅰ.目的不同
Ⅱ.性质不同
Ⅲ.法律关系不同
Ⅳ.对投资人要求不同
A.Ⅰ、Ⅱ、Ⅲ
B.Ⅱ、Ⅲ、Ⅳ
C.Ⅰ、Ⅲ、Ⅳ
D.Ⅰ、Ⅱ、Ⅲ、Ⅳ
**答案：** D
**解析：** 基金与保险产品的差异主要体现在四个方面：①目的不同，基金以获得投资收益为目的，保险以提供风险保障为目的；②性质不同，基金是集合投资工具，保险是风险保障类产品；③法律关系不同，基金建立在信托关系之上，保险基于保险合同关系；④对投资人要求不同，基金按风险承受能力匹配产品且不同投资人申赎价格一致，保险产品的购买和价格计算因人而异。四项均正确，本题选D。

**25.（单选题）** 基金与银行储蓄存款的差异有（　）。
A.性质不同
B.收益与风险特性不同
C.信息披露程度不同
D.以上都是
**答案：** D
**解析：** 基金是一种收益共享、风险共担的集合证券投资方式，银行储蓄存款是银行与存款人之间的债权债务关系凭证。二者性质不同；基金收益不固定，风险相对较高，银行储蓄存款收益相对固定，风险较低，收益与风险特性不同；基金信息披露要求更严格全面，银行储蓄存款信息披露程度低，所以信息披露程度也不同。综上，答案应选包含这三方面差异的选项。答案：D

**26.（单选题）** 投资基金的目的是获得（　）。
A.投资收益
B.资产保值
C.资产保障
D.资产升值
**答案：** A
