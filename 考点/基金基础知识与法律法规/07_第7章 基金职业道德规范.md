# 基金基础知识与法律法规 · 第7章 基金职业道德规范 考点笔记

本章先讲道德、职业道德与基金职业道德的一般原理、教育途径和修养途径，再逐项展开守法合规、诚实守信、专业审慎、客户至上、忠诚尽责、保守秘密六项基金职业道德规范的含义、调整对象与基本要求。

题量：145题

## 第1节 基金职业道德建设（66题）

1. 道德是由一定的社会经济基础决定并形成的、调整人与人之间和人与社会之间关系的行为规范的总和。⭐
2. 道德是社会认可和人们普遍接受的行为规范，既可以成文，也可以不成文，没有特定的表现形式。⭐
3. 道德以是与非、善与恶、美与丑、正义与邪恶、公正与偏私、诚实与虚伪等范畴为评价标准。⭐
4. 道德是一种社会意识形态，不是社会关系，也不是权利义务关系。
5. 道德依靠社会舆论、传统习俗和内心信念三种力量约束人的行为，不依靠国家强制力实施。⭐
6. 道德的约束力是有限的，不是无限的；有效的监督奖惩机制是道德约束力的有效保障，道德观念是道德实施的支撑力量。⭐
7. 道德具有差异性：社会经济基础和社会关系的不同决定了道德的差异性，不同社会条件下有不同的社会价值观念；但不同社会的道德并非"完全不同"，存在普遍认可的道德原则。
8. 道德具有继承性：影响道德形成和发展的各种因素具有历史延续性，因此道德有历史传承，现代道德深深烙有传统道德的印记；但不存在"现代道德与传统道德完全不一样"的情形。
9. 道德具有约束性、规范性，并且是具体的（通过行为规范等具体形式表现），不具有"抽象性"，也没有"形态性"这一特征。⭐
10. 影响道德形成和发展的因素包括社会经济基础、宗教信仰、国家政治；科学技术不属于影响道德形成和发展的因素。
11. 道德规范的表现形式可以是公约、行为准则、守则，但不能是法律；法律由国家制定或认可并由国家强制力保证实施，与道德规范有本质区别。
12. 社会道德规范包括基本道德规范和一系列特定道德规范；家庭美德规范、职业道德规范、社会公德规范属于特定道德规范，"一般社会道德"不属于特定道德规范。
13. 道德与法律的区别体现在表现形式不同、内容结构不同、调整范围不同、调整手段不同；两者的根本目的相同（都是维护社会秩序、保障社会稳定发展），"根本目的不同"不是二者的区别。
14. 道德与法律的调整手段不同：法律主要依靠国家强制力保证实施，道德主要依靠社会舆论、传统习俗和内心信念等力量实现约束力。⭐⭐
15. 道德调整的范围比法律调整的范围更为广泛；一种行为在法律上未被禁止却往往被社会公众诟病，正说明二者调整范围不同。
16. 法律与道德在内容结构上不同：法律强调权利与义务的对等，道德更多倡导义务；"是否要求权利与义务的对等"表现的是二者内容结构的不同。
17. 道德与法律的联系表现为功能互补、相互促进、内容转化；二者手段并不一致，不存在"手段一致"的联系。
18. 法律是最低限度的道德，绝大多数法律规范以道德作为价值基础（而非道德规范以法律为价值基础）；法律的实施对道德观念的培养起到强化促进作用。
19. 道德在调整范围上对法律有补充作用，但道德不具有法律那样的强制约束力，因此不能说道德在约束力方面对法律也有补充作用。
20. 道德和法律都是行为规范、都是重要的社会调控手段，二者都属于上层建筑，不属于经济基础，也不是单纯的自我约束或强制手段。
21. 社会法治建设偏重于外化机制，即主要依靠法律制度等外在的规范和约束来保障实施；内化机制强调个人内心的自我约束。
22. 职业道德是一般社会道德在职业活动和职业关系中的特殊表现，是与人们的职业行为紧密联系、符合职业特点要求的道德规范的总和。⭐
23. 职业道德是所有从业人员在职业活动中应该遵循的行为准则。
24. 人们的职业实践是职业道德产生的基础。
25. 职业道德的特征包括特殊性、规范性、继承性、具体性（行业性、多样性、适用性），不包括抽象性。⭐
26. 职业道德的具体性是指职业是多样的，每种职业都有其特有的职业活动和职业关系，都承担着特定的职业义务和责任。
27. 职业道德的作用包括调整职业关系、提升职业素质、促进行业发展；职业道德有助于缓解职业矛盾，但不能"消除职业矛盾"。⭐
28. 职业道德能够引导和规范从业人员的职业行为，其调整对象不只限于与服务对象的关系，也不只限于从业人员内部关系。
29. 职业道德具有引导、规范、评价和教化的功能；既有教化功能，也有评价功能，可以教化从业人员坚持原则。
30. 职业素质包括专业技能和道德素养；加强职业道德建设有助于从业人员提升业务能力，不会妨碍业务能力提高。
31. 职业关系具有社会性、专业性、复合性三个特点，不包括高效性。
32. 良好的职业道德风尚包括为客户服务、对单位负责、为行业争光。
33. 基金职业道德是在长期的基金职业实践中所形成的职业行为规范。
34. 基金行业是"受人之托，代人理财"的专业服务行业，基金从业人员必须具备优秀的职业道德，才能以专业能力取信于投资者。
35. 我国基金职业道德的主要内容包括守法合规、诚实守信、专业审慎等；"利益至上"不属于基金职业道德的内容。
36. 基金职业道德教育的内容主要包括两个方面：培养基金职业道德观念、灌输基金职业道德规范；"树立典型""提升素养"不属于教育内容本身。⭐
37. 基金职业道德规范教育是基金职业道德教育的核心内容。
38. 基金职业道德观念教育是基金职业道德规范教育的基础和保障。
39. 基金职业道德教育的途径包括岗前职业道德教育、岗位职业道德教育、基金业协会的自律、树立基金职业道德典型以及社会各界持续监督；不存在"后续职业道德教育""离岗道德教育"这类途径。⭐
40. 岗前教育是指在基金从业人员就业上岗之前，对其所进行的入职必备知识和职业道德的教育。
41. 岗前职业道德教育主要通过两条途径完成：一是基金从业资格考试，二是基金从业人员所在机构在其入职时、上岗前对其进行教育；在职培训属于岗后教育。
42. 岗位教育是指在基金从业人员就业上岗之后，对其所进行的业务能力和职业道德的继续教育，主要通过在职培训来完成。
43. 职业道德教育的目的，就是通过外在教育帮助和引导受教育者实现由被动接受教育到主动自我教育。
44. 基金职业道德教育是提高基金从业人员职业道德素养的基本手段。
45. 基金职业道德修养是指基金从业人员通过自我学习、自我改造、自我完善，将基金职业道德外在的职业行为规范内化为内在的职业道德情感、认知和信念。
46. 基金职业道德修养的具体内容（基本要求）是基金职业道德规范。⭐
47. 基金职业道德修养的方法包括正确树立基金职业道德观念、深刻领会基金职业道德规范、积极参加基金职业道德实践；"积极接受基金职业道德教育"属于外在培养，不属于修养方法。⭐
48. 基金职业道德修养的形成途径是基金从业人员主动自觉的自我学习、自我改造、自我完善，自我评价不属于形成途径。
49. 正确树立基金职业道德观念是基金职业道德修养的内在动力。
50. 积极参加基金职业道德实践是基金职业道德修养的有效途径。
51. 基金职业道德建设不能只抓领导干部，需要社会各界监督，并要同完善职业道德监督机制相结合。
52. 职业道德奖惩机制应由基金行业协会建立，而不是由政府建立。
53. 投资者的利益与基金运作紧密相关，因此投资者实施监督的动力最足，监督也最深、最细。
54. 与政府监管机构相比，基金业协会更侧重在职业道德层面对基金从业人员的执业活动进行监管；政府监管机构主要关注法律法规的宏观层面。
55. 2014年12月15日，基金业协会颁布了《基金从业人员执业行为自律准则》。

## 第2节 守法合规（11题）

1. 守法合规是对基金从业人员职业道德的最为基础的要求。
2. 守法合规调整的是基金从业人员与基金行业及基金监管之间的关系。⭐
3. 守法合规中的"法"与"规"包括《中华人民共和国证券投资基金法》、中国证券监督管理委员会制定的《证券投资基金销售管理办法》、中国证券投资基金业协会制定的《基金从业人员执业行为自律性规则》，以及基金从业人员所在机构的内部规章制度。
4. 守法合规要求基金从业人员熟悉法律法规等行为规范、自觉遵守法律法规及《自律准则》规定的各类行为规范、积极配合基金监管机构的监管。⭐
5. 守法合规的前提是熟悉相关的法律法规等行为规范。
6. 守法合规的目的是避免基金从业人员自己实施或者参与违法违规的行为，或者为他人违法违规的行为提供帮助。
7. 一旦发现违法违规行为，基金从业人员应当及时制止并向上级部门或者监管机构报告。
8. "不得欺诈客户"属于诚实守信的基本要求，不属于守法合规的基本要求。
9. 根据《证券投资基金法》的相关规定，公募基金管理人的从业人员并非禁止进行证券投资，而是可以进行，但必须按规定申报。
10. 守法合规的约束对象是基金从业人员；"不懂法也能守法""学法未必守法所以不必学法""自身守法即可不配合监管"等说法均不成立。

## 第3节 诚实守信（32题）

1. 诚实守信也称为诚信，就是真诚老实、表里如一、言而有信、一诺千金。⭐
2. 诚实守信是调整各种社会人际关系的基本准则。
3. 诚实守信是基金职业道德的核心规范（不是专业审慎）。⭐
4. 诚实守信是赢得基金投资人信心和信任的基本要素；投资人的信心和信任是支撑基金市场存续和基金行业发展的基础。
5. 基金行业要健康发展，必须以诚实守信为本，而不是以合法合规为本。
6. 诚实守信必然要落实到基金从业人员的执业行为上。
7. 基金行业的本质是资产管理行业（不是销售行业）。
8. 诚实守信的基本要求包括：不得欺诈客户、不得进行内幕交易和操纵市场、不得进行不正当竞争。⭐⭐
9. 公平合法有序竞争是符合诚实守信要求的做法；不正当竞争、内幕交易、操纵市场、欺诈客户均违反诚实守信要求。
10. 履行诚信职业道德规范必须正确对待利益问题，以正当方式获取利益；采用贬低同行方式招揽顾客、不择手段竞争、利用内幕交易盈利都是不诚信行为。
11. 诚实守信并非"无条件"的原则，面临利益冲突等特殊情况时仍需遵循法律和道德规范，不能盲目坚持诚信的无条件性。
12. 不得从事与投资人利益相冲突的业务属于忠诚尽责中"尽责"的要求，不属于诚实守信的要求。
13. 欺诈是指利用虚构事实或者隐瞒真相的方式欺骗客户，使客户产生错误的认识，最终做出错误的判断；虚假陈述、隐瞒真相、舞弊行为均属欺诈，"不承诺收益"不属于欺诈。
14. 内幕交易是指利用能够影响证券价格的重要非公开信息进行证券交易，以为自己或者他人牟取利益。
15. 内幕信息的构成要素为来源可靠的信息、"重要"的信息、"非公开"的信息；"市场上可获得的信息""及时的信息"不属于内幕信息的构成要素。
16. 基金从业人员不得从事或协同他人从事内幕交易或利用未公开信息从事交易活动，不得暗示他人从事内幕交易活动，不得泄露利用工作便利获取的内幕信息或其他未公开信息；自己或者促使他人利用内幕信息牟取不正当利益属于禁止行为。
17. 操纵市场是指通过扭曲证券价格形成机制或人为控制交易量等方式而意图误导市场参与者的行为。
18. 判定是否构成"操纵市场"的关键因素是有误导市场参与者的意图；歪曲证券价格、人为控制或虚增交易量、提供虚假信息等若没有误导意图，不一定构成操纵市场。
19. 内幕交易和操纵市场行为违反证券市场公开、公平、公正的原则。
20. 正当竞争的基本标准是：公平竞争是正当竞争的前提，合法竞争是正当竞争的基础，有序竞争是正当竞争的表现；"公开竞争是正当竞争的原则""平稳增长是正当竞争的结果"均不正确。⭐
21. 竞争是市场经济的核心机制。
22. 基金从业人员不得借助行政手段开展业务，不得采取赠送实物、保险、基金份额等方式销售基金，不宜从事自己力所不能及的工作，不能因为基金份额多寡而厚此薄彼。
23. 基金销售中可以按规定对申购费率进行8折优惠；压低基金的收费水平、赠送合作方提供的人身意外保险、配送少量货币基金份额均属于不正当竞争手段。
24. 基金从业人员在陈述所推介基金或基金管理人管理的其他基金的过往业绩时，应当使用来源符合法律法规要求的业绩信息、不得片面夸大过往业绩、不得预测基金的未来业绩。
25. 基金从业人员不得根据过往业绩预测所推介基金的未来业绩，否则属于误导投资者。
26. 基金从业人员应当积极参加宣传推介合规培训和教育活动，及时学习了解和落实最新合规规定。
27. 基金从业人员在向普通投资者销售产品或提供服务前，应当充分告知相关信息及可能存在的风险；在宣传、推介和销售基金产品时，应当客观、全面、准确地向投资者推介基金产品、揭示投资风险。
28. 只介绍表现最好的基金、刻意忽略业绩不突出基金的做法，违反了诚实守信原则（属于虚假陈述、未如实全面展示业绩）。
29. 通过互联网散布不实消息推高、压低股价以使自己管理的基金获利，属于操纵市场行为。

## 第4节 专业审慎（13题）

1. 专业审慎是指基金从业人员应当具备与其执业活动相适应的职业技能，具备从事相关活动所必需的专业知识和技能并保持和提高专业胜任能力，勤勉审慎开展业务，提高风险管理能力，不得做出任何与专业胜任能力相背离的行为。⭐
2. 专业审慎的基本要求包括持证上岗、持续学习、审慎开展执业活动；"恪尽职守"属于忠诚尽责的要求，"不得进行不正当竞争"属于诚实守信的要求。⭐
3. 持证上岗是指基金从业人员应当具备从事相关活动所必需的法律法规、金融、财务等专业知识和技能，必须通过基金从业人员资格考试（或符合规定的豁免条件），取得基金从业资格，并经由所聘用机构向基金业协会申请执业注册后，方可执业。
4. 持证上岗的目的在于保证基金从业人员具备必要的执业能力和专业水平。
5. 基金从业人员在执业之前考取执业证书是从业的入门要求；职业道德教育、上岗培训技能、后续职业培训都是在具备执业资格基础上进一步提升的内容。
6. 基金行业属于智力服务型行业，基金从业人员的职业技能直接关系客户的利益和整个行业的形象。
7. 基金从业人员应当在自己熟悉的领域内开展工作，为锻炼能力而从事从未接触的领域不符合要求。
8. 审慎开展执业活动要求：妥善记载并保留适当记录（交易结束后不得立即销毁记录）、区分投资分析和建议演示中的事实、观点和假设、牢固树立风险控制意识并强化投资风险管理、合理分析判断影响投资分析、建议或行动的重要因素、在投资分析、提供投资建议、采取投资行动时具有合理充分的依据。⭐
9. 向客户推荐合适的基金、向投资人调查风险承受能力、了解投资者的投资目标、推荐适合投资人的基金产品均属正确行为；向投资人承诺收益则被禁止。
10. 基金管理人应明确投资决策流程与授权管理制度，明确界定投资决策委员会、投资总监、基金经理、投资经理等各投资决策主体的职责和权限。

## 第5节 客户至上（8题）

1. 客户至上是指基金从业人员的执业活动应一切从投资人的根本利益出发，把客户利益放在首位。
2. 客户至上是调整基金从业人员与投资人之间关系的道德规范。
3. 客户利益优先要求基金从业人员不得从事与投资人利益相冲突的业务，不得在不同基金资产之间、基金资产和其他受托资产之间进行利益输送，不得侵占或者挪用基金投资人的交易资金和基金份额。⭐
4. "不得违规向投资人做出投资不受损失或保证最低收益的承诺"属于诚实守信中不得欺诈客户的要求，不属于客户利益优先要求遵守的规则。
5. 客户至上要求公平对待所有客户：不以财富多寡作为服务标准，不因客户身份差异提供特别服务，尊重残疾客户。
6. 遇到自身利益或相关方利益与投资人利益发生冲突时，应及时向所在机构报告，并采取合理措施避免与投资人发生利益冲突；不得利用工作之便向任何机构和个人输送利益。
7. 基金经理利用任职优势操作亲属开立的证券账户，先于自己管理的基金多次买入、卖出相同个股为自己牟利，违反了客户至上道德规范。
8. 基金经理因私人关系用自己管理的基金购买关联公司发行的债券，未把基金份额持有人利益放在首位，违反了客户至上原则。

## 第6节 忠诚尽责（8题）

1. 忠诚是指基金从业人员应当忠实于所在机构，避免与所在机构利益发生冲突，不得损害所在机构的利益。
2. 尽责是指基金从业人员应当以对待自己事情一样的谨慎和注意来对待所在机构的工作，勤勉履行岗位职责。
3. 忠诚尽责包括忠诚廉洁与勤勉尽责。
4. 忠诚廉洁要求基金从业人员公私分明、廉洁自律，自觉维护所在机构的利益和基金行业的形象，保护所在机构财产与信息安全，防止所在机构资产损失、丢失。
5. 忠诚廉洁要求基金从业人员不得接受利益相关方的贿赂或对其进行商业贿赂。⭐
6. 忠诚尽责的基本要求包括：不得利用基金财产或者所在机构固有财产为自己或者他人牟取非法利益，不得利用职务之便或者机构的商业机会为自己或者他人牟取非法利益，不得侵占或者挪用基金财产或者机构固有财产，不得从事可能导致与投资者或所在机构之间产生利益冲突的活动。
7. 严格遵守所在机构的授权制度、严格遵守所在机构工作纪律并服从领导、秉持勤勉的工作态度和爱岗敬业，都不属于"忠诚廉洁"的核心内涵。
8. 企业是员工发挥自己聪明才智的业务平台，对企业的忠诚实际上是一种对职业的忠诚。

## 第7节 保守秘密（7题）

1. 商业秘密是指不为公众所知悉的、能够带来经济利益、具有实用性并被采取保密措施的技术信息和经营信息。
2. 商业秘密的特点包括不为公众所知悉、能够带来经济利益、被采取保密措施、具有实用性；"不具有实用性"不是商业秘密的特点。
3. 商业秘密包括对证券市场的分析报告、对某一行业的研究报告、内控制度、员工激励机制等。
4. 保守秘密是基金从业人员的一项法定义务，也是基金职业道德的一项基本规范，对所有的基金从业人员均有约束效力。
5. 保守秘密要求基金从业人员无论在职还是离职，都要妥善保管并严格保守客户秘密，非经许可不得泄露客户资料和交易信息；离职后仍不得泄露。
6. 保守秘密要求不得泄露在执业活动中所获知的各相关方的信息及所属机构的商业秘密，更不得用以为自己或他人谋取不正当的利益；不得泄露在执业活动中所获知的内幕信息。
7. 基金从业人员将本机构的控制制度、工作流程等内部信息发送给其他机构人员参考，违反了保守秘密的要求。

## 易混易错

### 一、道德与法律

- **相同点**：都是行为规范、都是重要的社会调控手段、都属于上层建筑；根本目的相同（维护社会秩序、保障社会稳定发展）。
- **不同点**：表现形式不同（法律有明确条文，道德无特定表现形式、可成文可不成文）；内容结构不同（法律强调权利义务对等，道德更多倡导义务）；调整范围不同（道德比法律更广泛）；调整手段不同（法律靠国家强制力，道德靠社会舆论、传统习俗和内心信念）。
- **联系**：功能互补、相互促进、内容转化；手段不一致（干扰项"手段一致"错误）。
- **价值基础方向不能颠倒**：法律是最低限度的道德，绝大多数**法律规范以道德为价值基础**（干扰项：绝大多数道德规范以法律为价值基础）。
- **补充作用的边界**：道德只在**调整范围**上对法律有补充作用，在**约束力**上没有补充作用。
- **道德约束力**：有限、非无限、不依靠国家强制力（干扰项：道德依靠国家强制力实施；道德的约束力是无限的）。
- **外化与内化**：社会法治建设偏重**外化机制**，道德建设偏重内化机制。

### 二、道德的"特征"与"定义"干扰项

- 道德的特征：差异性、继承性、约束性、规范性、具体性。**"抽象性""形态性"均为干扰项。**
- 职业道德的特征：特殊性、规范性、继承性、具体性（行业性、多样性、适用性）。**"抽象性"为干扰项。**
- 道德的绝对化表述均为错误：不能说不同社会的道德"完全不同"，不能说现代道德与传统道德"完全不一样"。
- 道德评价标准：善与恶、是与非、正与邪；**"法与规"属于法律范畴，不是道德评价标准**。
- 道德规范的表现形式：公约、行为准则、守则；**法律不是道德规范的表现形式**。
- 特定道德规范：家庭美德规范、职业道德规范、社会公德规范；**"一般社会道德"不是特定道德规范**。
- 影响道德形成发展的因素：社会经济基础、宗教信仰、国家政治；**科学技术不是**。
- 道德是**社会意识形态**，不是社会关系、不是权利义务关系。

### 三、职业道德的"作用"与"功能"

- 作用：调整职业关系、提升职业素质、促进行业发展；**"消除职业矛盾"是干扰项**（只能缓解）。
- 功能：引导、规范、评价、教化（四种都有，不能说只有教化没有评价）。
- 职业素质 = 专业技能 + **道德素养**；加强职业道德建设不会妨碍业务能力提高。
- 职业关系特点：社会性、专业性、复合性；**"高效性"是干扰项**。
- 职业道德**不具有法律强制力**（干扰项：职业道德具有法律强制力）。

### 四、教育 vs 修养（最易混）

| 维度 | 对应内容 |
| --- | --- |
| 教育的内容 | 培养基金职业道德观念、灌输基金职业道德规范 |
| 教育的核心内容 | 基金职业道德规范教育 |
| 规范教育的基础和保障 | 基金职业道德观念教育 |
| 教育的目的 | 由被动接受教育到主动自我教育 |
| 提高职业道德素养的基本手段 | 基金职业道德教育 |
| 修养的具体内容 | 基金职业道德规范 |
| 修养的方法 | 正确树立观念、深刻领会规范、积极参加实践（**"积极接受教育"不是修养方法**） |
| 修养的形成途径 | 自我学习、自我改造、自我完善（**"自我评价"不是途径**） |
| 修养的内在动力 | 正确树立基金职业道德观念 |
| 修养的有效途径 | 基金职业道德实践 |

- 教育途径：岗前教育、岗位教育、基金业协会的自律、树立典型、社会各界持续监督；**"后续教育""离岗教育"是干扰项**。
- 岗前教育 = 上岗**之前**（入职必备知识和职业道德）；途径为基金从业资格考试 + 所在机构上岗前教育。
- 岗位教育 = 上岗**之后**（业务能力和职业道德的继续教育），主要通过**在职培训**完成。
- 职业道德奖惩机制由**基金行业协会**建立（干扰项：由政府建立）；职业道德建设要同完善监督机制相结合，且需要社会各界监督。
- 监督动力最足、最深最细的是**投资者**，不是监管机构、基金机构或行业自律组织。
- 基金业协会侧重**职业道德**层面监管；政府监管机构侧重法律法规层面。
- 《基金从业人员执业行为自律准则》由基金业协会于**2014年12月15日**颁布。

### 五、六项规范的要求归属辨析（最高频错点）

| 要求表述 | 正确归属 |
| --- | --- |
| 不得欺诈客户 | 诚实守信（**不是**守法合规） |
| 不得违规承诺收益、不保本保收益 | 诚实守信（**不是**客户利益优先规则） |
| 不得进行内幕交易和操纵市场 | 诚实守信 |
| 不得进行不正当竞争 | 诚实守信（**不是**专业审慎） |
| 不得从事与投资人利益相冲突的业务 | 客户至上 |
| 不得在基金资产之间、基金资产与其他受托资产之间利益输送 | 客户至上 |
| 不得侵占或挪用基金投资人的交易资金和基金份额 | 客户至上 |
| 不得从事可能导致与**投资者或所在机构**之间产生利益冲突的活动 | 忠诚尽责 |
| 恪尽职守 | 忠诚尽责（**不是**专业审慎） |
| 持证上岗、持续学习、审慎开展执业活动 | 专业审慎 |
| 熟悉法规、遵守自律准则、配合监管、举报违法违规 | 守法合规 |
| 在职与离职后均须保密 | 保守秘密（对所有基金从业人员均有约束效力） |

- 调整关系辨析：守法合规 → 与**基金行业及基金监管**的关系；客户至上 → 与**投资人**的关系。
- 最基础的要求 = **守法合规**；核心规范 = **诚实守信**。

### 六、内幕交易 vs 操纵市场 vs 欺诈

- 内幕交易：利用能影响证券价格的**重要非公开信息**进行交易牟利。内幕信息三要素 = 来源可靠 + 重要 + 非公开（**"及时""市场上可获得"是干扰项**）。
- 操纵市场：通过**扭曲证券价格形成机制或人为控制交易量**等方式意图误导市场参与者；判定关键在于**有误导市场参与者的意图**。
- 欺诈：虚构事实或隐瞒真相使客户产生错误认识并做出错误判断；虚假陈述、隐瞒真相、舞弊属欺诈，**不承诺收益不属欺诈**。
- 案例判断：散布不实消息影响股价获利 → 操纵市场（不是内幕交易、不是不正当竞争）；只宣传业绩最好的基金 → 违反诚实守信。
- 内幕交易与操纵市场违反证券市场**公开、公平、公正**原则。

### 七、正当竞争与销售行为

- 公平竞争 = 正当竞争的**前提**；合法竞争 = 正当竞争的**基础**；有序竞争 = 正当竞争的**表现**。干扰项："公开竞争是正当竞争的原则""平稳增长是正当竞争的结果"。
- 竞争是市场经济的**核心机制**。
- 允许：按规定对申购费率进行**8折优惠**。
- 禁止：压低基金收费水平、赠送实物/保险/基金份额、借助行政手段开展业务、因份额多寡厚此薄彼、从事力所不能及的工作。
- 过往业绩陈述三条红线：来源须合规、不得片面夸大、不得预测未来业绩（不得依过往业绩预测未来业绩）。

### 八、行业本质与主体定位

- 基金行业本质 = **资产管理行业**（干扰项：销售行业、投资咨询行业、资产托管行业、中间介绍行业）。
- 基金行业是"**受人之托，代人理财**"的专业服务行业；属于**智力**服务型行业。
- 基金市场存续和行业发展的基础是**投资人的信心和信任**（干扰项：基金经理盈利水平）。
- 职业道德的定义 = **社会道德在职业领域的特殊表现**（区别于道德、品德、素养）。
