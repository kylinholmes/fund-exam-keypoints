# 基金基础知识与法律法规 · 第8章 基金行业文化建设 考点笔记

本章先讲文化的一般含义与中国特色金融文化"五要五不"的内涵，再讲基金行业文化建设对机构、市场、投资者、风险防范的意义，随后梳理基金行业文化建设的制度实践与自律文件，最后落到证券期货市场诚信档案、诚信信息效力期限与查询更正的具体规定。

题量：144题

## 第1节 中国特色金融文化的内涵（27题）

1. 文化有广义与狭义之分：广义的文化又称"大文化"；狭义的文化专注于精神创造活动及其成果，排除人类社会关于物质创造活动及其结果。⭐
2. 狭义文化的范畴包括政治、法律、道德等精神层面内容；物质生产属于物质创造活动，不属于狭义文化范畴。
3. 一个群体或组织的文化要素包括价值观念、行为模式、伦理道德；个人喜好属于个体特性，不构成群体或组织文化要素。
4. 文化的力量体现在塑造个体思想观念、增强成员凝聚力、推动社会进步三个方面；文化不能决定社会制度变革，社会制度变革由生产力与生产关系、经济基础与上层建筑的矛盾运动决定。
5. 文化的多样性和包容性有利于促进科技进步、推动经济繁荣、增进文化交流。
6. 文化与经济相互交融，优秀文化能够促进商业活动和市场经济的发展，"文化不能促进商业活动和市场经济的发展"是错误说法。
7. 行业文化的内在要素包括价值观念、职业道德、管理理念，侧重精神、理念层面；行业公约是较为外在的、成文的规范，不属于内在要素。
8. 行业文化的作用包括为行业成员提供行为和思想指导、塑造正面的行业形象、对社会价值观产生积极引导支撑作用；行业文化不能决定行业的市场份额，市场份额受产品竞争力、营销策略等多种复杂因素影响。
9. 中国特色金融文化具体包含"五要五不"。⭐⭐
10. 金融行业以信用为基础；利益是金融活动追求的目标之一，创新是金融发展的推动因素，法治是规范金融的手段，三者都不是金融行业的基础。
11. "要诚实守信，不逾越底线"要求金融活动秉持诚信原则、遵守规则，具体体现为坚持欠债还钱、珍惜信誉。
12. "要以义取利，不唯利是图"源自中华优秀传统文化，体现"先义而后利者荣，先利而后义者辱"的义利观。⭐
13. 金融具有功能性和盈利性双重属性：一方面发挥融通资金等功能促进经济发展（功能性），另一方面金融机构以盈利为目的开展经营活动（盈利性）；公益性不是金融的属性。
14. "要稳健审慎，不急功近利"体现中华优秀传统文化中"欲速则不达，见小利则大事不成"。⭐
15. 金融行业稳健审慎经营，要树立正确的经营观、业绩观和风险观。⭐
16. 稳健审慎是国际上一些金融机构能够成为百年老店、基业长青最重要的秘诀。⭐
17. "要守正创新，不脱实向虚"的关键是解决好金融为谁服务、为什么创新问题，即坚守服务实体经济的本分，在此基础上创新。⭐
18. 金融的本质是服务实体经济，金融创新要紧紧围绕服务实体经济推动创新。⭐⭐
19. "要依法合规，不胡作非为"体现"法者，天下之仪也"，强调法是天下的准则、法律规范的重要性。⭐
20. 金融机构和从业人员要严格遵纪守法，遵守金融监管要求，自觉在监管许可的范围内依法经营。⭐
21. 中国特色金融文化是在金融领域中"把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合"的生动体现。
22. 2024年1月16日，习近平总书记在省部级主要领导干部推动金融高质量发展专题研讨班上指出，推动金融高质量发展、建设金融强国，要坚持法治和德治相结合，积极培育中国特色金融文化。
23. "五要五不"不包括"要追求利润，不避风险"这类片面强调逐利、不避风险的表述。
24. "三铁"传统指铁账本、铁算盘、铁规章，不包括铁纪律。

## 第2节 基金行业文化建设的重要意义（40题）

1. 金融是国家核心竞争力的重要组成部分。
2. 培育中国特色金融文化的目的包括推动金融行业高质量发展、建设金融强国、促进金融行业健康发展；"阻碍基金行业进步"不属于其目的。
3. 基金行业文化建设是培育中国特色金融文化的重要组成，不是唯一组成、无关部分或次要组成。
4. 基金行业文化建设体现基金行业的价值观、风险观、发展观，不只体现其中单一观念。
5. 与其他行业相比，基金行业具有外部性、涉众性、传导性，不具有封闭性；基金行业资金流动、信息披露等需要公开透明。
6. 基金行业单点的道德风险事件可能引发所在机构重大风险，并跨机构、跨行业、跨市场传导，危及金融安全和社会稳定，不会促进金融安全和社会稳定。
7. 不健康的企业文化对基金行业的危害包括损害行业内个体利益、侵蚀行业整体竞争力、削弱服务实体经济能力。
8. 建设良好基金行业文化的意义包括传承和弘扬行业精神、积淀和凝聚行业价值观、指导和引领基金行业高质量发展。
9. 信义义务是基金管理人必须恪守的首要原则，要求基金管理人将客户利益置于优先地位。⭐
10. 信义义务是基金行业建立信任和声誉的坚实基石；投资者正是基于对基金管理人履行信义义务的信任才将资产交予管理。
11. 在法律法规基础上，健康优良的行业文化为行业机构及从业人员提供明确的行为准则，不是模糊的行为指引、随意的操作空间或无约束的发展方向。
12. 健康良好的行业文化在复杂市场环境中为行业划定清晰发展方向，是基金行业行稳致远的立身之本。⭐
13. "金融活，经济活；金融稳，经济稳"体现金融对经济有重要影响。
14. 我国当前经济已由高速增长阶段转向高质量发展阶段，正在形成以国内大循环为主体、国内国际双循环相互促进的新发展格局。
15. 基金行业是直接融资体系的重要有机组成部分。
16. 基金行业机构在金融领域扮演直接融资的"服务商"、社会财富的"管理者"、金融创新的"领头羊"，不是实体经济的"破坏者"。
17. 健康良好的行业文化引导行业机构形成正确的价值观、业绩观和长远发展观，不倡导短期利益至上观。⭐⭐
18. 健康良好的行业文化能防止基金行业出现资源错配、"脱实向虚"问题，引导行业回归服务实体经济的初心，为服务实体经济提供精准高效的金融服务。⭐⭐
19. 基金行业将众多投资者资金集中起来进行投资，在资本市场是主要的买方力量之一，不是唯一买方力量，也不是主要卖方力量。
20. 基金管理人通过专业分析判断配置资金，目的是活跃资本市场、促进资源有效配置。
21. 良好的行业文化对资本市场的作用是提高资本市场效率、增强资本市场稳定性、提升投资者保护水平、为投资者创造价值，基金行业文化建设对资本市场健康发展起支柱作用。⭐⭐
22. 良好的行业文化鼓励基金管理人追求长期价值，而非短期投机利益、不正当交易或违规运作。⭐⭐
23. 健康良好的行业文化鼓励行业机构建立健全内控体系，严格遵守法律法规和行业准则，具备合规意识，承担相应社会责任，防止风险外溢。⭐⭐
24. 健康良好的行业文化有助于培养从业人员良好的职业道德操守，要求从业人员诚实守信、恪尽职守，谨守底线、远离乱象。⭐
25. 健康良好的行业文化是防范金融风险的有力抓手，不是无关因素、次要手段或无效措施。

## 第3节 基金行业文化建设的具体实践（37题）

1. 基金行业自诞生之初始终坚持的初心是"受人之托，代人理财"。
2. 中国基金行业推动规范发展的首要举措是制度先行；制度是行业规范发展的基础和保障。
3. 《证券投资基金法》是我国基金行业的根本大法，是基金行业规则体系的核心，行业自律公约、公司内部制度、地方监管条例等都要基于此制定。
4. 基金托管制度在保障基金资产安全、保护投资者利益方面起关键作用，被资产管理行业广泛效仿。
5. 基金行业的内控制度为财富管理行业树立标杆。
6. 完善的信息披露规范体系及 XBRL（可扩展商业报告语言）的运用，令基金信息披露更加透明、便于计算机处理和分析。
7. 基金行业较早全面实施了投资者适当性制度，该制度是基金行业率先推出的制度。
8. 2013年6月1日，修订后的《证券投资基金法》施行，将非公开募集基金纳入调整范围，标志着私募基金正式纳入监管；2014年8月21日，中国证监会发布《私募投资基金监督管理暂行办法》，进一步确立私募基金的监管规则。
9. 公募基金具有投资门槛较低、流动性良好、高度净值化的特点，面向社会公众发售，不只服务机构投资者。
10. 公募基金经营机构凭借专业的投资管理能力和丰富的产品线，是全国社保基金最主要的委托投资资产管理人。
11. 基金行业践行社会责任的领域包括救灾助困、乡村振兴、绿色经济，不包括恶意竞争。
12. 2019年11月，中国证监会发布《建设证券基金行业文化、防范道德风险工作纲要》。
13. 基金行业文化的核心是"合规、诚信、专业、稳健"。⭐⭐
14. 《公募基金行业文化建设倡议书》提出的行动方向包括恪守信托精神、敬畏法治、践行社会责任，不包括追求短期利益。⭐⭐
15. 基金行业文化建设的重要抓手是制度建设。
16. 基金行业文化建设中强化党组织作用的目的是确保文化建设与国家战略一致。⭐
17. 基金公司文化建设中，业绩考核与激励机制调整的方向是从追求规模和利润转向注重服务质量和风险管理。⭐⭐
18. 2022年，中国证监会发布《关于加快推进公募基金行业高质量发展的意见》。
19. 《公募基金行业文化建设自律公约》由中国证券投资基金业协会发布。
20. 《公募基金行业文化建设自律公约》规范的方面包括党的领导、守法合规、信义义务，不包括短期投机。
21. 私募基金行业修订《私募投资基金登记备案办法》的目的是明确文化建设要求、防范"伪"私募、提高登记要求，不包括鼓励买卖"壳"行为。
22. 《基金从业人员管理规则》明确的从业人员禁止性行为包括商业贿赂、声誉管理失当、奢靡炫富；提供专业服务不属于禁止性行为。
23. 《私募基金行业文化建设倡议书》首次对私募基金行业文化建设进行系统性规范。
24. 《私募基金行业文化建设倡议书》提出的文化建设方向包括初心使命、合规经营、专业精神，不包括短期理念。
25. 《习近平关于金融工作论述摘编》为金融机构高质量发展提供根本遵循。
26. 党的二十届三中全会通过《中共中央关于进一步全面深化改革推进中国式现代化的决定》。
27. 2024年，中国证监会发布《关于加强证券公司和公募基金监管加快推进建设一流投资银行和投资机构的意见（试行）》。
28. 《关于加强证券公司和公募基金监管加快推进建设一流投资银行和投资机构的意见（试行）》提出要大力弘扬和践行"五要五不"的中国特色金融文化。⭐⭐
29. 基金行业在新征程中应把功能性放在首要位置。
30. 基金行业服务中国式现代化需围绕"五篇大文章"发力，"五篇大文章"指科技金融、绿色金融、普惠金融、养老金融、数字金融，不包含投机金融。
31. 基金行业坚持党的全面领导的根本目的是确保工作沿正确政治方向。⭐
32. 基金行业工作重心应放在提高投资者获得感。⭐
33. 金融的天职和宗旨是服务实体经济。⭐⭐
34. 基金行业守正创新的"正"指服务经济发展和社会民生的本分。
35. 需推动中华优秀传统文化在金融领域的创造性转化和发展，不是简单复制、完全摒弃或形式化应用。
36. 基金行业应树立以人民为中心的价值取向。⭐
37. 我国公募基金已经成长为服务大众理财、百姓养老的专业化力量，以规范、透明、开放树立资产管理行业标杆，忠实于持有人利益铸就公募基金文化底色。

## 第4节 诚信管理的相关规定（40题）

1. 诚信是基金行业文化的核心理念与重要内涵之一，是基金行业的立业之本。⭐
2. 中国证监会建立证券基金期货行业诚信监督管理体系的基础是国家有关社会诚信建设。
3. 党中央和国务院发布一系列关于社会诚信建设文件的目的包括构建诚信建设长效机制、规范失信行为认定等机制、推动社会信用体系高质量发展，不包括阻碍社会信用体系发展。
4. 社会诚信建设相关文件包括《关于建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的指导意见》《关于加强个人诚信体系建设的指导意见》《关于推进社会信用体系建设高质量发展促进形成新发展格局的意见》。
5. 2020年，中国证监会修订完善并发布《证券期货市场诚信监督管理办法》。
6. 公民、法人或其他组织从事证券期货市场活动，禁止欺诈、内幕交易、操纵市场；诚实守信开展业务是鼓励倡导的行为，不属于禁止行为。
7. 《证券期货市场诚信监督管理办法》适用于基金管理人、基金从业人员、基金托管人及其相关高管人员。
8. 中国证监会建立的全国统一的证券期货市场诚信信息记录平台是诚信档案数据库。
9. 记入诚信档案的入档对象包括证券业从业人员、期货从业人员、基金从业人员，不包括与证券期货市场无关的普通公民。⭐
10. 区域性股权市场的运营机构及其董事、监事和高级管理人员属于记入诚信档案的入档对象。
11. 为证券期货业务提供存管、托管业务的商业银行及其存管、托管部门的高级管理人员属于记入诚信档案的入档对象。
12. 诚信档案采集公民的姓名、国籍、身份证件号码等与信用相关且必要的基本信息，不采集公民的宗教信仰。⭐
13. 应记入诚信档案的诚信信息包括中国证监会及其派出机构作出的行政许可决定；公民的疾病病史、法人的商业秘密、法律禁止采集的信息不属于应记入的诚信信息。
14. 发行人、上市公司等所作公开承诺的履行情况，无论履行与否，都属于应记入诚信档案的信息。
15. 因涉嫌证券期货违法被中国证监会及其派出机构调查及采取强制措施的信息，属于应记入诚信档案的信息。
16. 《诚信办法》第八条规定的违法失信信息，在诚信档案中的一般效力期限为3年。⭐
17. 因证券期货违法行为被行政处罚、市场禁入的信息，在诚信档案中的效力期限为5年。⭐
18. 违法失信信息的效力期限自对违法失信行为的处理决定执行完毕之日起算。
19. 超过效力期限的违法失信信息，不再进行诚信信息公开，不接受除本人查询外的申请查询，而不是直接从诚信档案中删除。⭐
20. 公民、法人或其他组织申报的诚信信息应当真实、准确、完整，不得夸大。
21. 依法向社会公开的是《诚信办法》第八条第(2)项至第(4)项、第(6)项信息和第(5)项的行政处罚、市场禁入信息。⭐
22. 证券期货市场违法失信信息公开查询平台供社会公众查询的信息包括《诚信办法》第八条第(5)项的行政处罚信息、市场禁入决定信息和第(6)项信息，不包括公民的个人隐私信息。
23. 严重违法失信主体的专项公示期为1年。
24. 因操纵市场被中国证监会及其派出机构作出行政处罚的市场主体，在证券期货市场违法失信信息公开查询平台进行专项公示。
25. 公民、法人或其他组织申请查询诚信信息，不符合《诚信办法》第十七条规定条件的，中国证监会及其派出机构不予办理。⭐
26. 发行人、上市公司申请查询拟任董事的诚信信息，符合查询条件的予以办理。⭐
27. 申请查询的诚信信息属于国家秘密的，不予查询，但应在答复中说明。
28. 中国证监会及其派出机构收到符合条件且材料齐备的诚信信息查询申请后，在5个工作日内反馈。⭐
29. 记入诚信档案的主体认为其诚信信息存在重大、明显错误，可以向中国证监会及其派出机构申请更正。⭐
30. 中国证监会及其派出机构收到诚信信息更正申请后，在15个工作日内进行处理并告知申请人。⭐
31. 通过申请查询获取的诚信信息，不得泄露给他人使用。
32. 中国证监会建立的诚信分类监督管理制度包括基金管理人诚信积分制度、证券期货服务机构诚信积分制度、证券期货基金从业人员诚信积分制度，不包括普通公民诚信积分制度。
33. 申请人向中国证监会及其派出机构申请行政许可时，应当书面承诺申请材料真实、准确、完整，不得夸大。
34. 中国证监会及其派出机构审查行政许可申请时，应当查阅申请人以及申请事项所涉及的有关当事人的诚信档案。
35. 行政许可申请人存在《诚信办法》第八条第(4)项中未履行承诺的信息，且属于法定不予许可条件范围的，中国证监会及其派出机构应当依法作出不予许可的决定。⭐
36. 业务创新试点申请人有《诚信办法》规定的违法失信信息，且不能证明该信息与业务创新无关的，中国证监会及其派出机构可以暂缓或者不予安排试点。⭐
37. 中国证监会及其派出机构进行行政处罚时，应当综合考虑违法行为的性质、损害投资者合法权益程度、当事人诚信状况，不包括当事人的家庭背景。
38. 基金管理人拟聘任高级管理人员时，应当将其诚信状况作为决定是否聘任的依据。
39. 证券期货市场行业组织对遵守法律、诚实信用的成员及从业人员，可以予以表彰、奖励。
40. 中国证监会与国务院其他部门、地方人民政府等建立的是失信联合惩戒和守信联合激励制度机制。

## 易混易错

### 一、文化的广狭之分与"要素/作用"边界

| 表述 | 归属 |
| --- | --- |
| 广义文化 | 又称"大文化" |
| 狭义文化 | 精神创造活动及其成果 |
| 物质生产、物质创造活动及其结果 | 属广义文化，**不属**狭义文化 |
| 政治、法律、道德 | 属狭义文化范畴 |
| 群体/组织文化要素 | 价值观念、行为模式、伦理道德 |
| 个人喜好 | 个体特性，**不是**群体或组织文化要素 |

- 文化**能**：塑造个体思想观念、增强凝聚力、推动社会进步、促进商业活动和市场经济发展、促进科技进步、推动经济繁荣、增进文化交流。
- 文化**不能**：决定社会制度变革；决定行业市场份额。
- 行业文化**内在**要素 = 价值观念、职业道德、管理理念；**行业公约**是外在的、成文的规范，属干扰项。
- 行业文化**不能**决定市场份额（干扰项"决定行业的市场份额"）；市场份额取决于产品竞争力、营销策略等。

### 二、"五要五不"原文与名言、要求的对应（最高频错点）

| 要/不 | 对应名言或要求 |
| --- | --- |
| 要诚实守信，不逾越底线 | 坚持欠债还钱、珍惜信誉 |
| 要以义取利，不唯利是图 | "先义而后利者荣，先利而后义者辱" |
| 要稳健审慎，不急功近利 | "欲速则不达，见小利则大事不成" |
| 要守正创新，不脱实向虚 | 解决好金融为谁服务、为什么创新；紧紧围绕服务实体经济创新 |
| 要依法合规，不胡作非为 | "法者，天下之仪也"；在监管许可范围内依法经营 |

- 干扰名言："诚者，天之道也"（对应诚信，**不**对应稳健审慎）；"穷则变，变则通，通则久"（对应变革，**不**对应稳健审慎）。
- 数量陷阱："三要三不""四要四不""六要六不"均为干扰项，正确为"**五要五不**"。
- 干扰项"要追求利润，不避风险"不属于"五要五不"。
- "三铁"传统 = **铁账本、铁算盘、铁规章**；"铁纪律"是干扰项。
- 金融的**双重属性** = 功能性 + 盈利性；干扰项：公益性、服务性。
- 金融行业的基础 = **信用**；干扰项：利益、创新、法治。
- 稳健审慎经营要树立的"三观" = **经营观、业绩观、风险观**；"价值观"是干扰项。

### 三、基金行业的特性与角色定位

- 基金行业特性 = 外部性、涉众性、传导性；**"封闭性"是干扰项**。
- 基金行业机构角色 = 直接融资的"服务商"、社会财富的"管理者"、金融创新的"领头羊"；**"实体经济的破坏者"是干扰项**。
- 资本市场地位 = **主要的买方力量之一**；干扰项："唯一的买方力量""主要的卖方力量之一""无关力量"。
- 直接融资体系地位 = **重要有机组成部分**；干扰项："次要组成部分""唯一组成部分""无关部分"。
- 培育中国特色金融文化的定位 = **重要组成**；干扰项："唯一组成""次要组成""无关部分"。

### 四、"良好/健康行业文化"的正负向干扰项模式

- 正向表述（正确选项）：明确的行为准则、划定清晰发展方向、立身之本、内控体系、合规意识、承担社会责任、防止风险外溢、培养良好职业道德操守、诚实守信恪尽职守、谨守底线远离乱象、防范金融风险的有力抓手、支柱作用、提高效率、增强稳定性、提升投资者保护水平、为投资者创造价值、长期价值、精准高效金融服务、提高投资者获得感。
- 负向表述（几乎均为干扰项）：模糊的行为指引、随意的操作空间、无约束的发展方向、混淆发展方向、限制行业发展、增加行业风险、松散的管理体系、随意的决策机制、违规意识、投机意识、冒险意识、逃避社会责任、忽视风险外溢、引发系统性风险、放任/扩大风险、短期利益至上观、短期投机利益、不正当交易、违规运作、资源错配"脱实向虚"、削弱服务实体经济能力。
- 单点道德风险事件的后果 = 引发所在机构重大风险 + 跨机构跨行业跨市场传导 + 危及金融安全和社会稳定；**"促进金融安全和社会稳定""增强服务实体经济能力"是反向干扰项**。
- 判断技巧：题目问"**不包括**"时，答案往往是三个正向 + 一个负向中的负向项，或三个负向 + 一个正向中的正向项。

### 五、制度与自律文件的"对应关系"（最易混）

| 制度/文件 | 关键定位 |
| --- | --- |
| 《证券投资基金法》 | 基金行业**根本大法**、规则体系的**核心** |
| 基金**托管**制度 | 被**资产管理行业广泛效仿** |
| 基金**内控**制度 | 为**财富管理行业树立标杆** |
| **投资者适当性**制度 | 基金行业**率先推出** |
| **XBRL**（可扩展商业报告语言） | 令信息披露更透明、便于计算机处理 |
| 《建设证券基金行业文化、防范道德风险工作纲要》 | **2019年11月**，中国证监会发布 |
| 《关于加快推进公募基金行业高质量发展的意见》 | **2022年**，中国证监会发布 |
| 《关于加强证券公司和公募基金监管加快推进建设一流投资银行和投资机构的意见（试行）》 | **2024年**，中国证监会发布，提出弘扬"五要五不" |
| 《公募基金行业文化建设自律公约》 | **中国证券投资基金业协会**发布 |
| 《私募基金行业文化建设倡议书》 | **首次**对私募基金行业文化建设进行系统性规范 |
| 《习近平关于金融工作论述摘编》 | 为金融机构高质量发展提供**根本遵循** |
| 《中共中央关于进一步全面深化改革推进中国式现代化的决定》 | 党的**二十届三中全会**通过 |

- 发文主体辨析：**证监会**发布工作纲要、公募基金高质量发展意见、一流投资银行和投资机构意见、诚信监督管理办法；**中国证券投资基金业协会**发布自律公约、倡议书。
- 行业文化核心 = "**合规、诚信、专业、稳健**"；干扰项："盈利、规模、速度、创新"等。
- 《公募基金行业文化建设倡议书》行动方向 = 恪守信托精神、敬畏法治、践行社会责任；**"追求短期利益"是干扰项**。
- 公约规范方面 = 党的领导、守法合规、信义义务；**"短期投机"是干扰项**。
- 私募倡议书方向 = 初心使命、合规经营、专业精神；**"短期理念"是干扰项**。
- 修订《私募投资基金登记备案办法》目的 = 明确文化建设要求、防范"伪"私募、提高登记要求；**"鼓励买卖'壳'行为"是干扰项**。
- 《基金从业人员管理规则》禁止行为 = 商业贿赂、声誉管理失当、奢靡炫富；**"专业服务"不是禁止行为**。
- "五篇大文章" = 科技金融、绿色金融、普惠金融、养老金融、数字金融；**"投机金融"是干扰项**。
- 金融的天职和宗旨 = **服务实体经济**；守正创新的"正" = 服务经济发展和社会民生的本分；行业工作重心 = 提高投资者获得感；价值取向 = **以人民为中心**；新征程中功能性应放在**首要位置**。

### 六、私募基金纳入监管与公募基金特点

- 私募基金正式纳入监管的标志：**2013年6月1日**修订后的《证券投资基金法》施行，将非公开募集基金纳入调整范围。
- **2014年8月21日**中国证监会发布《私募投资基金监督管理暂行办法》，进一步确立监管规则。
- 公募基金特点 = 投资门槛较低 + 流动性良好 + 高度净值化；**"仅服务机构投资者"是干扰项**。
- 全国社保基金最主要的委托投资资产管理人 = **公募基金经营机构**（干扰项：商业银行、证券公司、保险公司）。
- 我国公募基金 = 服务大众理财、百姓养老的专业化力量，以规范、透明、开放树立资产管理行业标杆。

### 七、诚信档案的"对象—信息—期限"三组数字

| 项目 | 规定 |
| --- | --- |
| 全国统一记录平台 | 诚信档案数据库 |
| 效力期限（第八条违法失信信息） | 一般 **3年** |
| 效力期限（行政处罚、市场禁入信息） | **5年** |
| 效力期限起算 | 对违法失信行为的**处理决定执行完毕之日** |
| 严重违法失信主体专项公示期 | **1年** |
| 查询申请反馈时限 | **5个工作日**（符合条件且材料齐备） |
| 更正申请处理并告知时限 | **15个工作日** |
| 查询申请依据条款 | 《诚信办法》**第十七条** |
| 诚信信息申报要求 | 真实、准确、完整（"夸大"是干扰项） |

- 超过效力期限的处理 = **不再公开 + 不接受除本人查询外的申请查询**；干扰项："仍进行信息公开""接受所有申请查询""直接从档案中删除"。
- 入档对象：证券业从业人员、期货从业人员、基金从业人员；区域性股权市场运营机构及其董事、监事、高级管理人员；为证券期货业务提供存管、托管业务的商业银行及其存管、托管部门的高级管理人员。**与证券期货市场无关的普通公民不是入档对象**。
- 不采集/不公开的信息：宗教信仰、疾病病史、法人商业秘密、公民个人隐私、国家秘密。采集的信息：姓名、国籍、身份证件号码。
- 应记入的诚信信息：中国证监会及其派出机构的行政许可决定；发行人、上市公司等公开承诺的**履行情况（无论是否履行）**；因涉嫌证券期货违法被调查及采取强制措施的信息。
- 依法向社会公开：第八条第(2)项至第(4)项、第(6)项信息和第(5)项的行政处罚、市场禁入信息。
- 诚信分类监管制度 = 基金管理人、证券期货服务机构、证券期货基金从业人员诚信积分制度；**"普通公民诚信积分制度"是干扰项**。
- 行政许可环节：书面承诺材料真实、准确、完整 → 查阅申请人及相关当事人的诚信档案 → 存在第八条第(4)项未履行承诺且属法定不予许可情形的**依法不予许可**。
- 业务创新试点：有违法失信信息且**不能证明**与业务创新无关 → **暂缓或者不予安排试点**。
- 行政处罚考量因素 = 违法行为性质、损害投资者合法权益程度、当事人诚信状况；**"家庭背景"是干扰项**。
- 查询获取的信息**不得泄露给他人使用**；属国家秘密的**不予查询但应在答复中说明**。
- 联合激励惩戒 = 中国证监会与国务院其他部门、地方人民政府等建立的**失信联合惩戒和守信联合激励制度机制**；行业组织对守法诚信成员可**予以表彰、奖励**。
