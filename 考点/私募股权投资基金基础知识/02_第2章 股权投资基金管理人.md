# 私募股权投资基金基础知识 · 第2章 股权投资基金管理人

本章考点覆盖管理人的法律地位与准入前提、信义义务的两项构成（忠实 + 勤勉）及利益冲突处理、专业要求下的投研与风控分工、以及内部治理中各部门的职责边界。题量少但辨析精度要求高，主要考查「职责归属」与「原则对应」。

题量：15题（第1节 管理人概述 5题，第2节 信义义务 3题，第3节 专业要求 3题，第4节 内部治理 4题）。

## 第1节 股权投资基金管理人概述

1. **股权投资基金的主要特征**：向**合格投资者非公开募集**、**委托管理人**进行管理、**依托专业机构运作**。**"投向公开交易的企业股权类资产"不是**其特征（主要投向**未公开交易**的股权）。⭐⭐
2. **管理人经营活动的目的**：为**基金投资者利益**服务，秉持**基金份额持有人利益优先**原则（不是为自身利益，也不是兼顾两者）。⭐⭐
3. **开展业务的前提**：须先完成**管理人登记**，方可开展基金募集、基金管理等业务活动。**工商注册、税务登记**不直接关联基金业务资格；**产品备案**在基金募集完成后进行。⭐⭐
4. **资本金的出资形式**：应当以**货币出资**。实物、知识产权、土地使用权等出资形式存在价值评估复杂、变现困难等问题。⭐⭐
5. **管理人的职责**：按基金合同约定**向投资者提供与基金管理业务活动相关的信息**；妥善**保存**基金财产管理业务活动的记录。⭐⭐
6. **不属于管理人职责的表述**：**代替投资者进行投资决策**（投资者自行决策）；**决定基金投资方向不受合同约束**（投资方向应受合同约束）；**不保存业务活动记录**。⭐

## 第2节 股权投资基金管理人的信义义务

1. **信义义务的两项构成**：**忠实义务** + **勤勉义务**。⭐⭐
2. **忠实义务的要求**：将基金/公司利益置于首位，**不得谋取私利**，不得与委托人利益发生冲突。⭐
3. **勤勉义务的要求**：以**合理谨慎和专业能力**履行职责。⭐
4. **向被投企业收取费用的归属**：管理人向被投企业收取咨询费等费用，**若未事先与投资者达成一致**，原则上应**归入基金收益**（不是归管理人、被投企业或捐赠）。⭐⭐
5. **投资机会分配的原则**：核心是**公平**，须避免**对不同投资者形成不公平对待**。⭐⭐
6. **不属于核心要求的干扰项**：优先满足机构投资者需求、过多投资早期项目、投资机会分配过于集中——均不直接等同于不公平对待。⭐

## 第3节 股权投资基金管理人的专业要求

1. **创业投资基金投后增值服务的重点**：**提升企业管理能力**（从根本上增强企业竞争力与运营效率）。⭐
2. **投资管理体系覆盖的流程**：行业研究与项目开发、项目筛选、尽职调查、投资决策、投后管理。**"员工绩效考核"不属于**（属人力资源管理）。⭐⭐
3. **保障专业审慎的重要做法**：保持**风险控制团队与投资团队的相对独立性**，形成有效监督与制衡。⭐⭐
4. **错误做法的辨识**：让投资团队独立完成项目风险评估（缺乏制衡）、仅依靠投资团队的专业水平（无外部监督）、减少风控团队参与（不利于风险把控）。⭐

## 第4节 股权投资基金管理人的内部治理

1. **基金管理人的法律组织形式**：我国现行立法下为**公司型**、**合伙型**。**信托型不是**管理人的组织形式；**契约型**通常是**基金**的形式而非管理人形式。⭐⭐
2. **"鼓励利益相关者参与"原则下行业协会的引导方式**：鼓励自身践行 **ESG 投资**；在管理人申请登记环节引入**法律意见书**；关注**管理层未持股情况下的稳定性**。⭐⭐
3. **不属于上述引导方式的项**：要求管理人**公平对待所有 LP**——那属于**信义义务**的基本要求，是行业监管的通用准则，不是该原则下特有的引导方式。⭐⭐
4. **财务审计部的职责**：公司财务**预决算规划**、**财务报告、记账、出纳**等基础财务工作。⭐⭐
5. **不属于财务审计部职责**：**制定投资决策策略**（属投资决策委员会、投资研究等部门）；**基金产品对外投资的资金管理**（多由投资部门负责）。⭐⭐
6. **风险控制与合规部的职责**：审核经营过程中的**法律文件**、参与**基金募集监督**、审核**基金信息披露文件**。⭐⭐
7. **不属于风险控制与合规部职责**：**拟定投资策略**（属投资管理部门）。⭐⭐

## 易混易错

**管理人的身份与前提**

1. 主要特征 = 合格投资者非公开募集 + 委托管理人管理 + 依托专业机构运作。
2. 易错点：把"投向**公开交易**的企业股权类资产"当特征（应为**未公开交易**）。
3. 经营目的 = 为**基金投资者**利益，份额持有人利益**优先**；"为自身利益""兼顾两者"均错。
4. 准入前提 = **管理人登记**（不是工商注册、税务登记，也不是产品备案）。
5. 出资形式 = **货币**（实物、知识产权、土地使用权均不行）。

**信义义务的两分法**

6. 信义义务 = **忠实义务 + 勤勉义务**。
7. 易错点：与"忠实义务与谨慎义务""忠实义务与风险义务"混淆——标准表述是**忠实 + 勤勉**。
8. 忠实义务 = 利益置于首位、不谋私利；勤勉义务 = 合理谨慎 + 专业能力。
9. 未与投资者达成一致的被投企业收费 → **归入基金收益**（这是保护投资者的关键落点）。
10. 投资机会分配的唯一核心 = **公平**，避免对不同投资者不公平对待。

**专业要求与团队制衡**

11. 创投投后增值服务重点 = **提升企业管理能力**（不是扩产、营销或找融资）。
12. 投资管理体系流程 = 行业研究与开发 → 筛选 → 尽调 → 决策 → 投后；**员工绩效考核不属于**。
13. 专业审慎的关键机制 = **风控团队与投资团队相对独立**（相互制衡）。

**部门职责边界（本章最高频）**

14. 财务审计部：预决算规划、财务报告、记账、出纳。
15. 财务审计部**不管**：制定投资决策策略、基金对外投资的资金管理。
16. 风险控制与合规部：审核法律文件、参与募集监督、审核信息披露文件。
17. 风险控制与合规部**不管**：拟定投资策略。
18. 记忆锚点：**策略类归投研/投委会，财务类归财务审计部，合规类归风控合规部**——三者交叉设置选项即为陷阱。

**组织形式与原则归属**

19. 管理人的组织形式 = **公司型 + 合伙型**；信托型不是管理人形式，契约型是**基金**的形式。
20. "鼓励利益相关者参与"下的协会引导 = ESG 践行 + 法律意见书 + 关注管理层未持股的稳定性。
21. 易错点：**"公平对待所有 LP"属信义义务**，不是该原则下的特有引导方式。
