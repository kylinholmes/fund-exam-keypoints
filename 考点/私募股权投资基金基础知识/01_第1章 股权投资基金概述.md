# 私募股权投资基金基础知识 · 第1章 股权投资基金概述

本章考点覆盖股权投资基金的概念边界（私人股权=非公开发行和交易）、四大特点、基本运作流程与收益分配、市场参与主体及监管原则、中美起源发展的时间节点，以及其对经济高质量发展的作用。考查以「概念归属判断 + 时间年份 + 参与主体职责对应」为主。

题量：80题（第1节 概念与特点 17题，第2节 基本运作模式 14题，第3节 市场参与主体 17题，第4节 起源与发展 26题，第5节 对经济高质量发展的作用 6题）。

## 第1节 股权投资基金概念与特点

1. **私人股权的范围**：包括未上市企业股权，以及上市企业**非公开发行和交易**的普通股、可转换为普通股的优先股、可转换债券。⭐
2. **私人股权不包括**：上市企业**公开发行和交易**的普通股（这是干扰项）。
3. **"私人股权投资基金"的定义**：主要投资于**非公开发行和交易**的股权。注意是"发行**和**交易"两者都非公开，不是只有一项。⭐⭐
4. **私人股权中的债务工具辨析**：可转债属于私人股权（因可转换为股权）；企业债、公司债、私募债均属债务工具，不属于股权范畴。⭐
5. **股权投资基金四大特点**：投资期限较长、专业性较强、流动性较差、投资收益波动性**较大**（不是平稳）。⭐⭐
6. **"有耐心的资本"**：因主要投资未上市企业股权或上市企业非公开交易股权，通常需要**5年以上**才能完成投资的全部流程实现退出。⭐⭐
7. **风险收益特征**：与其他资产类别相比，股权投资基金是**高期望收益、高风险**（不是低风险低收益，也不是高风险低收益）。
8. **专业性体现**：需要更多的**投资经验积累、团队培育和建设**，体现**智力密集型**特征。规模大、超额认购、分散投资都不是专业性的体现。⭐
9. **管理方式**：因专业性要求高，市场上的股权投资基金通常**委托专业机构**管理。⭐
10. **激励约束机制的成因**：因基金管理**专业性较强**（不是期限长、不是波动大），故需建立有效充分的针对投资管理团队成员的激励约束机制。⭐
11. **投资后管理投入**：投入资源**较多**（不是较少）。
12. **基金份额流动性**：**较差**。
13. **募集方式**：我国股权投资基金**只能非公开募集**。⭐
14. **国内与国外股权投资基金的主要区别**：**募集方式**不同（国内主要非公开募集；国外有私募也有公募）。不是投资标的、收费标准或称谓。⭐

## 第2节 股权投资基金的基本运作模式

1. **基本运作流程（四环节）**：募集 → 投资 → 管理 → 退出。⭐⭐
2. **投资阶段的内容**：项目开发与初审、签署投资备忘录、尽职调查、投资决策、签订投资协议。**信息披露不属于投资阶段**（它贯穿基金运作全过程）。⭐⭐
3. **基金规模的两个口径**：**认缴出资规模**（投资者承诺认缴的出资总额）与**实缴出资规模**（实际缴付到位的出资总额），即"认缴募资规模；实际募资规模"。⭐⭐
4. **管理方式的两种**：**自我管理**（基金自建投资管理团队并负责投资决策）与**受托管理**（委托外部机构）。
5. **投资策略的定义**：基金在选择具体投资对象时所使用的一系列**规则、行为和程序**的总和。⭐
6. **募集对象**：通常只能是**合格投资者**（具备相应风险识别和承担能力）。⭐
7. **出资形式**：**货币资金**。无形资产、实物资产、商誉均不适用（评估作价复杂、处置不便、难以独立转让）。⭐
8. **退出方式（四种）**：上市退出、挂牌转让退出、协议转让退出、清算退出。**注销不是变现方式**。⭐⭐
9. **收益分配去向**：主要在**投资者与基金管理人**之间分配，不是投资者与第三方服务机构之间。⭐⭐
10. **基金利润的界定**：基金收入扣除各项费用和税收后，**超出投资者出资本金的部分**为基金利润。⭐⭐
11. **收益分配顺序**：基金收入先扣除**各项费用和税收**，再返还投资者投资本金。
12. **门槛收益率**：管理人可能需先让投资者实现某一门槛收益率，之后才可获得业绩报酬。⭐
13. **投资者能获得什么**：**本金 + 投资收益**。管理费、业绩报酬归管理人，投资者不获得。⭐⭐
14. **市场参与主体**：投资者、管理人、第三方服务机构。**监管机构不属于直接参与基金运作的主体**。⭐

## 第3节 股权投资基金市场参与主体

1. **基金管理人承担的职能**：基金产品的设计、基金份额的销售与备案、基金资产的管理。**基金运作的监管不属于**（由监管机构承担）。⭐⭐
2. **基金管理人的基本职责**：募集设立基金、基金备案、基金资产投资运作、在有效控制风险基础上为投资者争取最大投资收益、定期编制并呈报财务报告、按合同约定向投资者提供相关信息、妥善保存业务记录。**每月披露基金净值不是**（多为证券投资基金要求）。⭐⭐
3. **基金管理人 ≠ 有限合伙人**：合伙型基金的**有限合伙人不执行合伙事务**、不参与基金管理。⭐
4. **基金管理人 ≠ 基金财产所有者**：基金财产所有者是**基金投资者**。基金管理人是基金产品的**募集者和管理者**。⭐⭐
5. **基金管理人的经营目的**：为**基金投资者利益**服务，秉持基金份额持有人利益优先原则。⭐
6. **开展业务的前提**：完成**管理人登记**（工商注册、税务登记不直接关联；产品备案在募集完成后）。⭐
7. **资本金出资要求**：应当以**货币出资**。
8. **基金投资者**：基金的出资人、基金资产的所有者、基金投资回报的受益人，按所持份额享受收益和承担风险。⭐
9. **基金托管人的职责**：根据**基金管理人**的指令，及时办理清算、交割事宜。⭐⭐
10. **基金销售机构的性质**：接受基金管理人委托的**委托募集**机构。⭐
11. **基金销售业务资格主体**：保险机构、期货公司、商业银行等金融机构。**中国人民银行不是**（央行负责货币政策）。⭐
12. **市场服务机构**：律师事务所、会计师事务所、基金销售机构等。**中国基金业协会不是市场服务机构**（是**自律组织**）。⭐⭐
13. **会计师事务所的执业原则**：**独立、客观、公正**。⭐⭐
14. **律师的执业原则**：**诚实守信、勤勉尽责、审慎**。⭐⭐
15. **政府监管的特征**：相对行业自律、内部控制和社会力量监督，具有**法定性和强制性**。⭐
16. **监管的五项基本原则**：依法监管、**高效监管**、适度监管、审慎监管、分类监管。⭐⭐
17. **五项原则的辨识**（题干关键词 → 原则）：
    - 不直接干预内部经营管理、范围限定在市场失灵领域 → **适度监管**
    - 注重风险防控和偿付能力、确保基金运行稳健和财产安全 → **审慎监管**
18. **监管的首要目标**：保护**基金投资者**合法权益（不是管理人）。⭐
19. **监管的基石**：防范**系统性**金融风险（不是非系统性）。⭐
20. **投资者是市场的支撑者**：提供资金，是股权投资基金市场的支撑者。
21. **管理人准入差异**：公开募集基金的基金管理人准入限制**严格**；非公开募集基金的基金管理人准入限制**较宽松**。⭐

## 第4节 股权投资基金的起源与发展

1. **起源地**：股权投资基金起源于**美国**（不是英国）。⭐⭐
2. **全球第一家以公司形式运作的创业投资基金**：**1946年**美国研究与发展公司（**ARD**）。⭐⭐
3. **发展里程碑**：**1958年**美国《**小企业投资法**》颁布。⭐⭐
4. **成为专门行业的标志**：**1973年**美国创业投资协会成立。⭐⭐
5. **并购投资基金专业化运作的起点**：**1976年 KKR** 成立。⭐⭐
6. **美国私人股权投资协会成立**：**2007年**，数家并购基金管理机构脱离**美国创业投资协会**发起设立。此前（2007年以前）并购基金管理人作为**美国创业投资协会**会员享受服务并接受自律。⭐
7. **概念从狭义到广义**：狭义股权投资基金特指**并购投资基金**；后因并购基金管理机构兼做**创业投资**，且出现定向增发股票投资基金、不动产投资基金等新品种，概念发展到广义。⭐⭐
8. **早期存在形式**：早期股权投资基金主要以**创业投资基金**形式存在。20世纪50—70年代的创业投资基金为**经典的狭义创业投资基金**；20世纪70年代以后"创业投资"概念从狭义发展到广义。⭐
9. **我国行业发展的三阶段**：探索与起步阶段、快速发展阶段、统一监管下的规范化发展阶段。**没有"平稳发展阶段"**。⭐⭐
10. **探索与起步阶段的两条主线**：**科技系统对创业投资基金**的最早探索 + **国家财经部门对产业投资基金**的探索。⭐⭐
11. **1985年9月**：经国务院批准，原国家科委出资**10亿元**成立**中国新技术创业投资公司**。⭐⭐
12. **1999年11月**：国务院办公厅发布《**关于建立风险投资机制的若干意见**》，是我国第一个有关创业投资发展的**战略性、纲领性文件**。⭐⭐
13. **1998年12月**：国家计委向国务院提出"尽早研究设立创业板块股票市场问题"，**首次提出开设创业板的建议**。⭐
14. **2005年11月**：《**创业投资企业管理暂行办法**》由国家发展改革委等**十部委**联合发布。⭐⭐
15. **2009年**：创业板**2009年10月30日**正式开市（注意：**1998年**是"提出建议"，**2009年**是"正式上市"，两个年份极易混淆）。⭐⭐
16. **2014年年初**：中国证券投资基金业协会开始对私募基金管理人**登记**、对所管理基金**备案**，并陆续发布自律规则。⭐⭐
17. **统一监管职责**：在中国，**证监会**统一行使股权投资基金监管职责。人民银行（货币政策）、银保监会（银行保险）、基金业协会（**自律**组织，非监管机构）均不是。⭐⭐
18. **全球地位**：当前我国已成为全球**第二大**股权投资市场。⭐
19. **行业作用（四个方面）**：解决中小企业融资难、促进创新创业、支持企业重组重建、推动产业转型升级。⭐⭐
20. **推动的融资形式**：有力地推动了**直接融资和资本市场**在我国的发展（不是间接融资）。⭐⭐
21. **创业投资基金与证券投资基金的显著区别**：创业投资基金**直接投资产业**，证券投资基金投资证券。⭐
22. **发展趋势判断**：未来金融市场将由**间接融资为主转向直接融资为主**（题目若写"直接转间接"即为错误）。⭐⭐

## 第5节 股权投资基金对经济高质量发展的作用

1. **中小微创业企业的融资需求特征（四项）**：信息不对称比较严重、创业成功的不确定性较高、科技型中小微企业资产结构中**无形资产占比较高**、融资需求呈现**阶段性**特征。⭐⭐
2. **无形资产占比高**：科技型中小微创业企业依赖技术，**无形资产**占比较高（不是固定资产、有形资产或流动资产）。⭐
3. **公司治理**：多数中小微企业公司治理**存在缺陷**。⭐
4. **创业失败率**：不少创业企业最终失败。
5. **融资方式的阶段差异**：早期发展阶段需要**较小规模**的股权投资；中后期发展阶段可能以**可转换债等准股权方式**融资。⭐⭐
6. **创业投资基金的四项机制作用**：可用多种机制获取真实信息、可实现风险和期望收益的均衡匹配、可通过投资后监督和增值服务提高创业成功可能性、所进行的股权投资**无须被投资企业提供担保**。⭐⭐
7. **风险收益匹配的手段**：通过创新的**动态估值方法**（不是常态/固定/阶段估值方法）实现风险和期望收益的均衡匹配。⭐⭐
8. **研发到上市的时间**：创业投资基金支持的科技企业，产品从研发到上市销售所花时间**明显短于**一般企业。⭐

## 易混易错

**"私人股权"的范围边界**

1. 属于：未上市企业股权 + 上市企业**非公开发行和交易**的普通股、可转换为普通股的优先股、可转换债券。
2. 不属于：上市企业**公开发行和交易**的普通股；企业债、公司债、私募债（债务工具）。
3. 易错点：只记住"非公开发行"，忽略"非公开**交易**"——定义是"非公开发行**和**交易"。

**四大特点的正反两面**

4. 正确：投资期限较长、专业性较强、流动性较差、收益波动性**较大**。
5. 错误表述（干扰项）：收益波动性**平稳**、流动性**较好**、低风险低收益、投资期限较短、可公开募集。
6. "有耐心的资本"的**唯一**原因 = 投资周期长（通常5年以上完成投资到退出全流程）；监管流程长、筛选管理人的时间长、等到清算才分配，都是干扰项。

**专业性 vs 智力密集型 vs 委托管理**

7. 专业性体现 = 更多投资经验积累、团队培育和建设 → 体现**智力密集型**特征。
8. 因专业性高 → 通常**委托专业机构**管理。
9. 因专业性较强 → 需建立针对**投资管理团队成员**的激励约束机制。
10. 易错点：把"规模大""超额认购""分散投资"当专业性体现（全错）。

**运作流程与收益分配**

11. 四环节 = 募集 → 投资 → 管理 → 退出。**信息披露**贯穿全过程，不属于投资阶段。
12. 投资阶段 = 开发与初审、签署投资备忘录、尽职调查、投资决策、签订投资协议（5项）。
13. 退出方式 = 上市、挂牌转让、协议转让、清算（4种）；**注销**不是变现方式。
14. 收益分配 = 在**投资者与管理人**之间（不是与第三方服务机构）。
15. 分配顺序 = 收入 − 各项费用 − 税收 → 返还本金 → 剩余为基金利润 → 管理人可提取业绩报酬（常设门槛收益率）。
16. 投资者得**本金+投资收益**；管理人得**管理费+业绩报酬**。
17. 基金规模 = **认缴**出资规模 + **实缴**出资规模。

**参与主体的职责对应（高频）**

18. 基金管理人：产品设计、份额销售与备案、资产管理、投资运作、备案、财务报告、信息提供、记录保存。**不承担**：基金运作监管、基金财产所有权、每月披露净值。
19. 基金投资者：出资人、**基金财产所有者**、收益风险承担者、市场支撑者。
20. 基金托管人：**根据基金管理人指令**办理清算、交割。
21. 基金销售机构：**委托募集**机构（受管理人委托）。
22. 中国基金业协会：**自律组织**，不是市场服务机构，也不是监管机构。
23. 会计师事务所原则 = 独立、客观、公正；律师原则 = 诚实守信、勤勉尽责、审慎。两组**极易互换**，务必分开记。

**监管原则的关键词匹配**

24. 法定性+强制性 = 政府监管的**特征**（相对自律/内控/社会监督）。
25. 不干预内部经营、限于市场失灵领域 = **适度监管**。
26. 风险防控+偿付能力+运行稳健 = **审慎监管**。
27. 五项原则 = 依法、高效、适度、审慎、分类（"高效"常被漏选，"行业自律""资格准入"是干扰项）。
28. 首要目标 = 保护**投资者**；基石 = 防范**系统性**风险（"非系统性"是干扰项）。

**时间年份（本章最密集的失分点）**

29. 1946 ARD 成立（第一家以公司形式运作的创投基金）→ 1958《小企业投资法》→ 1973 美国创业投资协会 → 1976 KKR → 2007 美国私人股权投资协会。
30. 中国线：1985.9 中国新技术创业投资公司（10亿元）→ 1998.12 首次提出开设创业板 → 1999.11《关于建立风险投资机制的若干意见》→ 2005.11《创业投资企业管理暂行办法》→ 2009.10.30 创业板开市 → 2014年初 协会开始登记备案。
31. 易错点：1998（提建议）vs 2009（真上市）；2005（办法）vs 2014（登记备案）。

**趋势类表述的正反**

32. 正确：间接融资为主 → **直接融资**为主；要素驱动 → 创新驱动；股权投资基金运作模式与创新驱动内在要求**高度一致**。
33. 错误表述：直接融资 → 间接融资；运作模式与创新驱动"**相区别**"。
