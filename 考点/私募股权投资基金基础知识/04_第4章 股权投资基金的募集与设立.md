# 私募股权投资基金基础知识 · 第4章 股权投资基金的募集与设立

本章考点覆盖募集方式的两组分类、合格投资者标准、国内外募集对象差异、募集四阶段流程与募集资料、三种组织形式的合同必备条款与人数上限、以及三类基金的税务处理（先税后分/先分后税、税率、增值税范围）。本章题量最大，是「数字 + 原则方向」的高密度失分区。

题量：91题（第1节 募集与设立概述 6题，第2节 募集对象 13题，第3节 募集与设立流程 15题，第4节 股权投资基金合同 57题）。

## 第1节 募集与设立概述

1. **募集的两组分类**（极易混）：
   - 按**募集主体机构**：**自行募集**、**委托募集** ⭐⭐
   - 按**募集对象**：**公开募集**、**非公开募集**
2. **设立的定义**：基金管理人依法设立开展股权投资业务主体的过程，主要考虑**基金组织形式、基金架构、登记备案**等问题。⭐⭐
3. **备案机构**：基金设立完成后，应在**中国证券投资基金业协会**办理基金备案。⭐⭐
4. **我国现行的三种组织形式**：**公司型、合伙型、信托（契约）型**。**不存在"基金型"**。⭐⭐
5. **影响组织形式选择的因素**：**法律依据、监管要求、股权投资业务的适应程度、基金运营实务的要求**。⭐⭐

## 第2节 募集对象

1. **合格投资者制度的起源**：**美国**。⭐
2. **合格投资者的三个限定维度**：**风险识别能力和风险承担能力**、**资产规模或收入水平**、**基金份额认购金额**。**不包括信用记录**。⭐⭐
3. **合格投资者的具体标准**：
   - 投资于单只私募基金金额**不低于100万元**
   - 单位：净资产**不低于1000万元**
   - 个人：金融资产**不低于300万元**，或最近三年个人年均收入**不低于50万元** ⭐⭐
4. **合格投资者 vs 一般投资者的优势**：**资本更雄厚**、**识别与承受风险能力更强**、**专业知识更为丰富**。⭐
5. **国内外共同的投资者类型**：**母基金、金融机构、企业、个人**。⭐⭐
6. **国外募集对象**：养老基金、母基金、大学基金会、富有的个人或家族。**不包括政府引导基金**（那是国内特色）。⭐⭐
7. **国内募集对象**：**政府引导基金、母基金、社会保障金**等。**大学基金会在国内发展尚不成熟**，不是主要募集对象。⭐⭐
8. **国外养老基金的两类**：**公司养老基金**、**公共养老基金**。⭐
9. **中国最大的养老基金**：**全国社会保障基金**。⭐
10. **母基金的高专业化环节（四项）**：基金的筛选、投资组合的分配、投资组合的风险管理、基金的监控。⭐
11. **大型企业的参与方式**：以**子公司**形式进行创业投资或并购投资业务；参与**专业基金管理人**发起设立的股权投资基金。⭐
12. **西方国家参与的金融机构**：主要是**商业银行**和**投资银行**。⭐
13. **监管放宽后日益重要的投资者**：保险公司、商业银行、证券公司、基金子公司。⭐

## 第3节 募集与设立流程

1. **募集四阶段的顺序**：**募集筹备期 → 基金路演期 → 投资者确认 → 协议签署及出资**。⭐⭐
2. **私募备忘录（PPM）的撰写时点**：**募集筹备期**（不是路演期）。⭐⭐
3. **路演期的动作**：准备**募集推介资料**并分发**私募备忘录**。⭐
4. **投资者确认阶段的动作**：鉴别主要基金投资者、就最终条款展开预先谈判、谈判基金合同和附属文件。⭐
5. **协议签署及出资阶段的动作**：确定募集结束日期、传阅最终文件、签署基金合同及附属文件、按约定履行出资义务。⭐
6. **募集的三类资料**：**私募备忘录（PPM）**、**募集推介资料**、**（反向）尽职调查资料**。**收益分析报告不是**（基金不得对收益作确定性承诺）。⭐⭐
7. **PPM 的内容（四项）**：基金的规模、存续期和预计封闭时间；管理人在管基金情况摘要；机构和基金的投资理念（投资策略+特定市场竞争优势）；重要基金条款（分配机制、管理费及管理人投入）。⭐⭐
8. **募集推介资料须保证**：**真实性、完整性、准确性**。**及时性不是**对内容本身的要求。⭐⭐
9. **反向尽职调查资料的内容（四项）**：管理人基本情况、内部治理和重要制度、历史基金或业绩项目、核心团队成员信息。⭐⭐
10. **基金管理人对投资者资金安全的责任（四项）**：恪尽职守、诚实守信、谨慎勤勉；充分沟通、客观描述；严格保密；建立安全保障制度。⭐
11. **募集阶段的沟通要求**：与投资者就基金合同及附属文件**充分沟通**，并就法规影响的合同生效程序进行**客观描述**。⭐
12. **代销机构的两个条件**：获得**中国证监会基金销售业务资格** + 成为**中国证券投资基金业协会会员**。⭐⭐
13. **委托募集的对象**：必须是同时满足上述两个条件的机构。仅登记为基金管理人**不必然**有销售资格；P2P平台不具备资质。⭐⭐
14. **投资者适当性评估的两个维度**：**风险识别能力**和**风险承担能力**。⭐⭐
15. **公开募集的界定**：通过**公开渠道向非特定对象**推介；向特定对象募集**累计超过200人**。⭐
16. **缴款安排的惯例**：承诺资金**并非一次性汇入**，在需要投资时由**基金管理人**向投资者提出缴款要求。⭐⭐
17. **我国私募募集的四个程序**：特定对象确认及投资者适当性匹配、基金风险揭示、合格投资者确认、投资冷静期及回访确认（**非强制**）。⭐⭐

## 第4节 股权投资基金合同

### 人数上限（数字必背）

1. **有限责任公司型**：不超过**50人**。⭐⭐
2. **股份有限公司型**：不超过**200人**，应有**2个以上发起人**，其中**二分之一以上**发起人须在**中国境内有住所**。⭐⭐
3. **有限合伙型**：**2个以上50个以下**合伙人设立，至少应有**一个普通合伙人**。⭐⭐
4. **信托（契约）型**：按《证券投资基金法》，投资者**不得超过200人**。⭐⭐
5. **单个资产管理计划**：委托人不超过**200人**，但单笔委托金额**300万元以上**的投资者数量**不受限制**。⭐⭐

### 治理结构与运营依据

6. **公司治理结构的基本特点**：**股东至上**。⭐
7. **有限合伙治理结构的基本特点**：**普通合伙人**掌握合伙企业事务执行权（有限合伙人不执行合伙事务）。⭐⭐
8. **信托（契约）型治理结构的基本特点**：**基金管理人**高度控制基金决策权。⭐⭐
9. **公司型基金的权力机构**：**股东大会（股东会）**；投资者在**股东大会（股东会）**层面对重大事项进行决策。⭐⭐
10. **公司型基金以（　）为收入来源**：转让财产收入、股息红利等权益性投资收益。⭐
11. **公司型基金章程中的投资事项**：投资范围、投资运作方式、所投标的担保措施、投资后对被投资企业的持续监控、关联方认定标准及关联方投资的回避制度。⭐
12. **公司型基金的运营依据**：**公司章程**（利润分配也按章程条款）。⭐⭐
13. **《公司法》不再强制规定的事项**：注册资本限额、缴付安排、出资方式（**投资者限制不在其中**）。⭐⭐

### 合伙协议必备内容

14. **《合伙企业法》规定的合伙协议应载明事项**：名称和主要经营场所地点、合伙目的和合伙经营范围、合伙人姓名或名称及住所、出资方式/数额/缴付期限、利润分配与亏损分担方式、合伙事务的执行、入伙与退伙、争议解决办法、解散与清算、违约责任。**"盈利目标"不是**法定必须载明事项。⭐⭐
15. **与股权投资业务相关的必备内容（四项）**：**合伙期限、托管事项、管理方式和管理费、利润分配及亏损分担**。⭐⭐
16. **合伙协议不包含**：**拟投资项目列表**（项目具有不确定性，难以事先精确列明）。⭐⭐
17. **出资信息**：出资方式、出资数额、缴付期限。**出资比例不属于**直接的出资信息（由出资情况计算得出）。⭐
18. **协议未约定或约定不明的处理**：由**全体合伙人协商**决定（不是仅普通合伙人、仅有限合伙人或部分合伙人）。⭐⭐
19. **有限合伙人的权利边界**：**没有执行合伙事务权**；独立审计权、知情权、监督权是有的。⭐⭐

### 收益分配

20. **公司型基金**：**先税后分**——先缴公司所得税，再按公司章程利润分配条款分配；分配时间安排**灵活性较低**。⭐⭐
21. **合伙型基金**：**先分后税**。⭐⭐
22. **契约型基金的灵活性**：收益分配原则灵活性**较大**（依基金合同约定）。⭐⭐
23. **合伙型收益分配的四步顺序**：按合伙协议约定 → 未约定或不明则合伙人协商 → 协商不成按**实缴出资比例** → 无法确定出资比例则**平均分配**。⭐⭐
24. **有限责任公司型的利润分配**：按股东**实缴的出资比例**分配；股份有限公司按**持有的股份比例**分配。⭐
25. **收益分配是核心约定内容**：收益分配是投资者和基金管理人需要约定的**关键内容**。⭐

### 税务处理（本章最密集的失分区）

26. **合伙企业的纳税义务人**：从所得税层面看，**以每一个合伙人为纳税义务人**。若合伙人为合伙企业，应继续分至最终合伙人纳税。⭐⭐
27. **合伙人的税种**：合伙人为**自然人** → 缴纳**个人所得税**；为**法人和其他组织** → 缴纳**企业所得税**。⭐
28. **自然人有限合伙人的税率**：两类收入（股息红利、股权转让所得）均按"生产、经营所得"，适用**5%~35%** 的超额累进税率。⭐⭐
29. **合伙企业生产经营所得的计算**：每一纳税年度**收入总额 − 成本 − 费用 − 损失**后的余额。⭐⭐
30. **合伙企业所得的涵盖范围**：包括合伙企业**分配给所有合伙人**的所得 + 企业**当年留存**的所得（利润）。⭐
31. **代扣代缴主体**：实务中由**基金**代扣代缴自然人投资者的个人所得税。⭐⭐
32. **公司型基金的税收规则**：**先税后分**。⭐⭐
33. **企业所得税的一般税率**：**25%**（10%、15%、20% 属优惠税率）。⭐⭐
34. **自然人投资者的股息红利所得税率**：**20%**。⭐⭐
35. **公司型基金的双重征税对象**：**自然人投资者**（公司层面缴企业所得税，个人层面再缴个税）。法人/企业投资者取得的股息红利等权益性投资收益通常**免税**。⭐⭐
36. **免税收入**：符合条件的**居民企业之间**的**股息、红利等权益性投资收益**为免税收入。⭐
37. **应纳税所得额的计算**：收入总额 − **不征税收入** − **免税收入** − **各项扣除** − **允许弥补的以前年度亏损**。⭐⭐
38. **公司的收入总额**：销售货物收入、提供劳务收入、转让财产收入、股息红利等权益性投资收益、利息收入等。⭐
39. **创业投资的税收优惠**：采取股权投资方式投资于**未上市中小高新技术企业2年以上**的，可按投资额的**70%** 在股权持有满2年的当年抵扣应纳税所得额。⭐⭐
40. **增值税征税范围（三类退出方式的辨析）** ⭐⭐：
    - 项目**股息、分红**收入 → **不属于**（税后利润分配）
    - **上市后通过二级市场**退出 → **属于**（金融商品转让，缴增值税）
    - 通过**并购或回购等非上市股权转让**方式退出 → **不属于**

### 其他

41. **股权投资基金的特点**：**资金规模较大、投资周期较长**。⭐
42. **资金来源**：各类**机构投资者**和**高净值个人客户**。⭐
43. **承诺资本制**：股权投资基金通常采用**承诺资本制**（投资者承诺出资额，需要时再实缴）。⭐⭐
44. **监管机构的历史变迁**：早期由**国家发展改革委**监管 → 现在由**中国证监会**监管。⭐⭐
45. **2007年6月1日《合伙企业法》（修订）**：增加了**有限合伙**这种新形式，更好适应股权投资基金运作。⭐⭐
46. **信托制度的法规配套**：《信托法》+ 2007年3月1日《**信托公司集合资金信托计划管理办法**》+ 后续股权投资信托业务操作指引，规定信托公司可运用**债权、股权、物权及其他可行方式**运用信托资金。⭐
47. **契约型基金合同的订立原则**：平等自愿、诚实信用、公平。**"收益最大化"不是**订立原则。⭐
48. **契约型基金合同的必备内容**：基金的募集、基金的投资、当事人及权利义务、基金的费用与税收。⭐
49. **信托制度与股权投资业务的结合度**：随法规完善**逐步提高**。⭐

## 易混易错

**两组募集分类不可交叉**

1. 按**募集主体机构** = 自行募集 / 委托募集。
2. 按**募集对象** = 公开募集 / 非公开募集。
3. 易错点：题目问"从募集主体机构角度看"，选项里给"公开募集、非公开募集"即为干扰项；反之亦然。
4. 委托募集的受托方必须**同时**具备：中国证监会基金销售业务资格 **+** 中国证券投资基金业协会会员。仅"已登记的基金管理人"不等于有销售资格。

**人数上限对照（最易混的四个数字）**

5. 有限责任公司型 = **50**；股份有限公司型 = **200**（且发起人2个以上、1/2以上境内有住所）。
6. 有限合伙型 = **2~50**（至少1个普通合伙人）；契约型 = **200**。
7. 单个资产管理计划 = **200**，但单笔委托 **300万元**以上不受限。
8. 判定公开/非公开：有限责任公司型和有限合伙型超**50**人、股份有限公司型和契约型超**200**人，即超出非公开募集的人数限制。

**"先税后分" vs "先分后税"（方向题，错一个字就全错）**

9. **公司型 = 先税后分**（先缴企业所得税，再按章程分配）。
10. **合伙型 = 先分后税**（先分至合伙人，再由合伙人各自纳税）。
11. 契约型**不是**企业所得税纳税主体，仅投资者就收益缴税，避免双重纳税。
12. 易错点：合伙企业"先税后分"是错误表述（高频错误项）；公司型"先分后税"同样错误。

**税率与税种**

13. 企业所得税一般税率 **25%**；自然人股息红利所得税率 **20%**；自然人有限合伙人按"生产、经营所得"适用 **5%~35%** 超额累进。
14. 双重征税只针对公司型基金的**自然人投资者**；法人/企业投资者的股息红利属**免税收入**。
15. 代扣代缴主体 = **基金**（不是管理人、托管人或普通合伙人）。

**增值税范围的三分法**

16. **征**：上市后通过**二级市场**退出（金融商品转让）。
17. **不征**：项目股息、分红收入；通过并购或回购等**非上市**股权转让方式退出。
18. 记忆锚点：只有"二级市场卖出"才是金融商品转让。

**合同必备条款的正反**

19. 合伙协议**法定应载明**：名称与经营场所、合伙目的与经营范围、合伙人姓名/名称与住所、出资方式/数额/缴付期限、利润分配与亏损分担、合伙事务执行、入伙退伙、争议解决、解散清算、违约责任。
20. 合伙协议**不包含**：盈利目标、拟投资项目列表、出资比例（后者是计算结果而非出资信息）。
21. 与股权投资业务相关的四项必备：合伙期限、托管事项、管理方式和管理费、利润分配及亏损分担。
22. 《公司法》不再强制：注册资本限额、缴付安排、出资方式。**投资者限制不在其中**（高频干扰项）。

**治理结构三型对照**

23. 公司型 → **股东至上**，权力机构是**股东大会（股东会）**。
24. 有限合伙型 → **普通合伙人**掌握事务执行权，有限合伙人**无**执行合伙事务权。
25. 契约型 → **基金管理人**高度控制决策权。
26. 易错点：把"董事会/股东大会"套到合伙型或契约型上（那是公司制专属机构）。

**募集流程的时点归属**

27. 顺序 = 募集筹备期 → 基金路演期 → 投资者确认 → 协议签署及出资。
28. **PPM 在筹备期撰写**（写成"路演期撰写"即错）。
29. 路演期 = 准备推介资料 + 分发 PPM；投资者确认 = 鉴别投资者 + 预谈判条款；签署阶段 = 确定结束日 + 签合同 + 履行出资。
30. 募集资料 = PPM + 推介资料 + （反向）尽职调查资料；**收益分析报告不是**（不得承诺收益）。
31. 推介资料保证**真实、完整、准确**；"及时性"是干扰项。

**募集对象的国别差异**

32. 国外有：养老基金（公司养老+公共养老）、母基金、大学基金会、富有的个人或家族。
33. 国内有：政府引导基金、母基金、社会保障金。
34. 交叉陷阱：**政府引导基金**是**国内**特色（国外不常见）；**大学基金会**是**国外**常见（国内尚不成熟）。
35. 合格投资者三要素 = 风险识别与承担能力 + 资产规模或收入水平 + 认购金额；**信用记录不在其中**。
36. 合格投资者门槛：单只基金 **100万元**；单位净资产 **1000万元**；个人金融资产 **300万元** 或近三年年均收入 **50万元**。
