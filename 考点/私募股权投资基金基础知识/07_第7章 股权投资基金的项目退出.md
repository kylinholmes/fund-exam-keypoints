# 私募股权投资基金基础知识 · 第7章 股权投资基金的项目退出

本章考点覆盖四种退出方式（上市转让/挂牌转让/协议转让/清算）的收益、效率与风险对比，境内 IPO 四步流程与境外上市的「四五六条款」，新三板（全国股转系统）挂牌条件与交易机制，协议转让中的并购与回购，以及清算退出的两类方式与法定程序。本章数字密集（年限、金额、比例、时点），是**记忆型失分重灾区**。

题量：78题（第1节 项目退出概述 7题，第2节 上市转让退出 28题，第3节 挂牌转让退出 18题，第4节 协议转让退出 13题，第5节 清算退出 12题）。

## 第1节 项目退出概述

1. **项目退出的定义**：选择合适的时机，将在被投资企业的股权变现，由**股权形态**转化为具有流动性的**现金收益**，以实现资本增值或及时避免和降低损失。⭐⭐
2. **项目退出的地位**：**实现项目退出**是整个投资的**关键环节**。⭐⭐
3. **退出的四个步骤顺序**：评估不同退出路径的收益 → 设计退出方案 → 退出启动前的准备 → 交易结算及退出后的评估与评价。⭐⭐
4. **收益对比**：**上市转让退出**的收益一般比挂牌转让退出和协议转让退出**高**。⭐⭐
5. **效率对比**：上市成功后一般有**相当期限的限售期**，实现最终退出**耗时较长**；场外股权交易市场挂牌一般实行**注册制**，所需时间相对较短。⭐⭐
6. **清算耗时**：受**债权公告、资产处置**等环节影响，不同企业清算所花时间**大体不同**（说"大体相同"即错）。⭐⭐

### 四种退出方式的风险（正反对照）

7. **上市转让退出的风险**：企业上市申请能否获得**核准**存在相当大的不确定性。⭐
8. **挂牌退出的风险**：挂牌后一段时间内**无人受让**，或价格被**低估**（不是"高估"）。⭐⭐
9. **协议转让退出的风险**：由**信息不对称**所引起的价格不能充分反映被投资企业实际价值的不确定性。⭐⭐
10. **清算退出的风险**：部分流动性较差的资产可能不得不以**极低价格**转让，甚至短期内**无法变现**。⭐
11. **协议转让退出的两种形式**：**并购退出**、**回购退出**（这是未上市企业股权非公开协议转让的两种方式）。⭐⭐

## 第2节 上市转让退出

### 上市的基本概念

1. **IPO 的定义**：被投资企业经营达到理想状态时，股权投资基金通过企业上市将其股份转变成可在公开市场流通的股票，通过公开市场转让实现退出和资本增值。⭐
2. **间接上市的方式**：**借壳上市**（通过收购已上市壳公司实现间接上市）。首发上市、改制上市、申报上市均属**直接上市**。⭐⭐
3. **境内 vs 境外股票**：**A股**在境内（沪深交易所）发行上市；**H股**在香港、**N股**在纽约、**S股**在新加坡——后三者属**境外**上市。⭐⭐
4. **我国企业境外 IPO 的主要市场**：**香港证券交易所、美国纳斯达克、纽约证券交易所**。**东京证券交易所不是**主要市场。⭐⭐

### 境外直接上市的「四五六条款」

5. **四项要求**：⭐⭐
   - **净资产不少于 4 亿元人民币**
   - 过去一年**税后利润不少于 6000 万元人民币**（不是 5000 万），并有增长潜力
   - 按合理市盈率预期，**筹资额不少于 5000 万美元**
   - 具有**规范的法人治理结构及较完善的内部管理制度**
6. **筹资用途要求**：符合**国家产业政策、利用外资政策及国家有关固定资产投资立项**的规定。⭐
7. **不属于**上述特定财务要求："有较稳定的主营业务收入来源"。⭐
8. **境外直接上市的含义**：企业直接以**国内股份有限公司**名义向国外证券主管机构申请发行股票，向当地**证券交易所**申请上市（不是向证监会、工商局申请）。⭐⭐
9. **境外上市的四步流程**：**策划上市方案 → 准备相关文件 → 上市申报 → 公开发行及交易**。⭐⭐
10. **不属于**境外上市流程：**准备协议转让文件**（那是国内股东间股份转让的情形）。⭐

### 境内 IPO 流程与交易机制

11. **境内首次公开发行上市的四步流程**：**改制 → 辅导 → 申报审核 → 股票发行及上市**。⭐⭐
12. **不属于**境内 IPO 流程：**策划上市方案**（那是境外上市的环节）。⭐⭐
13. **上市辅导的规定**：拟公开发行股票的股份有限公司在**向中国证监会提出股票发行申请前**，须由具有**主承销资格的证券公司**进行辅导。⭐⭐
14. **辅导阶段中介机构的作用**：帮助企业**完善公司治理结构**、明确**业务发展目标和募集资金使用计划**、**准备首次公开发行申请文件**。**刊登招股说明书及发行公告属发行阶段**，不是辅导阶段。⭐⭐
15. **招股说明书的预先披露**：申请文件受理后、发行审核委员会审核前，发行人应将招股说明书（申报稿）在**中国证监会网站**预先披露。⭐⭐
16. **涨跌幅限制**：一般股票（含 A、B 股）**10%**；**ST 和 *ST 股票 5%**。⭐⭐
17. **竞价交易制度的两种方式**：**集合竞价**、**连续竞价**。⭐
18. **集合竞价的定义**：对**一段时间内**接受的买卖申报**一次性撮合**的竞价方式。⭐⭐
19. **开市价格的形成**：证券交易所每个交易日的**开市价格**一般由**集合竞价**形成。⭐⭐
20. **连续竞价的定义**：按**时间优先、价格优先**原则**逐笔连续**撮合。⭐
21. **我国二级股票市场的四种交易机制**：竞价交易、大宗交易、要约收购、协议转让。⭐⭐
22. **要约收购的定义**：收购人向**所有股票持有人**发出购买上市公司股份的收购要约。⭐
23. **要约收购的触发比例**：收购人持有一个上市公司股份达到已发行股份的 **30%** 时，继续增持应采取要约方式。⭐⭐
24. **协议转让的分类**：⭐⭐
    - 按**转让股份类型**：流通股协议转让 / 非流通股协议转让
    - 按**转让主体类型**：国有股协议转让 / 非国有股协议转让
    - 按**转让情形**：协议收购、对价偿还、股份回购等
25. **大宗交易的特点**：低成本（经手费低于集中竞价）、定价灵活（可协议议价）、不对竞价交易价格形成巨大冲击。**易错点**：各交易所大宗交易经手费**下浮比例并不一致**，并非经证监会统一备案而保持一致。⭐⭐

## 第3节 挂牌转让退出

### 全国股转系统（新三板）

1. **新三板的正式名称**：**全国中小企业股份转让系统**。⭐⭐
2. **法律地位**：经国务院批准设立的**公司制全国性证券交易场所**，运营管理机构为全国中小企业股份转让系统有限责任公司。⭐⭐
3. **我国第三家全国性证券交易所**：**全国中小企业股份转让系统**（前两家为上交所、深交所）。⭐⭐
4. **挂牌的核心条件**：依法设立且**存续满 2 年**（不是 3 年）；业务明确、具有持续经营能力；公司治理机制健全、合法规范经营；股权明晰、股票发行和转让行为合法合规。⭐⭐
5. **股东所有制限制**：**无限制**，民营、国有、外资均可；**不要求**必须是高新技术企业。⭐⭐
6. **服务定位**：主要为**创新型、创业型、成长型中小微企业**发展服务。⭐⭐

### 场外市场的结构

7. **我国主要的场外交易市场**：**全国性股权交易市场**（全国股转系统/新三板）+ **区域性股权交易市场**。⭐⭐
8. **区域性股权交易市场的定位**：为**市场所在地省级行政区域内**的企业特别是中小微企业提供**股权、债权**的转让和融资服务的场外交易市场。⭐⭐
9. **功能归属的易错点**："鼓励科技创新和激活民间资本，加强对实体经济薄弱环节的支持"更贴合**区域性股权交易市场**，而非全国股转系统。⭐⭐

### 挂牌流程与交易机制

10. **挂牌的四个阶段**：**决策改制 → 材料制作 → 反馈审核 → 登记挂牌**。⭐⭐
11. **决策改制阶段的工作**：选聘中介机构、配合尽职调查、选定改制基准日、**整体变更为股份公司**。⭐⭐
12. **材料制作阶段**：制作挂牌申请文件（不属于决策改制阶段）。⭐
13. **反馈审核阶段的工作**：配合全国股转系统审核、对审核意见进行反馈。**"分配股票代码"不属于**该阶段（属后续挂牌阶段）。⭐⭐
14. **需复核的文件**：**《资产评估报告》《审计报告》《法律意见书》**。**《股份报价转让说明书》不属于**这一阶段的复核范围。⭐⭐
15. **新三板的交易机制**：**协议转让**、**做市转让**。**大宗交易不属于**新三板交易机制。⭐⭐
16. **协议转让的两种委托方式**：**定价委托**、**成交确认委托**。⭐⭐
17. **协议转让的三种成交方式**：**点击成交**、**互报成交确认申报**、**收盘自动匹配成交**。**"定价委托成交"不是**成交方式（定价委托是**申报**方式）。⭐⭐
18. **互报成交确认申报**：**老股东常用**方式，双方约定价格、数量和约定号，统一提交到股转中心完成交易。⭐⭐
19. **收盘自动匹配成交**：在每个收盘日 **15:00** 将盘中价格相同、交易方向相反的交易对手自动撮合。⭐⭐
20. **做市转让的特点**：为挂牌公司提供相对专业和公允的**估值服务和报价服务**；为引入外部投资者、申请银行贷款、股权质押融资等提供**定价参考**。⭐⭐

## 第4节 协议转让退出

### 并购退出与回购退出

1. **非公开协议转让退出的两种方式**：**并购退出**、**回购退出**。⭐⭐
2. **并购退出的定义**：股权投资基金向目标公司投资后，**其他收购方**购买基金所持目标公司的全部或部分股权，使基金实现退出。⭐⭐
3. **股权回购的三种类型**：**控股股东回购**、**管理层回购**、**员工收购**。⭐⭐
4. **不属于股权回购的类型**：**外部人员收购**、**实际控制人回购**、**央行回购**（央行是宏观调控机构，不参与企业股权回购）。⭐⭐
5. **并购退出的程序**：双方协商达成初步意向 → 受让方对目标公司进行**尽职调查** → 双方谈判并签署**股权转让协议** → 部分情形需**政府主管部门批准**。⭐⭐
6. **尽职调查的主体**：由**受让方**完成（不是转让方）。⭐⭐
7. **第三方机构的参与**：交易流程中**通常会有**律师事务所、会计师事务所等第三方机构参与（"因涉及商业机密不能有第三方参与"是错误表述）。⭐⭐
8. **不属于并购退出程序**：向**证券登记结算机构**申请公司变更登记（公司变更登记应向**工商行政管理部门**申请）。⭐⭐

### 有限责任公司的股权转让规则

9. **外部转让**：现有股东向**股东以外的人**转让股权，**需征得其他股东过半数同意**（除公司章程另有约定），且其他股东享有**优先购买权**。⭐⭐
10. **内部转让**：现有股东**之间**相互转让股权，**无需**经转让双方之外的其他股东同意。⭐⭐
11. **转让完成后的手续**：目标公司应向受让方签发**出资证明书**，并相应**修改公司章程和股东名册**。⭐⭐
12. **非上市股份有限公司**：我国《公司法》对其股份转让**没有特殊规定**（与上市公司有别）。⭐

### 股权回购的程序

13. **股权回购的四个环节**：**发起 → 协商 → 执行 → 变更登记**。⭐⭐
14. **发起环节**：出让方与受让方对可行性进行评估、达成初步意向，回购才正式发起。⭐
15. **协商环节的关键**：**定价与融资**；阶段成果是签订**《股权转让协议》**。⭐⭐
16. **执行环节**：**并非所有**股权回购交易都需经政府主管部门批准（"所有都需批准"是错误表述）。⭐⭐
17. **变更登记环节**：股东发生变化应依《公司登记管理条例》在**工商行政管理部门**办理变更登记。**若涉及修改公司章程，应向公司登记机关（不是基金业协会）提交**。⭐⭐

## 第5节 清算退出

### 两类清算

1. **清算退出的两种方式**：**破产清算**、**解散清算**。**账面价值清算、重置全价清算不是**清算分类。⭐⭐
2. **清算退出的性质**：主要是**投资项目失败后**的一种退出方式（不是项目成功的退出方式）。⭐⭐
3. **解散清算的情形（四项）**：⭐⭐
   - 公司章程规定的**营业期限届满**或章程规定的其他解散事由出现
   - **股东会或股东大会决议解散**
   - 公司依法被**吊销营业执照、责令关闭或者被撤销**
   - 公司经营管理发生严重困难，继续存续会使股东利益受重大损失，通过其他途径不能解决时，持有公司**全部股东表决权 10% 以上**的股东请求法院解散公司并获得法院支持（**不是 3%**）

### 清算流程

4. **清算退出的流程（三项）**：**清查公司财产、制订清算方案**；**了结公司债权债务、处理未了结业务**；**分配公司剩余财产**。⭐⭐
5. **不属于**清算流程：**办理变更登记**（属正常经营中的信息变更）；**开展新的经营活动**（与清算目的相悖，清算期间**不得**开展新经营活动）。⭐⭐
6. **清算方案的制订时点**：编制公司**财务会计报告**之后，清算组应当制订清算方案。⭐⭐
7. **清算方案的通过**：提出收取债权和清偿债务的具体安排，提交**股东大会**通过或报主管机关确认。⭐⭐
8. **财产不足清偿债务的处理**：清算组有责任向**有管辖权的人民法院**申请宣告**破产**（不是向政府主管部门）。⭐⭐
9. **破产宣告后的接管**：人民法院裁定宣告公司破产后，由**破产管理人**接管清算事务，**清算组不再继续推进**。⭐⭐

### 清算组的组成与清偿顺序

10. **清算组的组成**：**有限责任公司**由**股东**组成；**股份有限公司**由**董事**或者**股东大会确定的人员**组成。⭐⭐
11. **清算组的职责**：催告债权人申报债权、**调查和清理公司财产**（主要由清算组进行）。⭐
12. **未到期债权的处理**：清算组可要求**到期清偿**，但**不是强制提前清偿**。⭐⭐
13. **清偿顺序**：**先清偿全部公司债务**，财产还有剩余的，才能将剩余财产分配给包括股权投资基金在内的**股东**。⭐⭐

## 易混易错

**四种退出方式的收益 / 效率 / 风险对照**

1. **收益**：上市转让 > 挂牌转让、协议转让。
2. **效率**：上市成功后有限售期，最终退出**耗时较长**；场外挂牌实行**注册制**，时间相对**较短**。
3. **风险**：上市→**能否核准不确定**；挂牌→**无人受让或价格被低估**；协议转让→**信息不对称致价格失真**；清算→**资产低价转让或无法变现**。
4. 易错点：挂牌风险写成"价格被**高估**"（应为**低估**）；清算耗时写成"大体**相同**"（应为**不同**）。

**境内 vs 境外上市的流程（易互换）**

5. **境内 IPO**：改制 → 辅导 → 申报审核 → 股票发行及上市（**没有**"策划上市方案"）。
6. **境外上市**：策划上市方案 → 准备相关文件 → 上市申报 → 公开发行及交易（**没有**"准备协议转让文件"）。
7. 辅导：在**向证监会提出申请前**，由**具有主承销资格的证券公司**辅导。
8. 招股说明书（申报稿）预先披露在**中国证监会网站**。
9. 辅导阶段**不含**刊登招股说明书及发行公告（那是**发行阶段**的工作）。

**境外上市「四五六条款」的数字（最易错的两个）**

10. 净资产 ≥ **4 亿元**人民币；过去一年税后利润 ≥ **6000 万元**人民币（**不是 5000 万**）；筹资额 ≥ **5000 万美元**。
11. 记忆锚点："四五六"对应 4 亿净资产、6000 万利润、5000 万美元筹资——注意利润是**6000 万**，与筹资的 5000 万**美元**不同单位。
12. 境外直接上市向**当地证券交易所**申请（不是证监会/工商局）。

**股票代码与市场归属**

13. **A股**=境内（沪深）；**H股**=香港；**N股**=纽约；**S股**=新加坡。
14. 境外 IPO 主要市场 = 香港 + 纳斯达克 + 纽交所；**东京不是**。
15. **涨跌幅**：一般股票 **10%**；ST/*ST **5%**。
16. **要约收购触发线 = 30%**。

**新三板的三组易混点**

17. **挂牌条件**：存续满 **2 年**（不是 3 年）；股东所有制**无限制**（民营/国有/外资均可）；**不要求**高新技术企业。
18. **交易机制**：协议转让 + 做市转让；**大宗交易不属于**新三板。
19. **协议转让的"委托方式" vs "成交方式"**（最高频混淆）：
    - 委托方式（2种）：**定价委托**、成交确认委托
    - 成交方式（3种）：**点击成交**、互报成交确认申报、收盘自动匹配成交
    - 易错点：把"**定价委托**"当成成交方式（它其实是**申报**方式）。
20. **收盘自动匹配成交**时点 = **15:00**；**互报成交确认申报** = **老股东常用**。
21. 挂牌四阶段：决策改制 → 材料制作 → 反馈审核 → 登记挂牌。
22. 决策改制 = 选聘中介 + 尽调 + 选基准日 + 整体变更为股份公司；材料制作 = 制作挂牌申请文件。
23. 反馈审核阶段**不含**"分配股票代码"。
24. 复核文件 = 资产评估报告 + 审计报告 + 法律意见书；**股份报价转让说明书不属于**。
25. 场外市场 = **全国性**股权交易市场 + **区域性**股权交易市场；后者服务**省级行政区域内**中小微企业。
26. 功能归属陷阱："鼓励科技创新、激活民间资本、支持实体经济薄弱环节"→ **区域性**股权交易市场。

**协议转让与回购**

27. 非公开协议转让退出 = **并购退出 + 回购退出**。
28. 回购三类型 = 控股股东回购 + 管理层回购 + 员工收购；**外部人员收购、实际控制人回购、央行回购均不是**。
29. 有限责任公司：**外部转让**需**其他股东过半数**同意（不是 1/3）；**内部转让**无需他人同意。
30. 尽调由**受让方**做；第三方机构**可以**参与（商业机密不是排除理由）。
31. 并购退出**不含**"向证券登记结算机构申请变更登记"（应向**工商部门**）。
32. 回购四环节 = 发起 → 协商 → 执行 → 变更登记；协商关键 = **定价与融资**。
33. **并非所有**回购都需政府批准；章程修改向**公司登记机关**提交（不是基金业协会）。

**清算**

34. 两类清算 = **破产清算 + 解散清算**（账面价值清算、重置全价清算是干扰项）。
35. 清算退出 = **项目失败**时的退出方式（说"项目成功"即错）。
36. 清算流程 = 清查财产订方案 → 了结债权债务处理未了结业务 → 分配剩余财产；**不含**办理变更登记、开展新经营活动。
37. 清算期间**不得**开展新的经营活动。
38. 法院解散公司的请求权门槛 = **10% 以上**表决权（不是 3%）。
39. 清算方案在编制**财务会计报告**之后制订，提交**股东大会**通过。
40. 财产不足清偿债务 → 向**有管辖权的人民法院**申请破产（不是政府主管部门）。
41. 破产宣告后由**破产管理人**接管，清算组**退出**。
42. 清算组：有限责任公司 = **股东**；股份有限公司 = **董事**或股东大会确定的人员。
43. 未到期债权可要求**到期清偿**，**不可强制提前清偿**。
44. 清偿顺序：**先还清全部债务**，有剩余才分配给股东。
