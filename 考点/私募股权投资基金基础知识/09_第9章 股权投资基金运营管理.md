# 私募股权投资基金基础知识 · 第9章 股权投资基金运营管理

本章考点覆盖权益登记（增减资表决比例、各类变更登记事项、登记时限）、托管（是否强制、家数、原则、账户体系）、估值核算与业绩评价（三类倍数指标、估值原则、报送时限）、税收（增值税应税行为与纳税人、所得税主体、优惠税率）、收益分配（瀑布式与单一项目、回拨机制、资本账户调整）、投资者退出与清算、信息披露与报送、争议解决。本章**数字与时限最密集**（15日/30日/45日/6个月/7年/3年/2/3），是全书最后的失分集中区。

题量：54题（第1节 权益登记 11题，第2节 托管 6题，第3节 估值核算与业绩评价 11题，第4节 税收 7题，第5节 收益分配与账面分摊 6题，第6节 投资者退出与清算 6题，第7节 信息披露与报送 6题，第8节 争议解决 1题）。

## 第1节 股权投资基金权益登记

### 表决比例与人数

1. **增资/减资决议的表决比例**：**有限责任公司型**须经代表 **2/3 以上**表决权的股东通过；**股份有限公司型**须经出席股东会的股东所持表决权的 **2/3 以上**通过。⭐⭐
2. **股份有限公司型基金的发起人人数**：**1 人以上 200 人以下**（且半数以上发起人在中国境内有住所）。⭐⭐
3. **合伙型基金的合伙人数量**：**2 个以上 50 个以下**（有限合伙企业至少 1 个普通合伙人）。⭐⭐
4. **新合伙人入伙的表决要求**：除合伙协议另有约定外，需经**全体合伙人一致同意**（体现人合性）。⭐⭐
5. **新合伙人与原有合伙人的权益责任**：除合伙协议另有约定外，**权益相同、责任相同**。⭐⭐

### 变更登记的事项范围

6. **合伙型基金的变更登记事项**：**入伙/增加出资**、**退伙/减少出资**、**财产份额转让**。**"股份转让"不属于**（"股份"是股份有限公司概念，合伙型无"股份"）。⭐⭐
7. **契约型基金的变更登记事项**：**申购**、**赎回**、**基金份额转让**。**"基金管理人变更"不属于**变更登记范围（属重大实质性变更）。⭐⭐

### 登记时限（数字必背）

8. **公司董事组成清算组的时限**：解散事由出现之日起 **15 日**内。⭐⭐
9. **股份有限公司型基金的设立登记**：公司成立大会结束后 **30 日**内向公司登记机关申请设立登记。⭐⭐
10. **公司型基金增资的登记**：自作出增资决定之日起 **30 日**内申请变更登记。⭐⭐
11. **公司型基金减资的登记**：通知债权人并公告，自**公告之日起 45 日**后申请变更登记。⭐⭐

## 第2节 股权投资基金托管

1. **是否强制托管**：股权投资基金**未强制要求**托管；**全体投资者和管理人可约定不托管**（管理人**不能单方面**决定不托管）。⭐⭐
2. **托管人的家数**：**不得超过 1 家**。⭐⭐
3. **基金托管的作用（四项）**：有利于形成更**平衡的基金治理结构**；保障**基金财产安全**；**监督**管理人的投资运作；增加基金运作的**透明度**。⭐⭐
4. **基金托管的基本原则**：**合规性原则、安全性原则、独立性原则**。**"公开性原则"不是**托管原则。⭐⭐
5. **现金类资产的构成**：**货币市场工具、银行存款、理财产品**。**上市公司股票不属于**现金类资产。⭐⭐
6. **基金财产独立的目的**：确保**单只基金财产的完整与独立**（防止不同基金财产相互混淆干扰）。⭐⭐

### 账户体系

7. **基本存款账户**：每只基金只能开立 **1 个**。⭐⭐
8. **托管账户的开立与保管主体**：由**托管人**开立并保管（不是管理人）。⭐⭐
9. **募集账户 vs 托管账户**：募集期间投资者资金**先划入募集账户**，不是托管账户。⭐⭐
10. **投资款项划转流程**：需**管理人指令**，**托管人复核**。⭐⭐
11. **托管账户的地位**：基金资产的保管账户，**所有基金资产货币收支活动均需通过该账户进行**。⭐⭐

## 第3节 股权投资基金的估值核算与业绩评价

### 估值

1. **估值针对的期间**：**基金存续期间**（不是仅销售期间、成立时或清算时）。⭐⭐
2. **存在活跃市场且有报价的处理**：估值日有报价且**无减持限制**时，应将估值日报价**不加调整地应用**。⭐⭐
3. **估值的合理性原则**：依据投资项目的**核心价值决定因素、行业惯例**等选择估值方法。⭐⭐
4. **会计核算基础**：**权责发生制**——所有收入和费用在其**实际发生时**确认。⭐⭐
5. **基金收入的构成**：投资项目期间产生的**已实现投资收益** + **未实现公允价值变动损益**。⭐⭐

### 业绩评价指标

6. **股权基金业绩评价的三个主要指标**：**内部收益率（IRR）**、**已分配倍数（DPI）**、**总收益倍数（TVPI）**。**"市净率倍数"不是**（那是股票估值指标）。⭐⭐

### 费用与报送

7. **管理费的性质**：管理人因**投资管理基金资产**而向基金收取的费用。销售基金产品对应**销售费用**；保管基金资产是**托管人**职责，对应**托管费**。⭐⭐
8. **年度财务报告的报送时限**：每个会计年度结束之日起 **6 个月**内，向**中国证券投资基金业协会**报送经会计师事务所审计的年度财务报告。⭐⭐

### 《创业投资企业管理暂行办法》要点

9. **创业投资的界定**：对各类处于**创建或重建过程中**的未上市成长性企业的投资，均可归入创业投资。⭐⭐
10. **存续期限**：创业投资企业存续期限**最短不得短于 7 年**。⭐⭐
11. **管理方式**：以公司形式设立的创业投资企业**可以委托**其他创业投资企业、创业投资管理顾问企业作为管理顾问机构负责投资管理业务（**并非必须自行负责**）。⭐⭐
12. **法律关系**：创业投资企业与管理人之间是**委托管理关系**，**不是债权债务关系**。⭐⭐

## 第4节 股权投资基金的税收

### 所得税

1. **公司型创业投资企业的优惠**：转让持有 **3 年以上**股权的所得占年度股权转让所得总额比例**超过 50%** 时，可按**年末个人股东持股比例减半**征收当年企业所得税。⭐⭐
2. **所得税纳税主体的判定**：**居民个人投资者**应缴纳个人所得税；**个人独资企业、合伙型基金、契约型基金均不是**企业所得税纳税主体。⭐⭐
3. **小型微利企业的优惠税率**：减按 **20%** 征收企业所得税。⭐⭐

### 增值税

4. **可能涉及的增值税应税行为**：**固定收益投资**（利息等收益）和**金融商品转让**。单纯权益投资、单纯金融商品持有通常不涉及。⭐⭐
5. **资管产品运营中的增值税纳税人**：**资管产品管理人**（不是托管人、委托人或投资者）。⭐⭐
6. **基金管理人的计税方法**：作为**一般纳税人**时适用**一般计税方法**（简易计税方法有特定适用范围）。⭐⭐
7. **不属于基金及其投资者应税收入的项**：**管理费收入**（那是管理人为基金提供管理服务的收入）。⭐

## 第5节 股权投资基金的收益分配与账面分摊

### 分配方式

1. **瀑布式收益分配的顺序**：项目投资退出资金**先返还至基金投资者**（保障本金），之后才涉及门槛收益、业绩报酬。⭐⭐
2. **股权投资基金通常采用的分配方式**：按**基金整体收益**分配。⭐⭐
3. **单一项目收益分配 vs 基金整体分配**：单一项目方式下管理人获取业绩报酬**更提前**（整体方式需等基金清算统一分配，相对滞后）。⭐⭐
4. **单一项目分配的保护机制**：通常需设置**收益回拨机制**（前期分配不合理时，将已分配给管理人的部分业绩报酬返还基金资产）。⭐⭐
5. **管理人的业绩报酬权利**：管理人可在**特定项目退出收益**中，**符合约定条件时**收取业绩报酬。⭐⭐

### 资本账户调整

6. **资本账户的增项**：**投资者新增实缴出资额**。⭐⭐
7. **资本账户的减项**：分配给投资者的**现金**、投资者的**亏损分摊**、投资者应分摊的**基金费用**。⭐⭐

## 第6节 投资者退出与股权投资基金的清算

1. **投资者退出的含义**：收回对基金的投资并退出基金。⭐
2. **份额转让受让方的额外要求**：除符合**合格投资者**条件外，还需履行**投资者适当性管理**相关程序。⭐⭐
3. **投资者主导（LP-led）交易的后续手续**：交易完成后需管理人配合办理**工商变更登记**手续（出资人变更需登记公示；不涉及基金清算、备案或税务注销）。⭐⭐
4. **非现金分配的分类**：按标的公司是否上市分为**上市公司股票分配**与**未上市公司股权分配**。⭐⭐
5. **上市公司股票实物分配的范围**：限于基金所持有的上市公司**首次公开发行前的股份**。⭐⭐
6. **基金清算的原因**：基金合同约定**存续期届满**；**全部投资项目实现清算退出且管理人决定不再重复投资**；法律法规规定的其他清算事由。**"部分投资者要求提前清算"不是**清算原因。⭐⭐

## 第7节 股权投资基金信息披露与信息报送

1. **信息披露的作用**：有利于投资者作出**理性判断**；防范**利益输送与利益冲突**；促进市场**长期稳定**。**"有利于提高基金收益"不是**（收益受投资策略、市场环境等复杂因素影响）。⭐⭐
2. **披露内容的原则（六项）**：**及时性、真实性、准确性、完整性、风险揭示、公平披露**。⭐⭐
3. **易得性原则**：要求采用比较**便捷的披露渠道和方式**向投资者披露。⭐⭐
4. **募集期间应披露的信息**：基金合同、基金托管协议、销售推介材料。**定期报告不属于**募集期披露内容（属运作期间）。⭐⭐
5. **基金的定期报告**：**季度报告**、**年度报告**。⭐
6. **非居民金融账户涉税信息的报送频率**：**每年**报送（依《非居民金融账户涉税信息尽职调查管理办法》，基金管理人属金融机构）。⭐⭐

## 第8节 股权投资基金争议解决

1. **诉讼的地位**：争议解决的**最后手段**（具有权威性和终局性，不是常规手段、唯一手段或前置手段）。⭐⭐

## 易混易错

**表决比例与人数（数字必背）**

1. 增资/减资：有限责任公司 **2/3 以上表决权**；股份有限公司 **出席股东会表决权 2/3 以上**（两者都是 2/3，不是 1/2 或 3/4）。
2. 股份有限公司型基金发起人 = **1 人以上 200 人以下**（允许一人发起，注意不是"2人以上"）。
3. 合伙型基金合伙人 = **2 个以上 50 个以下**。
4. 新合伙人入伙 = **全体合伙人一致同意**（除协议另有约定）。
5. 新合伙人与原合伙人 = **权益相同、责任相同**。

**变更登记事项的边界（最易错）**

6. 合伙型变更登记 = 入伙/增加出资、退伙/减少出资、财产份额转让；**"股份转让"不属于**（合伙型无"股份"）。
7. 契约型变更登记 = 申购、赎回、基金份额转让；**"基金管理人变更"不属于**（属重大实质性变更）。
8. 记忆锚点：合伙型讲"财产份额"，契约型讲"份额申赎"，**"股份"专属于股份有限公司**。

**登记时限（四个数字易混）**

9. 董事组成清算组 = **15 日**。
10. 股份有限公司设立登记 = 成立大会结束后 **30 日**。
11. 公司型增资登记 = 增资决定起 **30 日**。
12. 公司型减资登记 = 公告之日起 **45 日**后。
13. 记忆锚点：**15（清算组）→ 30（设立/增资）→ 45（减资，多一个公告期）**。

**托管的三组正反**

14. 是否强制：**未强制**；**全体投资者 + 管理人**可约定不托管；**管理人单方不能决定**不托管。
15. 托管人家数 = **1 家**（不能多家）。
16. 托管基本原则 = **合规性 + 安全性 + 独立性**；**"公开性"不是**托管原则（那属信息披露范畴）。
17. 现金类资产 = 货币市场工具 + 银行存款 + 理财产品；**上市公司股票不属于**。
18. 基金财产独立的目的 = 确保**单只基金财产的完整与独立**。

**账户体系（四问必分清）**

19. 基本存款账户：每只基金 **1 个**。
20. 托管账户：由**托管人**开立并保管（不是管理人）。
21. 募集期资金：先入**募集账户**（不是托管账户）。
22. 划款流程：**管理人指令 + 托管人复核**（不是托管人自行划付）。
23. 托管账户地位：**所有**基金资产货币收支均须通过它。

**业绩评价与估值**

24. 业绩评价三指标 = **IRR + DPI + TVPI**；**市净率倍数不是**（那是股票估值）。
25. 估值期间 = **基金存续期间**（不是仅某阶段）。
26. 有活跃市场报价且无减持限制 → **不加调整**直接应用估值日报价。
27. 选择估值方法依据核心价值因素与行业惯例 → **合理性原则**。
28. 收入与费用在实际发生时确认 → **权责发生制**。
29. 基金收入 = **已实现投资收益 + 未实现公允价值变动损益**。
30. 管理费 = 因**投资管理基金资产**收取；销售→销售费用；保管→托管费（三者不可串）。
31. 年度财务报告报送 = 会计年度结束后 **6 个月**内报**协会**。

**税收的正反**

32. 公司型创投优惠：持有 **3 年以上**股权所得占年度股权转让所得 **>50%** → 按年末个人股东持股比例**减半**征收。
33. 所得税纳税主体：**居民个人投资者**缴个税；**个人独资企业、合伙型基金、契约型基金都不是**企业所得税纳税主体。
34. 小型微利企业税率 = **20%**（不是 15%/25%）。
35. 增值税应税行为 = **固定收益投资 + 金融商品转让**；单纯权益投资、单纯持有不涉。
36. 资管产品增值税纳税人 = **管理人**（不是托管人/委托人/投资者）。
37. 一般纳税人 → **一般计税方法**。
38. **管理费收入不属于**基金及其投资者的应税收入。

**收益分配与资本账户**

39. 瀑布式顺序：**先返还投资者** → 再门槛收益 → 最后业绩报酬。
40. 通常按**基金整体收益**分配。
41. 单一项目分配：业绩报酬**更提前**；需配**收益回拨机制**。
42. 资本账户**增项** = 新增实缴出资额；**减项** = 分配现金、亏损分摊、分摊费用（其余三项全是减项，方向勿反）。

**退出、清算与披露**

43. 份额转让受让方：合格投资者 + **投资者适当性管理程序**。
44. LP-led 交易完成后办 **工商变更登记**（不是清算、备案或税务注销）。
45. 非现金分配 = 上市公司**股票**分配 + 未上市公司**股权**分配。
46. 上市公司股票实物分配限于**IPO 前股份**。
47. 清算原因**不含**"部分投资者要求提前清算"。
48. 信息披露作用**不含**"提高基金收益"。
49. 披露内容六原则：及时、真实、准确、完整、风险揭示、公平披露。
50. **易得性**原则 = 便捷的渠道和方式。
51. 募集期披露**不含**定期报告；定期报告 = **季度 + 年度**。
52. 非居民金融账户涉税信息 = **每年**报送。
53. 诉讼 = 争议解决的**最后手段**。
