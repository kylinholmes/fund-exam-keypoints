# 私募股权投资基金基础知识 · 第5章 股权投资基金的投资

本章考点覆盖投资一般流程的八环节、三类尽职调查（业务/财务/法律）的内容与作用、估值方法（相对估值法各倍数、折现现金流法、成本法、清算价值法）的适用情形与计算、投资协议关键条款（保护性/随售权/第一拒绝权/拖售权）及债权投资方式。本章是全书**计算题最集中**的一章，务必掌握 EBIT 倍数法、终值折现法、清算价值法三类算式。

题量：95题（第1节 一般流程 12题，第2节 投资调查与分析 34题，第3节 投资项目估值 40题，第4节 交易文件 8题，第5节 投资交易结构 1题）。

## 第1节 股权投资的一般流程

1. **投资的一般流程（八环节）**：项目开发与筛选 → 初步尽职调查 → 项目立项 → 签署投资框架协议 → 尽职调查 → 投资决策 → 签署投资协议 → 投资交割。⭐⭐
2. **投资后管理与项目退出不属于"投资的一般流程"**（属投资交割完成后的后续阶段）。⭐⭐
3. **投资决策权的行使主体**：股权投资基金管理人设立**投资决策委员会**行使投资决策权。⭐⭐
4. **投资决策委员会委员的构成**：**不限于**管理人高级管理团队成员，还可包括**外部专家**。⭐⭐
5. **投资决策委员会委员聘任与议事规则**：通常由管理人**董事会或执行事务合伙人**负责。⭐
6. **投资流程围绕什么展开**：围绕**投资决策**展开（立项、尽调、签意向书都是为决策服务）。⭐⭐
7. **尽职调查的定义**：对目标公司**业务、财务与法律**进行非常详尽而深入的调查与了解。⭐⭐
8. **初步尽职调查的核心**：对拟投资项目进行**价值判断**（判断是否值得深入研究）。⭐⭐
9. **尽职调查的地位**：股权投资业务流程中**不可或缺**的环节，通常被视为投资管理人**核心竞争力**的体现。⭐⭐
10. **尽职调查的三项内容**：**业务、财务、法律**。**"管理"不属于**。⭐⭐
11. **投资意向书**：也称**投资条款清单**，通常由**领投方**（投资方）提出。⭐⭐
12. **中介机构推荐的项目来源**：律师事务所、会计师事务所、财务顾问。**基金公司不属于**。⭐

## 第2节 投资调查与分析

### 作用与分类

1. **尽职调查的三大作用**：**价值发现**、**风险发现**、**投资决策辅助**。**"客户关系维护"不属于**。⭐⭐
2. **尽职调查的目的**：尽可能全面获取目标公司**真实信息**；**发现潜在投资风险并评估其对投资项目的影响**。⭐
3. **尽职调查的具体作用（三项）**：帮助判断目标公司是否值得投资并获取估值所需信息；为投资条款谈判、投后管理重点、退出方式选择提供依据；**降低信息不对称**可能带来的问题。⭐
4. **尽调的三类**：业务、财务、法律。**"信用尽职调查"不是**独立类别。⭐⭐
5. **业务尽职调查是"整个尽职调查的核心"**（不是财务尽调）。⭐⭐
6. **财务尽调 vs 一般财务审计**：审计以**验证财务报表真实性**为目的；财务尽调强调发现企业的**投资价值**和**潜在风险**，并注重对未来价值和**成长性**的合理预测。⭐⭐

### 三类尽调的具体内容

7. **业务尽调的主要内容**：企业基本情况、管理团队、产品/服务。**纳税分析属于财务尽调**。⭐⭐
8. **财务尽调的作用**：了解目标公司**资产负债**、**内部控制**、充分揭示**财务风险**。⭐
9. **财务尽调重点考察的内容**：**会计政策与会计估计**、**财务报告及相关财务资料**、**财务比率分析**。**风险分析不属于**。⭐
10. **财务尽调涵盖的信息**：历史经营业绩、未来盈利预测、融资结构。⭐
11. **利润表的重点核查对象**：收入确认、销售成本、期间费用核算的规范性。**存货周转不属于**（属资产负债表存货项目）。⭐⭐
12. **资产负债表需重点核查真实性的资产项目**：货币资金、无形资产、坏账计提。**销售成本不是资产项目**。⭐
13. **参股子公司的资料要求**：获取**最近一年**的财务报告及审计报告。⭐⭐
14. **收购兼并的特殊要求**：被收购企业资产总额/营业收入/净利润超过一定比例的，应获得被收购企业**收购前一年**的财务报表。⭐⭐
15. **法律尽调的内容（四项）**：确认目标公司的**合法成立和有效存续**；从合规角度核查所提供文件资料的**真实性、准确性和完整性**；了解**组织结构、资产和业务的产权状况和法律状态**（产权、业务资质、控股结构合法合规）；**发现和分析现存法律问题和风险并提出解决方案**。⭐⭐
16. **主要股东情况的关注点**：主要股东与目标公司之间的**关联交易、资金往来及相互担保是否合法**。⭐

### 财务比率分析（三类指标必须分清）

17. **盈利能力分析**：毛利率、资产收益率、净资产收益率 → 分析盈利水平及**持续性**。⭐⭐
18. **偿债能力分析**：**资产负债率、流动比率、速动比率、利息保障倍数**。**存货周转率不属于**（那是营运能力）。⭐⭐
19. **偿债能力还需结合**：现金流量状况、银行资信状况、可利用的融资渠道及授信额度、表内负债、表外融资及或有负债。⭐⭐
20. **运营（营运）能力分析**：存货周转率等。⭐
21. **综合评价的维度**：盈利能力 + 偿债能力 + 运营能力。**"负债能力"不是**通用维度。⭐⭐

### 尽调的组织与报告

22. **尽职调查工作计划的内容**：尽调**对象**、**内容与方法**、**日程安排**。**"手段"不是**单独一项。⭐
23. **尽职调查小组的成员**：投资管理人员、**律师**、**会计师**。**审计师与会计师职责重合，一般不同时设**。⭐⭐
24. **复核的作用**：防范风险、提高尽调质量，属于股权投资机构**内部的自我监督机制**。⭐⭐
25. **尽职调查报告的结构**：**前言、正文、附件**三部分。**没有"引言"**，**"目录"也不是必需**。⭐⭐
26. **尽调报告的附件**：审计报告、法律意见书、行业分析报告。**风险揭示书不属于**（那是风险告知文件）。⭐⭐
27. **二手资料的别称**：**次级资料**。⭐
28. **二手资料的收集途径**：企业内部资料（工商登记、财务报告、董事会会议记录、业务文件、重大法律合同）、网络、行业协会和商会。**"客服提供"不是**典型途径。⭐⭐
29. **内部访谈的目的**：与各层级各职能员工访谈可获取各环节信息并**考证信息真实性**；与管理层沟通可**间接考察管理层素质**、**增进了解与信任**。⭐
30. **易错点**：与管理层会谈是"**局部**了解目标公司信息"——表述错误（应是全面了解战略与运营等关键信息）。⭐

### 不同阶段的考察重点

31. **成熟阶段企业的考察重点**：管理团队、资产质量、融资结构、融资用途、发展战略、风险分析。**产品服务在成熟阶段已相对定型，不是重点**。⭐⭐

## 第3节 投资项目估值

### 估值方法总览

1. **企业常用的三类估值方法**：**收益法**、**成本法**、**市场法**。**"随机估值法"不存在**。⭐⭐
2. **相对估值法的基础**：以**可比较的企业的估值**为基础。⭐⭐
3. **相对估值法的常用倍数（四种）**：市盈率倍数、市净率倍数、市销率倍数、企业价值/息税前利润（EV/EBIT）倍数。⭐⭐
4. **贴现率不是相对估值法**（它是绝对估值法如 DCF 中的一个参数）。⭐⭐
5. **相对估值法的四步程序**：**选取可比公司 → 计算可比公司的估值倍数 → 计算适用于目标公司的可比倍数 → 计算目标公司的企业价值或股权价值**。⭐⭐
6. **"分析目标企业及参照企业的经营状况与行业地位"不是**相对估值法的特有工作程序。⭐
7. **可比公司的判定维度**：**所处行业、公司规模、资本结构**。**成立时间不是**关键可比点。⭐⭐
8. **可比倍数参考值的选取**：可比公司倍数的**平均值或中位数**。⭐⭐
9. **相对估值法的优点**：运用简单易于理解、主观因素相对较少、可及时反映市场看法的变化。**"行业因素影响较小"是错误表述**（实际受行业因素影响**大**）。⭐⭐
10. **盈利数据的选择**：最近一个完整会计年度的历史数据、**最近十二个月**的数据、预测年度的盈利数据。**"最近三年"不是**常用口径。⭐⭐

### 各倍数法的公式与适用情形

11. **市盈率倍数** = **股权价值 ÷ 净利润**（或 每股价值 ÷ 每股收益）。⭐⭐
12. **市净率倍数** = **股权价值 ÷ 净资产**（或 每股价值 ÷ 每股净资产）。⭐⭐
13. **市净率的适用**：适合**制造企业**；**不适合新兴产业企业**（资产多为无形资产）；特别适合**资产流动性较高的金融机构**（净资产账面价值更接近市场价值）。⭐⭐
14. **净利润和市盈率都容易受**：**经济周期**的影响。⭐⭐
15. **EV/EBIT 倍数法**：**不受资本结构影响**（这是关键优点）。公式 **EV = EBIT × (EV/EBIT 倍数)**。⭐⭐
16. **EBIT 的计算**：**EBIT = 净利润 + 所得税 + 利息**。⭐⭐
17. **EBIT 的含义**：扣除**债权人利息**之前的利润，所有出资人（股东和债权人）对其享有分配权；**对应企业价值（EV）**。⭐⭐
18. **EBITDA 的含义**：扣除**利息费用、税收、折旧与摊销**之前的利润。⭐⭐
19. **市销率倍数的适用**：销售成本率较低的服务类企业、销售成本率趋同的传统行业企业；也适用于**净利润为负**等情形。⭐⭐
20. **特殊情形的唯一可选方法**：净利润为负、经营性现金流为负、账面价值较低 → 只能适用**市销率倍数**。⭐⭐
21. **市场乘数法的适用**：目标公司**相对成熟、可产生持续利润或收入**。⭐⭐
22. **历史数据计算市盈率时**：应尽可能使用最新公开信息，通常使用**最近十二个月**的数据。⭐⭐

### 企业价值与股权价值

23. **企业价值的定义**：**所有出资人**（股东和债权人）共同拥有的公司运营所产生的价值。⭐⭐
24. **股权投资基金作为股权投资者关心的是**：**股权价值**。⭐
25. **企业价值与股权价值的关系**：**企业价值 = 股权价值 + 净债务**（净债务 = 债务 − 现金及现金等价物）。⭐⭐
26. **简单价值等式**：**企业价值 + 现金 = 股权价值 + 债务**。⭐⭐
27. **等式中的"现金"**：指不用投入公司运营的**多余现金**（货币资金总额扣除日常经营所需现金后的余额）。⭐⭐

### 绝对估值法与其他方法

28. **折现现金流（DCF）估值法**：设定**详细预测期**，预测未来现金流并折现。⭐⭐
29. **折现率的对应关系**：**企业自由现金流 → 加权平均资本成本（WACC）**；**股权自由现金流 → 权益资本成本**。⭐⭐
30. **DCF 的终值（TV）估算方法**：**终值倍数法**、**Gordon 永续增长模型**。**倍数特性法、永续零增长模型不是**常用方法。⭐⭐
31. **DCF 的优点**：评估得到的是**内含价值**（不是外在价值），受市场短期变化和非经济因素影响较小；需深入分析财务数据和经营模式，有助于发现**价值的核心驱动因素**；为企业未来发展战略和经营决策提供依据。⭐⭐
32. **DCF 的适用情形**：目标公司**现金流稳定、未来可预测性较高**。⭐
33. **账面价值法**：公司**总资产 − 总负债 = 净值**（净资产）。评估真正价值还需对**资产负债表的各个项目**作必要调整。⭐⭐
34. **重置成本法**：**待评估资产价值 = 重置全价 − 综合贬值**。⭐⭐
35. **成本法的地位**：主要作为**辅助方法**存在。原因是企业**历史成本与未来价值往往无必然联系**（说"有一定联系"即错）。⭐⭐
36. **清算价值法的适用**：常见于**杠杆收购**和**破产投资策略**。⭐⭐
37. **清算的分类**：**破产清算**、**解散清算**。⭐⭐

### 三类计算题（必须掌握）

38. **EBIT 倍数法**（例：净利润1.2亿、税率25%、利息0.2亿、EV/EBIT=6倍）
    - 先求 EBIT：净利润 =（EBIT − 利息）×（1 − 税率）→ 1.2 =（EBIT − 0.2）× 0.75 → EBIT = 1.8亿
    - 再求 EV：1.8 × 6 = **10.8亿** ⭐⭐
39. **终值折现法**（例：5年后股权价值100亿、目标收益率80%）
    - 估值 = 终值 ÷（1 + 目标收益率）^n = 100 ÷ 1.8^5 ≈ **5.3亿** ⭐⭐
40. **清算价值法**（例：股权比例20%、资产变现10.8亿、负债及破产费用8.5亿）
    - 净资产 = 10.8 − 8.5 = 2.3亿
    - 股权估值 = 2.3 × 20% = **0.46亿** ⭐⭐
    - 注意：用**变现总值**而非账面总值；实收资本、累计亏损不参与计算

## 第4节 交易文件

1. **投资意向书的别称**：**投资条款清单**。⭐
2. **估值调整条款**：既可以**条款形式**存在于投资协议中，也可以专门的**估值调整协议（对赌协议）**形式存在。⭐⭐
3. **保护性条款的定义**：股权投资基金为保护自身利益而设置，要求目标公司在执行某些**可能损害投资者利益**或**对投资者利益有重大影响**的行为时，需取得投资者同意。⭐⭐
4. **保护性条款覆盖的行为（三项）**：损害投资人利益、**侵害公司控制权**、对投资人利益有重大影响。**"与投资人利益无关"的行为不需要**同意。⭐⭐
5. **重大关联交易需投资人同意**：体现的是**保护性条款**。⭐⭐
6. **董事会席位条款的实质**：对被投资企业**控制权**分配进行约定。⭐⭐
7. **保护股东权利的四类条款**：**优先认购权**（后续融资优先认购，防稀释）、**第一拒绝权**（其他股东对外转让时优先购买）、**随售权**（其他股东对外出售时按比例同条件跟卖）、**拖售权**（并购时大股东可强制小股东一起出售）。⭐⭐
8. **随售权的计算**：按**持股比例**参与。例：基金持股40%，创始人出售20000股 → 基金可卖 20000×40% = **8000股**，创始人卖 **12000股**。⭐⭐
9. **第一拒绝权与随售权的行使顺序**：通常**先行使第一拒绝权**，放弃后才可能行使随售权。⭐⭐

## 第5节 投资交易结构

1. **涉及债权投资方式的三种情形**：正式股权投资前发放**过桥贷款**、与商业银行合作**投贷联动**、与担保机构合作**投保贷联动**。⭐⭐
2. **"直接认购目标公司股权成为股东"是纯股权投资**，不涉及债权投资方式。⭐⭐

## 易混易错

**投资流程的边界**

1. 投资一般流程 = 开发与筛选 → 初步尽调 → 立项 → 签署投资框架协议 → 尽职调查 → 投资决策 → 签署投资协议 → 投资交割（8环节）。
2. **投资后管理、项目退出不属于**投资的一般流程——这是高频干扰项。
3. 投资流程围绕**投资决策**展开；投资决策权由**投资决策委员会**行使。
4. 投资决策委员会委员**不限于**高管团队成员，可含外部专家（"只能由高管担任"是错误项）。

**三类尽调的归属（最高频的串门错误）**

5. 业务尽调：企业基本情况、管理团队、产品/服务。
6. 财务尽调：会计政策与会计估计、财务报告及相关资料、财务比率分析、**纳税分析**。
7. 法律尽调：合法成立与存续、文件真实性完整性、产权与业务资质与控股结构、法律问题与风险方案。
8. 易错点：**纳税分析属财务**（不是业务）；**风险分析不属财务尽调的考察内容**；**"信用尽职调查"不存在**。
9. **业务尽调是整个尽调的核心**；"财务分析是核心"是错误表述。
10. 尽调三作用 = 价值发现 + 风险发现 + 投资决策辅助；"客户关系维护""提高中介机构素质"均非其作用。

**财务比率三分类（数字型失分点）**

11. **盈利能力**：毛利率、资产收益率、净资产收益率。
12. **偿债能力**：资产负债率、流动比率、速动比率、利息保障倍数。
13. **营运能力**：存货周转率。
14. 易错点：把**存货周转率**塞进偿债能力（高频错误）；综合评价三维度是盈利+偿债+运营，**没有"负债能力"**。
15. 利润表核查：收入确认、销售成本、期间费用规范性；**存货周转属资产负债表**。
16. 资产项目真实性：货币资金、无形资产、坏账计提；**销售成本不是资产项目**。

**尽调报告与组织**

17. 报告结构 = **前言、正文、附件**（无"引言"；"目录"非必需）。
18. 附件 = 审计报告 + 法律意见书 + 行业分析报告；**风险揭示书不属于附件**。
19. 尽调小组 = 投资管理人员 + 律师 + 会计师；**审计师与会计师职责重合，一般不同时设**。
20. 复核 = 内部自我监督机制（防范风险、提高质量）。
21. 工作计划 = 对象 + 内容与方法 + 日程安排；**"手段"不是**独立一项。
22. 二手资料 = **次级资料**；收集途径 = 企业内部 + 网络 + 行业协会商会；**"客服提供"不是**。
23. 参股子公司取**最近一年**报告；收购兼并取**收购前一年**报告。

**估值方法的选择逻辑**

24. 相对估值法（市场法）：以**可比企业估值**为基础，受**行业因素影响大**（说"影响小"即错），优点是简单、主观因素少、及时反映市场看法。
25. 相对估值法四步：选可比公司 → 算可比公司倍数 → 算适用目标公司倍数 → 算目标公司价值。
26. 可比公司维度 = 行业 + 规模 + 资本结构；**成立时间不是**。
27. 倍数参考值取**平均值或中位数**（不是众数、分位数）。
28. 各倍数适用：市净率→制造业/高流动性金融机构（**不适合新兴产业**）；市销率→净利润为负时**唯一可选**；市场乘数法→成熟且能持续产生利润；DCF→现金流稳定可预测。
29. EV/EBIT **不受资本结构影响**（这是它相对市盈率的关键优势）；EBIT = 净利润 + 所得税 + 利息；EBIT 对应**企业价值**。
30. 折现率配对：企业自由现金流→**WACC**；股权自由现金流→**权益资本成本**（不可互换）。
31. 成本法只作**辅助方法**，原因是历史成本与未来价值**无必然联系**（说"有一定联系"是错误项）。
32. 清算价值法 → **杠杆收购 + 破产投资策略**；清算分**破产清算、解散清算**。

**价值等式与计算题**

33. 企业价值 = 股权价值 + 净债务；简单价值等式：**企业价值 + 现金 = 股权价值 + 债务**。
34. 等式中的"现金" = **多余现金**（货币资金 − 日常经营所需）。
35. 企业价值归**所有出资人**；股权投资基金只关心**股权价值**。
36. EBIT 倍数法：先由净利润反推 EBIT（注意税率还原），再乘倍数。
37. 终值折现法：估值 = 终值 ÷ (1+目标收益率)^n。
38. 清算价值法：净资产 = **变现总值** − 负债及破产费用；股权估值 = 净资产 × 持股比例。用账面总值或掺入实收资本、累计亏损都是错的。

**投资协议条款**

39. 投资意向书 = **投资条款清单**。
40. 估值调整条款：可以是**条款**，也可以是**专门协议**（对赌协议）。
41. 保护性条款 = 需投资者同意的行为（损害利益 / 侵害控制权 / 有重大影响）；**与投资人利益无关的行为不需要**同意。
42. 董事会席位条款实质 = **控制权**分配（不是人事权、财政权）。
43. 随售权按**持股比例**计算跟卖数量；**第一拒绝权优先于随售权**行使（顺序不可颠倒）。
44. 债权投资方式 = 过桥贷款 + 投贷联动 + 投保贷联动；**直接认购股权是纯股权投资**。
