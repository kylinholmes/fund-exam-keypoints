# 私募股权投资基金基础知识 · 第8章 股权投资基金治理

本章考点覆盖治理的目的与机制构成、五项治理原则（利益一致/公平对待/专业审慎/信息透明等）、信息披露的三种性质与定期披露口径、以及内部治理的两个层面（治理结构 + 治理机制）与三会/投委会的权限划分。本章以「原则归属 + 机制层级」为主，题量少但辨析精度要求高。

题量：30题（第1节 治理概述 4题，第2节 治理主要原则 15题，第3节 内部治理 11题）。

## 第1节 股权投资基金治理概述

1. **广义基金治理权力配置的最终目的**：**确保科学决策、维护利益相关者利益**（内部机构相互制衡是手段，不是目的）。⭐⭐
2. **基金治理机制的构成**：**决策机制、激励机制、约束机制**。**"销售机制"不属于**基金治理机制。⭐⭐
3. **合伙型基金中 LP 与 GP 的关系**：**委托代理**关系（LP 出资不参与日常经营，GP 负责运营）。⭐⭐
4. **公司治理的价值取向**：以**公司股东利益为主导、兼顾利益相关者利益**（不是只关注股东或管理层）。⭐⭐

## 第2节 股权投资基金治理主要原则

### 治理原则的集合

1. **基金治理的主要原则**：**利益一致**、**公平对待**、**专业审慎**、**信息透明**等。**"优先对待部分投资者"违背公平原则，不是治理原则**。⭐⭐
2. **信义义务的核心目标**：防范**利益冲突**、确保基金**有效运作**、维护**投资者最佳利益**。**"维护基金管理人利益"不是**信义义务的目标。⭐⭐
3. **基金管理人与投资者的关系本质**：**信义**关系（受托管理基金财产，须恪尽职守、诚实信用、谨慎勤勉）。⭐⭐
4. **基金管理人是基金治理的第一责任人**（在治理中起核心主导作用）。⭐⭐

### 利益一致原则

5. **管理人出资比例与代理风险的关系**：管理人**出资比例越高** → **代理风险越低**（自身利益与基金利益绑定更紧）。⭐⭐
6. **基金合同须明确约定的收益分配内容**：**可分配资金**、**分配时间**、**分配模式**。**"管理人办公地址"不属于**。⭐⭐
7. **可能产生利益冲突的典型情形**：基金投资期内，**管理人关联方管理与本基金投资策略相同的基金**（会在项目获取、资源分配上冲突）。正常投资优质项目、按合同分配收益、定期披露报告均不构成冲突。⭐⭐
8. **投资者未按合同约定缴付出资的责任**：承担**违约责任**（不是行政、刑事或侵权责任）。⭐⭐

### 公平对待原则

9. **公平对待原则的适用范围**：同一只基金中的不同投资者；管理人管理的**不同基金**的投资者；**已履行出资义务**的投资者。⭐⭐
10. **不适用**公平对待原则的对象：**未履行出资义务的投资者**（情况特殊）。⭐⭐

### 专业审慎原则

11. **专业性的合同要求**：基金合同中通常要明确**关键人士的具体人选**（不是普通员工人选、不是所有员工职责分工、不是营销计划）。⭐⭐

### 信息透明原则

12. **信息披露按性质的三种分类**：**强制性信息披露**（法定）、**约定信息披露**（契约约定）、**自愿信息披露**（主动超出要求）。⭐⭐
13. **定期信息披露的口径**：**季度信息**、**半年度信息**、**年度信息**。**"月度信息"不是**普遍要求的定期披露内容。⭐⭐
14. **临时信息披露的针对对象**：可能影响**基金及基金投资者权益的重大事项**（不是日常常规事项、不是管理人个人事务）。⭐⭐
15. **信息披露机制的内容**：向投资者披露的**内容、频率、方式**；**信息披露管理部门、工作流程及内控机制**；**未按规定披露信息的责任追究机制**。**"基金管理人的个人财产状况"不属于**。⭐⭐
16. **合规风控人员定期自查后的披露对象**：**投资者**（保障投资者知情权；不是仅内部流转，也不是常规报监管或自律组织）。⭐⭐

## 第3节 股权投资基金内部治理

### 两个层面与机制构成

1. **基金内部治理的两个层面**：**治理结构** + **治理机制**。⭐⭐
2. **内部治理的规范对象**：规范**基金投资者、管理人等利益主体**之间的权利义务关系（不局限于托管人与管理人，也不限于管理人内部部门）。⭐⭐
3. **治理机制的三个核心内容**：**决策机制、激励机制、约束机制**。**监督机制是保障机制有效运行的支撑手段，不属于核心内容**。⭐⭐
4. **基金治理的核心机制**：**决策机制**（关乎运营方向、资产配置，起决定性作用）。⭐⭐
5. **科学决策的前提**：建立科学治理结构，明确划分**投资者与管理人**各自的权利和责任。⭐⭐

### 不同组织形式的治理要点

6. **公司型基金的运营安排**：除**自我管理型**外，通常委托**基金管理人**负责运营和管理。⭐
7. **公司型基金保证投资运作效率的关键**：**合理分配决策权限**（扩大投资者权限或完全由管理人决策都会损害效率或制衡）。⭐⭐
8. **聘请基金管理人的决定主体**：由**股东会**作出决定，**公司章程**可对相关程序作出规定。**董事会不是**常规决定主体。⭐⭐
9. **有限合伙治理与公司治理的归属**：均属**企业治理**范畴。⭐
10. **普通合伙人的责任**：对合伙企业债务承担**无限连带责任**。⭐
11. **投委会的常见人数**：**3—7 人**（由若干名自然人委员组成）。⭐⭐

## 易混易错

**"目的" vs "手段"**

1. 广义治理权力配置的**最终目的** = 确保科学决策 + 维护利益相关者利益。
2. **内部机构相互制衡是手段**，不是目的；"限制管理人权力""增加公司盈利"均非最终目的。

**治理机制的层级（本章最易错）**

3. **治理机制**（三大）= 决策 + 激励 + 约束。
4. **监督机制**是保障机制运行的**支撑手段**，**不是**核心内容之一——这是高频错误选项。
5. **核心机制 = 决策机制**（不是约束、激励或监督机制）。
6. **"销售机制"不属于**基金治理机制。
7. 内部治理**两个层面** = 治理结构 + 治理机制；决策/激励/约束只是**治理机制**的组成部分，不能当作两个层面。

**五项原则的边界**

8. 属于：利益一致、公平对待、专业审慎、信息透明。
9. 不属于：**优先对待部分投资者**（违背公平）、**维护管理人利益**（信义义务服务于投资者）。
10. 信义义务核心目标 = 防利益冲突 + 确保有效运作 + 维护**投资者**最佳利益。
11. 管理人与投资者的关系本质 = **信义关系**（不是债权债务、雇佣或合伙关系）。
12. 管理人是治理的**第一责任人**。

**公平对待原则的适用边界**

13. 适用：同一基金不同投资者、不同基金的投资者、**已履行出资义务**的投资者。
14. 不适用：**未履行出资义务**的投资者（这是唯一的排除项，易漏）。

**利益一致原则的具体化**

15. 管理人出资比例**高** → 代理风险**低**（方向不可反）。
16. 收益分配须约定：可分配资金 + 分配时间 + 分配模式；**办公地址无关**。
17. 典型利益冲突 = **管理人关联方管理与本基金策略相同的基金**。
18. 投资者未按约缴付 → **违约责任**。

**信息披露的三种性质与三种口径**

19. 按性质分三类：**强制性 + 约定 + 自愿**（三者全选，缺一即错）。
20. 定期披露 = **季度 + 半年度 + 年度**；**月度不是**普遍要求（这是最常设的干扰项）。
21. 临时披露 = 针对**可能影响基金及投资者权益的重大事项**。
22. 披露机制**不含**"管理人个人财产状况"。
23. 合规风控自查报告 → 向**投资者**披露（不是仅内部、不是常规报监管/自律组织）。

**公司型基金的权限划分**

24. 聘请基金管理人 → **股东会 + 公司章程**；**董事会不是**决定主体。
25. 保证投资效率 → **合理分配决策权限**（不是扩大投资者权限、不是完全由管理人决策、不是取消治理机构）。
26. 除**自我管理型**外，公司型基金委托**基金管理人**运营。

**其他数字**

27. 投委会常见人数 = **3—7 人**。
28. 普通合伙人（GP）对合伙企业债务 = **无限连带责任**。
29. 有限合伙治理与公司治理同属**企业治理**范畴。
