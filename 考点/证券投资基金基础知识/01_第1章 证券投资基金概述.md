# 证券投资基金基础知识 · 第1章 证券投资基金概述

本章考点覆盖证券投资基金的概念与各国称谓、"利益共享、风险共担"的含义、基金与股票债券及银行储蓄存款的区别、基金运作环节与各参与主体的职责分工，以及基金的起源和我国基金业发展历程中的标志性产品、阶段划分与政策节点。题量：21题（第1节 14题，第2节 1题，第3节 6题）。

## 第1节 证券投资基金简介（14题）

### 一、证券投资基金的概念与称谓

1. 证券投资基金是一种集合投资方式，通过公开募集或非公开募集的方式汇集投资者的资金形成独立财产，交由专业的基金管理机构进行投资管理。⭐
2. 证券投资基金在美国被称为"共同基金"，在英国和我国香港特别行政区被称为"单位信托基金"。
3. 证券投资基金反映的是一种信托关系，不是债权债务关系，也不是债权凭证。⭐
4. 基金是独立的资产管理产品，投资者自担风险。
5. 基金通过募集资金形成独立财产，该独立财产独立于基金管理人、基金托管人的固有财产。
6. 基金的资金主要投向有价证券等金融工具或产品。
7. 基金可以投资于众多金融工具或产品，因而能有效分散风险。
8. 集合理财是将众多投资者的资金集中起来形成规模，凭借规模优势在投资中降低成本，这是集合理财的优点。
9. 强化监管不是集合理财自身的优点；证券投资基金的收益不稳定，风险也不固定，"收益稳定""风险固定"的表述均错误。

### 二、利益共享、风险共担

10. 基金投资者是基金的所有者，基金投资收益在扣除由基金承担的费用后的盈余全部归基金投资者所有。
11. 基金收益依据各投资者所持有的基金份额比例进行分配。
12. 基金管理人、基金托管人只是按规定收取一定比例的管理费、托管费，并不参与基金收益分配，也不承担投资损失。

### 三、基金与股票、债券、银行储蓄存款的区别

13. 股票是股份公司发行的所有权凭证，反映的是股东权利关系；债券反映的是债务关系。
14. 开放式基金与银行储蓄存款在性质上不同：基金具有投资性质，存款是债权债务关系。
15. 开放式基金与银行储蓄存款的收益与风险特性不同：基金的收益、风险波动大，存款相对稳定安全。
16. 开放式基金与银行储蓄存款的信息披露程度不同：基金需定期披露净值等信息，存款的披露要求低。
17. 变现能力不是开放式基金与银行储蓄存款的主要差异：开放式基金赎回有一定流程和时间，银行储蓄也可提前支取，只是可能影响利息收益。

### 四、基金的运作环节

18. 基金的运作包括基金的募集、基金的投资管理、基金财产的托管、基金的估值与会计核算，四个环节都是基金运作不可或缺的部分。
19. 从基金管理人的角度看，基金的运作活动可分为基金的市场营销、基金的投资管理和基金的中后台管理。
20. 基金的盈亏核算只是投资管理等过程中的一个环节，不是与市场营销、投资管理、中后台管理并列的运作活动分类。

### 五、基金市场参与主体的职责

21. 基金管理人在基金运作中具有核心作用，负责基金的投资运作、资产估值等关键事务；其最核心的职责是按照基金合同的约定负责基金资产的投资运作，以实现基金资产的保值增值。⭐
22. 基金份额持有人是基金的所有者，但不直接参与基金的运作。
23. 基金销售机构只负责销售基金，证券交易所为基金交易提供场所，二者都不是基金运作的核心。
24. 基金托管人的主要职责是安全保管基金财产；办理清算交割是基金托管人等相关机构的部分职责。
25. 办理基金份额登记一般由基金注册登记机构等负责，不是基金管理人的职责。
26. 在我国，基金托管人只能由依法设立并取得基金托管资格的商业银行或其他金融机构担任，目前主要由商业银行承担基金托管工作。
27. 基金管理人将部分业务外包后，其依法应承担的责任不因委托给服务机构而免除。
28. 我国证券交易所是依法设立的、不以营利为目的的法人，为证券的集中和有组织的交易提供场所和设施，履行国家有关法律法规、规章、政策规定的职责，实行自律性管理。

## 第2节 证券投资基金的起源与发展（1题）

### 一、基金的起源

1. 1868年，英国成立"海外及殖民地政府信托基金"，这是世界上第一只公认的证券投资基金。

## 第3节 中国证券投资基金业的发展历程（6题）

### 一、法制基础与发展阶段

1. 《证券投资基金法》于2004年6月1日起施行。
2. 我国证券投资基金的探索阶段呈现探索性、自发性、不规范性的特点，当时监管体系尚不完善，并不具有监管严格性的特点。
3. 2008年至2014年属于我国基金业发展的平稳发展及创新探索阶段，该阶段基金行业面临市场波动等挑战，同时在产品创新、业务拓展等方面不断探索。

### 二、标志性基金产品

4. 2001年9月，我国第一只开放式基金——华安创新诞生。
5. 基金开元、基金金泰是我国首批封闭式基金。
6. 淄博基金是我国第一只投资基金。

### 三、重要政策文件与会议精神

7. 2018年10月，中国证监会出台《证券期货经营机构私募资产管理业务管理办法》《证券期货经营机构私募资产管理计划运作管理规定》，明确将各类私募资产管理业务统一为信托法律关系。
8. 上述文件确立的基本原则包括卖者尽责、买者自负，审慎经营，禁止刚兑；集中运作不是其确立的基本原则。
9. 2023年10月底召开的中央金融工作会议首次提出要做好"五篇大文章"，即科技金融、绿色金融、普惠金融、养老金融、数字金融。

## 易混易错

**称谓与关系性质**

1. 美国 = **共同基金**；英国和我国香港特别行政区 = **单位信托基金**。易错点：把美国称为"单位信托基金"（本题的错误选项即此）。
2. 四类关系不能互换：基金 = **信托关系**；股票 = **股东权利关系**（所有权凭证）；债券 = **债务关系**；银行储蓄存款 = **债权债务关系**。易错点：称基金"反映债权债务关系、是债权凭证"。

**特点辨析**

3. 集合理财的优点 = 资金集中形成**规模优势**、降低成本；"强化监管"不是集合理财自身的优点，"收益稳定""风险固定"是错误表述（基金收益不稳定、风险不固定）。
4. "利益共享、风险共担" = 扣除基金承担的费用后盈余**全部**归基金投资者、按**所持份额比例**分配；管理人、托管人只收管理费和托管费。干扰项：优先分配给管理人和托管人、管理人参与收益分配、托管人与管理人共同分担投资风险。

**基金与银行储蓄存款**

5. 主要差异为三项：性质不同、收益与风险特性不同、信息披露程度不同。易错点：把"变现能力不同"当作主要差异——开放式基金赎回有流程和时间，储蓄可提前支取（仅可能影响利息），变现能力并非本质区别。

**运作环节**

6. 基金运作四环节 = 募集 + 投资管理 + 财产托管 + 估值与会计核算。
7. 从基金管理人角度 = 市场营销 + 投资管理 + 中后台管理（三项）；"盈亏核算"是过程环节，不是并列分类，属干扰项。

**主体职责错位**

8. 基金管理人 = 投资运作（核心职责）、资产估值；**不是**份额登记、清算交割、财产保管。
9. 基金托管人 = 安全保管基金财产、办理清算交割；**不是**投资运作。
10. 基金注册登记机构 = 办理基金份额登记。
11. 基金销售机构 = 只负责销售；证券交易所 = 提供交易场所和设施，二者都不是运作核心。
12. 基金份额持有人 = 基金所有者，不直接参与运作。
13. 托管人资格：依法设立并取得基金托管资格的**商业银行或其他金融机构**（目前主要由商业银行担任）；"保险公司""基金管理公司""信托公司"为干扰项。
14. 业务外包：管理人依法应承担的责任**不因委托而免除**；"转由服务机构承担""自动免除""需重新约定"为干扰项。

**证券交易所性质**

15. 证券交易所 = 依法设立、**不以营利为目的**、实行自律性管理的法人；"以利润最大化为目的""以收入最大化为目的""以指数最大化为目的"为干扰项。

**财产性质**

16. 基金募集形成的是**独立财产**（独立于管理人、托管人固有财产）；"公司财产""集体财产""混合资产"为干扰项。

**起源与历史**

17. 1868年英国**海外及殖民地政府信托基金** = 世界上第一只公认的证券投资基金；"苏格兰美国投资信托""马萨诸塞投资信托基金""英国投资信托"为干扰项。
18. 《证券投资基金法》施行日 = **2004年6月1日**；"2003年7月14日""2005年1月1日""2002年8月1日"为干扰数字。
19. 探索阶段特点 = 探索性 + 自发性 + 不规范性；"监管严格性"为干扰项（当时监管体系尚不完善）。
20. 三只标志性产品极易错位：**华安创新**（2001年9月，第一只开放式基金）、**基金开元与基金金泰**（首批封闭式基金）、**淄博基金**（第一只投资基金）。
21. 2008年至2014年 = **平稳发展及创新探索阶段**；"萌芽和早期发展时期""试点发展阶段""快速发展阶段"为干扰项。

**政策文件与会议精神**

22. 2018年10月中国证监会两个文件（《证券期货经营机构私募资产管理业务管理办法》《证券期货经营机构私募资产管理计划运作管理规定》）= 各类私募资产管理业务统一为**信托法律关系**；基本原则 = 卖者尽责、买者自负 + 审慎经营 + 禁止刚兑；"集中运作"为干扰项。
23. 2023年10月底中央金融工作会议"五篇大文章" = 科技金融 + 绿色金融 + 普惠金融 + 养老金融 + 数字金融；"风险金融"为干扰项。
