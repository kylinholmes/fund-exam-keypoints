# 证券投资基金基础知识 · 第10章 投资交易管理

本章围绕证券市场的交易机制（交易主体、现货与保证金交易、指令类型与指令驱动成交原则）、交易执行（算法交易、交易成本构成与执行缺口、最佳执行）以及基金管理人投资交易管理（交易执行环节风险、交易指令内部执行流程）三条主线展开。题量：28题（第1节 证券市场的交易机制 13题，第2节 交易执行 12题，第3节 基金管理人投资交易管理 3题）。

## 第1节 证券市场的交易机制

### 一、交易中的各类主体

1. 经纪人在交易中执行投资者的指令，接受客户委托为买卖双方撮合交易。
2. 做市商主要提供买卖双边报价，并按报价与投资者交易。
3. 监管人负责监督管理市场，不执行投资者指令。
4. 托管人主要负责资产保管等，不执行投资者指令。

### 二、现货交易与保证金交易

5. 证券市场最常见、最主要的交易模式是现货交易，即"一手交钱，一手交货"，即时完成交割。
6. 投资者要卖出证券，证券账户上必须有属于投资者支配范围内的足量的可交易证券，这样的交易称为现货交易，不是期货交易。
7. 保证金交易使投资者能够以较小的资本基础参与超出其自身资金能力的交易，即"以小博大"。⭐
8. 保证金交易也叫杠杆交易，其本质是利用保证金撬动更大规模的交易。⭐
9. 保证金交易中投资者用于投资的自有资金或证券称为保证金。⭐
10. 保证金除以所投资金额（或证券总价值）的比率称为保证金率。⭐
11. 我国市场的"融资融券"属于保证金交易。⭐
12. 开展保证金交易（融资融券业务）需要符合一定条件，并非所有证券公司都能开展此项业务。⭐
13. 卖空交易是指投资者向证券公司借入一定数量的证券卖出，当证券价格下降时再以当时的市场价格买入证券归还证券公司，自己得到投资收益。
14. 融资（买空交易）是投资者借入资金买入证券，与卖空交易方向相反。

### 三、投资者下达的交易指令类型

15. 根据不同市场行情，投资者下达的常见指令包括市价指令、限价指令、止损指令三类，触价指令不属于此类常见分类。
16. 随价指令是指当市场价格达到客户预先设定的触发价格时，即变为市价指令予以执行的一种指令，主要包括止损指令和限价指令。
17. 限价买入指令设定一个最高买入价格；投资者认为目标公司股票价格偏高、尚不适合买入建仓时，可下达限价买入指令等待价格回落。
18. 持有指令、清仓指令不属于按市场行情下达的委托指令分类。

### 四、指令驱动的成交原则

19. 指令驱动的成交原则包括价格优先原则、时间优先原则、成交量最大原则，不包括交割最优原则。⭐
20. 价格优先原则：较高价格买进申报优先于较低价格买进申报，较低价格卖出申报优先于较高价格卖出申报。⭐
21. 价格优先不是"无论买卖皆以高价优先"，也不是"较低的买入价优于较高的买入价"。⭐
22. 时间优先原则：买卖方向、价格相同的，先申报者优先于后申报者，即同一价格上有多笔交易指令时遵循"先到先得"。
23. 同一价格上多笔交易指令优先成交委托时间较早的，而不是较晚的。

## 第2节 交易执行

### 一、算法交易策略

24. 常见的算法交易策略有四种：成交量加权平均价格算法（VWAP）、时间加权平均价格算法（TWAP）、跟量算法（TVOL）、执行缺口算法（IS）。⭐
25. 成交量加权平均价格算法（VWAP）根据市场成交量加权均价下单，以降低交易对市场的冲击。⭐
26. 时间加权平均价格算法（TWAP）按时间间隔均匀下单。
27. 跟量算法（TVOL）根据实时市场成交情况调整订单的执行节奏，使订单执行量与市场成交量占比相匹配，从而减少大额订单对市场价格的冲击、降低交易成本。
28. 执行缺口算法（IS）旨在最小化执行缺口。

### 二、交易成本的构成与各项费用

29. 显性成本按收费主体划分包括经纪商佣金、税费、交易所费用三类。⭐
30. 买卖价差属于隐性成本，不属于显性成本。⭐
31. 佣金是投资者在委托买卖证券成交后按成交金额一定比例支付的费用，是证券经纪商为客户提供证券代理买卖服务收取的费用。
32. 过户费是证券成交后更换户名支付的费用。
33. 印花税是对经济活动和经济交往中订立、领受具有法律效力的凭证的行为所征收的一种税。
34. 我国相关部门可以通过调节印花税税率和征收方向等来调节交易费用，进而调控市场活跃度；过户费率、交易佣金率并非主要由相关部门直接调节。
35. 买卖价差是当前最低卖出价与最高买入价之间的差额，在很大程度上由证券类型及其流动性决定：流动性好的证券买卖价差小，流动性差的证券买卖价差大。
36. 市场冲击是指因某笔交易指令的执行导致市场价格发生变动，从而产生的实际成交价格与假设该笔交易未发生时市场应有价格之间的差额。
37. 机会成本是指未成交部分股票价格变动所带来的成本，等于未成交股数乘以该期间每股价格的上涨幅度。
38. 机会成本率＝机会成本÷实际投资金额。
39. 执行缺口＝显性成本＋延迟成本＋已实现损失＋机会成本。

### 三、最佳执行与交易执行的意义

40. 最佳执行是指公司（包括买方和卖方）在既定的投资目标和限制内，为最大化客户投资组合价值而采用的交易流程。
41. 交易执行的时机、成本等因素直接影响投资绩效。
42. 交易成本是交易过程中产生的费用，不等于最佳执行；算法交易侧重于利用算法进行操作，也不是最佳执行。

## 第3节 基金管理人投资交易管理

### 一、交易执行环节的风险

43. 基金公司在交易执行环节的风险包括：未践行最佳执行原则导致交易效率低或差错率高；交易系统未经严格测试论证、系统缺陷造成交易失误；交易员不能有效履行对基金经理交易指令的监督、复核职责。
44. 交易执行独立于基金经理是合理的风险防控机制，不属于交易执行环节的风险。
45. 基金交易过程中的风险主要体现在投资交易过程中的合规风险和操作风险。
46. 经营风险主要侧重基金管理公司整体经营层面，利率风险由市场宏观因素导致，二者都不是投资交易过程特有的风险。

### 二、交易指令在基金公司内部的执行流程

47. 交易指令在基金公司内部执行流程的第一步是基金经理在授权范围内通过交易系统向交易室下达交易指令。
48. 交易指令下达后，由交易系统或相关责任人对投资指令的合法合规性进行审核。
49. 审核后，违规指令被系统拦截或人工驳回并反馈给基金经理，合规指令分发给交易员。
50. 基金托管人对交易指令的执行结果进行确认不属于基金公司内部执行流程，因为基金托管人是独立于基金公司的机构。

## 易混易错

**交易主体与交易模式**

1. 经纪人 vs 做市商：经纪人 = 执行投资者指令、为买卖双方撮合；做市商 = 提供买卖双边报价并按报价与投资者交易。监管人负责监管市场、托管人负责资产保管，两者都不执行投资者指令。
2. 现货交易 = "一手交钱，一手交货"、即时交割，是证券市场最主要交易模式；"远期合同交易""期货交易""非现金交易"均为干扰项。
3. 卖出证券前账户必须有足量可交易证券，这属于**现货交易**的特征，不是期货交易的特征（常见错项）。
4. 保证金交易的三重身份必须记全：以小博大 = 杠杆交易 = 我国市场的"融资融券"。干扰项是"所有的证券公司都可以开展此项业务"（错误，需符合一定条件）。
5. 保证金 = 投资者用于投资的自有资金或证券；保证金率 = 保证金÷所投资金额（或证券总价值）。"到期收益率""证券净资产比率""价值比率"均为干扰项。
6. 卖空交易 = 先借入**证券**卖出，价格下跌后买回归还；融资（买空）= 借入**资金**买入证券。二者方向相反，不可混用。

**指令类型与成交原则**

7. 随价指令 = 止损指令 + 限价指令；"市价指令""驱动指令""做市商指令"均为干扰项。
8. 按不同市场行情下达的常见指令 = 市价指令 + 限价指令 + 止损指令；**触价指令**是干扰项，不属于该常见分类。
9. 认为股价偏高、不宜立即建仓时应下达**限价买入指令**（设定最高买入价），不是限价卖出指令、持有指令或清仓指令。
10. 指令驱动成交原则 = 价格优先 + 时间优先 + 成交量最大；"交割最优原则"是干扰项。
11. 价格优先的正确表述：较高的**买入**申报优先于较低的买入申报，较低的**卖出**申报优先于较高的卖出申报。错误表述："较高的卖出价格总是优于较低的卖出价格""较低的买入价总是优于较高的买入价""无论买卖皆以高价优先"。
12. 时间优先 = 同一价格上"先到先得"、优先成交委托时间**较早**的交易；"优先成交委托时间较晚的交易"是错误表述。

**算法交易**

13. 四个英文简称不可错位：VWAP = 成交量加权平均价格算法；TWAP = 时间加权平均价格算法；TVOL = 跟量算法；IS = 执行缺口算法。
14. 算法与功能对应：按成交量加权均价下单、降低市场冲击 = VWAP；按时间间隔均匀下单 = TWAP；按实时成交量调整执行节奏 = TVOL；最小化执行缺口 = IS。

**交易成本**

15. 显性成本按收费主体划分 = 经纪商佣金 + 税费 + 交易所费用；**买卖价差属于隐性成本**，是最常见的错选点。
16. 佣金（按成交金额一定比例、经纪商代理买卖服务收费）vs 过户费（成交后更换户名支付）vs 印花税（对订立、领受具有法律效力凭证的行为征收）；"对冲费用"是干扰项。
17. 调节交易费用的政策工具是**印花税税率及征收方向**；"过户费率""交易佣金率"由市场主体在规则下确定，"到期收益率"与交易费用无关。
18. 买卖价差 = 当前最低卖出价与最高买入价之差，由证券类型及其流动性决定；市场冲击 = 指令执行导致价格变动后实际成交价与"假设未发生该笔交易时应有价格"的差额；机会成本 = 未成交部分价格变动造成的成本。三者定义不可互换。
19. 执行缺口 = 显性成本 + 延迟成本 + 已实现损失 + 机会成本（四项相加，缺一不可）。
20. 机会成本率 = 机会成本÷实际投资金额（分母是实际投资金额，不是计划投资金额或股票总市值）。

**基金管理人交易管理**

21. 交易执行环节的风险只包括：未践行最佳执行、交易系统缺陷、交易员未有效监督复核指令；**"交易执行独立于基金经理"不是风险**，而是风险防控机制。
22. 基金交易过程风险 = 合规风险 + 操作风险；"经营风险"（公司整体经营层面）、"利率风险"（市场宏观因素）均为干扰项。
23. 交易指令内部执行流程 = 基金经理在授权范围内下达指令 → 系统或责任人审核合法合规性 → 违规指令被拦截或驳回并反馈基金经理、合规指令分发给交易员；**基金托管人对执行结果确认不属于基金公司内部流程**（托管人独立于基金公司）。
