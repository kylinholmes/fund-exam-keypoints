# 证券投资基金基础知识 · 第2章 基金的类型

本章考点覆盖证券投资基金的分类维度与分类意义，以及股票基金、债券基金、货币市场基金、混合基金、指数基金（ETF/LOF）、基金中基金、QDII基金、基础设施基金、商品基金、MOM与养老目标基金等各类型基金的界定标准、投资对象、比例要求与风险收益特征。题量：58题（第1节 11题，第2节 7题，第3节 7题，第4节 6题，第5节 7题，第6节 2题，第7节 8题，第8节 3题，第9节 4题，第10节 3题）。

## 第1节 证券投资基金分类概述（11题）

### 一、基金分类的界定标准

1. 按中国证监会分类标准：60%以上的基金资产投资于股票的，为股票基金；80%以上的基金资产投资于债券的，为债券基金；仅投资于货币市场工具的，为货币市场基金。⭐
2. 混合基金是资产配置比例不符合股票基金、债券基金等标准的基金，即同时投资股票、债券等多类资产且达不到上述比例界定的基金。⭐
3. 将80%以上的基金资产投资于基金份额的，一般为基金中基金（FOF）。⭐

### 二、按投资对象划分的特殊基金类型

4. 商品基金是以商品现货或者期货等为投资对象的基金，包括黄金ETF和商品期货基金；黄金期货只是期货合约，不是基金，不属于商品基金。
5. ETF即交易型开放式指数基金，本质是追踪特定指数、紧密复制指数表现，属于指数基金。⭐

### 三、按募集方式、投资理念、运作方式等维度分类

6. 按募集方式的不同，证券投资基金分为公开募集基金和非公开募集基金。
7. 非公开募集基金的合格投资者累计不得超过200人。
8. 按投资理念的不同，证券投资基金分为主动型基金与被动型基金：主动型基金通过积极的投资策略，力图取得超越基准组合的表现；被动型基金复制指数，一般试图与指数表现一致。⭐
9. 按运作方式的不同，证券投资基金分为封闭式基金和开放式基金；按投资对象的不同，分为股票基金、债券基金等。

### 四、按资金来源和用途划分

10. 从基金的资金来源和用途划分，证券投资基金分为在岸基金、离岸基金和国际基金。
11. 在岸基金是本国募集资金并投资于本国市场的基金；离岸基金是一国基金组织在他国发售基金份额并将募集资金投资于本国或第三国市场的基金；国际基金是资本来源于国内、并投资于国外市场的证券投资基金。

### 五、基金分类的意义

12. 对证券投资基金分类有助于：①投资者对各种基金风险收益特征的把握；②基金公司完善不同风险收益特征的产品布局；③基金研究评价机构进行基金评级；④监管部门实施分类监管。
13. 基金分类是基金研究评价机构进行基金评级的基础，只有先对基金合理分类，才能在同类基金之间进行科学比较与评价。

### 六、管理人中管理人（MOM）产品

14. 管理人中管理人产品需委托两个或者两个以上符合条件的第三方资产管理机构，就资产管理产品的部分或者全部资产提供投资建议（不是资金支持、托管服务或销售服务）。

## 第2节 股票基金（7题）

### 一、股票基金的定位与特点

1. 股票基金以追求长期的资本增值为目标，是长期投资工具，其长期投资增值性可用于满足教育支出、退休支出等远期支出需要。
2. 股票基金风险较高，但预期收益也较高，是应对通货膨胀的有效手段（通货膨胀时股票价格可能上升）。
3. 股票基金不适合短期波段操作、通过买卖价差盈利：其净值波动非短期内能精准把握，频繁买卖还会增加成本。
4. 投资股票基金是较长期行为，主要关注基金的投资策略、投资风格和长期业绩，无需主要关注基金的短期净值波动。
5. 基金份额净值是由其持有的证券价格经过一系列计算复合形成的，因此其合理性无法简单判断。

### 二、股票的分类与风格

6. 按股票性质的不同，股票分为价值型股票与成长型股票：价值型股票通常是指模式成熟、增长稳定、业绩稳定、股息丰厚的上市公司股票，其市盈率、市净率通常较低；成长型股票通常是指未来收入增长较快、发展潜力大的上市公司股票，其市盈率、市净率通常较高。
7. 平衡型基金通常会同时投资于价值型股票和成长型股票，在两者之间合理配置以平衡风险与收益。
8. 按股票市值的大小分类，股票分为大盘股、中盘股、小盘股；蓝筹股是指长期稳定增长的、大型的、传统工业股及金融股等，并非按市值大小分类。

## 第3节 债券基金（7题）

### 一、债券基金的定位与关注要点

1. 债券基金主要投资于债券，投资者通常认为债券基金是收益稳定、中低风险的投资工具。
2. 投资债券基金需主要关注基金的平均持仓久期、杠杆率和基金所持债券的信用等级：久期影响利率风险，杠杆率影响风险与收益，债券信用等级关乎违约风险。

### 二、债券基金与单一债券的风险区别

3. 单一债券随着到期日的临近，所承担的利率风险会下降（剩余期限越短，受利率波动影响越小）。⭐
4. 债券基金没有固定的到期日，其所承担的利率风险取决于所持有的债券的平均到期日，而债券基金的平均到期日常常相对固定。⭐
5. 单一债券的信用风险比较集中（集中于单个发行人）；债券基金投资多种债券，能够分散部分信用风险，通常比单一债券的信用风险低。⭐

### 三、债券基金按投资范围的细分

6. 标准债券型基金仅投资于固定收益类金融工具，不能投资于股票市场。
7. 一级债基可参与一级市场新股申购等权益类投资；二级债基不仅可参与一级市场新股申购，还能在二级市场买卖股票；普通债券型基金包括一级债基和二级债基，都具有权益类投资。
8. 普通债券基金以投资固定收益类金融工具为主，也可以投资股票等权益类资产和可转换债券、可交换债券等金融工具；纯债基金不投资股票等权益类资产。

## 第4节 货币市场基金（6题）

### 一、投资对象与投资限制

1. 货币市场基金以货币市场工具为投资对象。
2. 《货币市场基金管理暂行规定》规定货币市场基金不能投资的金融工具包括：股票、可转换债券、信用等级在AA+级以下的债券。
3. 剩余期限在397天以内（含397天）的债券属于货币市场基金可以投资的金融工具，不是禁止投资的品种。

### 二、货币市场基金的特征

4. 货币市场基金每个交易日可办理基金份额申购、赎回。
5. 货币市场基金的收益分配方式约定为红利再投资，且每日分配。
6. 货币市场基金每日按照面值（一般为1元）进行报价。
7. 并非所有货币市场基金均提供T+0快速赎回服务，该项服务存在一定限制条件。

### 三、场内货币基金与估值方法

8. 场内货币基金可以分为申赎型和交易型两类。
9. 上交所交易型货币市场基金可在场内申购赎回，可在场内T+0交易；深交所交易型货币市场基金可在场内T+0交易，还可T+0申赎。
10. 与固定净值型货币市场基金相适配的估值方法为摊余成本法，该方法能平滑资产价值波动，维持相对稳定的净值。

## 第5节 基金中基金（7题）

### 一、FOF的定义、分类与特点

1. 基金中基金（FOF）是指以其他证券投资基金为投资对象的基金，其投资组合由其他基金组成。
2. 根据基金投资标的及投资方向的不同，FOF的产品可分为股票型FOF、债券型FOF、混合型FOF和货币型FOF。
3. 基金中基金的特点包括风险分散、资产优化和专业服务；FOF通常是降低投资门槛，而不是提高门槛。

### 二、FOF的比例界定

4. 80%以上的基金资产投资于股票型基金份额（包括股票指数基金）的，为股票型FOF。
5. 将80%比例以上的基金资产投资于商品期货基金份额的，为商品期货基金中基金。

### 三、养老目标基金

6. 养老目标基金发展初期主要采用基金中基金（FOF）形式运作，通过投资多只基金分散风险。
7. 养老目标基金采用成熟的资产配置策略，合理配置股票、债券等资产以实现养老资产的稳健增值。
8. 养老目标基金设置封闭期或投资者最短持有期限，以稳定资金规模，避免短期资金频繁进出影响长期投资策略。
9. 基金管理人可以根据实际情况为养老目标基金设置优惠费率，"禁止基金管理人设置优惠费率"的表述错误。
10. 养老目标基金按投资策略主要分为目标日期基金和目标风险基金两类。

## 第6节 混合基金（2题）

1. 混合基金的波动性小于股票基金，高于债券基金和货币基金：股票基金主要投资股票，波动性最大；债券基金波动性相对较小；货币基金具有高安全性、高流动性、稳定收益性，波动性最小。⭐
2. 灵活配置型基金的特点是股票、债券的配置比例不是固定不变，而是根据市场环境变化进行调整。

## 第7节 指数基金（8题）

### 一、指数基金的定义与分类

1. 指数基金是以特定指数为标的，通过购买该指数的全部或部分成分券构建投资组合，以跟踪标的指数或者基准业绩表现为主要投资目标的基金产品。⭐⭐
2. ETF即交易型开放式指数基金，属于指数基金；被动指数型基金以复制指数表现为目标，而非超越所跟踪的指数。⭐⭐
3. 按复制标的指数的方法（复制方法）分类，指数基金（ETF）分为完全复制型指数基金和抽样复制型指数基金。
4. 指数基金的其他分类维度：按投资标的分为股票指数基金和债券指数基金；按投资市场分为单市场指数基金和跨市场指数基金；标准指数型基金和指数增强型基金不是按复制标的指数的方法划分的。
5. 相比主动型基金，指数基金被动跟踪指数、管理相对简单，管理费用通常较低。

### 二、ETF与LOF的区别

6. ETF申购赎回的对价为一篮子证券或商品，LOF申购赎回的对价为现金。
7. ETF申购赎回只能在交易所进行；LOF可以场外申购赎回。⭐
8. ETF对申购赎回有资金规模限制，LOF没有特别的资金规模限制。
9. LOF净值报价频率较低，每日一次。

### 三、ETF的套利机制

10. 当同一商品在不同市场上价格不一致时，就会存在套利交易（低买高卖获利）。
11. 折价套利是投资者用ETF份额换取一篮子股票，会导致ETF总份额减少；溢价套利是投资者用一篮子股票换取ETF份额，会导致ETF总份额增加。

### 四、ETF联接基金

12. ETF联接基金绝大部分基金财产投资于某一ETF，密切跟踪标的指数表现，可以在场外申购或赎回。
13. ETF联接基金属于场外基金，并非场内基金。⭐
14. ETF联接基金为没有证券账户的场外投资者提供了投资目标ETF的便捷方式。
15. ETF联接基金可以提供定期定额投资、基金转换等投资方式。

## 第8节 合格境内机构投资者基金（3题）

1. QDII基金即合格境内机构投资者基金，可以用人民币、美元或其他主要外汇货币为计价货币募集。
2. 国际证券市场与国内证券市场通常具有较低的相关性；通过QDII基金进行国际投资，会降低投资组合的整体风险。
3. 被动指数型QDII基金的主要目标是复制特定市场指数的表现，而非超越所跟踪的市场指数，也不是投资国内市场指数或灵活调整组合以获取超额收益。

## 第9节 公开募集基础设施证券投资基金（4题）

1. 基础设施基金具有股债混合属性，其风险收益特征介于股票基金和债券基金之间。
2. 基础设施基金采取封闭式运作，不能自由申购与赎回，并在证券交易所上市交易。
3. 基础设施基金设有强制分红比例，收益分配比例不低于合并后基金年度可供分配金额的90%。
4. 产权类基础设施基金通过基础设施资产支持证券，穿透取得的是基础设施项目的完全所有权。

## 第10节 其他基金（3题）

1. 商品期货基金除中国证监会规定或准予注册的特殊基金品种外，持有所有商品期货合约的价值合计（买入、卖出轧差计算）不低于基金资产净值的90%，不高于基金资产净值的110%。
2. 商品基金的特点是：较直接投资商品现货或者期货合约门槛低且便捷；交易效率高；是大类资产配置的良好工具。商品基金主要投资于商品相关资产，并非主要投资于股票和债券。
3. MOM产品的特点包括：大类资产配置、精选子管理人、分散风险并提升收益、专业管理。

## 易混易错

**分类标准与比例（高频）**

1. 股票基金 = **60%以上**基金资产投资于股票；债券基金 = **80%以上**基金资产投资于债券；货币市场基金 = **仅**投资于货币市场工具；混合基金 = 资产配置比例**不符合**上述标准。易错点：把三个阈值互换，或把"仅投资货币市场工具"当作债券基金。
2. 题库口径提示：第1节第3题解析把"80%以上资产投资于股票"表述为股票基金特征，与第1节第4题解析"60%以上股票为股票基金"不一致；按证监会标准以**60%**为准，"80%"是债券基金与各类FOF（股票型FOF、商品期货FOF）的阈值。
3. **80%**这一比例在本章对应三处：债券基金（80%以上债券）、股票型FOF（80%以上股票型基金份额，含股票指数基金）、商品期货基金中基金（80%以上商品期货基金份额）。易错点：把FOF的80%套到股票基金上。

**分类维度对应关系（错位即错）**

4. 按**募集方式** = 公开募集基金 / 非公开募集基金；按**投资理念** = 主动型 / 被动型；按**运作方式** = 封闭式 / 开放式；按**投资对象** = 股票基金 / 债券基金等；按**资金来源和用途** = 在岸基金 / 离岸基金 / 国际基金。易错点：问"按募集方式"却答主动/被动、封闭/开放。
5. 主动型 = 力图**超越**基准组合表现；被动型 = 复制指数、试图**与指数表现一致**。易错点：把"超越基准"归给被动型或指数基金。
6. 在岸 / 离岸 / 国际三者的资金与投向易混：在岸 = 本国募集 + 投资本国；离岸 = 他国发售份额 + 投资本国或第三国；国际 = 资本来源于**国内** + 投资于**国外**市场。易错点：把"资金来源和运用都在国外"当作国际基金（那是离岸的特征）。

**商品基金相关**

7. 黄金ETF = 基金（商品基金）；商品期货基金 = 基金（商品基金）；**黄金期货 = 期货合约，不是基金**。易错点：把黄金期货选入商品基金。
8. 商品期货基金持有所有商品期货合约价值合计（买入、卖出**轧差**计算）= 不低于基金资产净值**90%**、不高于**110%**。易错点：与80%/100%、90%/100%混淆。
9. 商品基金特点 = 门槛低且便捷 + 交易效率高 + 大类资产配置良好工具；"主要投资于股票和债券"是干扰项。

**股票分类**

10. 价值型股票：模式成熟、增长稳定、股息丰厚，市盈率、市净率**较低**；成长型股票：收入增长快、潜力大，市盈率、市净率**较高**。易错点：把"价值股市盈率、市净率较高"当作正确表述。
11. 平衡型基金 = 同时投资价值型 + 成长型股票；混合型基金是更宽泛的概念；封闭式基金是按运作方式分类，与股票类型无关。
12. 按市值大小分类 = 大盘股 + 中盘股 + 小盘股；**蓝筹股**（长期稳定增长的大型传统工业股及金融股）不是按市值分类。易错点：把蓝筹股列入市值分类。
13. 股票基金的正确表述 = 风险较高、预期收益较高 + 追求长期资本增值 + 应对通胀有效手段；"适合短期波段操作、赚取买卖价差"是错误表述。投资时无需主要关注"短期净值波动"。

**债券基金内部细分**

14. 标准债券型基金（纯债）= **仅**固定收益类工具、**不投股票**；一级债基 = 可参与**一级市场**新股申购；二级债基 = 一级市场新股申购 + **二级市场买卖股票**；普通债券型基金 = 一级债基 + 二级债基（均含权益类投资）。
15. 题库口径提示：第3节第5题把"普通债券基金"直接对应为**二级债基**（题干描述含可投股票等权益类资产、可转换债券、可交换债券），而第3节第4题解析把普通债券型基金作为一级、二级债基的统称。判断时按题干描述的投资范围（是否可投权益类）选择。
16. 单一债券 vs 债券基金：到期日（有固定到期日 vs **无**固定到期日）、利率风险（随到期日临近**下降** vs 取决于所持债券**平均到期日**）、信用风险（**集中** vs **分散**、通常更低）。易错点：认为单一债券临近到期利率风险上升，或认为债券基金信用风险更高、无法分散风险。

**货币市场基金**

17. 不能投资 = 股票 + 可转换债券 + 信用等级在**AA+级以下**的债券；可投资 = 剩余期限在**397天以内（含397天）**的债券。易错点：把"397天以内债券"当作禁止投资品种，或把AA+级以下误记为可投资。
18. 特征三项正确项 = 每个交易日可申赎 + 红利再投资且每日分配 + 每日按面值（一般为1元）报价；"所有货币市场基金均提供T+0快速赎回"是错误项。
19. 场内货币基金 = 申赎型 + **交易型**；"单一型""普通型""创新型"为干扰项。
20. 交易所规则：上交所 = 场内申赎 + 场内T+0交易；深交所 = 场内T+0交易 + T+0申赎（深交所多了T+0申赎）。
21. 估值方法：固定净值型货币市场基金 → **摊余成本法**；市值法、成本法、净值法为干扰项。

**FOF与养老目标基金**

22. FOF特点 = 风险分散 + 资产优化 + 专业服务 + **降低**门槛；"提高门槛"是干扰项。
23. FOF分类按底层资产 = 股票型 + 债券型 + 混合型 + 货币型FOF。
24. 养老目标基金 = 初期主要采用FOF形式 + 成熟资产配置策略 + 设置封闭期或最短持有期限 + **可以设置优惠费率**；"禁止基金管理人设置优惠费率"是干扰项。
25. 养老目标基金分类 = **目标日期基金 + 目标风险基金**；"股票型养老基金""债券型养老基金"是从资产类别角度的一般划分，不是养老目标基金的独特分类。

**混合基金**

26. 波动性排序：股票基金 > **混合基金** > 债券基金 > 货币基金。易错点：把混合基金波动性写成大于股票基金，或低于债券基金、货币基金。
27. 灵活配置型基金 = 股票、债券配置比例**随市场环境调整**；"股票比例固定高于债券""债券比例固定高于股票""仅投资股票"均为干扰项。

**指数基金与ETF/LOF**

28. 按复制标的指数的方法 = **完全复制型 + 抽样复制型**；按投资标的 = 股票指数基金 + 债券指数基金；按投资市场 = 单市场 + 跨市场指数基金。易错点：把"标准指数型与指数增强型"当作按复制方法的分类。
29. ETF vs LOF 四项对比：申赎对价（一篮子证券或商品 vs **现金**）、申赎场所（ETF**只能**在交易所 vs LOF可场外）、规模限制（ETF**有**资金规模限制 vs LOF无特别限制）、净值报价（LOF**每日一次**）。易错点：把"资金规模限制"归给LOF。
30. ETF联接基金 = **场外**基金（"属于场内基金"是错误表述）；特征 = 绝大部分财产投资某一ETF + 为无证券账户的场外投资者提供途径 + 可定投与基金转换。
31. ETF套利方向：**折价**套利 = 用ETF份额换一篮子股票 → 总份额**减少**；**溢价**套利 = 用一篮子股票换ETF份额 → 总份额**增加**。易错点：把两者方向写反，或认为ETF不存在套利交易。

**QDII基金**

32. QDII计价货币 = 人民币 + 美元 + 其他主要外汇货币（不限于单一币种）。
33. 国际与国内证券市场相关性**较低** → 通过QDII国际投资会**降低**投资组合整体风险。易错点：把相关性记为较高、把结果记为提高风险。
34. 被动指数型QDII目标 = **复制**特定市场指数表现；"超越所跟踪的市场指数""投资国内市场指数""灵活调整组合获取超额收益"为干扰项（后者是主动型特征）。

**基础设施基金**

35. 基础设施基金 = 风险收益特征**介于股票基金和债券基金之间**（股债混合属性）；"高于股票基金""低于债券基金""等同于货币市场基金"为干扰项。
36. 基础设施基金 = **封闭式**运作（"开放式、可自由申购赎回"是干扰项）+ 在**证券交易所**上市交易 + 收益分配比例不低于合并后基金年度可供分配金额的**90%**（60%/70%/80%为干扰数字）。
37. 产权类基础设施基金通过基础设施资产支持证券穿透取得的是**完全所有权**；"部分所有权""经营权利""优先收益权"为干扰项。

**MOM与FOF辨析**

38. MOM = 委托**两个或者两个以上**符合条件的第三方资产管理机构就部分或全部资产提供**投资建议**（不是资金支持、托管服务、销售服务）；特点 = 大类资产配置 + 精选子管理人 + 分散风险提升收益 + 专业管理。
39. FOF = 以**其他证券投资基金**为投资对象，投资组合由其他基金组成。易错点：把FOF与分级基金、伞形基金、混合基金混淆。

**数字记忆点**

40. 非公开募集基金合格投资者累计上限 = **200人**（100人/300人/500人为干扰数字）；货币市场基金可投债券剩余期限 = **397天以内（含397天）**；基础设施基金分红比例 = **90%**；商品期货基金合约价值 = **90%—110%**；FOF/债券基金比例阈值 = **80%**；股票基金 = **60%**；货币市场基金报价面值 = 一般为**1元**。
