# 证券投资基金基础知识 · 第16章 基金的利润分配与税收

本章分两条线：一条是"利润来源—利润指标—分配规则"，核心是把利息收入、投资收益、其他收入三类边界分清楚，并记住封闭式基金"每年不少于一次、不低于90%、只能现金分红"和货币市场基金"每日分配、周五合并分配周末收益"；另一条是"基金税收"，核心是增值税、印花税、企业所得税三税的免征/暂免/单边征收规定与几个必须原样记住的数字（6%、千分之一、2008年9月19日）。

题量：16题（第1节 8题，第2节 8题）

## 第1节 基金利润及利润分配

1. 基金利润的来源主要有三类：**利息收入、投资收益、其他收入**。 ⭐
2. **佣金不属于基金利润来源**——佣金是基金交易时支付给券商等的费用，属于支出项，不是收入来源。 ⭐
3. **投资收益**包括三类：①买卖股票、债券、资产支持证券、基金等实现的**差价收益**；②因股票、基金投资等获得的**股利收益**；③**衍生工具投资**产生的相关损益。 ⭐
4. **利息收入**包括债券投资的利息收入和银行存款利息收入；**债券投资实现的利息收入属于利息收入，不属于投资收益**。 ⭐
5. **其他收入**包括赎回费扣除基本手续费后的余额。
6. 投资收益计算示例：投资债券利息收入12万元、银行存款利息8万元、买卖股票获利20万元、权证行权获利20万元、赎回费扣除基本手续费余额10万元时，**投资收益 = 买卖股票获利20万元 + 权证行权获利20万元 = 40万元**；其中债券利息12万元与银行存款利息8万元计入利息收入，赎回费余额10万元计入其他收入。
7. 与基金利润有关的财务指标主要有：**本期利润、本期已实现收益、期末可供分配利润**（期末可供分配利润包括已分配利润和未分配利润等情况）。
8. **"已分配利润"不是与基金利润有关的财务指标**——不能把已分配利润或未分配利润单独当作一项利润财务指标。
9. 基金进行利润分配后，**份额净值会相应下降，下降的数值就是每份分配的金额**：分配后份额净值 = 分配前份额净值 − 每份分配金额。
10. 计算示例：分配前份额净值1.62元，每份分配0.04元，则分配后份额净值 = 1.62 − 0.04 = **1.58元**。
11. **封闭式基金收益分配每年不得少于一次**。
12. **封闭式基金收益分配比例不得低于基金年度可供分配利润的90%**。
13. **封闭式基金只能采用现金方式分红**。
14. 封闭式基金收益分配**没有"不得高于基金年度可供分配利润的100%"这一规定**，该表述是错误的。
15. 对于**每日按照面值进行报价的货币市场基金，应当每日进行收益分配**。
16. 货币市场基金**每周五进行收益分配时，将同时分配周六和周日的收益**。
17. 货币市场基金**每周一至周四进行收益分配时，仅对当日收益进行分配**。
18. 投资者于**周五申购或转换转入**的货币市场基金份额，**不享有**周五、周六、周日的收益。
19. 投资者于**周五赎回或转换转出**的货币市场基金份额，**享有**周五、周六、周日的收益。

## 第2节 基金税收

20. **存款利息不征收增值税**。
21. 资管产品运营过程中发生的增值税应税行为，**以资管产品管理人为增值税纳税人**。
22. 证券投资基金开展**质押式买入返售业务**和**持有政策性金融债券**取得的金融同业往来利息收入**免征增值税**（不是计征增值税）。
23. **个人买卖基金份额的行为免征增值税**。
24. **2016年5月1日**起，全国范围内全面推开营业税改征增值税（营改增）试点，金融业纳入试点范围，由缴纳营业税改为缴纳增值税，**金融业增值税税率为6%**。
25. **机构投资者在境内买卖基金份额获得的差价收入，应并入企业的应纳税所得额，征收企业所得税**。
26. **个人投资者买卖基金份额暂免征收印花税**。 ⭐
27. **机构投资者买卖基金份额暂免征收印花税**——机构与个人买卖基金份额均暂免印花税。 ⭐
28. **自2008年9月19日起**，我国将证券（股票）交易印花税由对买卖、继承、赠与所书立的A股、B股股权转让书据按**千分之一**税率对**双方当事人**征收，调整为**单边（单向）征税**：对**出让方**按千分之一税率征收，对**受让方不再征税**。 ⭐
29. **自2008年9月19日起，基金卖出股票时征收印花税，买入股票时不征收印花税**。 ⭐
30. 对**香港市场投资者**通过基金互认买卖、继承、赠予**内地基金份额**，**暂不征收印花税**。 ⭐
31. 对**内地投资者**通过基金互认买卖、继承、赠予**香港基金份额**，**按照香港特别行政区现行印花税税法规定执行**，并非暂不征收印花税。 ⭐
32. 目前，我国对**证券投资基金从证券市场中取得的收入暂不征收企业所得税**。 ⭐

## 易混易错

**利润来源与三类收入的边界**

1. **佣金 vs 收入**：佣金是基金交易时支付给券商等的费用，属于支出，**不是基金利润来源**；利润来源只有利息收入、投资收益、其他收入三类。
2. **投资收益 vs 利息收入**：买卖股票/债券/资产支持证券/基金的差价收益、股利收益、衍生工具投资损益 → **投资收益**；债券投资利息收入、银行存款利息 → **利息收入**。把"债券投资而实现的利息收入"当作投资收益是错误项。
3. **其他收入**：赎回费扣除基本手续费后的余额 → **其他收入**，既不进投资收益也不进利息收入。
4. 投资收益计算题的陷阱：把**债券利息收入12万元、银行存款利息8万元**（利息收入）和**赎回费扣除基本手续费余额10万元**（其他收入）误加进投资收益，从而错选52万元或32万元；正确只加买卖股票获利20万元与权证行权获利20万元，得**40万元**。

**利润财务指标**

5. 与基金利润有关的指标：**本期利润、本期已实现收益、期末可供分配利润**；**"已分配利润"是干扰项**（它只是期末可供分配利润的组成部分，不是独立指标）。

**分配规则的三组易混点**

6. **封闭式基金分配三要件**：每年不得少于**一次**、比例不得低于年度可供分配利润的**90%**、**只能现金分红**；**"不得高于100%"是干扰项**（无此规定）。
7. **分配后净值**：下降额**等于每份分配金额**（1.62 − 0.04 = 1.58元），不是按比例下调，也不是只降一半。
8. **货币市场基金周五的两个方向（最易反）**：周五**申购或转换转入**的份额 → **不享有**周五、周六、周日收益；周五**赎回或转换转出**的份额 → **享有**周五、周六、周日收益。
9. **货币市场基金分配频率**：每日按面值报价的货币市场基金 → **每日**分配；周五分配时**合并分配周六、周日**收益；周一至周四**仅分配当日**收益。

**三税免征口径（增值税 / 印花税 / 企业所得税）**

10. **增值税"不征"与"免征"要分清**：**存款利息不征收**增值税；**质押式买入返售业务、持有政策性金融债券取得的金融同业往来利息收入免征**增值税（干扰项写成"计征增值税"）；**个人买卖基金份额免征**增值税。
11. **增值税纳税人主体**：资管产品运营过程中发生的增值税应税行为，**以资管产品管理人为纳税人**（不是基金本身、不是托管人、不是持有人）。
12. **金融业增值税税率6%**（营改增自**2016年5月1日**起全面推开）；2%、4%、8%均为干扰项。
13. **印花税单边征收的时间与方向**：**2008年9月19日**起单边征税，**出让方（卖出方）按千分之一征收，受让方（买入方）不征**；因此**基金卖出股票征收、买入股票不征收**。干扰日期有2007年6月5日、2008年6月5日、2009年9月19日。
14. **投资者买卖基金份额的印花税**：**机构与个人均暂免征收**；干扰项"减半""双倍""全额"。
15. **基金互认印花税的方向最易反**：**香港投资者**买卖/继承/赠予**内地基金份额** → **暂不征收**印花税；**内地投资者**买卖/继承/赠予**香港基金份额** → **按香港特区现行税法执行**（不是暂不征收）。
16. **企业所得税的两个口径**：**基金从证券市场中取得的收入暂不征收**企业所得税（干扰项"征收4%/5%/10%"）；**机构投资者买卖基金份额的差价收入并入企业应纳税所得额、征收企业所得税**。
17. **税种对应关系干扰项**：与"应纳税所得额"对应的是**所得税**；**印花税**针对合同、账簿等凭证；**消费税**针对特定消费品；**营业税**在营改增后已被增值税取代，均不对应应纳税所得额。
